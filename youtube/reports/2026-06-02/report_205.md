# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 16개의 키워드에 대한 현황 분석을 통해 채널의 콘텐츠 전략 방향성을 제시합니다. 현재 데이터 상 모든 키워드의 수치 메트릭(video_count, avg_views 등)이 수집되지 않은 상태이나, 키워드 구성을 통해 **정치·외교**, **경제·투자**, **첨단 기술**, **건강·라이프스타일**의 4대 축으로 콘텐츠가 집중되어 있음을 확인했습니다.

## 1. 데이터 현황 및 한계점
- **수집 상태**: 전체 키워드의 조회수, 영상 수, 경쟁도(nb_score)가 0으로 표기됨
- **분석 한계**: 정량적 경쟁 분석은 불가능하나, 키워드 텍스트 기반 정성적 분석 가능
- **권고사항**: 실제 검색량 및 경쟁 채널 데이터 연동 필요

## 2. 키워드 카테고리 분석

### A. 정치·외교 (25%)
- **한미 안보합의**, **선거 개표 방식**, **지역구 격전지 분석**
- 선거 시즌을 고려한 정치 뉴스 콘텐츠로, 시의성이 높은 단기 트래픽 키워드

### B. 경제·투자 (31%)
- **반도체 투자 전망**, **메모리 반도체 가격**, **증시 불장 분석**, **로보틱스 투자 동향**, **파산 면책 제도**
- 반도체(메모리, EUV)와 로보틱스는 기술 투자 테마로 고관여 시청자층 확보 가능
- **"증시 불장 분석"**과 **"파산 면책 제도"**는 대조적인 경제 주제로 서로 다른 타겟층 공략 가능

### C. 첨단 기술·과학 (19%)
- **AI 주도권 경쟁**, **EUV 도입 지원**, **탄소 수소 저장 기술**
- 산업 정책과 기술 동향의 교차점으로 전문성 있는 해설 콘텐츠 적합

### D. 건강·라이프스타일 (19%)
- **수면 시간 연구**, **요로결석 치료 후기**, **음주 문화 변화**
- **"요로결석 치료 후기"**는 개인 경험 기반 스토리텔링 콘텐츠로 감성적 접근 유효
- **"교황 AI 질문"**은 종교와 기술의 희귀한 조합으로 틈새 시장 공략 가능
