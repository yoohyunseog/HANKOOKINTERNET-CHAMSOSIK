# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 16개 키워드의 YouTube 검색 데이터를 분석하여 콘텐츠 전략 방향을 제시합니다. 분석 기간 내 수집된 키워드는 정치·외교, 경제·산업, 사회·문화 등 시사성 중심으로 구성되어 있으나, **대다수 키워드의 메타데이터 수집이 미완료**된 상태임을 확인했습니다.

## 2. 데이터 품질 현황

| 구분 | 키워드 수 | 특이사항 |
|------|----------|----------|
| **유효 데이터** | 1개 (6.25%) | "미 이란 협상 레바논"만 영상 1건, 3,606뷰 확인 |
| **미수집 데이터** | 15개 (93.75%) | video_count, avg_views, nb_score 전부 0값 |

**주요 이슈**: 데이터 수집 시스템의 오류 또는 API 제한으로 인해 실질적인 경쟁 분석이 불가능한 상태입니다. 단순 키워드 랭킹만 존재할 뿐, 검색량, 경쟁도, 조회수 분포 등 핵심 지표가 누락되어 있습니다.

## 3. 키워드 카테고리 분석

수집된 키워드들은 다음 4개 영역으로 분류됩니다:

- **정치·외교** (37.5%): 미 이란 협상 레바논, 지방선거 여야 격차, 한일 군사동맹 논란, 아프리카 외교 협력
- **경제·산업** (25%): AI 반도체 동맹, 엔비디아 한국 방문, 하이닉스 화재, 경제총조사
- **사회·복지** (18.75%): 발달장애인 참정권, 호주 노후 준비, 심장병 미세혈관 장애, 서대문형무소
- **기타** (18.75%): 오늘의 주요 뉴스, 캐시워크 정답, KBO 올스타 투표, 한화에어로스페이스 폭발

## 4. 유효 데이터 심층 분석

**"미 이란 협상 레바논"** (Rank 8)
- **영상**: 연합뉴스TV 보도 (3,606뷰)
- **특성**: 트럼프 전 대통령의 중동 외교 관련 속보
- **시사점**: 국제 정치 이슈에 대한 실시간 뉴스 수요가 존재하며, 특히 전직 고위 관련자의 발언이 즉각적인 트래픽으로 연결됨을 확인했습니다.

## 5. 결론 및 제언

### 즉각 조치 사항
1. **데이터 수집 시스템 점검**: 93% 키워드의 메타데이터 누락은 치명적입니다. API 연결 상태 및 수집 로직을 우선 점검하세요.
2. **모니터링 키워드 재설정**: 현재 "캐시워크 정답" 등 비일관적 키워드가 포함되어 있습니다. 채널 정체성에 맞는 코어 키워드로 필터링이 필요합니다.

### 콘텐츠 전략 방향
- **뉴스/시사 채널**로서 국제 외교(미-이란, 중동) 및 반도체 산업 동향 중심의 심층 보도에 집중할 것을 권장합니다.
- 단, 현재 데이터 신뢰도 하에선 **경쟁 강도(경쟁률) 분석 없이** 콘텐츠 기획이 어려우므로, 외부 트렌드 툴(Google Trends, Social Blade 등)을 병행 활용하시기 바랍니다.
