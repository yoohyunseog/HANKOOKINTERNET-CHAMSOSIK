# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 2024년 6월 기준 YouTube 검색 트렌드 상위 16개 키워드에 대한 채널 전략 분석을 목표로 합니다. **현재 수집된 데이터셋의 정량적 지표(nb_score, 조회수, 영상 수 등)가 미확보 상태**이므로, 키워드의 질적 특성과 주제별 분포를 중심으로 한 전략적 인사이트를 제공합니다.

## 2. 데이터 현황 및 한계점

**데이터 품질 진단:**
- 전체 키워드의 노출 지수(nb_score) 및 영상 메트릭스가 0으로 표기
- 조회수 분포(views) 및 영상 목록(videos) 미수집 상태
- **분석 한계:** 경쟁 강도, 콘텐츠 포화도, 평균 조회수 등 정량적 분석 불가

**권장 보완 방안:**
- YouTube Data API v3를 통한 실제 검색 결과 수집
- 경쟁 채널의 평균 조회수 및 업로드 주기 크롤링
- 검색량 추이(Google Trends 연동) 데이터 추가

## 3. 키워드 트렌드 매트릭스 분석

### 3.1 주제별 카테고리 분류

| 구분 | 키워드 | 특성 |
|------|--------|------|
| **정치/외교** | 지방선거 여야 격차, 한일 군사동맹 논란, 미 이란 협상 레바논, 아프리카 외교 협력, 발달장애인 참정권 | 시사성 높은 정치 콘텐츠 |
| **경제/산업** | AI 반도체 동맹, 엔비디아 한국 방문, 하이닉스 화재, 경제총조사, 한화에어로스페이스 폭발 | 반도체/방산 중심 산업 뉴스 |
| **사회/문화** | 오늘의 주요 뉴스, 서대문형무소, 호주 노후 준비, 심장병 미세혈관 장애 | 교육/역사/의료 정보성 콘텐츠 |
| **이벤트/앱** | 캐시워크 정답, KBO 올스타 투표 | 실시간 검색어 특화 키워드 |

### 3.2 전략적 인사이트

**① 뉴스 아그리게이션 기회**
- "오늘의 주요 뉴스 🔒" 키워드는 뉴스 큐레이션 채널의 구독 전략을 시사
- 잠금 이모지(🔒) 사용으로 프리미엄/구독자 전용 콘텐츠 가능성 암시

**② 실시간성 키워드 리스크**
- "캐시워크 정답", "KBO 올스타 투표"는 수명 주기가 짧은 트렌드 키워드
- Shorts 형식의 신속한 콘텐츠 제작 필요

**③ 산업 특화 콘텐츠 강세**
- 반도체(AI 반도체 동맹, 엔비디아, 하이닉스) 및 방산(한화에어로스페이스) 키워드 다수
- 전문가 포지셔닝을 통한 B2B/투자자 타겟 채널 구축 가능
