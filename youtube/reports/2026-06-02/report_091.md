# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 16개 키워드에 대한 YouTube 검색 데이터 분석 결과입니다. **데이터 품질상의 치명적 결함**이 확인되어 실제 성과 지표(조회수, 경쟁률 등) 분석은 불가능한 상태이며, 키워드 주제별 경향성 분석 및 데이터 수집 체계 개선 방안을 중심으로 분석을 진행합니다.

---

## 1. 데이터 품질 현황

| 구분 | 상태 | 비고 |
|------|------|------|
| 검색량(nb_score) | 0 (전체) | 데이터 미수집 |
| 동영상 수(video_count) | 0 (전체) | 인덱싱 오류 |
| 평균 조회수(avg_views) | 0 (전체) | 메트릭 누락 |
| 뷰/비디오 배열 | Empty | 원시 데이터 손실 |

**Critical Issue**: 모든 키워드의 정량적 지표가 '0'으로 표기되어 있어 알고리즘 노출 가능성, 경쟁 강도, 시청자 수요 등의 핵심 분석이 불가능합니다.

## 2. 키워드 카테고리 분석

현재 수집된 키워드는 **뉴스/시사 채널** 중심의 콘텐츠 전략을 암시합니다.

### 2.1 산업/테크 섹터 (37.5%)
- **하이닉스 화재**, **AI 반도체 동맹**, **엔비디아 한국 방문**, **한화에어로스페이스 폭발**
- 반도체·방산 업계의 이슈 중심으로, B2B 및 투자자 타겟팅 가능

### 2.2 정치/외교 섹터 (25%)
- **미 이란 협상 레바논**, **아프리카 외교 협력**, **한일 군사동맹 논란**, **지방선거 여야 격차**
- 지정학적 리스크와 선거 관련 시사성 높은 주제

### 2.3 사회/문화 섹터 (25%)
- **서대문형무소**, **발달장애인 참정권**, **호주 노후 준비**, **심장병 미세혈관 장애**
- 역사·복지·건강 정보로 4050 세대 타겟팅 적합

### 2.4 라이프/엔터테인먼트 (12.5%)
- **KBO 올스타 투표**, **캐시워크 정답**
- 실시간 검색어 트렌딩 키워드로 단기 조회수 상승 가능

## 3. 전략적 제안

### 3.1 데이터 인프라 개선 (Priority: High)
- **YouTube Data API v3** 연동 상태 점검 및 할당량 초과 여부 확인
- **nb_score** 산출 로직 검증 (검색량 데이터 소스 확인)
- 크롤링 봇 차단 여부 확인 및 헤더/프록시 설정 검토

### 3.2 콘텐츠 기획 방향
현재 키워드 구성상 **종합 뉴스 미디어** 또는 **경제 전문 채널**로의 포지셔닝이 유효합니다.

1. **시사 큐레이션**: "오늘의 주요 뉴스 🔒"를 메인으로 일일 브리핑 콘텐츠 기획
2. **심층 분석**: 반도체/방산 이슈(하이닉스, 한화에어로스페이스)에 대한 전문가 인터뷰
3. **실시성 활용**: KBO 투표, 캐시워크 정답 등 트렌딩 키워드의 Shorts 콘텐츠 제작

### 3.3 키워드 확장 권장
현재 데이터는 장기 검색어 위주로 보입니다. **급상승 검색어**(Trending Searches)와 **장기 검색어**(Evergreen Keywords)를 분리하여 수집할 것을 권장합니다.
