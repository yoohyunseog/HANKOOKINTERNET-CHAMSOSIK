# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 총 16개 키워드에 대한 채널 성과 데이터를 분석한 결과입니다. **현재 수집된 모든 메트릭(nb_score, 조회수, 영상 수)이 0으로 표기**되어 실제 콘텐츠 성과 분석이 불가능한 상태이나, 키워드 포트폴리오 구성을 통해 채널의 콘텐츠 전략 방향성을 도출할 수 있습니다.

## 2. 키워드 포트폴리오 분석

### 2.1 카테고리별 분포
수집된 키워드는 다음 5개 영역으로 분류됩니다:

| 카테고리 | 키워드 예시 | 비중 |
|---------|-----------|------|
| **정치·외교·안보** | 지방선거, 미이란협상, 한일군사동맹, 아프리카외교 | 25% |
| **경제·산업·기술** | AI반도체, 엔비디아방문, 하이닉스화재, 경제총조사 | 25% |
| **사회·복지** | 발달장애인참정권, 호주노후준비, 서대문형무소 | 19% |
| **스포츠·라이프** | KBO올스타, 캐시워크정답 | 13% |
| **의학·건강** | 심장병미세혈관 | 6% |

### 2.2 키워드 특성 인사이트
- **시의성 중심**: "오늘의 주요 뉴스", "엔비디아 한국 방문" 등 시기별 이슈 중심
- **이슈성 키워드 다수**: "하이닉스 화재", "한화에어로스페이스 폭발" 등 사고/논란 키워드 포함
- **정보형 vs 논란형 혼재**: 캐시워크 정답(실용정보)과 한일군사동맹 논란(정치이슈) 공존

## 3. 데이터 품질 검토 및 한계

**심각한 데이터 결함 발견**:
- 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 기록
- `views` 및 `videos` 배열 미수집 상태
- **분석 불가능 수준**으로, 실제 SEO 성과나 경쟁 강도 파악 불가

## 4. 전략적 제안

### 즉시 실행 필요 사항
1. **데이터 수집 시스템 점검**: YouTube Data API 연결 상태 및 크롤링 로직 확인
2. **키워드 정제**: "캐시워크 정답"과 같은 마이크로 키워드와 "AI 반도체 동맹" 같은 매크로 키워드의 우선순위 재설정 필요

### 콘텐츠 전략 방향
- **뉴스 채널 특화**: 정치(25%) + 경제(25%) 중심의 하이브리드 뉴스 포맷 강화
- **시의성 대응 체계**: "오늘의 주요 뉴스" 키워드를 중심으로 한 데일리 브리핑 콘텐츠 기획
- **이슈 복합 접근**: "엔비디아 방문"과 "AI 반도체 동맹"을 연계한 심층 분석 콘텐츠 기획

**결론**: 현재 데이터 품질상 정량적 분석은 불가능하나, 키워드 구성을 통해 시사·경제 복합 뉴스 채널로서의 정체성을 확인할 수 있습니다. 데이터 수집 시스템 정상화 후 재분석이 필수적입니다.
