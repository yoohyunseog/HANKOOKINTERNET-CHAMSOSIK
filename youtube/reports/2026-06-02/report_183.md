# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
본 분석은 총 16개 키워드에 대한 성과 지표를 검토한 결과, **모든 지표(nb_score, video_count, avg_views 등)가 0값을 기록**하고 있어 정량적 성과 분석은 불가능한 상태입니다. 이는 데이터 수집 초기 단계, API 연동 오류, 또는 비공개/실시간 데이터 미반영으로 추정됩니다. 따라서 본 리포트는 키워드 구성의 **질적 특성(Qualitative Analysis)**과 전략적 방향성에 중점을 두고 분석합니다.

## 2. 키워드 클러스터 분석

### 2.1 카테고리별 분포
수집된 키워드는 다음 5개 카테고리로 분류됩니다:

| 카테고리 | 키워드 예시 | 특성 |
|---------|------------|------|
| **시사/뉴스** | 오늘의 주요 뉴스, 경제총조사, 지방선거 | 실시간성, 생명주기 짧음 |
| **산업/사고** | 하이닉스 화재, 한화에어로스페이스 폭발, AI 반도체 동맹 | 이슈성, 검색 급증형 |
| **국제/외교** | 미 이란 협상, 아프리카 외교, 엔비디아 방문 | 고관여 키워드, 전문성 요구 |
| **사회/복지** | 발달장애인 참정권, 심장병 미세혈관 장애 | 사회적 가치, 저조회수/고참여 |
| **라이프/엔터** | 캐시워크 정답, KBO 올스타 투표 | 검색 트래픽 중심, 단기 집중 |

### 2.2 검색意圖 분석
- **정보형(Informational)**: 75% (뉴스, 사고, 정책 관련)
- **해결형(Navigational)**: 12.5% (캐시워크 정답)
- **엔터테인먼트**: 12.5% (KBO 투표)

## 3. 시사점 및 리스크 분석

### 3.1 채널 정체성 혼재 위험
현재 키워드 포트폴리오는 **반도체 산업**부터 **퀴즈 앱 정답**까지 지나치게 광범위합니다. 
- **문제점**: 알고리즘이 채널을 특정 카테고리로 분류하기 어려워 추천 노출 저하
- **권장**: 뉴스/시사 중심 또는 산업 분석 중심으로 niche(틈새) 축소 필요

### 3.2 시의성 콘텐츠의 생산성 한계
"오늘의 주요 뉴스", "캐시워크 정답" 등은 **단기 검색 급증 키워드**이나 경쟁이 치열하고 콘텐츠 수명이 24-48시간에 불과합니다. 지속적 트래픽 창출이 어려운 구조입니다.
