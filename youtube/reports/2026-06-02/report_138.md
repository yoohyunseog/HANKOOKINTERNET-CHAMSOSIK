# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 2024년 주요 검색 트렌드를 반영한 16개 키워드에 대한 채널 최적화 분석입니다. 현재 수집된 메트릭 데이터(조회수, 경쟁률, 영상 수)는 로딩 지연 상태이나, 키워드 구성을 통해 **시사/경제 중심 채널**의 콘텐츠 전략 수립이 가능합니다.

---

## 1. 데이터 현황 및 한계점

| 항목 | 상태 | 분석 |
|------|------|------|
| **NB Score** | 0 (전체) | 경쟁 밀도 데이터 수집 필요 |
| **Video Count** | 0 (전체) | 플랫폼 API 연동 지연 확인 |
| **Avg Views** | 0 (전체) | 실시간 트래픽 데이터 미반영 |

**※ 참고사항**: 현재 키워드별 수치 데이터가 초기화 상태입니다. 정확한 경쟁률 분석을 위해서는 24-48시간 내 데이터 리로딩이 필요합니다.

## 2. 키워드 트렌드 분석

### 2.1 카테고리별 분포
수집된 16개 키워드를 5개 영역으로 분류한 결과:

**A. 정치/사회 (31%)**
- `오늘의 주요 뉴스 🔒`, `지방선거 여야 격차`, `한일 군사동맹 논란`, `발달장애인 참정권`, `서대문형무소`
- **특징**: 락 아이콘(🔒) 포함 키워드는 구독자 전용 콘텐츠 가능성

**B. 경제/산업 (31%)**
- `경제총조사`, `하이닉스 화재`, `AI 반도체 동맹`, `엔비디아 한국 방문`, `한화에어로스페이스 폭발`
- **특징**: 반도체-방산 밸류체인 이슈 집중, 실시간 뉴스성 강함

**C. 국제/외교 (13%)**
- `미 이란 협상 레바논`, `아프리카 외교 협력`
- **특징**: 지정학적 리스크 관련 검색 수요

**D. 스포츠/라이프 (13%)**
- `KBO 올스타 투표`, `캐시워크 정답`
- **특징**: 퀴즈/이벤트형 콘텐츠, 단기 트래픽 유발

**E. 사회/복지 (12%)**
- `호주 노후 준비`, `심장병 미세혈관 장애`
- **특징**: 4050 세대 타겟 헬스케어/금융 콘텐츠

## 3. 시사점 및 전략 제언

### 3.1 우선 순위 키워드
**즉시 제작 권장**: `AI 반도체 동맹`, `엔비디아 한국 방문`
- 반도체 산업은 현재 검색 알고리즘 상 **고 CPC(클릭당 단가)** 키워드로, 조회수 대비 수익성 우수
- 관련 영상: 기술 브리핑 + 주식 분석 복합 포맷 추천

**단기 트래픽 확보**: `KBO 올스타 투표`, `캐시워크 정답`
