# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 총 16개 키워드에 대한 YouTube 검색 트렌드 분석을 수행하였으나, **수집된 메트릭스 데이터(video_count, avg_views 등)가 전무**하여 정량적 경쟁 분석은 불가능한 상태입니다. 다만 키워드 구성을 통해 유추할 수 있는 시장 흐름과 콘텐츠 기회 요소를 도출하였습니다.

---

## 2. 데이터 품질 진단

| 항목 | 상태 | 분석 |
|------|------|------|
| **nb_score** | 0 (전체) | 키워드 경쟁 강도 측정 불가 |
| **video_count** | 0 (전체) | 검색 결과 영상 수 집계 실패 |
| **avg_views** | 0 (전체) | 조회수 기반 수익성 분석 불가 |

**진단 결과**: API 연동 오류 또는 크롤링 차단으로 인해 실제 메트릭스가 수집되지 않은 것으로 판단됩니다. 현재 데이터는 **키워드 아이디어만 유효**한 상태입니다.

## 3. 키워드 카테고리 분석

수집된 키워드를 4개 영역으로 분류하면 다음과 같습니다:

### A. 경제·금융 (5개, 31%)
- 경제총조사, 네이버 주가, 자본시장 규제 개선, 트럼프 경제 정책, 기업 지배구조 개선
- **특징**: 거시 경제와 기업 밸류에이션 관심이 높은 투자자층 타겟팅 가능

### B. 기업·산업 (4개, 25%)
- 하이닉스 화재, AI 반도체 경쟁, 삼성전자 직원 복지, 로보틱스 기술 발전
- **특징**: 반도체·AI 산업 클러스터 형성, B2B 및 취업 준비생 수요 예상

### C. 사회·이슈 (4개, 25%)
- 오늘의 주요 뉴스, 서대문형무소 역사, 한국 아프리카 협력, 호주 노후 준비
- **특징**: 시의성(時宜性)이 강한 뉴스성 콘텐츠, Shorts 알고리즘 노출 유리

### D. 생활·소비 (3개, 19%)
- 캐시워크 정답, 스타벅스 카드 혜택, KBO 올스타 투표
- **특징**: 실용적 정보 탐색 목적의 고전환율 키워드군

## 4. 시사점 및 전략 제안

### 🔴 긴급 조치 필요
**데이터 재수집**: 현재 0값 메트릭스로는 경쟁 분석이 불가능하므로, YouTube Data API v3 또는 서드파티 툴(예: VidIQ, TubeBuddy)을 통해 **실제 검색량 및 경쟁 채널 수를 재확인**해야 합니다.

### 🟡 기회 키워드 (Low Competition 예상)
메트릭스가 없는 키워드 중에서도 다음은 블루오션 가능성이 있습니다:
1. **"경제총조사"** - 공식 통계청 자료 해설 콘텐츠 부재
2. **"한국 아프리카 협력"** - 외교 분야 틈새 마켓
3. **"서대문형무소 역사"** - 교육 콘텐츠와 여행 콘텐츠의 결합 가능

### 🟢 콘텐츠 시너지 전략
- **"AI 반도체 경쟁" + "하이닉스 화재"**: 반도체 산업 리스크&기회 분석 시리즈 기획
- **"캐시워크 정답" + "스타벅스 카드 혜택"**: 생활 경제 정보 통합 채널 포지셔닝
