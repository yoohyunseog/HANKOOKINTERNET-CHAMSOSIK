**YouTube 채널 키워드 분석 리포트**

## 1. Executive Summary

본 보고서는 총 16개의 키워드에 대한 트렌드 분석을 수행하였으나, **수집된 메트릭스 데이터(조회수, 영상 수, NB Score 등)가 모두 0값으로 기록**되어 정량적 성과 분석은 불가능한 상태입니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 방향성과 잠재적 기회 영역을 도출할 수 있습니다.

## 2. 키워드 카테고리 분석

현재 수집된 키워드는 **5개의 주요 영역**로 분류됩니다:

| 카테고리 | 키워드 예시 | 비중 |
|---------|-----------|------|
| **시사/사고** | 하이닉스 화재, 한화에어로스페이스 폭발, 미국 이란 갈등 | 37.5% |
| **경제/금융** | 네이버 주가, 글로벌 일자리, 부동산 탈세 | 18.8% |
| **사회/생활** | 캐시워크 정답, 스타벅스 환불, 일본 공무원 연봉 | 18.8% |
| **스포츠/문화** | KBO 올스타, 서대문형무소 역사 | 12.5% |
| **건강/의료** | 심장병 미세혈관 관리 | 6.3% |

**주요 특징**: **실시간 이슈 중심의 뉴스 키워드**가 전체의 40%에 달하며, 이는 뉴스 큐레이션 채널 또는 시사 정보 채널의 성격을 반영합니다.

## 3. 전략적 시사점

### 3.1 콘텐츠 다각화 필요성
현재 키워드가 산업사고(하이닉스, 한화), 외교(아프리카, 이란), 경제(주가, 일자리) 등 **지나치게 광범위한 영역**에 분포되어 있습니다. 채널 정체성을 명확히 하기 위해서는 2-3개의 핵심 테마로 축소가 필요합니다.

### 3.2 검색 최적화 기회
- **"캐시워크 정답"**, **"스타벅스 카드 환불"** 등의 키워드는 **정보형 검색 의도**가 명확하여 단기 조회수 상승 효과가 기대됩니다.
- **"오늘의 주요 뉴스 🔒"**는 뉴스레터형 콘텐츠로, 구독자 유지율(Retention) 향상에 기여할 수 있습니다.

### 3.3 데이터 수집 개선 방안
현재 모든 메트릭스가 0으로 표기된 점은 다음과 같은 문제를 시사합니다:
- YouTube Data API 할당량 초과
- 키워드 검색 결과 필터링 미적용
- 데이터 수집 시점의 검색량 부재

**즉각적인 조치**: 향후 7일간의 검색 트렌드 데이터를 수집하여 경쟁 강도(Competition Rate)와 검색량(Search Volume)을 재측정할 것을 권장합니다.
