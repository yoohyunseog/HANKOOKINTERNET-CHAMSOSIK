# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 16개 키워드에 대한 채널 성과 데이터를 분석한 결과입니다. 현재 수집된 데이터는 초기 단계로 보이며, 실제 성과 지표(조회수, 영상 수, 경쟁 점수 등)가 미측정 상태입니다. 따라서 본 분석은 키워드 구성과 주제별 특성을 중심으로 한 정성적 분석에 중점을 두었습니다.

## 2. 데이터 품질 현황
- **수집 상태**: 모든 키워드의 `nb_score`, `video_count`, `avg_views`가 0으로 표기
- **분석 한계**: 경쟁 강도 및 시청량 예측 불가
- **필요 조치**: YouTube Data API 연동 및 실제 검색량 데이터 수집 필요

## 3. 키워드 카테고리 분석

### 3.1 시사/정치 (37.5%)
- 오늘의 주요 뉴스, 경제총조사, 지방선거 여야 격차, 한일 군사동맹 논란, 미 이란 협상 레바논, 아프리카 외교 협력
- **특징**: 국내외 정치 외교 이슈 중심, 검색 시의성 높음

### 3.2 기업/경제 (25%)
- 하이닉스 화재, AI 반도체 동맹, 엔비디아 한국 방문, 한화에어로스페이스 폭발
- **특징**: 반도체/방산 업계 이슈 중심, 투자자 및 산업 종사자 타겟 유효

### 3.3 사회/문화/복지 (25%)
- 서대문형무소, 발달장애인 참정권, 호주 노후 준비, 심장병 미세혈관 장애
- **특징**: 사회적 가치 및 교육 콘텐츠 적합

### 3.4 기타 (12.5%)
- KBO 올스타 투표(스포츠), 캐시워크 정답(앱/게임)

## 4. 전략적 제언

**즉각 실행 과제**:
1. **데이터 수집 인프라 구축**: 실제 검색량 및 경쟁 채널 분석 필요
2. **시사 키워드 우선순위 설정**: "오늘의 주요 뉴스" 등 검색량 급증 키워드 중심 콘텐츠 제작
3. **니치 전략**: "발달장애인 참정권", "심장병 미세혈관 장애" 등 저경쟁 사회 이슈 키워드 선점

**장기 전략**:
- 반도체/방산 산업 이슈를 연결한 심층 분석 콘텐츠 기획
- 정치 외교 키워드와 기업 이슈의 연관성 분석을 통한 차별화

## 5. 결론
현재 키워드 포트폴리오는 시사/경제 중심의 뉴스 채널로 적합한 구성을 보이나, 실제 성과 데이터 부재로 인해 구체적 ROI 산정이 불가능합니다. 우선적으로 데이터 수집 체계를 마련하고, 시의성 높은 키워드 중심의 신속한 콘텐츠 제작을 권장합니다.
