# YouTube 채널 키워드 분석 리포트

## 1. 데이터 수집 현황 및 품질 분석

본 분석 대상 16개 키워드 중 **15개(93.75%)**에 대한 실제 영상 데이터가 수집되지 않았습니다. `video_count`, `avg_views`, `nb_score` 등 핵심 지표가 모두 0으로 표기되어 있어, 실제 콘텐츠 성과 분석이 불가능한 상태입니다.

유일하게 데이터가 확인된 키워드는 **"미 이란 협상 레바논"**(8위)로, 연합뉴스TV의 보도 영상 1건(3,636뷰)이 수집되었습니다. 이는 데이터 수집 시점의 실시간성 문제 또는 API 제한으로 인한 샘플링 오류로 추정됩니다.

## 2. 키워드 카테고리 분류

수집된 키워드는 다음 6개 카테고리로 분류됩니다:

| 카테고리 | 키워드 | 특징 |
|---------|--------|------|
| **정치/외교** | 미 이란 협상 레바논, 지방선거 여야 격차, 한일 군사동맹 논란, 아프리카 외교 협력 | 국제정세 및 국내 정치 이슈 |
| **경제/산업** | 경제총조사, 하이닉스 화재, AI 반도체 동맹, 엔비디아 한국 방문, 한화에어로스페이스 폭발 | 반도체/방산 중심 산업 뉴스 |
| **사회/문화** | 캐시워크 정답, 서대문형무소, 호주 노후 준비, 발달장애인 참정권 | 생활정보 및 사회 이슈 |
| **스포츠** | KBO 올스타 투표 | 시즌별 이벤트성 키워드 |
| **의료/건강** | 심장병 미세혈관 장애 | 전문 의학 정보 |
| **뉴스** | 오늘의 주요 뉴스 🔒 | 뉴스 큐레이션 |

## 3. 유효 데이터 상세 분석

**"미 이란 협상 레바논"** 키워드는 트럼프 전 대통령의 중동 정책 및 이스라엘-헤즈볼라 교전 관련 속보 영상으로, 3,636회 조회를 기록했습니다. 자막 분석 결과 고농축 우라늄 처리 방안을 둘러싼 미국의 강경 입장과 군사적 압박 메시지가 핵심 쟁점으로 나타났습니다.

해당 영상은 뉴스 속보 형태로 긴급성이 높은 콘텐츠 특성을 보이며, 정치/외교 분야 키워드가 단기간 집중 조회를 유발할 수 있음을 시사합니다.

## 4. 전략적 제안

### 데이터 인프라 개선
- 현재 93% 이상의 키워드가 데이터 미수집 상태이므로, 수집 주기 및 API 설정 점검이 시급합니다.
- `nb_score`(경쟁 강도) 및 `video_count`(콘텐츠량) 지표가 0인 것은 해당 키워드의 시장성 및 경쟁 분석이 불가함을 의미합니다.

### 콘텐츠 기회 요소
- **반도체/방산 클러스터**: 하이닉스, 엔비디아, 한화에어로스페이스 등 연관 키워드가 다수 포진하여 해당 분야 전문 채널로의 포지셔닝 가능성이 있습니다.
- **실시간 뉴스**: "오늘의 주요 뉴스" 등 큐레이션 키워드가 상위권에 위치하여, 신속한 뉴스 요약 콘텐츠의 수요가 존재함을 확인할 수 있습니다.

**결론**: 현재 데이터의 신뢰성이 낮아 구체적인 경쟁 전략 수립은 어려우나, 반도체·방산·국제정세 분야의 뉴스 콘텐츠가 주요 트래픽 원천임을 간접적으로 확인할 수 있습니다. 데이터 수집 시스템 보완 후 재분석을 권장합니다.
