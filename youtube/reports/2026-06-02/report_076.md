# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 보고서는 총 16개의 트렌딩 키워드에 대한 분석을 수행하였으나, **모든 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표기**되어 정량적 분석이 불가능한 상태입니다. 이는 데이터 수집 초기 단계 또는 API 연동 오류를 시사하며, 현재로서는 키워드의 주제적 특성과 카테고리 분류를 통한 정성적 분석만 가능합니다.

## 1. 데이터 품질 진단

| 항목 | 상태 | 분석 |
|------|------|------|
| **NB Score** | 0 (전체) | 경쟁 강도 측정 불가 |
| **Video Count** | 0 (전체) | 콘텐츠 공급량 파악 불가 |
| **Avg Views** | 0 (전체) | 수요 규모 측정 불가 |
| **Views/Videos** | Empty Array | 세부 데이터 누락 |

**결론**: 현재 데이터는 실제 검색량 및 경쟁 분석에 활용할 수 없으며, 키워드 리스트업 단계로 보입니다.

## 2. 키워드 카테고리 분류

수집된 키워드는 다음 6개 카테고리로 분류됩니다:

### 📰 시사/뉴스 (5개)
- 오늘의 주요 뉴스 🔒
- 미 이란 협상 레바논  
- 지방선거 여야 격차
- 한일 군사동맹 논란
- 아프리카 외교 협력

### 💼 경제/산업 (4개)
- 경제총조사
- AI 반도체 동맹
- 엔비디아 한국 방문
- 하이닉스 화재

### ⚠️ 사고/이슈 (2개)
- 하이닉스 화재
- 한화에어로스페이스 폭발

### 🏥 사회/복지/의료 (3개)
- 호주 노후 준비
- 심장병 미세혈관 장애
- 발달장애인 참정권

### 🎮 라이프/기타 (2개)
- 캐시워크 정답 (앱/게임)
- KBO 올스타 투표 (스포츠)
- 서대문형무소 (역사/문화)

## 3. 시사점 및 전략 제안

### 🔴 긴급 조치 필요사항
1. **데이터 재수집**: YouTube Data API v3 또는 외부 분석 툴(예: VidIQ, TubeBuddy)을 통해 실제 검색량 및 경쟁률 데이터 확보 필요
2. **락(🔒) 표기 키워드 주의**: "오늘의 주요 뉴스"의 🔒 표기는 유료 콘텐츠 또는 접근 제한을 의미할 수 있음

### 📊 콘텐츠 전략 (데이터 수집 후)
- **즉시성 우선**: "하이닉스 화재", "엔비디아 한국 방문" 등 시의성 있는 키워드는 24-48시간 내 발행 필요
- **틈새 키워드**: "발달장애인 참정권", "심장병 미세혈관 장애" 등 저경쟁 사회 이슈는 롱테일 트래픽 확보 가능
- **지역 연계**: "서대문형무소"는 역사 교육 콘텐츠와 결합 시 시너지 예상
