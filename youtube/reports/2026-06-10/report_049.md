# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 분석은 총 16개의 핵심 키워드를 대상으로 진행되었으나, **현재 데이터 수집 시점에서 정량적 지표(nb_score, 조회수, 영상 수 등)가 미산출**된 상태입니다. 이는 실시간 트렌드 반영 지연, 데이터 수집 권한 제한, 또는 초기 크롤링 단계의 특성으로 판단됩니다. 본 리포트는 키워드 구성 패턴을 중심으로 한 정성적 분석과 향후 데이터 확보 전략을 제시합니다.

## 2. 키워드 카테고리 분석

현재 수집된 키워드는 다음과 같이 4대 영역으로 분류됩니다:

| 카테고리 | 키워드 수 | 비율 | 주요 키워드 |
|---------|---------|------|------------|
| **정치/사회 뉴스** | 8개 | 50% | 트럼프 최신 뉴스, 투표용지 사태, 재선거 논란, EU 정상회담 |
| **경제/투자** | 5개 | 31% | 나스닥 지수, 코스피 야간선물, 반도체 전망, 배당주 전략 |
| **기술/게임** | 2개 | 13% | AI 기술 도입, 오버워치 트렌드 |
| **산업/노동** | 1개 | 6% | 레미콘 노조 휴업 |

### 2.1 콘텐츠 특성 분석
- **시사성**: "오늘의 주요 뉴스 🔒"를 포함한 8개 키워드가 현재 진행형 사건 중심
- **투자 심리**: 나스닥, 코스피, 암호화폐, 배당주 등 **개인 투자자 관심사**에 초점
- **지정학적 리스크**: 이스라엘-헤즈볼라, 필리핀 사건 등 국제 안보 이슈 포함

## 3. 데이터 품질 진단 및 한계

### 주요 이슈
- **Zero-value 현상**: 모든 키워드의 `video_count`, `avg_views`가 0으로 표기
- **락 아이콘(🔒) 표기**: 1위 키워드의 잠금 표시는 유료 구독 콘텐츠 또는 접근 제한 데이터를 시사
- **배열 미반영**: `views`, `videos` 배열이 비어있어 세부 분석 불가

### 원인 추정
1. YouTube Data API 할당량 초과
2. 실시간 검색 트렌드 데이터의 지연 반영
3. 채널별 비공개 설정으로 인한 메타데이터 접근 제한

## 4. 전략적 제안

### 단기 조치 (즉시 실행)
- **데이터 소스 검증**: API 키 상태 및 할당량 확인
- **수동 샘플링**: 상위 3개 키워드("오늘의 주요 뉴스", "오버워치 게임 트렌드", "트럼프 최신 뉴스")에 대해 수동 검색을 통한 기준 데이터 확보
- **캐싱 전략**: 동일 키워드 재수집 시 이전 데이터 대조 및 누적 추이 분석

### 중장기 전략
- **카테고리별 콘텐츠 밸런스 조정**: 정치/사회(50%) 비중이 과도하게 높아 경제/기술 콘텐츠 다각화 필요
- **시즈널리티 분석**: "재선거", "투표용지" 등 선거 관련 키워드의 시의성을 고려한 단기 집중 전략 수립
- **경쟁 강도 분석**: 데이터 확보 후 `nb_score` 기반 블루오션 키워드 선별 (현재 0점으로 경쟁 심화 여부 불명)
