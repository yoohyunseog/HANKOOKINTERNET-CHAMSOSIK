**YouTube 채널 키워드 분석 리포트**

## Executive Summary

본 리포트는 총 16개 키워드에 대한 채널 분석 데이터를 바탕으로 작성되었습니다. 현재 제공된 데이터는 **모든 성과 지표(nb_score, 조회수, 영상 수 등)가 0으로 표기**되어 실제 성과 측정이 불가능한 상태입니다. 따라서 본 분석은 키워드 포트폴리오의 구성 특성과 주제별 분포를 중심으로 전략적 방향성을 제시합니다.

## 1. 데이터 품질 현황

| 구분 | 상태 | 분석 |
|------|------|------|
| **수집 완료** | ⚠️ 미완료 | 모든 키워드의 video_count, avg_views가 0으로 표기 |
| **데이터 신뢰성** | 🔴 낮음 | views/videos 배열 Empty 상태로 인해 경쟁 분석 불가 |
| **즉시 조치 필요** | ✅ 필수 | API 연결 상태 확인 및 데이터 재수집 필요 |

## 2. 키워드 포트폴리오 분석

현재 채널이 타겟팅한 키워드는 **5대 카테고리**로 분류됩니다:

### A. 정치/사회 이슈 (25%)
- `지방선거 투표용지 부족`, `재보축 축하메시지 논란`, `임대주택 청년 혜택`
- **특징**: 선거법 및 주거 정책 관련 시의성 높은 키워드

### B. 국제/안보 (19%)
- `이란 미군 헬기 공격`, `종전 협상 전망`, `베트남 항공 최신 소식`
- **특징**: 지정학적 리스크와 외교 관련 뉴스성 콘텐츠

### C. 기술/투자 (25%)
- `AI 반도체 국산화`, `스페이스X 상장 일정`, `코인베이스 주가 전망`, `엔비디아 AI 대체재`
- **특징**: 반도체, 우주산업, 암호화폐 등 첨단 산업 집중

### D. 환경/공공보건 (19%)
- `플라스틱 사용 줄이기`, `여름 오존 주의보`, `국제 무건 건강 불평등`
- **특징**: ESG 및 공중보건 관련 지속가능성 키워드

### E. 부동산/도시계획 (6%)
- `공원 도시 녹지 수익`
- **특징**: 도시 재생 및 녹색 인프라 관련 틈새 주제

## 3. 전략적 제언

### 즉시 실행 과제
1. **데이터 수집 시스템 점검**: YouTube Data API v3 연결 상태 및 할당량 확인
2. **키워드 정제**: `재보축`(재보궐선거 오타 추정), `무건`(의미 불명확) 등 키워드 정확성 검증
3. **검색意圖 분석**: `오늘의 주요 뉴스 🔒`와 같은 메타 키워드는 실제 검색량 대비 채널 경쟁력이 낮을 수 있음
