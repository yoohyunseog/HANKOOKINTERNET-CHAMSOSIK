# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 총 16개 키워드에 대한 검색 트렌드 데이터를 대상으로 진행되었으나, **모든 지표(video_count, avg_views, nb_score 등)가 미수집 상태(0값)**인 것으로 확인되었습니다. 따라서 본 리포트는 정량적 성과 분석 대신, 키워드 포트폴리오의 주제별 특성과 컨텐츠 전략적 방향성을 중심으로 분석합니다.

## 1. 키워드 트렌드 분석

### 1.1 주요 카테고리 분포
수집된 키워드는 다음 4개 카테고리로 분류됩니다:

| 카테고리 | 키워드 예시 | 비중 |
|---------|-----------|------|
| **지정학/안보** | 트럼프 이란, 아파치 격추 | 37.5% (6개) |
| **경제/금융** | 나스닥 하락 반도체주, 철강 관세 | 31.3% (5개) |
| **정책/무역** | 관세 폭탄, EU 철강 관세 | 18.7% (3개) |
| **일반 정보** | 오늘의 주요 뉴스, 서울특별시 날씨 | 12.5% (2개) |

### 1.2 핵심 이슈 클러스터링
- **트럼프-이란 갈등**: "트럼프 이란"을 중심으로 한 변형 키워드(2~5위, 16위)가 다수 포진하여, 해당 이슈에 대한 세분화된 검색 수요가 존재함을 시사
- **관세 정책 영향**: 철강 관세, 반도체주 급락 등 미국의 보호무역 정책이 금융시장 및 산업에 미치는 영향에 대한 관심 집중

## 2. 데이터 품질 진단 및 한계

### Critical Issue: 데이터 미수집 상태
- **모든 키워드의 성과 지표가 0값**으로 표기되어 있어, 실제 검색량, 경쟁 강도, 평균 조회수 등의 정량적 분석이 불가능한 상태입니다.
- **원인 추정**: 
  1) 데이터 수집 API 연동 오류
  2) 검색 기간 설정 미스 (최근 24시간 등 단기간 설정 시 신규 콘텐츠 부재)
  3) 키워드 정확도 문제 (장문 키워드 "트럼프 이란이 아파치" 등의 자연 검색량 부족)

## 3. 전략적 제안

### 3.1 Short-term Action
- **데이터 재수집**: YouTube Data API v3 또는 외부 분석 툴(Tubular Labs, Social Blade 등)을 활용하여 실제 검색량 및 경쟁 지표 확보 필요
- **키워드 정제**: "트럼프 이란이", "트럼프 이란에" 등 조사 변형 키워드는 검색意圖가 중복될 가능성이 높아, 핵심 키워드("트럼프 이란") 중심으로 클러스터링 권장

### 3.2 Content Strategy
현재 키워드들이 모두 **시의성이 높은 뉴스 키워드**임을 고려할 때:
- **Speed to Market**: "오늘의 주요 뉴스" 키워드(1위)를 활용한 일일 뉴스 큐레이션 콘텐츠 기획
- **심층 분석 콘텐츠**: 단순 속보가 아닌 "관세 폭탄이 반도체주에 미치는 영향"과 같은 연결고리 분석 콘텐츠로 차별화

## 4. 결론
본 데이터는 현재 수집 단계의 문제로 인해 정량적 분석이 불가능한 상태입니다. 데이터 정합성 확보 후 재분석이 필수적이며, 현재로서는 **지정학 리스크(트럼프-이란)와 무역 정책(관세)**에 대한 시청자 관심이 높다는 정성적 인사이트만 확인 가능합니다.

**즉시 조치사항**: 데이터 수집 시스템 점검 및 7일간의 시계열 데이터 확보를 권장합니다.
