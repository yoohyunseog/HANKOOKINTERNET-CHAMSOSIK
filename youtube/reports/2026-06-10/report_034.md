# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드에 대한 YouTube 검색 트렌드 분석 결과를 제시합니다. 현재 데이터 수집 단계에서 실제 조회수 및 영상 수치가 확인되지 않아 정량적 분석은 제한적이나, 키워드 구성을 통한 질적 인사이트와 향후 데이터 수집 완료 시 예상되는 분석 방향을 제시합니다.

## 1. 데이터 현황 분석

**수집 상태**: 현재 모든 키워드의 NB Score, 조회수(views), 영상 수(video_count)가 0으로 표기되어 있어 데이터 수집이 완료되지 않았거나 API 연동에 지연이 발생한 것으로 판단됩니다.

**키워드 분포**: 총 16개 키워드는 다음과 같이 카테고리별로 분류됩니다.

| 카테고리 | 키워드 수 | 주요 키워드 |
|---------|---------|------------|
| **정치/사회** | 7개 | 트럼프 최신 뉴스, 국회 민생입법, 투표용지 사태, 송파구 부정선거 시위 |
| **경제/금융** | 6개 | 나스닥 지수, 코스피 야간선물, 비트코인, 반도체 산업 |
| **게임/엔터** | 1개 | 오버워치 게임 트렌드 |
| **기타** | 2개 | 롯데백화점 할인, 우크라이나 에너지난 |

## 2. 키워드 특성 분석

### 2.1 시의성 중심 키워드
- **"오늘의 주요 뉴스"**, **"트럼프 최신 뉴스"** 등은 실시간성이 높은 뉴스 키워드로, 단기 조회수 급등 가능성이 높으나 지속성은 낮을 것으로 예상됩니다.

### 2.2 투자/경제 정보 키워드
- **"나스닥 지수 동향"**, **"코스피 야간선물"**, **"주식 ETF 투자 전략"**은 투자자 세그먼트를 타겟으로 하며, 주중(월-금) 조회수 집중 패턴을 보일 가능성이 높습니다.

### 2.3 정치적 민감도
- **"송파구 부정선거 시위"**, **"투표용지 사태 진상규명"** 등은 정치적 성향이 명확한 키워드로, 노출 알고리즘에서 제한적일 수 있으나 특정 성향 시청자의 높은 참여율(댓글, 공유)을 기대할 수 있습니다.

## 3. 전략적 제언

### 단기 전략 (데이터 수집 완료 시까지)
1. **우선순위 설정**: 경제/투자 키워드(나스닥, 코스피, 비트코인)가 안정적인 장기 트래픽을 제공할 것으로 예상되어 우선 모니터링 대상으로 선정
2. **시의성 키워드 선제 대응**: 뉴스 키워드는 24-48시간 내 콘텐츠 제작이 필요하므로 알림 시스템 구축

### 중장기 전략
- **니치 마켓 공략**: "오버워치 게임 트렌드"는 경쟁이 덜한 게임 세그먼트로, 특정 게임 커뮤니티 타겟팅 가능
- **지역 백화점 키워드**: "롯데백화점 인천점 할인"은 로컬 SEO 전략 적용 시 지역 기반 채널 성장에 유효

## 4. 결론
현재 데이터 미수집 상태로 인해 구체적인 경쟁 강도(NB Score) 및 예상 조회수 산정은 불가능합니다. 데이터 정상화 후 재분석을 권장하며, 특히 정치/사회 키워드(7개, 43.8%)와 경제 키워드(6개, 37.5%)가 주를 이루는 만큼, 현 시점 채널의 콘텐츠 방향성이 시사/경제 중심임을 확인할 수 있습니다.
