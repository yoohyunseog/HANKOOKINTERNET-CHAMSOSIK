# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 총 14개 키워드에 대한 YouTube 검색 성과 데이터를 대상으로 진행되었으나, **모든 지표(nb_score, 조회수, 영상 수 등)가 0으로 수집**되어 유효한 성과 분석이 불가능한 상태입니다. 데이터 품질 이슈 또는 API 수집 제한으로 판단되며, 키워드별 콘텐츠 전략 수립을 위해서는 데이터 재수집이 필수적입니다.

---

## 1. 데이터 현황 및 품질 분석

### 1.1 수집 데이터 현황
| 구분 | 상태 | 비고 |
|------|------|------|
| **검색 키워드** | 14개 | 정치/사회(7개), 경제/생활(4개), 트렌드(3개) |
| **nb_score** | 0 (전체) | 노출 경쟁력 지표 미측정 |
| **영상 수(video_count)** | 0 (전체) | 검색 결과 미반영 |
| **평균 조회수(avg_views)** | 0 (전체) | 성과 데이터 부재 |
| **접근 제한** | 🔒 표기 존재 | "오늘의 주요 뉴스" 키워드 접근 제한 가능성 |

### 1.2 데이터 품질 이슈 원인 분석
- **API 수집 오류**: YouTube Data API 할당량 초과 또는 키워드 필터링 로직 오류
- **접근 제한 콘텐츠**: 🔒 표기로 보아 뉴스 콘텐츠의 저작권/지역 제한으로 인한 데이터 차단
- **Long-tail 키워드 특성**: "동일 득표 논란", "투표용지 부족" 등 시의성 키워드의 검색 결과 부재

## 2. 키워드 카테고리 분석 (의미적 분류)

현재 수집된 키워드는 다음 3개 카테고리로 분류됩니다:

### A. 정치/사회 이슈 (50%, 7개)
- 부정선거 시위, 투표용지 부족, 지방선거 재실시, 동일 득표 논란
- 국정조사 특검, 민생 개혁 입법, 러시아 미국 외교
- **특징**: 선거/정치 사건 중심의 시의성 키워드, 검색량 급등/급감 패턴 예상

### B. 경제/생활 인프라 (29%, 4개)
- 롯데백화점 인천점, 한국경제TV 소상공인, 행복주택 입주민
- **특징**: 지역/업종 특화 키워드, 타겟팅 광고 적합성 높음

### C. 라이프스타일 트렌드 (21%, 3개)
- 비알코올 음식 트렌드, K푸드 건강식, 배달앱 중독 뇌과학
- **특징**: Z세대/건강 conscious 소비층 타겟, 콘텐츠 수요 안정적

## 3. 문제점 및 개선 방안

### Critical Issue: Zero-Data 현상
모든 키워드의 성과 지표가 0으로 표기된 것은 **통계적 오류** 또는 **수집 파이프라인 장애**를 의미합니다. 이 상태로는 경쟁 강도 분석, 조회수 예측, 콘텐츠 기회영역(Blue Ocean) 식별이 불가능합니다.

### 개선 방안
1. **데이터 소스 검증**
   - YouTube API v3 정상 연결 상태 확인
   - 검색 파라미터(`publishedAfter`, `regionCode`) 설정 재검토

2. **키워드 세분화**
   - "부정선거 시위" → "부정선거 시위 2024", "부정선거 시위 서울" 등 장문 키워드로 확장
   - "K푸드 건강식" → "K푸드 다이어트", "건강식 레시피" 등 검색 볼륨 확보

3. **뉴스 콘텐츠 처리**
   - 🔒 표기 키워드는 뉴스 저작권 정책으로 인해 API 미제공 가능성
   - 공식 뉴스 채널 데이터 대신 UGC(사용자 생성 콘텐츠) 필터링 적용
