**YouTube 채널 키워드 분석 리포트**

## 1. Executive Summary

본 리포트는 해당 채널의 핵심 키워드 15개에 대한 데이터 현황을 분석한 결과입니다. **현재 수집된 모든 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표시**되어 있어 정량적 성과 분석은 불가능한 상태입니다. 이는 데이터 수집 시점의 미스매치, API 연동 오류, 또는 해당 키워드들이 아직 실제 콘텐츠로 제작되지 않은 기획 단계의 키워드 풀일 가능성을 시사합니다.

## 2. 키워드 포트폴리오 분석

제시된 키워드들은 **시사/뉴스 전문 채널**의 특성을 반영하고 있습니다:

- **정치/외교 (40%)**: "투표지 부족 논란", "선관위 감사", "이민 난민 협약", "주한 미군 현황" 등 선거와 외교 안보 이슈 중심
- **경제/산업 (33%)**: "스페이스X 기업가치", "환율 상승 원인", "K-철도 수출", "빚투 브레이크 정책" 등 거시경제 및 산업 정책
- **사회/문화 (20%)**: "고기대신 한표 캠페인", "데뷔 10", "이탈리아 정상회담" 등 사회 캠페인과 문화 교류
- **건강/의료 (13%)**: "위암 생존율 연구", "혈압 기준 강화" 등 공중보건 이슈

## 3. 데이터 품질 진단

**Critical Issue**: 모든 키워드의 `video_count`와 `avg_views`가 0인 것은 다음 중 하나의 상황을 의미합니다:
1. **Pre-production 단계**: 아직 영상이 제작되지 않은 기획 단계의 키워드 리스트
2. **데이터 수집 실패**: YouTube Data API 연동 오류 또는 검색 파라미터 미스
3. **채널 미개설**: 해당 키워드들이 실제 채널 콘텐츠가 아닌 경쟁사 분석용 키워드 풀

## 4. 전략적 제언

**즉시 실행 필요 사항**:
- 데이터 수집 시스템의 정상 작동 여부 확인
- 키워드별 검색량 및 경쟁 강도(NB Score) 재측정 필요

**콘텐츠 기획 관점**:
"오늘의 주요 뉴스 🔒"와 같은 락(🔒) 표시 키워드는 구독자 전용 콘텐츠를 의미할 수 있으므로, 회원 전용 콘텐츠 전략 수립이 필요합니다. 또한 "데뷔 10"과 같은 엔터 키워드는 기존 뉴스 중심 채널 정체성과의 일관성 검토가 필요합니다.

**데이터 기반 운영을 위해서는 실제 영상 업로드 후 72시간 이후의 성과 데이터 재수집이 필수적**입니다.
