# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 분석 대상 키워드 16개는 **시사·경제·문화·사회** 등 광범위한 영역을 포괄하고 있으나, 현재 모든 메트릭(nb_score, 조회수, 영상 수)이 `0`으로 수집되지 않은 상태입니다. 이는 데이터 수집 초기 단계 또는 특정 필터링 조건 미적용으로 판단되며, 실제 콘텐츠 성과 분석을 위해서는 추가 데이터 수집이 필수적입니다.

## 2. 키워드 카테고리 분석

제공된 키워드는 다음 5개 카테고리로 분류됩니다:

| 카테고리 | 키워드 예시 | 시장성 특징 |
|---------|-----------|------------|
| **시사/뉴스** | 오늘의 주요 뉴스 🔒, 조선호텔 참사 언론 보도 | 실시간성 중시, 수명 주기 짧음 |
| **경제/금융** | 스페이스X 상장, 연방공개시장위원회 금리, 주담대 금리 인상 | 전문 시청층 대상, CPM 높음 |
| **기술/교육** | AI 수능 만점 논란 | 교육 계열 채널과 시너지, 장기 조회수 유지 |
| **외교/국제** | 한이 특별 전략 동반자, UAE 천궁2 수송 | 니치 타겟, 고관여 청중 |
| **문화/엔터** | BTS 컴백 라이브, 스테픈 커리 농구 | 바이럴 잠재력 높으나 경쟁 심화 |
| **사회/복지** | 활동지원사 보람, 고령 장애인 복지 | 저조회수·고전문성, 정책 채널 적합 |

## 3. 데이터 품질 진단 및 한계

**주요 이슈사항:**
- **메트릭 공백**: 모든 키워드의 `nb_score`, `avg_views`, `video_count`가 0으로, 경쟁 강도 및 검색량 분석 불가
- **콘텐츠 매핑 부재**: `videos` 배열 미제공으로 실제 어떤 영상이 해당 키워드로 노출되는지 확인 불가
- **시급성 키워드 포함**: "오늘의 주요 뉴스" 등 시간 민감형 키워드는 데이터 수집 시점에 따라 결과 급변

## 4. 전략적 제언

### 단기 조치 (1-2주 내)
1. **데이터 리수집**: YouTube Data API 또는 외부 분석 툴(예: VidIQ, TubeBuddy)을 통해 실제 검색량, 경쟁 채널 수, 평균 조회수 재수집
2. **키워드 정제**: "🔒" 특수문자 포함 키워드는 검색 알고리즘에서 필터링될 수 있으니 순수 텍스트 버전 병행 분석

### 중장기 전략
- **카테고리 집중**: 현재 산만한 포트폴리오 대신 경제/시사 중심으로 채널 포지셔닝 통일 권장
- **시즌성 고려**: "월드컵 경제 효과", "BTS 컴백" 등 이벤트 기반 키워드는 사전 콘텐츠 제작 일정 수립 필요

**결론**: 현재 데이터로는 우선순위 산정이 불가하므로, 위 조치를 통해 정량적 데이터 확보 후 재분석을 권장합니다.
