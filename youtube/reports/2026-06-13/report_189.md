# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 16개 대상 키워드에 대한 YouTube 콘텐츠 성과 분석을 수행한 결과입니다. **현재 수집된 모든 메트릭(nb_score, 조회수, 영상 수 등)이 0값으로 표시**되어 실제 콘텐츠 성과 비교분석은 불가능한 상태입니다. 이는 데이터 수집 시점의 필터링 조건 미충족, API 제한, 또는 검색 알고리즘 차단 등 기술적 이슈로 추정됩니다. 본 분석은 키워드 주제별 분류와 트렌드 특성 분석에 중점을 두었습니다.

---

## 1. 키워드 카테고리 분석

수집된 16개 키워드는 다음 5개 섹터로 분류됩니다:

| 카테고리 | 키워드 수 | 주요 키워드 | 특성 |
|---------|----------|------------|------|
| **시사/정치** | 4개 | 여의도 재선거, 선관위 성과급, 산불 피해, 한이탈리아 협력 | 시의성 높은 사회이슈 중심 |
| **경제/금융** | 3개 | 비트코인, 환율 대응, 국민연금 | 개인 투자자 관심 키워드 |
| **부동산** | 2개 | 재건축 분양, 집값 상승 지역 | 실수요자 및 투자자 타겟 |
| **테크/모빌리티** | 5개 | 테슬라, 스페이스X, HBM 반도체, AI 에이전트, 유전자 교정 | 첨단 기술 및 산업 소식 |
| **스포츠/엔터** | 1개 | KIA 타이거즈 | 계절성 스포츠 콘텐츠 |
| **뉴스 종합** | 1개 | 오늘의 주요 뉴스 | 큐레이션 형식 |

## 2. 데이터 품질 진단 및 한계

### 🔴 Critical Issue: 메트릭 Null 상태
- **video_count**: 모든 키워드 0건
- **avg_views**: 산출 불가
- **nb_score**: 경쟁 강도 측정 불가

**원인 추정:**
1. 검색 필터(기간/지역/언어) 과다 제한
2. YouTube Data API 할당량 초과
3. 키워드 정확도 불일치 (예: "🔒" 특수문자 포함 키워드)

---

## 3. 키워드 전략적 평가

### High Potential (잠재력 높음)
- **"테슬라 모델 Y 출시"**: 전기차 시장 관심도 지속 상승 중인 테마
- **"HBM 반도체 기술 발전"**: AI 붐 연계 반도체 섹터 핵심 키워드
- **"AI 에이전트 데이터 연동"**: 기술 전문 채널 타겟팅 적합

### Seasonal Risk (계절성 리스크)
- **"KIA 타이거즈 경기"**: 프로야구 시즌 외 조회수 급감 예상
- **"산불 피해 복구"**: 재난 발생 시점에 한정된 트래픽

### Policy Sensitive (정책 민감)
- **"선관위 성과급 논쟁"**, **"국민연금 납부 한도"**: 정부 정책 변동 시 급격한 검색량 변동 예상

---

## 4. 권고사항 및 다음 단계

### 즉시 조치 필요
1. **데이터 재수집**: 특수문자(🔒) 제거 및 검색 기간 설정 재확인
2. **API 상태 점검**: YouTube Data API 할당량 및 인증키 유효성 확인
3. **키워드 정제**: "오늘의 주요 뉴스"와 같이 범용적 표현은 세부 키워드로 세분화 필요

### 콘텐츠 전략 제안
- **테크-경제 융합**: "HBM 반도체"와 "비트코인"을 연계한 반도체 공급망 분석 콘텐츠 기획
- **부동산 심층 분석**: "재건축"과 "집값 상승" 키워드 결합하여 특정 지역(예: 서울 재건축 단지) 심층 취재
