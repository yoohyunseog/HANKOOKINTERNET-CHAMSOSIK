# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드의 검색 트렌드 및 경쟁 환경을 분석한 결과입니다. **현재 수집된 모든 키워드의 정량적 지표(nb_score, video_count, avg_views 등)가 0으로 표시**되어 있어, 데이터 수집 과정의 오류 또는 특정 필터링 조건 내 검색 결과 부재를 시사합니다. 본 분석은 키워드의 주제적 특성과 카테고리 분류를 중심으로 채널 전략 방향을 제시합니다.

## 1. 데이터 현황 및 한계점
- **수집 상태**: 전 키워드에 대해 조회수, 영상 수, 경쟁 점수 등의 메트릭스 미확인
- **가능성 분석**:
  1. 데이터 수집 API 연결 오류
  2. 과도한 필터링 조건(기간/지역)으로 인한 결과 0건
  3. 신규 생성 키워드 또는 저경쟁 키워드(장기적 관점 필요)

## 2. 키워드 주제 클러스터링 분석

### 2.1 경제/투자 (4개, 25%)
- 샌디스크 주가 분석, 테슬라 주가 전망, 스페이스X 상장 영향, 공급망 네트워크 전략
- **특징**: 기업 특정 뉴스(SanDisk, Tesla, SpaceX)와 거시 경제(공급망)가 혼재

### 2.2 정치/외교/안보 (5개, 31%)
- 주한 미군 한미동맹, 호남 정치권 동향, 한동훈 차기 지도자, 이란 종전 합의 전망, 이민난민 협약 EU
- **특징**: 국내 정치(한동훈, 호남)와 국제 안보(이란, EU, 주한미군) 균형 잡힌 포트폴리오

### 2.3 사회/정책/기술 (4개, 25%)
- 대한민국 교육정책 개편, 혈압 기준 강화 효과, AI 감별 기술 발전, 슈퍼 엘니뇨 기상이변
- **특징**: 공공 정책(교육, 의료)과 첨단 기술(AI) 및 환경 이슈 복합

### 2.4 기타 (3개, 19%)
- 오늘의 주요 뉴스 🔒, 캐나다 축구 팀, 한이탈리아 경제협력
- **특징**: 일반 뉴스 큐레이션 및 스포츠/국제 협력 소재

## 3. 채널 성향 추정 및 전략 제안

### 추정 채널 아이덴티티
**종합 시사/경제 뉴스 채널**로 보이며, 단순 뉴스 리포트를 넘어 주식 분석, 정치 평론, 기술 트렌드 등 **심층 분석 콘텐츠**를 지향하는 것으로 판단됩니다.

### 즉시 실행 필요사항
1. **데이터 검증**: YouTube Data API v3 또는 분석 툴(TubeBuddy, vidIQ)의 연결 상태 확인
2. **키워드 정제**: "오늘의 주요 뉴스 🔒"와 같이 이모지 및 특수문자 포함 키워드의 검색 가능성 재확인
3. **경쟁 강도 분석**: 데이터 복구 후 nb_score(경쟁 점수) 기준으로 
   - 상위 20%: 단발성 뉴스 (빠른 발행 필요)
   - 하위 20%: 블루오션 키워드 (선점 전략)
