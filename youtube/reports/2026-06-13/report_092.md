# YouTube 채널 키워드 분석 리포트

## 1. 개요 및 데이터 현황

본 리포트는 제공된 15개 핵심 키워드에 대한 YouTube 콘텐츠 분석 자료입니다. **현재 수집된 데이터(nb_score, 조회수, 영상 수 등)가 모두 0으로 표시되어 있어 정량적 분석이 불가능한 상태**이므로, 키워드의 주제별 특성과 트렌드 잠재력을 중심으로 한 정성적 분석을 제공합니다.

## 2. 키워드 카테고리 분석

수집된 키워드는 다음 6개 카테고리로 분류됩니다:

| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **시사/뉴스** | 오늘의 주요 뉴스, 교육부 정책, 한미 연합훈련, 이란 핵 합의, 한-이탈리아 협력, EU 이민 협약 | 시의성이 높은 정치·외교 키워드 |
| **경제/투자** | 테슬라 주가, 샌디스크 주가 | 재무제표 분석 및 전망 콘텐츠 적합 |
| **기업/브랜드** | 맥도날드 신제품 | 리뷰 및 언박싱 콘텐츠 잠재력 보유 |
| **문화/여행** | 보스니아 관광객, 문채원 드라마 | 라이프스타일 및 엔터테인먼트 콘텐츠 |
| **과학/환경** | 슈퍼 엘니뇨, 여성 위암 생존율 | 전문 지식 기반 교육 콘텐츠 |
| **예술/스포츠** | 호크니 추모, 한진만 하이라이트 | 니치 타겟층 대상 세분화 콘텐츠 |

## 3. 콘텐츠 전략 제안

### 3.1 단기 전략 (데이터 수집 우선)
- **API 연동 상태 점검**: 현재 모든 메트릭이 0으로 표시되므로, YouTube Data API v3 또는 분석 도구의 연결 상태를 우선 확인해야 합니다.
- **경쟁사 벤치마킹**: "테슬라 주가 분석", "맥도날드 신제품" 등 검색량이 높은 키워드는 경쟁 채널의 평균 조회수 및 썸네일 전략을 수동 분석하여 참고해야 합니다.

### 3.2 중장기 콘텐츠 방향
1. **시사 통합 콘텐츠**: "오늘의 주요 뉴스"를 메인으로 교육부 정책, 한미훈련 등을 묶은 일일 브리핑 형식 제작
2. **경제 뉴스 세분화**: 테슬라·샌디스크 등 반도체/EV 테마로 주제 특화 채널링
3. **트래블 콘텐츠**: 보스니아 관광객 증가 데이터를 활용한 '새로운 유럽 여행지' 발굴 콘텐츠 기획

## 4. 결론 및 권고사항

현재 데이터는 **수집 완료 후 재분석이 필수적**입니다. 키워드 선정 자체는 시사·경제·문화의 균형 잡힌 포트폴리오를 보여주나, 검색량(nb_score) 및 경쟁 강도 확인 없이는 우선순위 판단이 어렵습니다.

**즉시 실행 과제**: 
- 데이터 수집 시스템 점검
- "오늘의 주요 뉴스" 및 "테슬라 주가" 등 상위 키워드의 실제 검색량 확인
- 콘텐츠 제작 전 키워드 경쟁 강도(KD) 추가 조사
