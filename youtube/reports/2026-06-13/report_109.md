# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 대상 채널의 키워드 포트폴리오 15개에 대한 성과 분석을 수행한 결과입니다. **현재 모든 키워드에서 영상 콘텐츠(nb_score=0, video_count=0)가 검출되지 않아 데이터 공백 상태**임을 확인했습니다. 이는 채널이 해당 키워드 영역에서 아직 콘텐츠를 제작하지 않았거나, 메타데이터 수집 시점의 차이를 반영합니다.

## 데이터 현황 및 품질 분석

| 구분 | 상태 | 분석 |
|------|------|------|
| **데이터 커버리지** | 미흡 | 전체 15개 키워드에서 조회수, 영상 수, 경쟁 점수 등 모든 메트릭이 0값으로 기록 |
| **콘텐츠 존재 여부** | 없음 | views[], videos[] 배열 Empty 상태로 실제 업로드 영상 없음 확인 |
| **키워드 다양성** | 우수 | 시사/정치(40%), 경제/기업(20%), 문화/여행(20%), 기타(20%)로 분포 |

## 키워드 카테고리별 인사이트

### 1. 시사/정치 키워드 (Rank 1, 6-8, 10-11)
- **대상 키워드**: 오늘의 주요 뉴스, 교육부 정책, 한미 연합훈련, 이란 종전, EU 이민난민 협약, 한이탈리아 행동계획
- **분석**: 실시간성이 높은 뉴스 키워드군으로, **"오늘의 주요 뉴스 🔒"**는 락 아이콘 포함으로 프리미엄 콘텐츠 가능성을 시사. 단, 영상 수가 0인 것은 뉴스 채널로서의 콘텐츠 공백을 의미하며, 검색 수요 대비 공급 부재로 **블루오션 기회**로 해석 가능.

### 2. 경제/기업 키워드 (Rank 2, 4-5)
- **대상 키워드**: 맥도날드 신제품, 샌디스크 주가, 테슬라 주가
- **분석**: 검색 수요가 높은 상업적 키워드이나, 채널 내 관련 콘텐츠 부재. 특히 테슬라/샌디스크는 주식 정보 검색량이 높은 키워드로, 진입 시 높은 트래픽 유입 기대.

### 3. 문화/여행/기타 (Rank 3, 9, 12-15)
- **대상 키워드**: 보스니아 여행, 슈퍼 엘니뇨, 호크니 추모, 혈압 기준, 월드컵, 이민 여성 역사관
- **분석**: 틈새(Niche) 키워드 중심으로 장기적 SEO 가치가 높으나, 현재 콘텐츠 미제작 상태.

## 전략적 권고사항

### 단기 전략 (1-4주)
1. **뉴스 키워드 선점**: "오늘의 주요 뉴스" 키워드로 일일 뉴스 브리핑 콘텐츠 제작 시작. 실시간성이 핵심이므로 업로드 주기 중요.
2. **경제 키워드 진입**: 테슬라 주가 분석 콘텐츠 제작 (검색량 안정적, 수익화 가능성 높음)

### 중장기 전략 (1-3개월)
1. **데이터 추적 인프라 구축**: 현재 0값으로 표시된 메트릭이 정상 수집되도록 채널 분석 도구 재설정 필요
2. **키워드 밀도 조정**: 시사(40%) 비중이 과도하므로 여행/문화 콘텐츠 비중 확대로 시청자층 다변화
