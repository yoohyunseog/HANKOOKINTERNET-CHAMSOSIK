# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 15개 키워드에 대한 YouTube 채널 성과 데이터 분석을 수행한 결과입니다. 현재 수집된 데이터는 키워드 목록만 존재하며, 조회수(nb_score), 영상 수(video_count), 평균 조회수(avg_views) 등 핵심 성과 지표가 미수집 상태입니다. 따라서 본 분석은 키워드 구성의 주제별 분포와 콘텐츠 전략적 방향성 제시에 중점을 두었습니다.

## 1. 데이터 현황 분석

### 1.1 수집 상태
- **분석 대상 키워드**: 15개
- **데이터 완성도**: 0% (모든 성과 지표 미수집)
- **상태**: 데이터 수집 진행 중 또는 API 연동 미완료로 판단됨

### 1.2 키워드 구성 분류
현재 선정된 키워드는 다음 4개 카테고리로 분류됩니다:

| 카테고리 | 키워드 수 | 주요 키워드 |
|---------|----------|------------|
| **정치/사회** | 3개 | 오늘의 주요 뉴스, 투표용지 부족 논란, 정치권 대권 주자 경쟁 |
| **경제/산업** | 5개 | 한미반도체 협력, AI 칩 생산 병목 현상, 스페이스X IPO 청약 |
| **IT/테크** | 3개 | 이탈리아 첨단기술 MOU, 쿠팡 개인정보 유출, 암호화폐 거래소 규제 |
| **사회/문화** | 4개 | 청소년 소셜미디어 우울증, 한인 이민사, 팝아트 거장 추모 |

## 2. 전략적 분석 및 제안

### 2.1 콘텐츠 다각화 평가
현재 키워드 포트폴리오는 **뉴스/시사 중심의 종합 채널**로 보입니다. 반도체, 우주산업(스페이스X), AI 등 첨단 산업 키워드와 사회 이슈(청소년 우울증, 의료 사고)가 균형을 이루고 있어 시청자층이 광범위할 것으로 예상됩니다.

### 2.2 우선순위 조정 권고
데이터 수집 완료 후 다음 우선순위로 분석을 권장합니다:

1. **고성장 잠재력**: "AI 칩 생산 병목 현상", "스페이스X IPO 청약" - 테크 투자자층 타겟
2. **트래픽 안정성**: "오늘의 주요 뉴스" - 일일 검색량이 안정적인 핵심 키워드
3. **틈새 마켓**: "한인 이민사 뉴저지" - 타겟팅이 명확한 틈새 콘텐츠

## 3. 향후 분석 방향

데이터 수집 완료 시 다음 지표를 중심으로 심층 분석이 필요합니다:

- **경쟁 강도(NB Score)**: 0~100점 체계에서 70점 이상은 진입 장벽이 높은 것으로 판단
- **조회수 분포**: Max/Avg 비율을 통해 해당 키워드의 조회수 편중도 확인
- **영상 수 대비 기회**: Video Count가 낮고 Avg Views가 높은 **블루오션 키워드** 도출
