# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 15개 키워드에 대한 데이터 현황을 분석한 결과입니다. **모든 키워드의 성과 지표(nb_score, 조회수, 영상 수 등)가 0으로 수집되지 않은 상태**이므로, 현재 데이터는 정량적 분석이 불가능합니다. 본 보고서에서는 키워드 주제별 분류를 통한 질적 분석과 데이터 수집 개선 방안을 중심으로 제시합니다.

## 1. 데이터 품질 진단

### 1.1 수집 현황
| 지표 | 상태 | 분석 가능 여부 |
|------|------|---------------|
| NB Score | 0 (미수집) | 불가 |
| Video Count | 0 (미수집) | 불가 |
| Avg Views | 0 (미수집) | 불가 |
| Views/Videos 배열 | Empty | 불가 |

**진단 결과**: API 연동 오류, 검색 필터 미설정, 또는 데이터 크롤링 미완료로 추정됩니다. 실제 분석을 위해서는 데이터 재수집이 필수적입니다.

## 2. 키워드 카테고리 분석

수집된 키워드 15개를 주제별로 분류하면 다음과 같습니다:

### A. 경제/금융 (40%, 6개)
- **기업 특화**: 테슬라 주가 전망, 샌디스크 주가 분석, 스페이스X 상장 영향
- **시장 동향**: 한국 증시 빚투 현상
- **인물 연계**: 머스크 조만장자 기록

### B. 정치/시사 (26.7%, 4개)
- **외교/안보**: 주한 미군 현황, 이탈리아 경제 협력, 이민 난민 협약 발효
- **국내 정치**: 이재명 윤석열 예산 비교

### C. 사회/문화 (20%, 3개)
- **역사**: 한국 이민 여성 역사
- **정책**: 중장비 면허 무료 지원
- **예술**: 호크니 팝아트 추모

### D. 건강/의료 (13.3%, 2개)
- 여성 위암 생존율 연구, 혈압 기준 강화 효과

## 3. 전략적 제안

### 3.1 데이터 인프라 개선
- **YouTube Data API v3** 연결 상태 점검 및 할당량 확인
- 검색 파라미터 설정 (업로드 날짜 필터, 지역 설정 등)
- 수집 주기 자동화 (일일/주간 단위)

### 3.2 콘텐츠 기회 분석 (키워드 특성 기반)
**즉시 실행 권장 키워드**:
- `테슬라 주가 전망`: 높은 검색 수요, 시의성 강함
- `오늘의 주요 뉴스`: 뉴스 채널의 핵심 콘텐츠, 일일 업로드 권장

**틈새 기회 키워드**:
- `한국 이민 여성 역사`: 경쟁 저감, 교육 콘텐츠 적합
- `호크니 팝아트 추모`: 예술 분야 특화, 타겟 명확

### 3.3 리스크 관리
- **정치 키워드**(`이재명 윤석열 예산 비교`): 민감한 주제로 알고리즘 노출 리스크 고려
- **의료 정보**(`여성 위암 생존율`): 전문성 및 출처 명확화 필요

## 4. 향후 분석 방향

정상적인 데이터 수집 완료 후 다음 지표 중심으로 재분석이 필요합니다:

1. **경쟁 강도 분석**: Video Count 대비 검색량 비율
2. **수익화 가능성**: CPM이 높은 금융/건강 키워드 우선 순위
3. **시즌성 트렌드**: 주가 관련 키워드의 발행 시점 최적화

---

**결론**: 현재 데이터는 분석 불가 상태이나, 키워드 구성을 통해 경제/시사 중심의 채널 성향을 확인할 수 있습니다. 즉시 데이터 수집 시스템을 점검하고, 테슬라/뉴스 키워드를 우선 테스트 콘텐츠로 활용할 것을 권장합니다.
