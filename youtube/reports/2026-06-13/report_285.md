# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 16개 급상승 검색 키워드에 대한 블루오션 기회 진단입니다. 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 집계된 점은 **콘텐츠 공백 상태**를 의미하며, 이는 선점적 콘텐츠 제작의 전략적 기회로 해석됩니다.

## 데이터 품질 진단
- **수집 상태**: 메트릭 미집계 (신규 급상승 키워드 또는 실시간 검색어 추정)
- **데이터 특성**: 뷰/영상 수 0 → 경쟁 채널 부재 상태
- **분석 한계**: 성과 비교 불가, 트렌드 잠재력 중심 분석 진행
