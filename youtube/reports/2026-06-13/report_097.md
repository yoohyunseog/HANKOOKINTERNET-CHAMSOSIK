# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 총 16개 키워드에 대한 분석을 수행하였으나, **모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0으로 수집되지 않은 상태**임을 확인하였습니다. 이는 데이터 수집 시점의 API 제한, 검색 필터 미적용, 또는 비공개/신규 키워드로 인한 결과로 분석됩니다. 따라서 본 리포트는 키워드의 **정성적 특성과 카테고리 분류**를 중심으로 전략적 방향성을 제시합니다.

## 2. 키워드 카테고리 분석

수집된 16개 키워드를 5개 영역으로 분류한 결과는 다음과 같습니다:

### 📰 시사/뉴스 (37.5%, 6개)
- **주요 키워드**: 오늘의 주요 뉴스 🔒, 대한민국 교육정책 개편, 주한 미군 군사훈련, 이란 핵합의 체결, 한국 이탈리아 정상회담, EU 난민 협약 발효
- **특성**: 국내외 정치·외교·사회 이슈 중심의 정보성 콘텐츠. '🔒' 표시는 유료 구독 콘텐츠 또는 제한적 접근을 암시할 수 있음.

### 💹 경제/투자 (18.75%, 3개)
- **주요 키워드**: 테슬라 주식 분석, 샌디스크 주가 전망, 한국 이탈리아 경제협력
- **특성**: 개별 기업(테슬라, 샌디스크) 및 국가 간 경제 협력에 대한 심층 분석 콘텐츠. 재무 분석가 또는 투자 정보 채널 타겟팅 적합.

### 🌍 라이프스타일/여행 (12.5%, 2개)
- **주요 키워드**: 보스니아 여행 정보, 맥도날드 신제품 출시
- **특성**: 소비자 중심의 실용적 정보. F&B(맥도날드)와 니치 여행지(보스니아)가 혼재되어 있어 타겟층이 상이함.

### 🔬 기술/과학/환경 (18.75%, 3개)
- **주요 키워드**: AI 패러독스 논란, 슈퍼 엘니뇨 기상이변, 혈압 기준 강화
- **특성**: 전문 지식 기반 콘텐츠. AI 윤리, 기상 변화, 의료 기준 변화 등 고도화된 주제로 전문성이 요구됨.

### 🎨 문화/스포츠 (12.5%, 2개)
- **주요 키워드**: 팝아트 거장 추모, 월드컵 열기 멕시코
- **특성**: 예술사(팝아트)와 스포츠 이벤트(월드컵)가 포함된 문화 콘텐츠.

## 3. 데이터 품질 및 한계점

| 지표 | 상태 | 분석 |
|------|------|------|
| **NB Score** | 0 (전체) | 키워드 경쟁 강도 및 검색량 분석 불가 |
| **Video Count** | 0 (전체) | 시장 포화도 및 콘텐츠 공급량 파악 불가 |
| **Avg Views** | 0 (전체) | 기대 조회수 및 수익성 예측 불가 |
| **Views/Videos** | Empty Array | 개별 영상 성과 비교 분석 불가 |

**결론**: 현재 데이터로는 경쟁 분석(Competitive Analysis) 및 수익성 예측(RPM 추정)이 불가능합니다. YouTube Data API v3의 검색 쿼리 파라미터 조정 또는 서드파티 툴(예: VidIQ, TubeBuddy) 연동을 권장합니다.
