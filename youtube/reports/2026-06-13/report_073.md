# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 총 15개의 키워드에 대한 YouTube 채널 분석 데이터를 검토한 결과입니다. 
현재 수집된 데이터의 모든 성과 지표(nb_score, 조회수, 영상 수 등)가 0으로 표기되어 있어, **실제 콘텐츠 성과 분석은 불가능한 상태**입니다. 
다만, 키워드 구성을 통해 채널의 콘텐츠 전략 방향성과 시장 기회 요소를 도출할 수 있습니다.

## 2. 데이터 현황 및 한계점

| 구분 | 상태 |
|------|------|
| **수집 상태** | 미수집 (All metrics: 0) |
| **키워드 수** | 15개 |
| **데이터 신뢰성** | 분석 불가 (샘플 부재) |
| **시급성** | 데이터 재수집 필요 |

**주요 이슈**: 모든 키워드의 `video_count`와 `avg_views`가 0으로, 실제 YouTube 검색 결과가 반영되지 않았거나 API 수집 오류가 발생한 것으로 판단됩니다. 정확한 경쟁 분석을 위해서는 해당 키워드로 실제 검색된 영상 데이터의 재수집이 필수적입니다.

## 3. 키워드 카테고리 분석

현재 키워드군은 **5개의 주요 섹터**로 분류됩니다:

### 3.1 경제/투자 (40%, 6개)
- 샌디스크 주가 전망
- 테슬라 주가 분석  
- 스페이스X 상장 영향 / 기업가치 전망
- 한국 증시 빚투 현황
- 레미콘 노조 휴업 영향

*특징*: 테슬라-스페이스X 연계(일론 머스크 테마), 반도체(샌디스크), 국내 증시(빚투)로 **기술주 중심의 투자 심리**를 반영합니다.

### 3.2 국제/정치/외교 (20%, 3개)
- 주한 미군 최신 뉴스
- 한국 이탈리아 경제 협력  
- EU 이민 난민 협약

*특징*: **지정학적 리스크**와 다자간 외교 관심사가 공존합니다.

### 3.3 과학/환경/의료 (20%, 3개)
- 슈퍼 엘니뇨 전망
- 여성 위암 생존율 연구
- 혈압 기준 심혈관 질환

*특징*: **기후 위기**와 ** precision medicine(정밀 의료)** 트렌드를 포착하고 있습니다.

### 3.4 문화/라이프스타일 (13%, 2개)
- 팝아트 거장 호크니
- 제네시스 르망 24시간

*특징*: 고급 문화 예술과 모터스포츠를 아우르는 **프리미엄 콘텐츠** 성향입니다.

### 3.5 뉴스 아우라 (7%, 1개)
- 오늘의 주요 뉴스 🔒

*특징*: 락(🔒) 표시로 **구독자 전용 프리미엄 콘텐츠**로 추정됩니다.

## 4. 전략적 제언

### 즉시 실행 과제
1. **데이터 재수집**: YouTube Data API v3를 활용하여 각 키워드별 실제 검색 결과(최소 상위 50개 영상)의 조회수, 업로드 일자, 채널 구독자 수를 수집해야 합니다.

2. **경쟁 강도 분석**: 특히 "테슬라 주가", "오늘의 주요 뉴스" 등은 이미 포화 상태일 가능성이 높으므로, **Long-tail 키워드**로의 전환을 검토해야 합니다.

### 콘텐츠 기획 방향
- **시너지 키워드 발굴**: "스페이스X 상장"과 "테슬라 주가"를 연계한 일론 머스크 포트폴리오 분석 콘텐츠 기획
- **틈새 시장 공략**: "한국 이탈리아 경제 협력", "팝아트 호크니" 등은 경쟁이 덜한 Blue Ocean으로, **선점 콘텐츠** 제작 시 조회수 독점 가능성이 있습니다.

### 리스크 관리
- **빈도 조절**: "주한 미군", "EU 난민" 등 정치적 민감도가 높은 키워드는 커뮤니티 가이드라인 위반 리스크가 있으므로, 사실 확인 및 중립적 보도 원칙이 필요합니다.
