# YouTube 채널 키워드 분석 리포트

## 1. 데이터 현황 요약

분석 대상 16개 키워드 중 **실제 영상 데이터가 수집된 키워드는 4개(25%)**에 불과하며, 나머지 12개 키워드는 영상 미게재 또는 데이터 미수집 상태입니다. 이는 키워드 선정과 실제 콘텐츠 생산 간의 괴리를 시사하며, 데이터 기반 의사결정을 위한 수집 인프라 보완이 시급함을 보여줍니다.

## 2. 키워드별 성과 분석

### 고성과 콘텐츠
- **밀워키 브루어스 (28,371 조회수)**: 스포츠 콘텐츠로서 유일하게 5자리수 조회수를 기록. 제이콥 미시오로스키 선수의 15K 커리어 하이 경신 소식은 야구 팬층의 높은 관심을 반영합니다.

### 중간 성과 콘텐츠  
- **스페이스X IPO 청약 (4,800 조회수)**: 미래에셋증권 배정 취소 소식은 투자자들의 실질적 관심을 끌었으나, 단일 영상으로 분석 한계가 존재합니다.
- **군 차세대 공격헬기 엔진 결함 (967 조회수)**: '미르온' 헬기 결함 보도는 niche한 국방 소식임을 고려할 때 양호한 성과입니다.

### 저성과 콘텐츠
- **이탈리아 한국 비즈니스 라운드테이블 (평균 209 조회수)**: 3개 영상 모두 저조(8-586 조회수). 정치/외교 행사 콘텐츠의 시청자 참여도가 낮음을 확인했으며, 특히 제주방송 소재(8 조회수)는 알고리즘 노출 최적화 실패 가능성이 있습니다.

## 3. 전략적 제언

**콘텐츠 포트폴리오 재조정**: 스포츠(밀워키 브루어스)와 같은 대중적 키워드는 지속 생산 가치가 높으나, 정치 외교 행사는 숏폼 또는 핵심 하이라이트 편집으로 전환 필요.

**데이터 수집 체계 개선**: NB Score가 0으로 표기된 키워드(12개)의 실제 검색 트렌드 및 경쟁 강도 파악이 선행되어야 합니다. 현재 데이터 품질로는 알고리즘 전략 수립이 불가능합니다.

**타이밍 최적화**: 스페이스X IPO(4,800 조회수) 사례처럼 실시간 금융 이슈는 신속성이 핵심 성과 요인임을 확인, 뉴스 속보형 콘텐츠 파이프라인 구축을 권장합니다.
