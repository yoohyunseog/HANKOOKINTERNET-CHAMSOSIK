# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 제공된 16개 키워드에 대한 채널 분석 데이터를 바탕으로 작성되었으나, **모든 정량적 지표(nb_score, video_count, avg_views 등)가 0으로 표시**되어 실제 성과 측정이 불가능한 상태입니다. 따라서 본 분석은 키워드 구성의 질적 특성과 카테고리 분포에 중점을 두고 있습니다.

## 2. 데이터 품질 현황

| 구분 | 상태 | 비고 |
|------|------|------|
| 조회수 데이터 | 미수집 | views[], avg_views = 0 |

## 3. 키워드 카테고리 분석

수집된 키워드는 시사/뉴스 중심 채널의 특성을 반영하고 있습니다:

### A. 정치·외교 (37.5%)
- **이탈리아 국빈방문**, **정치 개표 시위**, **선거 부정 의혹**
- 선거 관련 키워드(개표 시위, 부정 의혹)가 2개로, 정치적 민감도가 높은 콘텐츠임을 시사

### B. 경제·산업 (31.3%)
- **스페이스X 상장**, **한미 증시 동향**, **금리 정책 전망**, **자동차 산업 노사 분쟁**, **기술 협력 체결**
- 금융(상장, 증시, 금리)과 산업(노사분쟁, 기술협력)이 균형 있게 분포

### C. 사회·노동 (25.0%)
- **주한 미군 현황**, **이민 난민 협약**, **이민자 사회 기여**, **노동조합 파업**
- 이민 관련 키워드가 2개로 사회적 이슈에 대한 높은 관심도 추정

### D. 의료·건강 (12.5%)
- **의료 연구 결과**, **건강 검진 중요성**
- 예방의학 관점의 콘텐츠 구성

## 4. 전략적 제안

1. **데이터 재수집**: YouTube Data API v3 연결 상태 점검 및 쿼터 확인

### 중장기 전략

- **이슈 클러스터링**: 선거(개표·부정 의혹), 이민(협약·사회기여) 등 연관 키워드 시리즈 기획 권장
