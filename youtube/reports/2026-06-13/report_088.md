# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (실행 요약)

본 리포트는 채널 모니터링 대상 키워드 14건에 대한 초기 분석 데이터를 바탕으로 작성되었습니다. 현재 수집된 영상 데이터(video_count: 0) 및 조회수 지표(avg_views: 0)가 미확인 상태이나, 키워드 구성을 통해 채널의 콘텐츠 전략 방향성을 도출할 수 있습니다.

**분석 대상 키워드 수:** 14개  
**주요 카테고리:** 정치/외교(36%), 경제/금융(36%), 기술/사회(28%)

---

## 2. 키워드 구성 분석

### 2.1 카테고리별 분포
| 구분 | 키워드 | 비중 |
|------|--------|------|
| **정치/외교** | 한-이탈리아 경제 협력, 이민 난민 협약, 주한 미군 현황, 선관위 투표용지 부족, 여론조사 | 35.7% |
| **경제/금융** | 테슬라 주가, 이탈리아 공급망, 스페이스X 주가, 쿠팡 과징금, 증권사 실적 | 35.7% |
| **기술/환경** | AI 병역특례, 슈퍼 엘니뇨 | 14.3% |
| **사회/문화** | 한인 이민사 박물관 | 7.1% |
| **뉴스 종합** | 오늘의 주요 뉴스 🔒 | 7.1% |

### 2.2 키워드 특성 분석
- **시의성 높은 뉴스성 키워드**: '슈퍼 엘니뇨', '선관위 투표용지 부족', '쿠팡 개인정보 유출' 등은 단발성 이슈로 빠른 콘텐츠화가 필요합니다.
- **지속적 관심 키워드**: '테슬라 주가', '주한 미군 현황'은 장기적 검색 수요가 있는 시드 키워드입니다.
- **프리미엄 콘텐츠**: '오늘의 주요 뉴스 🔒'는 잠금 아이콘을 통해 구독자 전용 콘텐츠 또는 멤버십 전략을 시사합니다.

---

## 3. 데이터 수집 현황 및 한계

**현재 데이터 상태:**
- 모든 키워드의 NB Score, 조회수(views), 영상 수(video_count)가 0으로 표기
- 실제 YouTube 검색 결과 미반영 또는 API 수집 전 상태로 추정

**분석 한계:**
실제 경쟁 강도(competition)와 검색량(volume) 데이터가 없어 키워드 난이도 및 파급력을 정량적으로 평가하기 어려운 상황입니다.

---

## 4. 전략적 제안

### 4.1 우선 순위 설정
**즉시 실행 권장**: 'AI 병역특례 제도', '슈퍼 엘니뇨 전망'  
→ 기술/환경 이슈는 초기 업로드 시점에 따른 조회수 격차가 큼

**장기 모니터링**: '테슬라 주가 전망', '스페이스X 주가'  
→ 금융 키워드는 주기적 업로드를 통한 채널 권한 구축 필요

### 4.2 콘텐츠 기획 방향
- **이탈리아 관련 키워드**('한-이탈리아 경제 협력', '이탈리아 공급망')를 클러스터링하여 시리즈 기획
- '이민 난민 협약'과 '한인 이민사 박물관'을 연계한 역사/사회 심층 콘텐츠 제작 검토

## 5. 결론

현재 키워드 포트폴리오는 뉴스/시사 채널로서 균형 잡힌 구성을 보이나, **실제 검색 데이터 수집이 선행**되어야 효과적인 콘텐츠 우선순위 판단이 가능합니다. 특히 '🔒' 마크가 포함된 키워드는 구독자 전환 전략과 연계된 배포 일정 수립이 필요합니다.
