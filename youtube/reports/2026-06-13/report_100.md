# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 YouTube 채널의 키워드 성과 데이터를 분석하여 콘텐츠 전략 및 방향성을 제시하는 것을 목적으로 합니다. 분석 기간 내 수집된 16개 핵심 키워드를 대상으로 하였습니다.

## 2. 데이터 현황 및 품질 분석

### 2.1 데이터 수집 상태
**중요 알림**: 현재 제공된 데이터셋의 모든 성과 지표(`nb_score`, `video_count`, `avg_views`, `max`, `min`)가 **0값**으로 표기되어 있으며, 실제 영상 목록(`videos`) 및 조회수 데이터(`views`)가 비어있는 상태입니다.

이는 다음의 가능성을 시사합니다:
- 데이터 수집 API의 연결 오류 또는 권한 제한
- 키워드 검색 결과가 없는 신규/희귀 키워드 중심의 콘텐츠 전략
- 비공개(🔒) 콘텐츠에 대한 접근 제한으로 인한 데이터 부재

## 3. 키워드 카테고리 분석

제공된 키워드들은 다음과 같이 5개 주요 영역로 분류됩니다:

| 카테고리 | 키워드 | 비중 |
|---------|--------|------|
| **정치·외교** | 대한민국 교육부 정책, 주한 미군 현황, 이란 종전 합의, 한국 이탈리아 전략적 행동계획, EU 이민 난민 협약, 광주 정청래 호남, 위안부 문제 고노 담화, 송파구 무번호 투표지 | 50% (8개) |
| **경제·기업** | 맥도날드 보스니아, 샌디스크 주가 변동, 테슬라 주가 전망 | 18.7% (3개) |
| **스포츠** | 월드컵 한국 멕시코, 한국 축구 월드컵 승리 | 12.5% (2개) |
| **기술·환경** | AI 감별능력 테스트, 슈퍼 엘니뇨 전망 | 12.5% (2개) |
| **뉴스** | 오늘의 주요 뉴스 🔒 | 6.3% (1개) |

### 3.1 주요 특징
- **정치·외교 중심 채널 성향**: 전체 키워드의 절반(50%)이 정치 및 외교 관련으로, 시사·정치 전문 채널의 특성을 보입니다.
- **실시성 및 논쟁성**: "송파구 무번호 투표지", "정청래 호남" 등 특정 사건/인물 중심의 키워드가 다수 포함되어 있어 뉴스 속보성 콘텐츠가 주를 이루는 것으로 추정됩니다.
- **글로벌 이슈 복합성**: 보스니아(맥도날드), 이란, 이탈리아, EU 등 해외 현안에 대한 관심도 높은 편입니다.

## 4. 전략적 제언

### 4.1 데이터 인프라 구축 우선
현재 모든 성과 지표가 0으로 표기되어 있어 **실제 콘텐츠 성과 측정이 불가능**합니다. YouTube Data API v3 연결 상태 확인 및 검색어 최적화(SEO) 데이터 수집 환경 구축이 시급합니다.

### 4.2 콘텐츠 포트폴리오 조정
정치·외교 키워드(50%)와 경제·기술 키워드(31.2%)의 비중이 높은 만큼, **"글로벌 시사 분석"** 채널로의 포지셔닝을 고려할 것을 제안합니다. 특히:
- "오늘의 주요 뉴스 🔒"는 멤버십 전용 콘텐츠로 보이므로, 유료 구독
