# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 13개의 키워드에 대한 초기 분석 데이터를 기반으로 작성되었습니다. **현재 모든 키워드의 정량적 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표시**되어 있어, 성과 기반의 데이터 분석은 불가능한 상태입니다. 따라서 본 보고서는 키워드의 **주제별 분류 및 트렌드 잠재력 분석**에 중점을 두었습니다.

## 1. 키워드 카테고리 분석

제공된 키워드는 4개의 주요 영역으로 분류됩니다:

- **신용대출 한도 축소 정책**: 정책 관심 키워드 (서민 경제 영향)
- **바이낸스 한국 시장**: 가상자산 규제 관련 이슈
- **NH투자증권 투톱 체제**: 기업 내부 governance 이슈
- **스페이스X 투자 동향/기업가치**: 우주 산업·벤처 투자 트렌드

## 2. 데이터 품질 진단 및 보완 방안

### ⚠️ Critical Issue
모든 키워드의 `video_count`, `avg_views`, `nb_score`가 **0값**으로 수집되었습니다. 이는 다음 경우로 추정됩니다:
- API 수집 오류 또는 타임아웃
- 키워드 필터링 단계에서의 데이터 손실
- 초기 크롤링 단계 (메타데이터 미수집 상태)

### 🔧 권장 보완 조치
1. **수집 재시도**: YouTube Data API v3를 통한 재수집
2. **검색 파라미터 확인**: `publishedAfter`, `regionCode`(KR), `relevanceLanguage`(ko) 설정 검증
3. **동의어 확장**: "스페이스X" → "SpaceX", "오픈AI" → "OpenAI" 등 영문 키워드 병행 수집 필요

## 3. 전략적 제언

### 단기 전략 (1-2주)
- **시의성 키워드 우선**: "코스피 급등", "오픈AI CEO 방한 연기" 등 시급성 높은 키워드 먼저 콘텐츠화
- **정책 키워드 모니터링**: "신용대출 한도 축소"는 정부 정책 발표 시점에 맞춰 타이밍 전략 수립

### 중장기 전략 (1개월+)
- **시리즈 기획**: "스페이스X" 관련 키워드(투자동향+기업가치)를 묶어 우주산업 심층 분석 시리즈 구성
- **카테고리 밸런스**: 금융(46%) 비중이 과도하므로, 기술/사회 분야 콘텐츠 비중 조정 검토

### 데이터 기반 의사결정
정량적 메트릭 수집 후 다음 지표를 반드시 확인하세요:
- **경쟁 강도(Competition Rate)**: `video_count` 대비 `avg_views` 비율
- **성장성**: 최근 30일 대비 90일 평균 조회수 변화율
- **시청 유지율**: 해당 키워드 영상의 평균 시청 지속 시간
