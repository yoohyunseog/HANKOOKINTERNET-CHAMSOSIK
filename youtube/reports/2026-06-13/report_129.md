# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
본 리포트는 14개 주요 키워드에 대한 YouTube 검색 데이터 분석 결과를 제시합니다. **단, 현재 수집된 모든 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표시되어 데이터 정합성에 심각한 문제가 확인되었습니다.** 이는 API 연동 오류, 수집 기간 미설정, 또는 필터링 로직 오류로 추정됩니다.

## 2. 키워드 카테고리 분석
제공된 키워드들은 다음 4개 영역으로 분류됩니다:

| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **경제/금융** | 스페이스X 주가, 뉴욕증시, 금값 하락 | 단기 트렌드 민감형 |
| **정치/외교** | 미이란 핵합의, 이탈리아 정상회담, 선관위 논란 | 사회적 이슈 중심 |
| **반도체/기술** | 삼성 AI칩, 한미반도체 수주, 반도체 고용 | 산업 심층 분석 콘텐츠 적합 |
| **부동산/기타** | 동탄 아파트 시세, 공격헬기 엔진 | 틈새 시장 타겟팅 가능 |

## 3. 데이터 품질 진단 및 위험 요인
- **Critical Issue**: 모든 키워드의 `video_count`와 `avg_views`가 0으로, 실제 검색량이 존재함에도 불구하고 데이터가 누락되었습니다.
- **영향도**: 경쟁 강도 분석(nb_score) 및 조회수 예측이 불가능하여 콘텐츠 기획에 활용할 수 없는 상태입니다.
- **조치 필요**: 데이터 수집 파이프라인 점검 및 재수집이 시급합니다.

## 4. 콘텐츠 전략 제안 (키워드 기반)
데이터 부재에도 불구하고 키워드 구성을 통해 다음 전략을 제안합니다:

**즉시 실행 권장**: 
- "반도체 호황 고용" + "삼성 AI칩 생산" → 기업 연계 심층 보도
- "선관위 성과급 논란" + "투표용지 부족" → 공공기관 감시 콘텐츠 기획

**장기 관점**: 
- "이탈리아 정상회담"과 "한국 이탈리아 기술 협력"을 연계한 국제 외교 분석 콘텐츠는 경쟁이 적을 것으로 예상됩니다.
