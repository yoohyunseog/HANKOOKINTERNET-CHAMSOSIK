# YouTube 채널 키워드 분석 리포트

**분석 기간:** 최신 데이터 기준

## Executive Summary

본 분석은 금융·경제 뉴스 중심의 YouTube 채널 키워드 성과를 평가한 결과이다. 전체 16개 키워드 중 **31.25%(5개)**만 실제 영상 데이터가 존재하며, 나머지는 콘텐츠 공백 상태로 나타났다. 특히 **"미래에셋 스페이스X 청약"** 키워드가 NB Score 1.042, 평균 조회수 31만 회로 압도적인 성과를 보였으나, 대부분의 정치·사회 이슈 키워드는 영상화되지 않아 기회 요인으로 판단된다.

## 1. 데이터 품질 및 커버리지 현황

### 1.1 데이터 완성도 분석
- **유효 데이터 보유 키워드:** 5개 (Rank 1-4, 13)
- **데이터 미수집/미생산 키워드:** 11개 (68.75%)
  
상위 랭크(1-10) 중 **"오늘의 주요 뉴스 🔒"**, **"신용대출 한도 축소"**, **"삼성전자 구글 AI칩"** 등은 검색 수요는 높으나 실제 영상 콘텐츠(video_count: 0)가 존재하지 않아 데이터 수집의 한계 또는 콘텐츠 공급 부족을 시사한다.

### 1.2 조회수 분포 특성
실제 데이터가 존재하는 5개 키워드의 총 조회수는 **62만 회**이며, 극단적인 편중 현상이 관찰된다. SBS의 "미래에셋증권 배정 스페이스X 공모주 '전량 취소'" 영상이 61만 회로 전체 트래픽의 98.5%를 차지하고 있어, **단일 이슈에 대한 언론사의 독점적 콘텐츠 효과**가 두드러진다.
