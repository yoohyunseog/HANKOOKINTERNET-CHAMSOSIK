# YouTube 채널 키워드 분석 리포트

**분석일:** 2024년  
**분석대상:** 16개 핵심 키워드  
**데이터 상태:** 초기 수집 단계 (성과 지표 미측정)

---

## 1. Executive Summary

본 분석은 16개 키워드에 대한 YouTube 콘텐츠 경쟁력 평가를 목표로 하였으나, 현재 모든 키워드의 성과 지표(`nb_score`, `video_count`, `avg_views` 등)가 **0값**으로 수집되지 않은 상태입니다. 이는 데이터 수집 API의 연결 문제 또는 분석 대상 채널의 콘텐츠 부재를 의미할 수 있습니다.

다만, 키워드 구성을 통해 채널의 **콘텐츠 전략 방향성**과 **잠재적 기회 영역**을 도출할 수 있습니다.

---

## 2. 키워드 카테고리 분석

제공된 16개 키워드는 다음과 같이 6대 영역로 분류됩니다:

| 카테고리 | 키워드 수 | 대표 키워드 | 특징 |
|---------|---------|------------|------|
| **경제/금융** | 4개 | 비트코인 가격 상승 분석, 커버드콜 ETF 수익률, 가온전선 주가 전망 | 투자 정보 중심 |
| **부동산/지역** | 2개 | 과천시 재건축 뉴스, 부동산 매매계약 필수 체크리스트 | 실용적 정보 제공 |
| **테크/모빌리티** | 3개 | 테슬라 모델 Y 출시, 스페이스X 상장 영향, AI 에이전트 데이터 연동 | 최신 기술 동향 |
| **시사/사회** | 4개 | 오늘의 주요 뉴스 🔒, 선관위 성과급 논란, 한국 이탈리아 전략적 협력 | 뉴스 및 정책 |
| **과학/환경** | 2개 | 슈퍼 엘니뇨 기상 이변, 유전자 교정 기술 논란 | 전문 지식 콘텐츠 |
| **스포츠/문화** | 2개 | KIA 타이거즈 우승, 월드컵 거리 응원 행사 | 팬덤 중심 콘텐츠 |
| **사회복지** | 1개 | 장애인 활동지원사 보람 | 틈새 감성 콘텐츠 |

### 주요 인사이트
- **다각화 전략**: 금융·부동산·테크 등 **고수익 광고 단가(CPM)** 영역에 집중된 구조
- **이슈 민감도**: 실시간 뉴스(🔒 표시) 및 우승/출시 등 **타이밍 의존형** 키워드 다수
- **틈새 기회**: "장애인 활동지원사 보람"과 같은 **저경쟁 사회공헌** 키워드 포함

## 3. 데이터 품질 진단 및 한계

### 현재 데이터 상태
```json
{
  "nb_score": 0,        // 경쟁 강도 점수 미측정
  "video_count": 0,     // 검색 결과 영상 수 미확인
  "avg_views": 0,       // 평균 조회수 미산출
  "views": [],          // 개별 영상 성과 데이터 부재
  "videos": []          // 대상 영상 목록 미수집
}
```

### 유발 가능 원인
1. **API 할당량 초과**: YouTube Data API 일일 할당량 소진
2. **키워드 검색 결과 부재**: 너무 특수하거나 최신 키워드로 인한 데이터 누락
3. **채널 미등록**: 분석 대상 채널이 해당 키워드로 콘텐츠를 보유하지 않음

---

## 4. 전략적 제언

### 단기 조치 (즉시 실행)
- **데이터 재수집**: API 연결 상태 확인 및 검색 파라미터 검증
- **키워드 정제**: "🔒" 특수문자 포함 키워드의 검색 가능성 테스트
- **경쟁사 분석**: `video_count`가 0인 키워드는 **블루오션** 또는 **비수요**
