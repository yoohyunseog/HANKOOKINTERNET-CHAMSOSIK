# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 15개 대상 키워드에 대한 초기 데이터 수집 현황을 분석한 결과입니다. 현재 모든 키워드에서 영상 수(nb_score), 조회수(views), 참여도 지표가 **0값**으로 표시되어 실제 콘텐츠 성과 분석이 불가능한 상태입니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 방향성과 잠재적 성장 영역을 파악할 수 있습니다.

---

## 1. 데이터 현황 분석

### 1.1 수집 상태 진단
- **데이터 품질**: 전체 키워드(15/15)에서 메트릭스 미수집 상태
- **영상 데이터**: video_count, views, videos 배열 전체 누락
- **영향**: 경쟁 강도 분석, 조회수 예측, 콘텐츠 갭 분석 불가

> **⚠️ 주의**: 현재 데이터는 키워드 기획 단계의 '시드 리스트' 수준으로, 실제 YouTube 검색 API 또는 크롤링 데이터가 반영되지 않은 상태입니다.

|---------|--------|------|------|

- **실시간성 의존도 높음**: "오늘의 주요 뉴스" 등 시의성 키워드 다수
- **테슬라/머스크 클러스터**: 일론 머스크 관련 키워드(테슬라, 스페이스X, 조만장자)가 별도 생태계 형성
- **정책/제도 키워드**: 중장비 면허, 혈압 기준 등 실용 정보형 콘텐츠 존재

## 3. 전략적 제안

### 3.1 데이터 수집 우선순위
**즉시 수집 필요 키워드** (높은 검색량 예상):
1. `테슬라 주가 전망` - 투자자 세대 높은 관심
2. `오늘의 주요 뉴스` - 일일 트래픽 확보 가능
3. `이재명 윤석열 예산 비교` - 정치적 이슈성

### 3.2 콘텐츠 기획 방향
- **경제 키워드**: 단순 주가 분석을 넘어 "빚투 현상"과 같은 사회적 연결고리 강조
- **건강 키워드**: "여성 위암 생존율" 등 전문 의료 정보는 전문가 인터뷰 형식 권장
- **틈새 키워드**: "한국 이민 여성 역사"는 경쟁 채널 적을 가능성, 블루오션 전략 적합

### 3.3 데이터 품질 개선 조치
- YouTube Data API v3 연동 상태 점검
- 검색 기간 필터(최근 30/90일) 설정 확인
- `nb_score` 산출 로직 검증 (검색량/경쟁도 비율)
