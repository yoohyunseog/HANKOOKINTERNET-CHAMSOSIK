# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 15개 키워드에 대한 YouTube 채널 성과 데이터를 분석한 결과입니다. 현재 수집된 데이터의 모든 수치(nb_score, 조회수 등)가 0으로 표기되어 있어 **정량적 성과 분석은 불가능한 상태**입니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 전략 방향성과 향후 데이터 수집 필요성을 도출할 수 있습니다.

## 1. 키워드 포트폴리오 분석

현재 등록된 키워드는 다음 4개 카테고리로 분류됩니다:

| 카테고리 | 키워드 수 | 주요 키워드 |
|---------|---------|------------|
| **정치/외교** | 5개 | 한미 정상회담, 주한미군 동맹, 이민난민 협약, 이란 종전 합의문, 투표지 부족 |
| **경제/비즈니스** | 4개 | 이탈리아 경제협력, 스페이스X 상장/주가, 바이낸스 규제, 현대차 노조 |
| **기술/산업** | 2개 | AI 첨단기술 MOU, 중장비 면허 지원 |
| **건강/의료** | 2개 | 심혈관 질환 기준, 여성 위암 생존율 |
| **뉴스 종합** | 1개 | 오늘의 주요 뉴스 🔒 |

**분석 의견**: 시사/경제 중심의 종합 뉴스 채널로 보이며, 특히 국제 정세(한미관계, 중동)와 기업 동향(스페이스X, 현대차)에 중점을 둔 콘텐츠 전략을 추정할 수 있습니다.

## 2. 데이터 품질 이슈

**심각한 결함**: 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 표기되어 있습니다.

- **원인 추정**: 
  1. 데이터 수집 API 연동 실패
  2. 키워드 설정 후 아직 영상이 업로드되지 않은 상태
  3. 검색 필터링 기간 설정 오류
  
- **영향**: 경쟁 강도 분석, 조회수 기반 우선순위 설정, 콘텐츠 성과 예측이 불가능함

## 3. 전략적 제안

### 즉시 실행 필요사항
1. **데이터 재수집**: YouTube Data API 또는 검색엔진 최적화(SEO) 도구를 통해 실제 검색량, 경쟁률, 평균 조회수 데이터 확보
2. **키워드 세분화**: "스페이스X"와 같이 광범위한 키워드는 "스페이스X 상장 일정", "스페이스X 주가 전망" 등 장/단타 키워드로 구체화 필요

### 콘텐츠 기획 방향
- **시의성 우선**: "이란 종전 합의문", "한미 정상회담" 등 시급성 높은 키워드는 발행 타이밍이 조회수에 결정적 영향을 미침
- **니치 전략**: "중장비 면허 무료 지원"은 경쟁이 덜한 특화 주제로, 초기 채널 성장 시 블루오션 활용 가능

## 4. 결론

현재 데이터는 **콘텐츠 기획 초기 단계의 키워드 풀(keyword pool)**로 보이며, 실제 성과 측정을 위해서는 즉각적인 데이터 정합성 확인과 재수집이 필요합니다. 시사/경제 분야의 특성상 발행 시점과 제목의 구체성이 핵심 성과 지표(KPI)에 미치는 영향이 크므로, 데이터 복구 후 시간대별 트렌드 분석을 병행할 것을 권장합니다.
