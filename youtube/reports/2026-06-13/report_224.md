# YouTube 채널 키워드 분석 리포트
**분석 기간:** 2024년 데이터 수집 예정  
**분석 대상:** 16개 핵심 키워드 성과 지표  

---

## 1. Executive Summary

본 리포트는 YouTube 채널의 콘텐츠 전략 수립을 위한 키워드 성과 분석 자료입니다. 현재 수집된 16개 키워드에 대한 성과 데이터(조회수, 영상 수, 경쟁 점수 등)가 **미수집 상태**로 확인되어, 본 보고서에서는 키워드 카테고리별 특성 분석 및 데이터 기반 의사결정을 위한 향후 수집 방향을 제시합니다.

---

## 2. 데이터 품질 현황

| 지표 | 상태 | 분석 가능성 |
|------|------|-------------|
| NB Score (경쟁 강도) | 0 (미수집) | 불가 |
| Video Count (영상 수) | 0 (미수집) | 불가 |
| Avg Views (평균 조회수) | 0 (미수집) | 불가 |
| Views Range (최소/최대) | 0 (미수집) | 불가 |

**진단:** 현재 모든 키워드에 대한 정량적 성과 지표가 누락되어 있어, 경쟁력 분석 및 ROI 예측이 불가능한 상태입니다. 데이터 수집 API 연동 상태 및 검색 필터 설정을 우선 점검할 필요가 있습니다.

## 3. 키워드 카테고리 분석

수집 대상 키워드는 4개의 주요 섹터로 분류됩니다:

### A. 시사/정치 (25%)
- **오늘의 주요 뉴스 🔒**, **선관위 서버 압수수색 전망**, **정청래 김민석 갈등 전망**, **이란 외무부 종전 MOU 서명**
- *특징:* 실시간성이 중요하며, 검색량 변동성이 큰 트렌드 키워드

### B. 경제/산업 (43.75%)
- **초음속 여객기 개발 현황**, **스페이스X 나스닥 상장 성과**, **외국인 삼성하이닉스 매수 동향**, **국제유가 안정화 전망**, **슈퍼 엘니뇨 경제 영향 전망**, **AI 발전 간병비 물가 상승**, **비트코인**
- *특징:* 정보 검색형(Intent: Informational) 키워드로, 교육 콘텐츠 및 전문 분석 영상에 적합

### C. 스포츠/엔터테인먼트 (18.75%)
- **다저스 대 화이트삭스 경기 하이라이트**, **트럼프 UFC 백악관 대회**, **데뷔 10주년 대니 구 공연**
- *특징:* 이벤트 기반으로 조회수 급등 가능성이 높으나 수명 주기가 짧음

### D. 기타/브랜드 (12.5%)
- **한이탈리아 전략적 행동계획**, **피자플래닛 팝업 스토리**
- *특징:* 틈새 마켓(Niche) 키워드로 경쟁은 낮으나 검색량 제한적

## 4. 전략적 제안

### 단기 조치 (1-2주 내)
1. **데이터 수집 인프라 점검**
   - YouTube Data API v3 할당량 확인
   - 키워드 검색 시 필터(업로드 날짜, 지역, 카테고리) 설정 검토

2. **우선순위 키워드 선정**
   - **비트코인**, **오늘의 주요 뉴스** 등 검색 볼륨이 높을 것으로 예상되는 키워드부터 수동 데이터 보충

### 중기 전략 (1개월 내)
1. **콘텐츠 포지셔닝**
   - **경제/산업** 키워드 중심의 전문가 브랜딩 (경쟁 강도가 낮은 **AI 발전 간병비 물가 상승** 등 틈새 키워드 공략)
   - **스포츠 하이라이트**는 Shorts 형태로 빠른 대응 전략 수립

2. **경쟁사 벤치마킹**
   - 각 키워드별 상위 노출 채널의 썸네일 패턴 및 제목 구조 분석 필요
