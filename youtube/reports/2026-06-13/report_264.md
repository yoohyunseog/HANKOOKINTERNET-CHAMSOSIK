# YouTube 채널 키워드 분석 리포트

**분석 기준일:** 2024년  
**분석 대상:** 16개 키워드  
**데이터 소스:** YouTube 채널 메트릭스  

---

## 1. Executive Summary

본 분석은 16개 키워드에 대한 YouTube 콘텐츠 성과를 점검한 결과, **데이터 불균형 현상**이 심각하게 나타났습니다. 전체 키워드 중 단 1개(6.25%)인 "합수본 선관위 압수수색"만 실제 영상 데이터를 보유하고 있으며, 나머지 15개 키워드는 영상 수(view count) 및 조회수 데이터가 전무한 상태입니다. 이는 데이터 수집 시점의 차이 또는 비공개 콘텐츠 존재를 시사합니다.

---

## 2. 데이터 품질 및 커버리지 분석

| 구분 | 키워드 수 | 비율 | 특성 |
|------|----------|------|------|
| **유효 데이터 보유** | 1개 | 6.3% | 실제 영상 및 조회수 확인 가능 |
| **데이터 미수집** | 15개 | 93.7% | 영상 수 0, 조회수 0 상태 |

**주요 발견사항:**
- **실시간 뉴스 이슈**("합수본 선관위 압수수색")만 유일하게 콘텐츠화되어 있음
- 경제/금융 키워드(FOMC 금리 인상, 한은 총재 발표 등), 엔터테인먼트(뉴진스, 케이티 페리), 기업동향(기아 셀 토스, 삼성전자 투자) 등은 데이터 미존재
- 데이터 부재 키워드들은 향후 **모니터링 대상**으로 설정하거나, 데이터 수집 파이프라인 점검이 필요함
