# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 총 15개 키워드에 대한 트렌드 데이터를 대상으로 진행되었으나, **모든 메트릭(nb_score, video_count, avg_views 등)이 0으로 수집**되어 유효한 성과 분석이 불가능한 상태입니다. 이는 데이터 수집 초기 단계 또는 API 연동 오류를 시사하며, 키워드 기반 콘텐츠 전략 수립을 위해서는 추가 데이터 수집이 필수적입니다.

## 1. 키워드 카테고리 분석

수집된 키워드는 4개 주요 영역으로 분류됩니다:

| 카테고리 | 키워드 | 비중 |
|---------|--------|------|
| **정치/외교/안보** | 오늘의 주요 뉴스, 한미 정상회담, 주한미군 한미동맹, 이민난민 협약, 투표지 부족 선거, 이란 종전 합의문 | 40% |
| **경제/산업** | 이탈리아 경제협력, 스페이스X 상장/주가, 바이낸스 암호화폐, 현대차 노조, AI 첨단기술 MOU | 40% |
| **사회/복지** | 중장비 면허 무료 지원 | 7% |
| **건강/의료** | 심혈관 질환 혈압 기준, 여성 위암 생존율 | 13% |

**주요 인사이트:**
- **정치·경제 복합 트렌드**가 80%를 차지하여 시사/뉴스 채널의 특성이 뚜렷함
- **스페이스X** 관련 키워드가 2개(상장, 주가) 노출되어 머스크/우주산업에 대한 높은 관심도 반영
- **노사갈등**(현대차 파업) 및 **선거관리**(투표지 부족) 등 사회적 이슈 포함

## 2. 데이터 품질 진단

### Critical Issue: 메타데이터 누락
- **nb_score 0**: 경쟁 강도 파악 불가
- **video_count 0**: 콘텐츠 공급량 측정 불가  
- **avg_views 0**: 시청자 수요 분석 불가

### 개선 방안
1. **수집 기간 설정**: 실시간 트렌드보다는 최소 7-30일 구간의 누적 데이터 확보
2. **세분화 지표 추가**: 조회수 증감률, 좋아요 비율, 댓글 참여도 등 Engagement 지표 수집
3. **경쟁 채널 매핑**: 해당 키워드로 성과를 내는 채널의 구독자 수 및 평균 조회수 벤치마킹

## 3. 전략적 제언

현재 데이터로는 **키워드 선정의 적절성**만 확인 가능합니다. 유효한 분석을 위해 다음 단계를 권장합니다:

**Phase 1: 데이터 보완 (1-2주)**
- YouTube Data API v3를 통한 검색량 및 경쟁도 데이터 재수집
- 긴급도 높은 키워드("오늘의 주요 뉴스", "스페이스X 주가") 우선 모니터링

**Phase 2: 콘텐츠 기회 분석**
- `video_count` 대비 `avg_views` 비율로 **공급 과잉/부족** �
