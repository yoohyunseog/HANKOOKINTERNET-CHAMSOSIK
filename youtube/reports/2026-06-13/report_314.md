# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 해당 YouTube 채널의 핵심 키워드 16개에 대한 분석 결과를 제시합니다. **현재 수집된 데이터 상 모든 키워드의 노출 지수(nb_score) 및 조회수 관련 지표가 0으로 표기**되어 있어 정량적 성과 분석은 불가능한 상태입니다. 다만, 키워드 구성을 통해 채널이 **정치/사회 뉴스, 기술/우주 산업, 국제 외교** 등을 아우르는 복합 정보 채널로 포지셔닝하고 있음을 확인할 수 있습니다.

## 2. 키워드 카테고리 분석

### 2.1 주제별 분포 현황
수집된 키워드는 다음 6개 카테고리로 분류됩니다:

| 카테고리 | 키워드 수 | 대표 키워드 |
|---------|---------|------------|
| **우주/기술** | 4개 | 스페이스X 나스닥 상장, AI 미토스, 한미반도체 지분, ETF 물량 |
| **정치/사회** | 3개 | 선관위 서버 압수수색, 사전투표 확산, 오늘의 주요 뉴스 |
| **경제/산업** | 3개 | 반도체 공장 투자설, 레미콘 휴업, 쿠팡 과징금 |
| **국제/외교** | 2개 | UAE 이란 자산 해제, 이민 여성 역사(뉴저지) |
| **국방/안보** | 1개 | 원자력 잠수함 개발 현황 |
| **문화/스포츠** | 2개 | 한복 패션쇼 로마 반응, 축구 역전승 하이라이트 |

### 2.2 핵심 인사이트
- **스페이스X 집중 현상**: 전체 키워드 중 25%(4개)가 스페이스X 및 관련 우주산업에 집중되어 있어, 해당 채널은 일론 머스크 관련 콘텐츠를 핵심 트래픽 원으로 삼고 있을 가능성이 높습니다.
- **뉴스 큐레이션 역할**: "오늘의 주요 뉴스 🔒" 키워드는 잠금(🔒) 표시를 통해 **구독자 전용 콘텐츠** 또는 **멤버십 전용 콘텐츠**로 운영 중임을 시사합니다.

## 3. 데이터 품질 진단 및 권고사항

### 3.1 현재 데이터 한계
- 모든 키워드의 `video_count`, `avg_views`가 0으로 표기되어 **경쟁 강도 분석 및 조회수 예측이 불가능**합니다.
- `nb_score` 0점은 해당 키워드가 실제로 검색되지 않았거나, 데이터 수집 API 연동에 문제가 있음을 의미합니다.

### 3.2 개선 방안
1. **데이터 수집 주기 확인**: YouTube Data API v3의 쿼터 한도 및 수집 로직 점검 필요
2. **키워드 정제**: "AI 미토스"와 같은 신조어/오타 가능성 확인 (미토스→미토스?)
3. **장기 데이터 축적**: 최소 30일간의 시계열 데이터 확보 후 재분석 권장

## 4. 콘텐츠 전략 제안

**단기 전략**: 스페이스X 관련 키워드(상장, 지분, ETF)를 클러스터링하여 **"우주산업 투자 가이드"** 시리즈 기획  
**중기 전략**: 정치/사회 키워드(선관위, 사전투표)와 국제 외교 키워드를 결합한 **"글로벌 정치 경제 분석"** 콘텐츠 라인 확장
