## 1. Executive Summary

본 리포트는 총 16개의 키워드에 대한 YouTube 검색 및 성과 데이터를 분석한 결과입니다.  
**주요 발견:** 현재 모든 키워드의 NB Score, 조회수, 영상 수 등 핵심 지표가 `0`으로 표기되어 있어, 실제 성과 분석이 불가능한 상태입니다. 이는 데이터 수집 API 미연동, 검색 필터 미적용, 또는 초기화 상태를 의미합니다.

## 2. 키워드 포트폴리오 분석

제공된 키워드들은 다음 4개의 주요 카테고리로 분류됩니다:

### 2.1 시사/경제 뉴스 (40%)
- **오늘의 주요 뉴스 🔒**, **스페이스X 상장**, **연방공개시장위원회 금리**
- **특징:** 실시간성이 중요한 핫이슈 키워드. 🔒 표시는 프리미엄 콘텐츠 또는 구독자 전용 콘텐츠를 암시할 수 있음.

### 2.2 금융/부동산 (20%)
- **이민자 자산 동결 해제**, **주담대 금리 인상**
- **특징:** 니치 타겟(이민자, 주택 소유자)을 겨냥한 고관여도 키워드. CPC(클릭당 비용)가 높을 가능성.

### 2.3 사회/복지 (15%)
- **활동지원사 보람**, **고령 장애인 복지**
- **특징:** 공공기관 또는 사회적 기업 콘텐츠에 적합. 검색량은 낮으나 전환율(engagement)이 높은 장기적 키워드.

### 2.4 엔터테인먼트/스포츠 (25%)
- **BTS 컴백 라이브**, **스테픈 커리 농구**, **월드컵 경제 효과**
- **특징:** 바이럴 성향 강하며, 단기간 집중 조회수 발생 예상.

## 3. 데이터 품질 진단 및 권고사항

### ⚠️ Critical Issue: Zero-Value Data
모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 기록되어 있습니다.

**원인 추정:**
1. YouTube Data API 할당량 초과
2. 키워드 검색 시 날짜 필터 미적용 (예: "지난 30일")
3. 검색어 인코딩 오류 (한글 키워드 처리 문제)

**즉시 조치 필요:**
```sql
-- 데이터 검증 쿼리 예시
SELECT keyword, COUNT(*) as valid_count 
FROM keyword_data 
WHERE nb_score > 0 
GROUP BY keyword;
```

## 4. 전략적 제안

### Short-term (1-2주)
1. **데이터 파이프라인 점검:** API 연결 상태 및 키워드 인코딩 확인
2. **긴급 키워드 선별:** "스페이스X 상장", "BTS 컴백" 등 시의성 있는 키워드 우선 모니터링

### Mid-term (1개월)
1. **경쟁 강도 분석:** NB Score가 정상 수집되면 30 이상의 키워드는 신규 진입 난이도가 높으므로 롱테일 키워드로 전략 전환
2. **시즌성 대응:** "월드컵 경제 효과"는 4년 주기 이벤트로, 비월드컵 기간에는 관련성 하락 예상

### Long-term (3개월+)
- **크로스 카테고리 콘텐츠:** "AI 수능 만점 논란" + "활동지원사 보람" 등 사회 이슈와 복지를 결합한 차별화 콘텐츠 기획
