**YouTube 채널 키워드 분석 리포트**

## 1. 개요
본 리포트는 채널의 콘텐츠 전략 수립을 위한 키워드 분석 자료입니다. 총 16개의 키워드를 대상으로 하였으나, **현재 수집된 데이터에 결측치가 100% 발생**하여 정량적 성과 분석은 불가능한 상태입니다.

## 2. 데이터 품질 현황
- **수집 상태**: 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 표기
- **영향**: 조회수 추이, 경쟁 강도, 콘텐츠 성과 비교 분석 불가
- **원인 추정**: API 수집 오류, 검색 필터 미설정, 또는 특정 기간 내 업로드 영상 부재

## 3. 키워드 카테고리 분석
현재 리스트는 **시사·경제 중심의 복합 채널** 성향을 보입니다:

| 구분 | 키워드 | 특성 |
|------|--------|------|
| **정치·외교** | 한미 반도체 협력, 이탈리아 FTA, 주한 미군 현황 | 국제 관계 및 통상 이슈 |
| **경제·투자** | 스페이스X 주식, 바이낸스 뉴스, 기업가치 2조달러 | 고수익·고위험 투자 정보 |
| **사회·사건** | 투표지 부족, N웹툰 공조, 소방관 괴롭힘 | 공공·노동 이슈 |
| **건강·과학** | 청소년 SNS 우울증, 여성 위암 생존율, AI MOU | 의료·기술 융합 |
| **문화** | 팝아트 거장 추모 | 예술·인물 평론 |

## 4. 전략적 제언

### 즉시 조치 필요
1. **데이터 재수집**: YouTube Data API v3 연동 상태 확인 및 30일·90일 조회수 데이터 확보
2. **검색 파라미터 설정**: 업로드 날짜 필터(최근 1개월) 및 지역 설정(KR) 추가

### 콘텐츠 기획 방향
- **시사 키워드**("오늘의 주요 뉴스")는 경쟹률이 높으므로 **독점 소스 확보** 또는 **빠른 업로드**(브레이킹 뉴스) 전략 필요
- **투자·경제 키워드**는 구독자 전환율이 높으나, **금융 규제 준수** 및 투자 유의사항 고지 필수
- **사회·건강 키워드**는 2030 여성 타겟층 선호도가 높아 **감성적 스토리텔링** 적용 권장

## 5. 결론
현재 데이터는 분석 대상이 아닌 **수집 대상**입니다. 정상적인 데이터 확보 후 재분석을 요청드리며, 위 카테고리별 특성을 참고하여 콘텐츠 라인업을 우선 구성하시기 바랍니다.
