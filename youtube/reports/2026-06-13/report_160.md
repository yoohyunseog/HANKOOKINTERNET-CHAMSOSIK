# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드에 대한 데이터 기반 분석 결과를 제시합니다. 분석 대상 키워드는 정치·외교, 경제·산업, 사회·문화, 과학·기술 등 폭넓은 영역을 포괄하며, 시의성이 높은 뉴스 중심의 콘텐츠 특성을 보입니다. 다만, 현재 수집된 데이터의 모든 수치 지표(nb_score, 조회수 등)가 0으로 표기되어 있어 정량적 분석에 한계가 있으므로, 본 리포트는 키워드의 정성적 특성과 카테고리별 분포를 중심으로 전략적 방향을 제시합니다.

## 1. 데이터 품질 현황
- **수집 상태**: 16개 키워드 모두에서 video_count, avg_views, nb_score 등 핵심 지표가 미수집 상태
- **영향**: 경쟁 강도, 조회수 잠재력, 콘텐츠 성과 예측이 불가능한 상황
- **권고**: 데이터 재수집 또는 API 연동 상태 점검이 필수적임

## 2. 키워드 카테고리 분석

### 2.1 정치·외교·행정 (37.5%)
- **키워드**: 소방청장 임명, 한국-이탈리아 정상회담, 이란 합의(트럼프)
- **특성**: 국내 행정 소식과 국제 외교 현안이 혼재되어 있음
- **시사점**: 정치 채널의 경우 즉각적인 뉴스 클리핑 콘텐츠 제작 가능

### 2.2 경제·산업·금융 (31.3%)
- **키워드**: 재건축 투표, AI 반도체, 스페이스X 상장, 삼성전자 주식, 고유가 금융지원
- **특성**: 부동산, 기업 공시, 거시 경제 정책이 균형 있게 분포
- **시사점**: 투자자 및 실수요자 타겟팅이 명확한 고부가가치 키워드

### 2.3 과학·기술·건강 (25.0%)
- **키워드**: 엘니뇨 현상, 스트레스-기억력 연구, 유전자 교정, 위암 생존율
- **특성**: 학술적 연구 결과와 환경 이슈가 복합적으로 나타남
- **시사점**: 전문 지식 기반의 해설 콘텐츠 제작 시 장기적 SEO 효과 기대

### 2.4 사회·문화·스포츠 (18.8%)
- **키워드**: KIA 타이거즈 우승, 송혜교 이혼, 호크니 별세
- **특성**: 대중적 관심사이나 지속성이 낮은 이벤트성 키워드
