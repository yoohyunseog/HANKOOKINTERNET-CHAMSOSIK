# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 채널의 콘텐츠 전략 수립을 위해 선정된 16개 핵심 키워드에 대한 초기 분석 결과를 제시합니다. 현재 수집된 데이터가 미비하여 정량적 성과 지표는 확인할 수 없으나, 키워드 포트폴리오의 주제별 분포와 시장 진입 전략을 중심으로 분석하였습니다.

## 1. 데이터 품질 현황

**수집 상태**: 모든 키워드의 노출 점수(nb_score), 조회수(views), 영상 수(video_count)가 0으로 표기되어 **데이터 수집 미완료 상태**로 판단됩니다.

**조치 필요사항**:
- YouTube Data API 연동 상태 점검
- 키워드 검색 필터(기간, 지역, 언어) 설정 확인
- 수집 주기 및 크롤링 로그 검증

## 2. 키워드 포트폴리오 분석

선정된 16개 키워드는 다음 6개 카테고리로 분류됩니다:

| 카테고리 | 키워드 | 시장 특성 |
|---------|--------|----------|
| **정치/외교** | 주한 미군 현황, 이탈리아 국빈방문, 정치 개표 시위, 선거 부정 의혹 | 고시청률/높은 경쟁률 |
| **경제/금융** | 스페이스X 상장, 한미 증시 동향, 금리 정책 전망, 자동차 산업 노사 분쟁 | 실시간성 중요, 전문가 권위 필요 |
| **사회/노동** | 이민 난민 협약, 노동조합 파업, 이민자 사회 기여 | 감정적 이슈, 댓글 참여율 높음 |
| **과학/의료** | 의료 연구 결과, 건강 검진 중요성 | 신뢰도 중시, 장기 조회수 유지 |
| **기술/산업** | 기술 협력 체결 | B2B 성향, 니치 타겟 |
| **종합** | 오늘의 주요 뉴스 🔒 | 브랜딩 핵심, 일일 콘텐츠 허브 |

## 3. 전략적 제안

### 단기 (1-2주)
1. **데이터 인프라 구축**: API 수집 오류 해결 및 백데이터 확보
2. **시드 키워드 선정**: '오늘의 주요 뉴스 🔒'를 중심으로 한 토픽 클러스터링

### 중기 (1개월)
1. **블루오션 키워드 발굴**: '이탈리아 국빈방문', '기술 협력 체결' 등 경쟁이 덜한 외교/산업 키워드 선제적 공략
2. **시리즈 기획**: '주한 미군 현황'→'이민 난민 협약'→'이민자 사회 기여' 연계 기획으로 시청자 여정 설계

### 장기 (3개월)
1. **금융 뉴스 전문성 강화**: '스페이스X 상장', '금리 정책 전망' 등 해설형 콘텐츠로 구독자 충성도 제고
2. **이슈 선점 체계**: 선거/파업 등 급발성 이슈 대응을 위한 알림 시스템 구축

## 4. 결론

현재 데이터 수집 문제 해결이 최우선 과제입니다. 키워드 구성은 시사 전반을 아우르는 밸런스를 보이나, **정치(4개)와 경제(4개)에 편중**되어 있어 라이프스타일/엔터테인먼트 키워드 보완을 권장합니다. 데이터 정상화 후 재분석을 통해 구체적인 조회수 기대치와 경쟁 강도를 측정할 예정입니다.
