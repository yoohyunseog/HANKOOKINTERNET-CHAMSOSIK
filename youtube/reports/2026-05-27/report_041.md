# YouTube 키워드 분석 보고서

**생성 시각:** 2025년 4월 8일 14:00 KST  
**분석 대상:** YouTube 채널 키워드 데이터 (총 16개 키워드)  
**데이터 기준:** N/B 스코어, 영상 수, 조회수, 자막 요약

---

## 1. 분석 요약

본 보고서는 제공된 16개 키워드 데이터를 기반으로 YouTube 채널의 콘텐츠 트렌드와 시청자 관심사를 분석한 결과입니다. 전체 키워드의 **N/B 스코어가 모두 0**으로 나타나, 해당 키워드들의 검색 경쟁도나 노출 빈도에 대한 정량적 데이터가 부재한 상태입니다. 이는 데이터 수집 기간이 짧거나, 채널의 콘텐츠가 아직 충분한 검색 트래픽을 확보하지 못했음을 시사합니다.

영상이 실제로 게시된 키워드는 **3개(5위, 7위, 9위)** 에 불과하며, 나머지 13개 키워드는 영상 수와 조회수가 모두 0입니다. 이는 해당 키워드들이 **검색 의도는 높지만 아직 콘텐츠로 연결되지 않은 영역**일 가능성이 큽니다. 특히 상위권 키워드(1~4위)는 경제·증시·국방 등 고관심 주제임에도 불구하고 콘텐츠가 전혀 없어, **콘텐츠 공백(Content Gap)** 이 존재하는 것으로 분석됩니다.

## 2. 상위 5개 키워드 심층 분석

### 1위: `오늘의 주요 뉴스 🔒`  
- **N/B 스코어 0, 영상 0건**  
- 🔒 이모지가 포함된 점으로 미루어 **유료 콘텐츠 또는 멤버십 전용 영역**으로 추정됩니다. 뉴스 종합 채널의 핵심 키워드로, 일일 뉴스 요약 콘텐츠에 대한 수요가 높음을 반영합니다. 다만 영상이 전혀 없어, 해당 키워드에 대한 콘텐츠 제작이 시급합니다.

### 2위: `삼성전자 성과급 합의`  
- **N/B 스코어 0, 영상 0건**  
- 삼성전자 노사 간 성과급 협상은 매년 반복되는 이슈로, 시청자들의 관심도가 높습니다. 특히 최근 반도체 업황 회복과 맞물려 **경제·증권 채널의 단골 소재**입니다. 영상이 없으므로, 관련 뉴스 요약이나 전문가 분석 콘텐츠를 제작할 경우 높은 조회수를 기대할 수 있습니다.

### 3위: `코스피 사상 최고치 돌파`  
- **N/B 스코어 0, 영상 0건**  
- 코스피 지수 관련 키워드는 투자자들의 심리와 직결됩니다. 사상 최고치 돌파는 **단기적 이슈**이므로, 실시간 대응 콘텐츠(라이브 또는 속보 형식)가 효과적일 수 있습니다. 현재 영상이 없어 기회를 놓치고 있는 상태입니다.

### 4위: `SK하이닉스 시가총액 글로벌 순위`  
- **N/B 스코어 0, 영상 0건**
