## 1. 분석 요약

본 데이터는 총 16개의 키워드에 대해 채널 내 연관 영상 존재 여부와 성과를 분석한 결과입니다. **전체 키워드 중 단 1개(‘오늘의 주요 뉴스 🔒’)만이 실제 영상(1개, 조회수 912회)과 연결**되어 있으며, 나머지 15개 키워드는 모두 `video_count = 0`, `views = []`로 나타나 해당 키워드에 대응하는 콘텐츠가 채널에 존재하지 않습니다. 이는 채널이 특정 키워드(예: ‘서소문 고가 붕괴사고’, ‘금융소득종합과세’, ‘HMM 부산 수소 동맹’ 등)에 대해 검색 유입 가능성이 있음에도 불구하고, 실제로는 해당 주제를 다루는 영상을 제작·게시하지 않았음을 의미합니다.

N/B 스코어는 모든 키워드에서 0으로 기록되었습니다. N/B 스코어는 일반적으로 키워드의 경쟁 강도나 검색 트래픽 대비 채널의 점유율을 나타내는 지표로 해석되며, 값이 0이라는 것은 해당 키워드에 대해 채널이 아직 유의미한 노출이나 점유를 확보하지 못했음을 시사합니다. 특히 `video_count = 0`인 키워드에서는 N/B 스코어가 0인 것이 자연스럽지만, 유일하게 영상이 존재하는 ‘오늘의 주요 뉴스 🔒’에서도 N/B 스코어가 0인 점은 해당 영상의 검색 엔진 최적화(SEO) 성과가 미미하거나, 키워드 자체의 검색량이 매우 낮을 가능성을 암시합니다.
