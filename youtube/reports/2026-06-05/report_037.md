# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드에 대한 초기 분석 결과를 제시합니다. 현재 수집된 정량적 데이터(nb_score, 조회수 등)가 미확보 상태이나, 키워드 구성을 통해 **정치·외교(25%)**, **경제·금융(37.5%)**, **반도체·테크(25%)**, **기타(12.5%)**의 4대 카테고리로 분류됨을 확인했습니다. 특히 경제 금융 및 첨단 산업 관련 키워드가 전체의 60% 이상을 차지해 채널의 전문성 방향성이 명확히 드러납니다.

## 1. 데이터 수집 현황 및 한계점
- **상태**: 모든 키워드의 nb_score, video_count, avg_views가 0으로 표기
- **해석**: 실제 콘텐츠 수집 전 예비 키워드 리스트이거나, API 수집 과정에서 데이터 누락 발생
- **권고**: YouTube Data API v3를 통한 재수집 또는 외부 분석 툴(VidIQ, TubeBuddy) 연동 필요

- **젠슨 황 방한 영향**: NVIDIA CEO 방한 관련 지정학적 이슈
- **TSMC 삼각 동맹 강화**: 미·대만·한국 반도체 공급망

- 안보 외교: "한미 핵잠 후속 협의", "UN 안보리 상임이사국 역할"

## 3. 콘텐츠 전략 제안

### 즉시 실행 가능한 우선순위
1. **DIFM(Do It For Me) 경제**: 아직 블루오션인 신경제 키워드로 선점 효과 기대
2. **젠슨 황 방한**: 인물 중심 스토리텔링으로 조회수 상승 가능성 높음
3. **원전주 폭염 수혜**: 계절성(6-8월) 고려한 시즌성 콘텐츠 기획

### 주의 키워드
- **금감원 ELS 과징금**: 금융 규제 관련으로 사실 확인 철저 필요
- **삼성전자 노조 붕괴**: 기업 이미지 관련 민감 이슈로 중립적 보도 필요
