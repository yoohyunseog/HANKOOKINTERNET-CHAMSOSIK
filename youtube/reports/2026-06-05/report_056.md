## 3. Data Integrity Assessment (데이터 무결성 평가)

**⚠️ Critical Issue**: 현재 제공된 데이터셋의 모든 정량적 지표(`nb_score`, `video_count`, `avg_views`, `max`, `min`)가 **0값 또는 null 상태**입니다.

**필수 조치사항**:
1. **YouTube Data API v3** 연동을 통한 실제 검색량 및 경쟁도 데이터 수집
2. **TubeBuddy** 또는 **VidIQ** 등의 서드파티 툴을 활용한 키워드 난이도(NB Score) 측정
3. **검색 기간 설정**: 최근 30일/90일/1년 데이터 비교 분석 필요
