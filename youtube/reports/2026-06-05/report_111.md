## 3. 데이터 품질 진단 및 한계점

현재 데이터셋의 모든 정량 지표(nb_score, video_count, avg_views)가 **Null 또는 0값**으로 표시되어 있어 다음과 같은 분석 한계가 존재합니다:

1. **경쟁 강도 측정 불가**: 키워드별 검색량 및 경쟁 채널 수 파악이 되지 않아 블루오션/레드오션 구분이 어려움
2. **수익성 예측 불가**: 평균 조회수 데이터 부재로 RPM/CPM 기반 수익 모델링이 불가능함
3. **시계열 분석 불가**: views 배열의 미수집으로 트렌드 상승/하강 곡선 분석이 불가능함

**즉시 조치 필요사항**: YouTube Data API v3 또는 외부 분석 툴(예: VidIQ, TubeBuddy)을 통한 메타데이터 재수집이 선행되어야 합니다.
