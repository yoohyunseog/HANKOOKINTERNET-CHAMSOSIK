# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 총 13개 키워드에 대한 YouTube 콘텐츠 성과를 평가한 결과입니다. **전체 키워드 중 84.6%(11개)가 유효한 영상 데이터 없이 노출되지 않은 상태**이며, 실제 콘텐츠가 확인된 키워드는 '오늘의 주요 뉴스'와 '정치 당' 2개에 불과합니다. 데이터 수집 오류 또는 콘텐츠 미게재 가능성이 높아 실질적인 키워드 전략 수립에 한계가 있습니다.

## 1. 데이터 품질 현황

| 구분 | 키워드 수 | 비율 | 주요 특징 |
|------|----------|------|-----------|
| **유효 데이터** | 2개 | 15.4% | 실제 영상 및 조회수 확인 가능 |
| **미게재/오류** | 11개 | 84.6% | video_count=0, 조회수 데이터 없음 |

**심각한 데이터 결함**: '유로 환율 전망', '원달러 환율 전망', '코스피 8000 시대 전망' 등 금융·경제 키워드 6개(46%)를 포함한 대부분의 키워드에서 콘텐츠가 확인되지 않습니다.

- **'정치 당'**: 6,297 조회수 (김태현의 정치쇼 - 박정훈 의원 인터뷰)
- **'오늘의 주요 뉴스'**: 850 조회수 (SBS 12뉴스)

**인사이트**: 정치 토론 콘텐츠가 뉴스 요약 콘텐츠 대비 **7.4배 높은 조회수**를 기록. 시사·정치 카테고리에서 심층 인터뷰 형식이 단순 뉴스 클리핑보다 높은 사용자 참여를 유도함을 시사합니다.

### 2.2 콘텐츠 품질 평가
- **SBS 뉴스**: 850뷰로 채널 구독자 대비 저조한 성과. 썸네일 또는 제목 최적화 필요
- **정치쇼**: 6,297뷰로 양호한 성과. 정치 당 관련 키워드에서 높은 검색 수요 확인
