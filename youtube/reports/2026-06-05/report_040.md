# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드에 대한 성과 데이터 분석 결과를 제시합니다. **현재 수집된 모든 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표시**되어 있어, 유효한 성과 데이터가 확인되지 않는 상태입니다. 따라서 본 분석은 키워드 구성의 특성과 주제별 트렌드 패턴에 중점을 두고 진행되었습니다.

## 1. 데이터 수집 현황 및 품질 진단

| 구분 | 상태 | 비고 |
|------|------|------|
| **nb_score** | 0 (전체) | 노출 빈도 및 경쟁력 지표 미수집 |
| **avg_views** | 0 (전체) | 평균 조회수 데이터 누락 |
| **video_count** | 0 (전체) | 관련 영상 수 집계 불가 |
| **views/videos** | Empty Array | 원시 데이터 미로드 |

**진단 결과**: API 연동 오류, 데이터 수집 기간 미설정, 또는 검색 필터링 조건 불일치로 인해 정량적 분석이 불가능한 상태입니다. 즉각적인 데이터 재수집이 필요합니다.

## 2. 키워드 카테고리 분석

제공된 키워드는 **시사/뉴스 중심 채널**의 특성을 명확히 보여줍니다:

### 2.1 정치·외교 (40%)
- 유엔 안보리 상임이사국
- 한미 핵잠 재처리 협의  
- 이란 혁명수비대 이스라엘
- 오세훈 서울시장 5선
- 투표 용지 부족 사태

### 2.2 경제·금융·기업 (37.5%)
- 젠슨 황 방한 / TSMC 최태원 만남 (반도체/AI)
- 공매도 재개 논란 / 주가누르기방지법 (자본시장)
- 이더리움 가격 전망 (가상화폐)
- 삼성전자 초기업노조 과반 붕괴 (노사관계)
- 스타벅스 탱크데이 결제액 감소 (유통)

### 2.3 산업·에너지 (12.5%)
- 해양플랜트 수주 루이지애나
- 원전주 폭염 예보 반등

### 2.4 기타 (10%)
- 오늘의 주요 뉴스 🔒 (섹션 타이틀 추정)
- 미국 한국 면담

## 3. 시사점 및 전략적 제언

### 🔴 긴급 조치 필요사항
1. **데이터 파이프라인 점검**: 현재 모든 성과 지표가 0으로 표시되어 콘텐츠 성과 측정이 불가능합니다. 검색 API 할당량, 수집 기간 설정, 키워드 정확도를 즉시 확인해야 합니다.

2. **"오늘의 주요 뉴스 🔒" 키워드 처리**: 랭킹 1위 키워드에 잠금 아이콘(🔒)이 포함된 것으로 보아 프리미엄 콘텐츠 또는 구독자 전용 섹션일 가능성이 있습니다. 이는 데이터 수집 시 인증 토큰 문제를 야기할 수 있습니다.

### 📊 콘텐츠 전략 제안
- **실시간 뉴스 대응형 채널**로서의 정체성이 명확하므로, 데이터 수집 주기를 최소 일 단위(Daily)로 설정할 것을 권장합니다.
- **"젠슨 황 방한"**, **"TSMC 최태원 만남"** 등 반도체/AI 관련 키워드가 동시에 노출된 것은 현재 글로벌 공급망 이슈에 대한 시청자 관심이 높음을 시사합니다. 해당 분야 콘텐츠 강화를 고려하세요.
