# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 총 16개 키워드에 대한 YouTube 채널 분석 데이터를 바탕으로 작성되었습니다. **현재 수집된 데이터 상 모든 키워드의 노출 지수(nb_score), 조회수(views), 영상 수(video_count) 등이 0으로 표기**되어 있어, 해당 키워드들이 아직 콘텐츠화되지 않은 신규 트렌드 키워드이거나, 데이터 수집 과정에서의 지연/오류가 발생한 상태로 판단됩니다.

따라서 본 분석은 정량적 수치 기반 분석 대신, **키워드의 정성적 특성과 시장적 잠재력**을 중심으로 콘텐츠 전략 방향을 제시합니다.
