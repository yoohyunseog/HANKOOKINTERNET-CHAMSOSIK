# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 총 16개 키워드에 대한 YouTube 검색 트렌드 분석을 수행하였으나, **수집된 모든 정량적 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표기**되어 있어 통계적 분석에 한계가 있습니다. 따라서 본 보고서는 키워드의 **의미적 카테고리 분류**와 **주제별 트렌드 패턴** 분석에 중점을 두었습니다.

## 2. 데이터 현황 및 한계점

| 항목 | 상태 | 비고 |
|------|------|------|
| 키워드 수 | 16개 | 순위 1~16위 |
| 평균 조회수 | 0 | 데이터 미수집 |
| 영상 수 | 0 | 데이터 미수집 |
| 경쟁 강도(nb_score) | 0 | 데이터 미수집 |

**※ 데이터 품질 경고**: 모든 수치 데이터가 초기화 상태이므로, 실제 검색량 기반의 경쟁 분석은 불가능합니다. 향후 API 재호출 또는 데이터 재수집이 필요합니다.

## 3. 키워드 카테고리 분석

### 3.1 정치/사회 (25%, 4개)
- **서울시장 5선 의미**, **사전투표율 역대 기록**, **잠실 투표소 소송 전말**, **오늘의 주요 뉴스 🔒**
- 특징: 선거 관련 키워드가 다수 포진, 뉴스 실검 트렌드 반영

### 3.2 경제/금융 (19%, 3개)
- **원달러 환율 전망**, **코스피 급락 이유 반도체**, **사이드카 발동 조건**
- 특징: 단기 시장 변동성에 대한 투자자 관심사 반영

### 3.3 기술/과학 (25%, 4개)
- **GPU 개발자 컨퍼런스**, **화성 탐사선 메이븐 성과**, **탄소중립 기술 개발 현황**, **유기분자 합성 신약 개발**
- 특징: 첨단 기술 및 우주/바이오 분야의 전문성 요구 키워드

### 3.4 문화/스포츠/국제 (19%, 3개)
- **US 여자 오픈 골프 중계**, **뉴욕 미니멀리즘 전시회**, **빔 벤더스**, **쿠바 제재 미국 정부**
- 특징: 해외 콘텐츠 및 국제 정세에 대한 니치 관심사

### 3.5 생활/정보 (12%, 2개)
- **통신사 통합 요금제 비교**

## 4. 시사점 및 제언

### 콘텐츠 전략 제안
1. **뉴스/시사 채널**: 정치(25%) + 경제(19%) 키워드가 44%를 차지하므로, 선거 및 금융 시장 콘텐츠가 유효
2. **테크 채널**: GPU, 화성 탐사, 탄소중립 등 고부가가치 기술 키워드 다수 존재
3. **초기 진입 기회**: 모든 키워드의 `video_count`가 0으로 표기되어 있으나, 실제로는 경쟁이 적은 **블루오션 키워드**일 가능성 존재

### 데이터 보완 필요사항
- YouTube Data API v3를 통한 실제 검색량 및 경쟁 채널 분석 재수행
- `nb_score` 및 조회수 데이터의 정상 수집 확인
- 키워드별 **검색 의도(Intent)** 분석 추가 필요

## 5. 결론
