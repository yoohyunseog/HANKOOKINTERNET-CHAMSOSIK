# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드에 대한 성과 메트릭 분석을 수행하였으나, **모든 정량적 지표(nb_score, video_count, avg_views 등)가 0으로 수집되어 실제 성과 측정이 불가능한 상태**임을 확인하였습니다. 이하에서는 키워드 구성의 질적 특성과 카테고리별 트렌드 분석을 중심으로 전략적 방향성을 제시합니다.

## 1. 데이터 품질 현황

| 지표 | 상태 | 분석 가능성 |
|------|------|-------------|
| 조회수(views) | 미수집 | 불가 |
| 영상 수(video_count) | 미수집 | 불가 |
| NB Score | 미수집 | 불가 |
| **키워드 텍스트** | **확보** | **가능** |

**결론**: 현재 데이터는 템플릿 상태로 보이며, 실제 YouTube API 연동 또는 검색량 데이터 수집이 필요합니다.

## 2. 키워드 카테고리 분석

### A. 정치/선거 트랙 (Rank 1-8)
- **핵심 주제**: 제8회 전국동시지방선거 관련 이슈
- **세부 키워드**: 
  - 선거 운영: "투표지 부족 사태", "교차투표 현상", "경찰 투표소 시위"
  - 정치 분석: "민주당 압승 비결", "서울시장 5선 과제"
  - 뉴스 큐레이션: "오늘의 주요 뉴스 🔒"

**특징**: 시의성이 매우 높은 선거 관련 키워드로, 단기적 트래픽 집중이 예상되나 선거 이후 수요 급감이 우려됨.

### B. 경제/금융 트랙 (Rank 9-16)
- **시장 동향**: "코스피 5000 돌파", "뉴욕증시 반도체 랠리", "비트코인 최저가"
- **금융 상품**: "ELS 금감원 제재", "커버드콜 ETF", "국민연금 롤러코스터"
- **산업 이슈**: "데이터센터 조성", "헬기 도입 지연", "반도체 쏠림"

**특징**: 장기적 검색 수요가 안정적인 evergreen 콘텐츠에 적합하며, 특히 "커버드콜 ETF", "ELS" 등은 투자자 교육 콘텐츠로 활용 가능.

## 3. 전략적 제언

### 즉시 실행 필요사항
1. **데이터 수집 인프라 구축**: YouTube Data API v3 연동을 통해 실제 조회수, 좋아요 수, 댓글 참여율 수집
2. **키워드 검색량 확인**: Google Trends 또는 Naver Data Lab을 통해 월간 검색량 확인 필요

### 콘텐츠 전략 방향
- **정치 키워드**: 선거 이후 후속 이슈(당정 관계, 지방정부 과제)로 키워드 마이그레이션 필요
- **경제 키워드**: "코스피 5000", "커버드콜 ETF" 등 검색량 상위 키워드 중심의 심층 분석 콘텐츠 기획 권장

### 리스크 관리
- 🔒 표시가 있는 "오늘의 주요 뉴스"는 유료 콘텐츠 또는 구독자 전용 콘텐츠로 보이므로, 접근성 제한으로 인한 낮은 도달률을 고려해야 함.
