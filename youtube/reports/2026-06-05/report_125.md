# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 채널의 콘텐츠 전략 수립을 위한 키워드 포트폴리오 분석 결과입니다. 현재 수집된 16개 핵심 키워드는 정치·경제·사회·문화 등 광범위한 영역을 포괄하나, 실제 성과 지표(video_count, avg_views 등)가 미수집 상태이므로 **정성적 콘텐츠 방향성 분석**에 중점을 두었습니다.

---

## 1. 키워드 포트폴리오 현황

### 1.1 주제별 분류
| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **경제/금융** | 코스피 5000 돌파, 원화 달러 환율, 반도체 호황 경상수지, HBM 반도체 전망, 장기 분할 매도 전략 | 시장 동향 및 투자 전략 중심 |
| **정치/선거** | 지방선거 투표지 부족, 서울시장 5선, 발달장애인 참정권 운동 | 선거법 및 정치 참여 이슈 |
| **스포츠** | 메이저리그 다저스, 로스앤젤레스 다저스 경기 | 해외 스포츠 특화 콘텐츠 |
| **사회/안보** | 테라파워 발전소, 미국 쿠바 제재 현황, 해병대 전작권 전환 | 에너지·외교·국방 복합 이슈 |
| **문화/건강** | 미니멀리즘 예술가 캐롤린, 간 건강 UDCA | 틈새 라이프스타일 및 의학 정보 |

### 1.2 데이터 품질 진단
- **수집률**: 0% (모든 지표 미수집 상태)
- **영상 자산**: 공란 (views[], videos[] 배열 비어있음)
- **NB Score**: 산출 불가 (데이터 부재)

> ⚠️ **주의**: 현재 데이터는 키워드 기획 단계의 후보군 목록으로 보이며, 실제 유튜브 검색 성과 분석이 이루어지지 않은 상태입니다.

## 2. 전략적 제안

### 2.1 콘텐츠 클러스터링
**경제 블록** (5개 키워드)이 가장 밀도 높은 클러스터를 형성하고 있습니다. 
- *코스피 5000*, *HBM 반도체*, *환율* 키워드를 연계한 **"반도체 슈퍼사이클 특집"** 기획 권장
- *장기 분할 매도 전략*과 결합하여 투자자 교육 콘텐츠로 확장 가능

### 2.2 틈새 기회 분석
- **발달장애인 참정권**: 사회적 가치(Social Value)와 정치적 이슈의 교차점으로 공공기관·NGO 협업 콘텐츠 적합
- **테라파워 발전소**: SMR(소형모듈원자로) 글로벌 동향과 결합한 미래 에너지 분석 콘텐츠

### 2.3 우선순위 조정 필요 키워드
- **"오늘의 주요 뉴스 🔒"**: 락(🔒) 표시는 구독자 전용 콘텐츠를 의미할 수 있으나, 검색 최적화 관점에서 비효율적. **"오늘의 뉴스 브리핑"** 등으로 정제 필요
- **"로스앤젤레스 다저스 경기"**: "메이저리그 다저스"와 중복 가능성. 통합 또는 세분화(하이라이트 vs 풀경기) 전략 수립 필요

## 3. 향후 실행 계획

### 단기 (1-2주)
1. YouTube Data API v3 연동하여 실제 검색량, 경쟁 강도, 평균 조회수 수집
2. NB Score(Niche Benchmark) 산출 공식 검증 및 역산

### 중기 (1개월)
- 상위 5개 키워드에 대한 **콘텐츠 갭 분석** (Competitor Content Gap Analysis)
- *서울시장 5선*, *지방선거* 등 시의성 키워드의 검색 트렌드 주기 분석

### 장기 (분기)
- 16개 키워드 중 성과 상위 30% 선별하여 **채널 대표 콘텐츠**로 육성
- 비성과 키워드는 아카이빙 또는 재기획
