# YouTube 채널 키워드 분석 리포트
**분석 기간:** 실시간 트렌딩 데이터  
**채널 성격:** 뉴스/시사 보도 채널  

---

## 1. Executive Summary

본 분석은 채널의 핵심 키워드 16개에 대한 노출도 및 성과 지표를 점검한 결과입니다.  
**주요 발견사항:** 현재 수집된 모든 키워드의 정량적 지표(nb_score, video_count, avg_views)가 **0값**으로 표시되어 데이터 정합성 문제가 확인되었습니다. 이는 API 수집 오류, 데이터 미동기화, 또는 비공개 콘텐츠 집계 제한 등의 기술적 이슈로 추정됩니다.

---

## 2. 데이터 품질 진단

| 지표 | 상태 | 분석 |
|------|------|------|
| **NB Score** | 0 (전체) | 키워드 경쟁력/노출 점수 미측정 |
| **Video Count** | 0 (전체) | 색인된 영상 수 미집계 |
| **Views** | Empty Array | 조회수 데이터 누락 |
| **Trending** | 활성 | 키워드 자체는 실시간 검색어로 등록됨 |

**조치 권고:** 데이터 수집 모듈의 로그 확인 및 YouTube Data API v3 할당량 초과 여부 점검이 필요합니다.

## 3. 키워드 트렌드 분석 (Qualitative)

데이터 정량화는 불가하나, 키워드 구성을 통해 채널의 **콘텐츠 포트폴리오**를 다음 4개 영역으로 분류할 수 있습니다:

### A. 정치/선거 (37.5%)
- *오세훈 5선 서울시장 당선*, *부산시장 당선자 전재수*, *한동훈 보수 재건 선언*
- *잠실7동 투표소 시위*, *투표 용지 부족 사태*
- **특징:** 제8회 전국동시지방선거 후폭풍 및 당권 경쟁 관련 이슈 집중

### B. 경제/금융 (25%)
- *공매도 규제 현황*, *원달러 환율 1529원*, *코스피 1만2000 전망*
- *정부 최고가격제 해제 검토*, *수입차 판매 순위 테슬라*
- **특징:** 환율 변동성 및 증시 변동에 대한 시장 심리 반영

### C. 국제/외교 (25%)
- *젠슨 황 방한* (NVIDIA CEO), *유엔 안보리 상임이사국*
- *이란 혁명수비대 이스라엘군*, *헤즈볼라 휴전 제안 거부*
- *이르면 내달 美서 2차 회의*
- **특징:** 중동 지정학 리스크 및 반도체 산업 외교 병행

### D. 일반 뉴스 (12.5%)
- *오늘의 주요 뉴스 🔒* (구독자 전용 콘텐츠 추정)

## 4. 전략적 제안

### 즉시 실행 과제
1. **데이터 인프라 점검**
   - YouTube Analytics 연동 상태 확인
   - 검색 콘솔(Search Console) 키워드 임프레션 데이터 대조

### 콘텐츠 최적화
2. **시의성 강화**
   - *젠슨 황 방한*, *원달러 환율* 등 검색량 급증 키워드에 대한 **숏폼(Shorts)** 선제 투고
   - 정치 키워드는 선거 이후 후속 보도보다 **정책 분석**으로 전환 필요

3. **시리즈화 기회**
   - *공매도 규제* ↔ *코스피 전망* ↔ *환율* 연계 분석 콘텐츠 기획
   - 중동 리스크(*이란*, *헤즈볼라*) 에너지 가격 파급효과 연결 보도

## 5. 결론

다만, 키워드 구성이 **정치·경제·국제** 3축으로 명확히 정렬되어 있어 채널 아이덴티티는 일관성을 유지하고 있습니다. 

**우선순위:** 데이터 복구 → 실시간 검색어 대응 콘텐츠 제작 → 구독자 전용 콘텐츠(*오늘의 주요 뉴스 🔒*)의 공개 범위 전략 수립
