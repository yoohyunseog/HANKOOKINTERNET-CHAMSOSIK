### ⚠️ Critical Issue: 데이터 미수집 상태

### 필요 조치:
1. **YouTube Data API v3** 또는 **크롤링 도구**를 통한 실제 검색량 및 조회수 데이터 수집
2. **검색 경쟁률(Competition Rate)** 및 **CPC(클릭당 비용)** 데이터 추가 수집 권장
3. **시계열 데이터** 수집을 통해 키워드 트렌드 변화 추적 필요
