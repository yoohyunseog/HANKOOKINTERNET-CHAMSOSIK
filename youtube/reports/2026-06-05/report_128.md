# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 총 16개의 키워드에 대한 YouTube 채널 분석 데이터를 바탕으로 작성되었습니다. **현재 모든 키워드의 수치 데이터(nb_score, 조회수, 영상 수 등)가 0으로 표기**되어 있어, 정량적 경쟁 분석은 불가능한 상태입니다. 다만 키워드의 주제별 분류를 통해 **정치·선거(37.5%), 경제·금융(43.7%), 산업·사회(18.8%)**의 분포를 확인할 수 있으며, 이는 시의성이 높은 뉴스 및 금융 콘텐츠 중심의 채널 기획이 필요함을 시사합니다.

## 2. 키워드 카테고리 분석

### A. 정치·선거 분야 (6개 키워드, 37.5%)
- **핵심 키워드**: 지방선거 투표지 부족 사태, 서울시장 5선 당선자 과제, 민주당 압승 비결 분석, 교차투표 현상 분석, 경찰 투표소 시위 해산
- **특징**: 제8회 전국동시지방선거(2022년 기준) 및 관련 정치 현상에 대한 심층 분석 콘텐츠를 예상
- **시사점**: 선거 이후 당정 갈등, 투표 행태 분석 등 후속 보도 콘텐츠 기획 가능

### B. 경제·금융 분야 (7개 키워드, 43.7%)
- **증시 동향**: 코스피 5000 돌파 전망, 뉴욕증시 반도체 랠리, 반도체 쏠림 바이오 위기
- **금융 상품**: 국민연금 롤러코스터 국장, ELS 금감원 제재, 커버드콜 ETF 인기
- **글로벌 자산**: 비트코인 최저가 동향, 중동 긴장 환율 영향
- **특징**: 단기 트레이딩 및 중장기 투자 전략 콘텐츠에 적합한 키워드군

### C. 산업·사회 분야 (3개 키워드, 18.8%)
- **산업 정책**: 데이터센터 조성 계획, 헬기 도입 지연 문제
- **뉴스 큐레이션**: 오늘의 주요 뉴스 🔒 (잠금 표시로 인해 프리미엄 콘텐츠 가능성)

## 3. 데이터 품질 및 한계 분석

| 항목 | 현황 | 분석 가능성 |
|------|------|------------|
| **nb_score** | 0 (전 키워드) | 난이도/경쟁도 분석 불가 |
| **video_count** | 0 (전 키워드) | 시장 포화도 파악 불가 |
| **avg_views** | 0 (전 키워드) | 수익성 예측 불가 |
| **views/videos** | Empty Array | 참고 영상 분석 불가 |

**결론**: 현재 데이터는 **키워드 선별 단계**로 보이며, 실제 YouTube Data API를 통한 수집이 완료되지 않은 상태입니다. 본격적인 콘텐츠 기획을 위해서는 위 키워드들의 실제 검색량, 경쟁 채널 수, 평균 조회수 데이터 추가 수집이 필수적입니다.

## 4. 전략적 제언

### 즉시 실행 과제 (Short-term)
1. **데이터 수집 완료**: 제공된 16개 키워드에 대한 실제 유튜브 메트릭스 수집
2. **시의성 우선순위**: "지방선거" 관련 키워드는 선거일로부터 시간이 경과함에 따라 조회수 감소 예상. 신속한 콘텐츠화 필요

### 중장기 전략 (Long-term)
- **니치 선정**: 금융 키워드(커버드콜 ETF, ELS 제재)는 구독자 충성도가 높은 펀드/투자 채널에 적합
- **정치 분석 콘텐츠**: 교차투표, 당정 갈등 등은 2030 세대의 정치 참여 관심도를 고려한 딥다이브 콘텐츠 기획 권장
