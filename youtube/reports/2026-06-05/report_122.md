# YouTube 채널 키워드 분석 리포트

## Executive Summary (요약)

본 리포트는 총 15개 키워드에 대한 YouTube 검색 데이터 분석 결과를 제시합니다. 분석 대상 키워드는 뉴스·정치(3개), 경제·금융(3개), 기업·산업(5개), 스포츠·문화(4개) 등 4대 카테고리로 분류되며, **실시성이 높은 이슈 중심의 키워드 구성**을 보입니다. 그러나 현재 모든 키워드의 NB Score, 조회수, 영상 수 등 핵심 지표가 0으로 표기되어 있어 **실제 경쟁 강도 및 시장성 분석은 불가능한 상태**입니다.

## 1. 키워드 카테고리 분석

### 1.1 뉴스·정치 이슈 (Rank 1-3)
- **"오늘의 주요 뉴스"**, **"투표용지 부족 사태"**, **"지방선거 결과 분석"**
- 시의성이 중요한 뉴스 키워드로, **단기 조회수 급증 가능성**이 높으나 지속성은 낮은 특성을 보입니다.
- 특히 선거 관련 키워드는 정치적 중립성 및 사실 확인이 필수적인 영역입니다.

### 1.2 경제·금융 정보 (Rank 4, 7, 14)
- **"코스피 3000 돌파 전망"**, **"중앙은행 금리 정책"**, **"ETF 순자산 규모 순위"**
- 투자자 대상의 **고관여도 콘텐츠**로, 조회수 대비 전환율(구독·좋아요)이 높을 가능성이 있습니다.
- "코스피 3000"은 심리적 저항선으로서 지속적인 검색 수요가 예상됩니다.

### 1.3 기업·산업 동향 (Rank 5, 8, 12, 13, 15)
- **"테라파워 원자력 발전"**, **"홈플러스 경영 현황"**, **"삼성전자 반도체 장비 수주"**, **"애플 AI 수혜주"**, **"캐나다 잠수함 수주 현대차"**
- **글로벌 기업(애플, 테라파워)과 국내 대기업(삼성, 현대차)이 혼재**된 구조입니다.
- 방산(현대차 잠수함)과 첨단 기술(반도체, AI)이 교차하며 **산업 전문성이 요구되는 영역**입니다.

### 1.4 스포츠·문화 (Rank 6, 9, 10, 11)
- **"메이저리그 다저스"**, **"일본 축구 팀"**, **"로스앤젤레스 단"**(산불 추정), **"미니멀리즘 미술 전시"**
- 해외 스포츠와 문화 소식이 포함되어 **글로벌 콘텐츠 비중**을 확인할 수 있습니다.

## 2. 데이터 품질 진단 및 한계

**심각한 데이터 결함이 확인**되었습니다. 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 표기되어 있어 다음과 같은 분석이 불가능합니다:
- 경쟁 강도(Competition Level) 측정
- 예상 조회수(Expected Views) 산정  
- 수익화 가능성 평가

이는 데이터 수집 API 오류, 검색 기간 설정 미스, 또는 필터링 로직 문제로 추정됩니다.

## 3. 전략적 제언

### 즉시 실행 필요 사항
1. **데이터 재수집**: YouTube Data API v3를 통해 실제 검색량, 경쟁 채널 수, 평균 조회수 데이터 확보가 긴급합니다.
2. **키워드 세분화**: "오늘의 주요 뉴스"와 같은 **범용 키워드는 경쟁이 과열**되어 있으므로, "투표용지 부족 사태"와 같은 **특정 이슈 키워드로 포지셔닝**을 좁히는 것이 유리합니다.

- **뉴스·이슈 키워드(30%)**: 단기 조회수 확보용으로 활용하되, **
