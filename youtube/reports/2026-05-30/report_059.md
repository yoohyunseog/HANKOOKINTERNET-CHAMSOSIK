# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 16개 키워드에 대한 초기 수집 데이터를 분석한 결과입니다. 현재 제공된 데이터는 **성과 지표(Views, NB Score, Video Count 등)가 미수집 상태**로, 실제 콘텐츠 성과 분석보다는 키워드 기획 및 카테고리 전략 수립 단계의 참고 자료로 활용 가능합니다.

## 1. 데이터 품질 현황
- **수집 상태**: 모든 키워드의 조회수(avg_views), 경쟁도(nb_score), 영상 수(video_count)가 0값으로 표기
- **분석 한계**: 실제 검색량 대비 공급량 분석, 경쟁 강도 측정, 수익성 예측이 불가능한 상태
- **권고사항**: 본 데이터를 바탕으로 실제 YouTube 검색 API 또는 분석 툴(예: VidIQ, TubeBuddy)을 활용한 2차 데이터 수집 필요

## 2. 키워드 카테고리 분석

### A. 시사/정치 (25%, 4개)
- 오늘의 주요 뉴스 🔒, 지방선거 사전투표율, 부실 교량 안전 점검, 원전 전력 공급 중단
- **특징**: 시의성이 강하며, Shorts 형식의 빠른 뉴스 클립에 적합

### B. 경제/금융 (31%, 5개) 
- 주식 시장 불장 분석, 가상자산 과세 찬반 논란, 국민연금 노후 대비, 유턴기업 지원 정책, 외국인 국내 주택 보유
- **특징**: 2030-4050 세대의 재테크 니즈와 연결된 고관여 키워드군

### C. 기술/IT (19%, 3개)
- AI 반도체 기술 개발, 삼성 HBM4E AI칩, LG 네이버 협업
- **특징**: B2B 및 테크 열성 팬층 타겟팅 가능한 전문성 높은 키워드

### D. 건강/의학 (13%, 2개)
- 코로나19 혈관 노화, 수면 규칙성 심혈관 건강
- **특징**: 중장년층을 타겟으로 한 롱폼 콘텐츠 적합

### E. 라이프스타일 (13%, 2개)
- 밀크티 인기 가게 비결, 비확장 발코니 인테리어
- **특징**: 브이로그(Vlog) 및 리뷰 콘텐츠 형태로 전환 용이

## 3. 전략적 제안

**단기 전략**: 데이터 정합성 확보를 위해 실제 검색량 및 경쟁 채널 분석 선행  
**중장기 전략**: 
- 경제/금융 키워드(31%)가 가장 비중이 크므로 재테크 채널로의 포지셔닝 고려
- AI 반도체(삼성 HBM4E)와 같은 기술 키워드는 조회수 대비 CPM이 높은 우수 키워드로 예상
- "오늘의 주요 뉴스"는 검색 유입보다는 구독자 리텐션용 시리즈로 기획 권장

## 결론
현재 데이터는 키워드 아이디어 제안 단계로 보이며, 실제 콘텐츠 기획을 위해서는 **검색량 대비 경쟁률(공급량) 데이터의 추가 수집이 필수적**입니다. 특히 경제/기술 분야의 키워드 밀도가 높아 해당 분야로의 채널 특화를 검토할 것을 권장합니다.
