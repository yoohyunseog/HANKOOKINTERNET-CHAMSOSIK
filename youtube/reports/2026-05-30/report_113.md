# YouTube 채널 키워드 분석 리포트

**분석일:** 2024년  
**대상:** 키워드 15개  
**상태:** 초기 발굴 단계 (성과 지표 미측정)

---

## 1. Executive Summary

본 리포트는 YouTube 채널 운영을 위한 키워드 후보 15개에 대한 **초기 발굴 분석**입니다. 현재 제공된 데이터는 순위별 키워드 목록만 확인 가능하며, 조회수(nb_score), 경쟁강도, 영상 수 등의 정량적 지표는 수집되지 않은 상태입니다. 따라서 본 분석은 키워드의 **주제별 분류 및 콘텐츠 방향성**에 중점을 두고 있습니다.

---

## 2. 키워드 카테고리 분석

수집된 15개 키워드를 주제별로 분류한 결과如下:

| 카테고리 | 키워드 | 특징 |
|---------|--------|------|
| **정치/사회** | 오늘의 주요 뉴스 🔒, 한국 지방선거 투표율, 사전투표율, 발달장애인 참정권 | 시의성 높은 뉴스 키워드. 🔒 표시는 유료 콘텐츠 또는 제한적 접근 가능성을 시사 |
| **경제/금융** | 코스피 시가총액, 삼성전자 HBM4E, 개미주식 삼전닉스 레버리지 | 반도체/주식 중심의 투자 정보 키워드. '개미투자자' 타겟팅 명확 |
| **산업/인프라** | 한미 동맹 현대화, 반도체 클러스터 용인, GTX 호택 아파트, F-15K, 폭염 기후위기 | 안보, 부동산, SOC 인프라 관련. 지역 이슈(용인, 목포) 포함 |
| **라이프스타일** | 반려동물행동지도사, 피시 샤퀴테리 목포 셰프, 비확장 | 전문 자격증 및 틈새 요리 콘텐츠. '비확장'은 맥락 불명확 |

### 2.1 핵심 인사이트
- **뉴스/시사(40%)**: 정치 선거 관련 키워드가 상위권을 차지하여 채널의 정치 성향 가능성을 시사
- **경제 집중(27%)**: 반도체(삼성전자, HBM4E)와 부동산(GTX)에 대한 높은 관심 반영
- **지역 밀착**: 용인(반도체), 목포(셰프) 등 특정 지역 이슈 포함

## 3. 데이터 품질 진단

### ⚠️ Critical Issue: 측정 지표 부재
현재 모든 키워드의 핵심 성과 지표가 `0`으로 표기되어 있습니다:
- **nb_score (경쟁 점수)**: 0
- **video_count (영상 수)**: 0  
- **avg_views (평균 조회수)**: 0
- **views/videos array**: Empty

**영향:** 검색량, 경쟁도, 수익화 가능성 등의 정량적 분석이 불가능하여 키워드 우선순위 선정에 한계가 있습니다.

---

## 4. 전략적 제언

### 단기 조치 (1-2주 내)
1. **데이터 재수집**: YouTube Data API 또는 SEO 도구(TubeBuddy, vidIQ)를 활용하여 실제 검색량, 경쟁 채널 수, 평균 조회수 수집
2. **'비확장' 키워드 검증**: 의미가 모호한 키워드의 정확한 맥락 파악 필요

### 중장기 전략
- **정치/경제 채널 포지셔닝**: 뉴스와 주식 키워드가 혼재된 것으로 보아 '시사 경제' 복합 채널 가능성을 검토
- **틈새 키워드 발굴**: "피시 샤퀴테리"와 같은 저경쟁 니치 키워드에 대한 선점 전략 수립
