# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 채널의 콘텐츠 전략 수립을 위한 키워드 우선순위 분석 자료입니다. 총 16개의 타겟 키워드를 대상으로 경쟁 강도(nb_score) 및 조회수 성과 지표를 분석하였습니다.

## 2. 데이터 품질 진단 (Critical Issue)

**⚠️ 데이터 수집 이상 감지**
- 전체 키워드의 `nb_score`, `video_count`, `avg_views`가 **일괄 0값**으로 표기됨
- `views` 및 `videos` 배열 미수집 상태
- **분석 결론**: 현재 데이터는 통계적 유의성을 확보하지 못하여 경쟁 난이도 및 시장 규모 판단이 불가능함

## 3. 키워드 주제 클러스터링 분석

수집된 키워드 텍스트 기반 주제 분류 결과는 다음과 같습니다:

| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **경제/금융** | 시가총액 2000조 돌파, 삼성전자 주가 급등, 청년 적금 연 19%, 주유소 할인 전쟁, 아파트 분양가 상승률 | **5개(31%)** - 비중 최대, 시사 경제 채널 성향 추정 |
| **정치/사회** | 낙선운동 여론 반응, 지방선거 사전투표율, 한미 동맹 현대화 협의 | **3개(19%)** - 선거 및 외교 이슈 중심 |
| **사건/사고** | 마약왕 수사 최신 동향, 고가도로 붕괴 사고 | **2개(13%)** - 사회적 이슈 트래킹 |
| **산업/기술** | 광전자 산업 발전 전망, 친환경 재료 농업 효과 | **2개(13%)** - 전문 산업 정보 |
| **기타** | 오늘의 주요 뉴스, 친선 경기 하이라이트, 첫 번째 남자 인터뷰, 코로나19 혈관 노화 | **4개(25%)** |

## 4. 전략적 제언

### 4.1 데이터 인프라 보완
- YouTube Data API v3 연동 상태 점검 및 수집 로그 확인 필요
- `nb_score` 산출 알고리즘(경쟁 채널 수 대비 조회수 비율) 검증
- 최소 30일간의 시계열 데이터 확보 권장

### 4.2 콘텐츠 기획 방향
**경제 금융 중심 채널**로 포지셔닝될 가능성이 높음:
- **즉시성 키워드**: "삼성전자 주가 급등", "시가총액 2000조" → 단기 조회수 급등 예상
- **정책 정보 키워드**: "청년 적금 연 19%" → 타겟 세대(20대) 구독 유도 효과
- **이슈 키워드**: "마약왕 수사", "고가도로 붕괴" → 검색 알고리즘 노출 우위
