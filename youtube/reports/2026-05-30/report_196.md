# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

분석 대상 16개 키워드 중 **실제 영상 데이터가 존재하는 키워드는 2개(12.5%)**에 불과하며, 나머지 87.5%는 영상 수집 실패 또는 미등록 상태입니다. 수집된 데이터조차 평균 조회수 산정 오류(0값 표기)와 같은 품질 이슈가 확인되어, **현재 데이터셋은 의사결정에 활용하기에 신뢰도가 부족**한 실정입니다.

## 2. 데이터 품질 및 수집 현황 분석

### 2.1 데이터 공백 현황
- **Zero-data 키워드**: 14개 (87.5%) - `video_count`, `views`, `nb_score` 등 모든 지표가 0값
- **유효 데이터 키워드**: 2개 (12.5%)
  - `사전투표율 여야 해석` (조회수: 1,081 / 연합뉴스TV)
  - `이란 합의 행동 신뢰` (조회수: 462 / YTN)

### 2.2 데이터 처리 오류
- `avg_views` 계산 로직 오류: 개별 영상 조회수가 존재함에도 평균값이 0으로 표기
- `subtitle_summary` 필드에 메타데이터(영어 프롬프트 설명)가 포함된 데이터 오염 현상

## 4. 경쟁 환경 분석

### 4.1 미디어사 독점 구조
유효 데이터를 보유한 키워드 모두 **연합뉴스TV, YTN 등 공중파/뉴스 전문 채널**이 독점하고 있습니다. 이는:
- 뉴스 키워드의 경우 **실시간성과 공신력**이 핵심 경쟁요인임을 시사
- 개인/기업 채널의 진입 시 **속도 전쟁** 또는 **심층 분석** 차별화 필요

데이터가 수집되지 않은 키워드 중 다음은 경쟁이 낮을 가능성이 있습니다:
- `MZ세대 K이너웨어 일본 진출`: 해외 진출 사례, 소비 트렌드 분석

- `국민성장펀드 완판 서민`: 금융 상품 리뷰/분석
