**YouTube 채널 키워드 분석 리포트**

## 1. Executive Summary

본 리포트는 대상 채널의 키워드 포트폴리오에 대한 초기 분석 결과를 제시합니다. 현재 수집된 16개 키워드는 시사·경제 중심의 heavy-weight 토픽과 엔터테인먼트·기술 키워드가 혼재된 구조를 보이나, **모든 성과 지표(nb_score, 조회수, 영상 수)가 미측정 상태**로 확인되어 데이터 기반 성과 분석은 불가능한 상황입니다.

## 2. 키워드 포트폴리오 분석

### 2.1 카테고리별 분류
수집된 키워드는 다음 4개 섹터로 분류됩니다:

| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **시사/사회** | 오늘의 주요 뉴스, 주한 미군, 의정부 싱크홀, 서소문 고가도로 붕괴, 정치인 TV토론 | 시의성 높은 뉴스 키워드 |
| **경제/금융** | SK이노베이션, 코스피 하락, 부채 경고 IMF 전망, 삼성전자 젠슨 황 방한, SK하이닉스 시가총액, 외국인 주택 소유 현황 | 기업 뉴스 및 거시 경제 지표 |
| **엔터테인먼트** | 백룸 쿠키, 스파이에어 내한공연, 광주 신세계 | 대중문화 및 지역 상권 |
| **기술/글로벌** | AI 패러독스, 우크라이나 원전 전력 중단 | 첨단 기술 및 국제 이슈 |

### 2.2 키워드 특성 진단
- **검색意圖 혼재**: 정보형(뉴스)과 거래형(주식, 부동산) 키워드가 공존
- **경쟁 강도**: "코스피 하락", "삼성전자" 등은 언론사 및 증권 채널의 레드오션 키워드
- **니치 기회**: "백룸 쿠키", "스파이에어 내한공연"은 상대적으로 경쟁이 덜한 롱테일 키워드로 추정

## 3. 데이터 품질 및 수집 현황

**Critical Issue**: 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 기록되어 있습니다.

**가능한 시나리오**:
1. **초기 크롤링 단계**: 키워드 등록 후 실제 영상 데이터 매핑 전 상태
2. **채널 불일치**: 해당 키워드로 대상 채널에 업로드된 영상이 없음
3. **API 수집 오류**: YouTube Data API 호출 실패 또는 할당량 초과

## 4. 전략적 제안

### 4.1 데이터 인프라 구축
- **검색 파라미터 재설정**: `publishedAfter`, `regionCode` 등 필터 추가하여 국내 한정 최신 영상 수집
- **경쟁 채널 벤치마킹**: 동일 키워드로 조회수 상위 10위 채널의 썸네일/타이틀 패턴 분석 필요

### 4.2 콘텐츠 전략
**즉시 실행 가능한 키워드**:
- **"AI 패러독스"**: 설명형 콘텐츠로서 교육 채널과의 차별화 가능
- **"의정부 싱크홀"**, **"서소문 고가도로"**: 지역 뉴스 채널의 신속한 현장 보도가 유리한 키워드

**장기적 접근 필요**:
- **"코스피 하락"**, **"SK하이닉스"**: 전문 금융 채널과의 경쟁을 위해 뉴스 해설보다는 심층 분석 콘텐츠 기획
