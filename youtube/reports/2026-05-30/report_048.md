# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
본 리포트는 총 16개의 키워드에 대한 트렌드 분석을 수행하였으나, **현재 모든 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표시**되어 정량적 분석이 불가능한 상태입니다. 이는 데이터 수집 API 미연동, 검색 필터 미적용, 또는 초기 크롤링 단계를 의미합니다.

## 2. 키워드 카테고리 분석
제공된 키워드는 다음 5개 영역으로 분류됩니다:

| 카테고리 | 키워드 | 시장성 |
|---------|--------|--------|
| **정치/선거** | 지방선거 사전투표율, 자 TV토론, 유튜브 사전투표 독려 캠페인 | 시의성 높음 |
| **경제/금융** | 삼성전자 시총 2000조, 가상자산 과세, 국민연금, 주식 심리 | 높은 검색수 예상 |
| **기술/IT** | AI 반도체 HBM4E, 앤트로픽 투자 | 니치 but 전문성 |
| **건강/의료** | 코로나19 혈관 노화, 수면 규칙성, MASH 치료제 | 안정적 수요 |
| **라이프스타일** | 밀크티 여의도, 비확장 발코니 인테리어 | 로컬/홈콘텐츠 |

## 3. 주요 인사이트

### 3.1 정치 콘텐츠 비중 과다
선거 관련 키워드가 3개(18.75%)로, **시의성 의존도가 높은 단기 트래픽**에 집중되어 있습니다. 선거 이후 급격한 조회수 감소가 예상됩니다.

### 3.2 프리미엄 콘텐츠 표시
"오늘의 주요 뉴스 🔒"의 잠금 아이콘은 **멤버십 전용 콘텐츠** 또는 구독자 전용 콘텐츠 전략을 시사합니다.

### 3.3 데이터 수집 오류
모든 키워드의 `video_count`와 `avg_views`가 0인 것은:
- YouTube Data API 할당량 초과
- 검색 파라미터 오류 (날짜 범위, 지역 설정 등)
- 키워드 인코딩 문제

를 의심할 수 있습니다.

## 4. 전략적 제안

1. **즉시 조치**: 데이터 수집 스크립트 및 API 연결 상태 점검
2. **우선순위 설정**: 
   - 단기: 정치/선거 키워드 (시의성 활용)
   - 중장기: 경제/건강 키워드 ( evergreen 콘텐츠)
3. **경쟁 분석**: `nb_score`가 확보되면 경쟁률 대비 검색량 비율을 확인하여 **블루오션 키워드** 선별 필요
