# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
본 리포트는 제공된 16개 키워드에 대한 데이터 기반 분석 결과를 제시합니다. **현재 수집된 모든 메트릭(nb_score, 조회수, 영상 수)이 0으로 표시**되어 있어, 실제 검색량 및 경쟁 강도에 대한 정량적 분석은 불가능한 상태입니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 방향성 및 잠재적 기회 영역을 도출할 수 있습니다.

## 2. 키워드 카테고리 분석

### 2.1 정치/사회 시사 (37.5%)
- **주요 키워드**: 선거 허위사실 공표, 계엄령 장교 징계, 사전투표율 역대 최고, 한미 동맹 현대화, 지방선거 투표율 전망
- **분석**: 현재 정국 상황(선거, 군사, 외교)에 민감하게 반응하는 뉴스성 콘텐츠 중심
- **특징**: 시의성이 강하며, 선거일 기준으로 급격한 검색량 변동 예상

### 2.2 경제/금융/투자 (31.3%)
- **주요 키워드**: JP모건 체이스 한국 투자, 청년 적금 연19%, ETF 수익률 81%, 코인 거래소 대기업 투자
- **분석**: 고수익률(19%, 81%)과 같은 구체적 수치를 활용한 자극적인 금융 정보 콘텐츠
- **위험요소**: 과장된 수익률 표현으로 인한 규제 리스크 존재

### 2.3 산업/기술/국방 (18.8%)
- **주요 키워드**: 광전자 산업 동향, 삼성전자 HBM4 출하, F-15K 영공방위
- **분석**: 반도체(HBM4), 방위산업 등 첨단 제조업 및 B2B 산업 동향 다룸

### 2.4 스포츠/엔터테인먼트 (12.5%)
- **주요 키워드**: 야구 경기장 관람 정보, 싱가포르오픈 골프 하이라이트, 마약왕 영화 리뷰
- **분석**: 생활/여가 정보와 팝컬처 콘텐츠 혼재

## 3. 데이터 품질 진단

| 항목 | 상태 | 분석 |
|------|------|------|
| **검색량 데이터** | 누락 | 모든 키워드의 nb_score가 0으로, 실제 검색량 반영 안됨 |
| **영상 메트릭** | 누락 | video_count, avg_views 미수집 |
| **경쟁 분석** | 불가 | max/min 조회수 데이터 부재로 난이도 측정 불가 |

**원인 추정**: 
- YouTube Data API 할당량 초과 또는 수집 오류
- 신규 급상승 키워드로 인한 데이터 색인 지연
- 비공개/지역제한 영상 포함으로 인한 메트릭 은닉
