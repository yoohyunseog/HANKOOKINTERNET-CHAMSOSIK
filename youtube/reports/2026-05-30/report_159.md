## 3. 데이터 품질 진단 및 한계

### ⚠️ Critical Issue: 데이터 수집 실패
- **현상**: 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0값으로 기록
- **추정 원인**: 
  1. YouTube Data API 할당량 초과 또는 인증 오류
  2. 키워드 필터링 조건(검색 기간, 지역 제한 등) 과다 설정
  3. 데이터 수집 시점과 분석 시점의 시간차 미스매치
- **영향**: 경쟁 강도 분석, 조회수 기반 우선순위 산정, 콘텐츠 갭 분석 등 **정량적 의사결정이 불가능**한 상태
