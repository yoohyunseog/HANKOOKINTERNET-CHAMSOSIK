# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 2024년 실시간 검색 트렌드 기반 16개 키워드에 대한 채널 콘텐츠 전략 분석입니다. 현재 수집된 메트릭(nb_score, view_count 등)은 초기화 상태이나, 키워드 텍스트 분석을 통해 시사점을 도출하였습니다.

---

## 1. 데이터 현황 분석

### 수집 메트릭 현황
- **분석 대상**: 16개 핵심 키워드
- **데이터 품질**: 모든 수치형 지표(nb_score, video_count, avg_views) 미수집 상태
- **키워드 특성**: 실시간 뉴스/이슈 중심의 트렌딩 토픽

> ⚠️ **데이터 품질 알림**: 현재 뷰 수, 경쟁도, 영상 수 등 정량적 지표가 수집되지 않아 경쟁 분석이 제한적입니다. 향후 API 재수집이 필요합니다.

---

## 2. 키워드 카테고리 분석

### 2.1 사회/안전 이슈 (긴급성 높음)
- **의정부 싱크홀**, **서소문 고가도로 붕괴**
- 특징: 지역 기반 사고 소식, 생활 밀착형 키워드
- 콘텐츠 전략: 현장 취재, 전문가 인터뷰, 예방 수칙 안내

### 2.2 경제/기업 동향 (브랜드 연계 가능)
- **SK이노베이션**, **삼성전자 젠슨 황 방한**, **SK하이닉스 시가총액**, **코스피 하락**
- 특징: 반도체/AI 산업 중심의 기업 뉴스 클러스터 형성
- 시사점: 젠슨 황 방한 키워드는 NVIDIA와 삼성의 협력 관련 콘텐츠 기획 기회

### 2.3 정치/외교 (시사 교양 채널 적합)
- **주한 미군**, **정치인 TV토론**, **우크라이나 원전 전력 중단**
- 특징: 국제 정세 및 국내 정치 복합적 관심사

### 2.4 문화/엔터테인먼트 (젊은층 타겟)
- **백룸 쿠키**, **스파이에어 내한공연**
- 특징: 서브컬처(백룸) 및 J-rock 팬덤 중심의 니즈 키워드

### 2.5 경제 정책/부동산 (중장기 콘텐츠)
- **부채 경고 IMF 전망**, **외국인 주택 소유 현황**
- 특징: 경제 전문가 채널의 심층 분석 콘텐츠 적합

---

## 3. 전략적 시사점

### 즉시 실행 가능한 키워드
1. **"삼성전자 젠슨 황 방한"** - AI 반도체 협력 관련 기술 뉴스 콘텐츠
2. **"의정부 싱크홀"** - 지역 뉴스 채널의 신속한 현장 보도
3. **"백룸 쿠키"** - 게임/호러 콘텐츠 채널의 숏폼 기획

### 장기적 관점 키워드
- **"AI 패러독스"**: 기술 윤리 및 미래 사회 관련 심층 다큐멘터리 기획
- **"IMF 부채 경고"**: 거시경제 분석 콘텐츠 (시즌제 기획 추천)

---

## 4. 데이터 보완 권고사항

현재 모든 키워드의 검색량 및 경쟁도(nb_score) 데이터가 누락되어 있어 다음 조치가 필요합니다:

1. **YouTube Data API v3**를 통한 검색량 및 조회수 재수집
2. **경쟁 채널 분석**: 각 키워드별 상위 노출 영상의 썸네일/타이틀 패턴 분석
3. **시계열 데이터 수집**: 트렌딩 키워드의 지속 기간(24h/48h/1주) 모니터링
