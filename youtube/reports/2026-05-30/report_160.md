# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 채널의 검색 키워드 노출 현황을 분석한 결과입니다. 현재 분석 대상 16개 키워드 중 **15개(93.8%)가 아직 콘텐츠 노출 데이터가 수집되지 않은 초기 단계**로 확인되었으며, 유일하게 "AI 관련주 급등" 키워드만 1개의 비디오(조회수 263회)가 매핑되어 있습니다. 전반적으로 뉴스·시사·경제 중심의 키워드 포트폴리오를 구성하고 있으나, 실제 검색 노출로 연결된 콘텐츠는 미흡한 상태입니다.

## 1. 키워드 포트폴리오 분석

### 카테고리별 분포
수집된 키워드는 다음 4개 카테고리로 분류됩니다:

| 카테고리 | 키워드 예시 | 비중 |
|---------|------------|------|
| **정치/선거** | 지방선거 사전투표율, 사전투표 행렬 현장, 자 공약 | 25% |
| **경제/금융** | 코스피 사상 최고치, AI 관련주 급등, 삼성전자 주가 전망 | 31% |
| **사회/문화** | BTS 부락 콘서트 바가지요금, 쿠팡 한미 파열 봉합전 | 19% |
| **안보/외교** | 한미 방위비 분담 협상, 핵잠수함 보유 추진, F-15K | 19% |

*특징: 실시간 뉴스성 키워드("오늘의 주요 뉴스 🔒")와 구체적인 종목/이슈 키워드가 혼재되어 있습니다.*

2. **노출 부재**: 제작되었으나 검색 알고리즘에 노출되지 않아 데이터 미수집
