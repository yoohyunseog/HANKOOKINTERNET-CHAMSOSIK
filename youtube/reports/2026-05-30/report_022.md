# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 해당 채널의 핵심 키워드 16개에 대한 트렌드 분석을 제공합니다. 분석 대상 키워드는 **종합 시사/뉴스 중심의 콘텐츠 포트폴리오**를 보여주며, 정치·경제·사건사고·국제 이슈까지 폭넓은 스펙트럼을 커버하고 있습니다. 

**주요 발견사항:**
- **카테고리 분포**: 경제/기업(31%), 사건사고/재난(19%), 정치/외교(25%), 엔터테인먼트(13%), 기타(12%)
- **콘텐츠 특성**: 실시간 뉴스 및 단발성 이슈 중심의 키워드가 다수 포함됨
- **데이터 품질**: 현재 수집된 성과 지표(조회수, 영상 수 등)가 미반영 상태로, 정확한 경쟁력 분석을 위한 데이터 갱신이 필요함

### 2.2 사건사고·재난 키워드 (급등형 트래픽)
- **의정부 싱크홀**, **서소문 고가도로 붕괴**: 지역 사고 및 인프라 붕괴 관련 키워드로, 발생 초기 24시간 내 검색량 급증 패턴 예상
- **우크라이나 원전 전력 중단**: 국제 안보 이슈로 정치·외교 관심층 유입

### 2.3 정치·정책 키워드
- **정치인 TV토론**: 선거철/정치적 대립 시즌 고성과 예상
- **외국인 주택 소유 현황**: 부동산 정책 관심층 타겟팅 가능

### 2.4 엔터테인먼트·라이프스타일
- **백룸 쿠키**: 게임/인디 게임 콘텐츠 (젊은층 타겟)
- **스파이에어 내한공연**: J-POP/애니메이션 OST 팬덤 타겟팅
- **광주 신세계**: 지역 상권 및 백화점 오픈 이슈

## 3. 데이터 품질 진단 및 한계

현재 제공된 데이터셋의 모든 수치 지표(`nb_score`, `video_count`, `avg_views` 등)가 **0값**으로 표기되어 있어, 정량적 경쟁력 분석이 불가능한 상태입니다.

**가능한 원인:**
1. **수집 시점 문제**: 키워드 선정은 되었으나 실제 영상 메타데이터 수집 전 상태
2. **API 제한**: YouTube Data API 할당량 초과 또는 접근 권한 제한
3. **필터링 미적용**: 채널 필터 미설정으로 인한 데이터 공백
