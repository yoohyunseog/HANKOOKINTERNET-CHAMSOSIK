# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 수집된 16개 키워드에 대한 초기 분석 데이터를 바탕으로 작성되었습니다. **현재 모든 키워드의 실제 콘텐츠 데이터(video_count, nb_score 등)가 미수집 상태(값 0)**이므로, 키워드 자체의 시맨틱 특성과 카테고리 분포를 중심으로 한 정성적 분석을 제공합니다.

## 1. 데이터 현황 및 한계점

| 구분 | 현황 |
|------|------|
| **수집 키워드 수** | 16개 |
| **실제 콘텐츠 연동** | 0건 (미수집) |
| **검색량/노출지수** | 0 (측정 불가) |
| **시급성** | 데이터 정합성 확인 필요 |

**주요 이슈**: 현재 데이터베이스에 키워드는 등록되어 있으나, YouTube 메타데이터 연동이 이루어지지 않은 상태입니다. 실제 트래픽 분석을 위해서는 API 재수집 또는 크롤링 업데이트가 필수적입니다.

## 2. 키워드 카테고리 분석

### 2.1 정치·외교·안보 (43.8%, 7개)
- **한미 안보 협상**, **지방선거 사전투표율**, **발달장애인 참정권**, **선거 TV 토론**, **한미 동맹 현대화**, **실용외교 국익**, **군수산업 협력**
- **특징**: 시의성이 강하며, 특히 선거 관련 키워드(3, 8, 14번)는 특정 기간 내에만 검색량이 급증하는 **이벤트성 키워드**입니다.

### 2.2 경제·IT·금융 (25%, 4개)
- **삼성전자 HBM4E**, **반도체 초과이익 분배**, **코스피 AI 랠리**, **주식 시장 양극화**
- **특징**: 전문성이 요구되는 **니치 키워드**로, HBM4E와 같은 기술 특화 키워드는 경쟁이 낮을 수 있으나 타겟층이 명확합니다.

### 2.3 사회·복지·안전 (12.5%, 2개)
- **부실 교량 점검**, **수면 규칙성 심혈관**
- **특징**: **공익성·실용성**을 겸비한 키워드로, 정보 제공형 콘텐츠 제작에 적합합니다.

### 2.4 라이프스타일·문화 (12.5%, 2개)
- **밀크티 인기 비결**, **비확장 발코니 인테리어**
