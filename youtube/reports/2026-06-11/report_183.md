# YouTube 채널 키워드 분석 리포트
**분석 기간:** 실시간 트렌딩 데이터  
**분석 대상:** 15개 핵심 키워드  

---

## 1. Executive Summary

본 리포트는 채널의 콘텐츠 전략 수립을 위한 키워드 포트폴리오 분석입니다.  
**중요 제한사항:** 현재 수집된 데이터에서 모든 성과 지표(nb_score, 조회수, 영상 수)가 `0`값으로 표기되어 있어 **정량적 성과 분석은 불가능**한 상태입니다. 따라서 본 분석은 키워드의 주제적 구성과 잠재적 트렌드 특성에 기반한 **정성적 분석**으로 한정됩니다.

---

## 2. 키워드 포트폴리오 구성 분석

수집된 15개 키워드는 다음 5개 카테고리로 분류됩니다:

| 카테고리 | 키워드 수 | 대상 키워드 | 특성 |
|---------|----------|------------|------|
| **시사/정치** | 7개 | 오늘의 주요 뉴스, KF-21 보라매 첫 비행, 텔레그램 성착취, 고려아연, 코스피 빚투, 투표용지 부족, 유보통합 3법 | 국내외 현안 중심의 뉴스성 콘텐츠 |
| **경제/산업** | 2개 | 볼보 ES90 출시, 엔비디아 CEO | 기업 동향 및 제품 소식 |
| **사회/환경** | 3개 | 도시 녹지 공원, 여름 오존 주의보, 공공생리대 코리요 | 공공정책 및 계절별 이슈 |
| **건강/의학** | 1개 | 디스크 혈관 문제 | 의학 정보 콘텐츠 |
| **학술/글로벌** | 1개 | 국제 무역 건강 불평등 | 심층 리서치 주제 |

**핵심 인사이트:**  
채널의 콘텐츠가 **시사 뉴스 중심(46.7%)**에 편중되어 있으며, 경제/산업 정보와 사회 이슈를 보조적으로 다루는 **종합 뉴스 미디어** 형태로 추정됩니다.

---

## 3. 데이터 품질 진단 및 한계

### 🚨 Critical Issue: 메트릭스 누락
- **video_count = 0**: 키워드별 검색 결과 영상 수집 실패
- **avg_views = 0**: 조회수 데이터 미수집  
- **nb_score = 0**: 경쟁 강도 및 성과 점수 산출 불가

**원인 추정:**  
1. API 할당량 초과 또는 수집 오류  
2. 키워드가 너무 새롭거나(Long-tail) 검색량이 극히 적음  
3. 데이터 정제 과정에서의 필터링 오류  

---

## 4. 전략적 제언

### 즉시 실행 필요사항 (Action Items)
1. **데이터 재수집**: YouTube Data API v3를 통해 실제 `viewCount`, `videoCount` 메트릭스 확보
2. **키워드 정제**: "오늘의 주요 뉴스 🔒"의 잠금 이모지(🔒)는 검색 알고리즘에서 특수문자로 처리될 수 있으므로 순수 텍스트 버전 병행 분석 필요
3. **경쟁 강도 분석**: `nb_score` 산출을 위한 경쟁 채널 대비 상대적 성과 지표 도입

### 콘텐츠 전략 방향
- **시사 콘텐츠**: "KF-21 보라매", "엔비디아 CEO" 등의 키워드는 **시의성**이 중요하므로 24시간 내 발행 필요
- **시즌성 콘텐츠**: "여름 도깨비 오존"은 계절성 키워드로, 6-8월 집중 전략 수립
- **틈새 키워드**: "공공생리대 코리요", "국제 무역 건강 불평등"은 경쟁이 적을 가능성이 높은 틈새 주제로 활용 가능
