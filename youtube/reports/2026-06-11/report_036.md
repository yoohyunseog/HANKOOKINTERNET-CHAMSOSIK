# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 16개 키워드에 대한 채널 키워드 분석 데이터를 바탕으로 작성되었으나, **현재 수집된 메트릭(nb_score, video_count, avg_views 등)이 전무(0값)**하여 정량적 분석은 불가능한 상태입니다. 따라서 본 리포트는 키워드의 질적 특성과 카테고리 분류를 중심으로 한 전략적 방향성 제시에 중점을 둡니다.

## 1. 데이터 품질 진단
- **수집 상태**: 모든 키워드의 nb_score, video_count, avg_views가 0으로 표기
- **영향도**: 경쟁도 분석, 조회수 예측, 수익성 평가 등 정량적 의사결정 불가
- **필수 조치**: YouTube Data API v3 또는 외부 분석 툴(예: VidIQ, TubeBuddy)을 통한 메타데이터 재수집 필요

## 2. 키워드 카테고리 분석

| 구분 | 키워드 | 특성 |
|------|--------|------|
| **정치/외교** | 트럼프 이란 공격, 우크라이나 지원, IAEA 이란 우라늄, 선관위 개혁, 투표지 부족 | 시의성 높은 뉴스 키워드. 조회수 급등 가능성 있으나 수명 주기 짧음 |
| **경제/금융** | 미래에셋 증시 전망, 헤지펀드 투자, 스페이스X 기관청약 | 니치(Niche) 타겟층 확보 가능. 높은 CPM(단가) 예상 |
| **기술/산업** | 연료전지 산업, AI 신약 개발, 중국 반도체 유출 | 정보탐색형 검색意圖. 심층 콘텐츠 기획 시 구독자 전환율 우수 |
| **사회/문화** | 월드컵 개막전, 극한 직업 흥행, 카카오 파업 | 대중성 보유. 단, 경쟁 채널 다수 예상 |

## 3. 전략적 제언

### 즉시 실행 과제
1. **데이터 재수집**: 현재 0값으로 표기된 메트릭 긴급 보완
2. **우선순위 설정**: 
   - **단기**: "오늘의 주요 뉴스" (검색량 급상승 예상)
   - **중기**: "AI 신약 개발" (성장성 있는 블루오션)

### 콘텐츠 기획 방향
- **시사 키워드(1~4위)**: 속보성 콘텐츠보다는 **"왜(Why)"**와 **"어떻게(How)"**를 분석하는 심층 해설 콘텐츠 권장
- **금융/기술 키워드**: 10분 이상 장폭 콘텐츠로 전문성 강조 (시청 지속률 관리 필수)

## 결론
현재 데이터는 키워드 발굴 단계에 머물러 있으며, 실제 채널 성장 전략 수립을 위해서는 **최소 30일간의 누적 메트릭 수집**이 선행되어야 합니다. 특히 "nb_score"가 0인 점은 해당 키워드가 실제 검색되지 않거나, 데이터 수집 시점의 오류임을 시사하므로 검증이 필요합니다.
