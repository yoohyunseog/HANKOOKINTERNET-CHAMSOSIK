# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 수집된 16개 키워드에 대한 분석 결과를 제시합니다. 그러나 **모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0으로 표기**되어 있어 경쟁도 및 검색량 기반의 심층 분석은 제한적입니다. 따라서 본 분석은 키워드의 주제적 특성과 카테고리별 분포를 중심으로 한 정성적 분석에 중점을 두었습니다.

## 1. 데이터 품질 현황

| 구분 | 상태 | 비고 |
|------|------|------|
| 정량 데이터 | 미수집 | nb_score, avg_views, video_count 전부 0값 |
| 키워드 목록 | 정상 | 16개 키워드 확인됨 |
| 영상 데이터 | 미수집 | videos 배열 empty |

**분석 제한사항**: 현재 데이터는 키워드 목록만 존재하고, YouTube 검색 결과의 실제 성과 지표(조회수, 경쟁도, 영상 수)가 수집되지 않은 상태입니다. 정확한 경쟁 분석을 위해서는 데이터 재수집이 필요합니다.

## 2. 키워드 카테고리 분석

수집된 키워드는 다음 4개 카테고리로 분류됩니다:

### A. 시사/뉴스 (37.5%)
- 오늘의 주요 뉴스 🔒
- 우크라이나 전쟁 최신 상황  
- 이란 우라늄 농축 문제
- 선거 투표용지 부족 사태

**특징**: 실시간성이 강한 뉴스 키워드로, 검색량은 높으나 수명 주기가 짧습니다.

### B. 경제/금융/산업 (31.3%)
- 미국 헤지펀드 투자 전략
- 주가지수 변동성 분석
- 카카오 첫 노조 파업
- 중국 반도체 기술 유출

**특징**: 투자자 및 경제 관심층을 타겟으로 하는 고부가가치 키워드입니다.

### C. 과학/기술/에너지 (25.0%)
- 연료전지 기술 발전 현황
- AI 신약 개발 소식
- 지자기 폭풍 전력망 영향
- 스페이스X 기관 청약 제한

**특징**: 전문 지식을 요구하는 니치 키워드로, 조회수는 낮을 수 있으나 시청자 충성도가 높습니다.

### D. 스포츠/문화 (6.3%)
- 월드컵 개막전 하이라이트
- 훌리안 알바레스 월드컵
- 극한 직업 영화 다시보기

## 3. 전략적 시사점

### 즉시 실행 필요사항
1. **데이터 재수집**: 현재 모든 메트릭이 0이므로, YouTube Data API 또는 분석 툴을 통해 실제 검색량, 경쟁도, 평균 조회수 데이터를 수집해야 합니다.

2. **키워드 우선순위 설정**:
   - **단기 전략**: "월드컵", "오늘의 주요 뉴스" 등 트렌딩 키워드는 즉시성이 중요
   - **중장기 전략**: "AI 신약 개발", "연료전지 기술" 등 에버그린 콘텐츠 기획

### 리스크 요인
- **뉴스 키워드 과다**: 6개(37.5%)가 시사 뉴스 관련으로, 채널이 뉴스 특화가 아닐 경우 정체성 혼란 가능
- **지정학적 민감성**: "이란", "우크라이나", "중국" 관련 키워드는 정치적 중립성 유지 필요
