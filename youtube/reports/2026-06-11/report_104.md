# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드의 성과 데이터를 분석한 결과입니다. **현재 모든 키워드의 성과 지표(nb_score, 조회수, 영상 수)가 0으로 수집**되어 실제 성과 비교는 불가능한 상태이나, 키워드 구성을 통한 콘텐츠 전략 방향성은 도출 가능합니다.

## 1. 데이터 품질 현황
- **수집 상태**: 전체 키워드(16/16)의 정량적 지표 미수집
- **영상 데이터**: views[], videos[] 배열 empty 상태
- **분석 가능 범위**: 키워드 명칭 기반 정성적 분석만 가능

## 2. 키워드 카테고리 분석

### 2.1 경제/금융 (50%, 8개)
- **거시 경제**: 미국 인플레이션 CPI, CPI 물가 상승률, NDF 환율 변동성
- **투자/증시**: 반도체주 하락 이유, ETF 레버리지 출혈
- **기업 특화**: LG엔솔 미국 관세 환급, 연체채권 소각 소식
- **정책**: 건강보험 재원 안정화

### 2.2 정치/외교 (25%, 4개)
- 한미 환율 협의, 한미 고위 당국자 회담, 기자회견, 한국 캐나다 해군 훈련

### 2.3 기술/산업 (12.5%, 2개)
- MASGA 군함 건조, KMF 오감 기술

### 2.4 스포츠/기타 (12.5%, 2개)
- 한국 경기 멕시코 월드컵, 오늘의 주요 뉴스 🔒

## 3. 전략적 제안

### 즉시 실행 필요 사항
1. **데이터 재수집**: YouTube Data API v3를 통한 실제 조회수, 경쟁도(nb_score) 수집
2. **🔒 마크 키워드 분석**: "오늘의 주요 뉴스"의 잠금 표시는 구독자 전용 콘텐츠 가능성을 시사. 멤버십 전환율 분석 필요

### 콘텐츠 전략
- **시의성 우선**: CPI, 환율, 관세 등 거시 경제 지표는 발표 일정에 맞춘 선제적 업로드 필요
- **이슈 결합**: "반도체주 하락" + "미국 CPI" 복합 키워드로 검색 노출 극대화
- **지역 확장**: 캐나다, 멕시코 등 북미 관련 키워드 다수 - 북미 시청자 타겟팅 고려

## 4. 결론
현재 데이터는 성과 측정이 불가능하나, **경제 뉴스 중심의 전문 채널**로서의 정체성이 명확히 드러납니다. 데이터 정상 수집 후 재분석을 권장하며, 특히 "ETF 레버리지 출혈", "NDF 환율" 등 틈새 금융 키워드의 경쟁 강도 파악이 우선순위입니다.
