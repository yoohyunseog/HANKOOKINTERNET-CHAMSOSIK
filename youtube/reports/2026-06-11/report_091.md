# YouTube 채널 키워드 분석 리포트

**분석일:** 2024년 1월  
**대상:** 유튜브 채널 키워드 16개  
**분석 범위:** 검색어 트렌드 및 콘텐츠 기획 방향성 분석

## 1. Executive Summary (요약)

본 분석은 총 16개 키워드에 대한 경쟁 강도(NB Score) 및 영상 성과 지표를 검토한 결과, **모든 정량적 지표(nb_score, video_count, avg_views 등)가 0으로 수집되지 않은 상태**임을 확인했습니다. 이는 데이터 수집 과정의 미완료 또는 API 응답 오류를 시사하며, 현재로서는 키워드의 주제적 특성과 시사성을 중심으로 한 정성적 분석만 가능한 상황입니다.

---

## 2. 키워드 카테고리 분석

수집된 키워드는 4개의 주요 클러스터로 분류됩니다:

### A. 시사/정치 (25%)
- 오늘의 주요 뉴스 🔒, 기자회견 요지, 트럼프 이란 발언 반응
- **특징:** 실시간성이 핵심이며, '🔒' 표시는 유료 콘텐츠 또는 회원 전용 콘텐츠를 암시할 수 있음

### B. 경제/금융/정책 (44%)
- 기초노령연금 정책, 한국 물가지수, 반도체주 하락, 광주 앰코 증설, 건강보험 재정, 미국 인플레이션, 금리 인상, 주담대 금리, AI 초과이익 분배
- **특징:** 거시 경제 지표와 개인 금융(주담대)이 혼재되어 있어 시청자 타겟팅이 중요함

### C. 문화/스포츠 (19%)
- 대한민국 축구 팀 경기 일정, 유 퀴즈 온 더 블럭 최신회, KMF 기술 축제
- **특징:** '다시보기' 키워드는 VOD 소비 패턴을 반영하며, 축구 일정은 시즌성 콘텐츠로 전환율이 높음

### D. 산업/기술/국방 (12%)
- 광주 앰코 증설 투자, 한국 캐나다 군사 연합훈련, AI 초과이익 메커니즘
- **특징:** B2B 및 니치 오디언스 타겟으로 조회수는 낮으나 CPC(클릭당 비용)가 높은 키워드군

## 3. 전략적 시사점

### 데이터 품질 문제
현재 모든 키워드의 NB Score가 0인 점은 **경쟁 강도 분석의 불가능**을 의미합니다. 정확한 분석을 위해서는:
- YouTube Data API v3를 통한 재수집
- 검색 결과 페이지(SERP) 크롤링을 통한 영상 수 및 조회수 확인
- 경쟁 채널의 평균 조회수 기준 설정

### 콘텐츠 기획 방향
1. **뉴스 해설형 채널**로 보이며, '오늘의 주요 뉴스'가 🔒 표시를 가진 점으로 보아 **멤버십 전략**을 고려해야 함
2. **경제 키워드가 과도하게 많음**(44%). 채널 포지셔닝이 '경제/시사'에 치중되어 있으며, 이는 시청자 피로도를 유발할 수 있으므로 **라이프스타일/정보형 콘텐츠 비중 조정** 필요
3. **지역 특화 키워드**('광주 앰코') 발견 - 지역 기반 SEO 전략 수립 가능
