# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 보고서는 제공된 16개 키워드 데이터를 분석하여 채널 콘텐츠 전략을 수립하기 위한 인사이트를 제시합니다. **현재 수집된 데이터의 모든 수치 지표(nb_score, 조회수 등)가 0으로 표기**되어 있어 정량적 분석은 불가능하나, 키워드의 주제적 특성과 트렌드 방향성을 중심으로 정성적 분석을 수행하였습니다.

## 2. 데이터 현황 및 한계점

| 구분 | 현황 | 분석 가능성 |
|------|------|------------|
| **수집 상태** | 모든 수치 데이터 미수집 (0값) | 정량 분석 불가 |
| **키워드 수** | 총 16개 | 정성 분석 가능 |
| **주제 범위** | 시사/정치/기술/사회/경제 | 카테고리 분류 가능 |

> **주의**: 현재 데이터는 API 연동 오류 또는 초기 수집 단계로 보이며, 실제 검색량 및 경쟁도 분석을 위해서는 데이터 재수집이 필요합니다.

## 3. 키워드 카테고리 분석

수집된 키워드는 5대 영역으로 분류됩니다:

### A. 정치·외교·안보 (6개, 37.5%)
- **고위험-고수익**: "오늘의 주요 뉴스 🔒", "한-EU 비밀정보보호협정", "IAEA 이란 우라늄 결의"
- **방위산업**: "지대공 미사일 시스템"
- **선거제도**: "투표지 부족 선관위 개혁"

*특징*: 시의성이 강하나 정책 변화에 따른 수명 주기가 짧음

### B. 산업·기술·과학 (5개, 31.3%)
- **첨단 기술**: "연료전지 기술 발전", "AI 신약 개발 기술"
- **반도체·우주**: "반도체 기술 유출 중국", "스페이스X 기관청약 제한"
- **자연현상**: "지자기 폭풍 전력 마비"

*특징*: 전문성이 요구되나 구독자 충성도가 높은 카테고리

### C. 사회·노동·인프라 (3개, 18.8%)
- "서울 경전철 강북횡단선", "정년 65세 로드맵", "카카오 첫 부분 파업"

*특징*: 대중적 관심사로 조회수 변동성이 큼

### D. 경제·금융 (1개, 6.3%)
- "롤러코스피 변동성 주의"

### E. 트렌드·문화 (1개, 6.3%)
- "휴머노이드 패션 트렌드"

## 4. 콘텐츠 전략 제안

### 단기 전략 (1-2주)
1. **시사 키워드 선점**: "오늘의 주요 뉴스"는 잠금(🔒) 표시가 있어 프리미엄 콘텐츠 기획 검토
2. **이슈 몰아치기**: "카카오 파업", "선관위 개혁" 등 현재 진행형 사안에 대한 심층 분석

### 중장기 전략 (1개월+)
1. **기술 시리즈화**: 연료전지→반도체→AI 신약으로 이어지는 'K-기술' 테마 기획
2. **글로벌 안보**: 미사일 시스템, IAEA 결의 등을 연결한 국제 정치 콘텐츠
