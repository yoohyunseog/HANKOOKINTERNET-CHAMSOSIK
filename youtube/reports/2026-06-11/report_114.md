# YouTube 채널 키워드 분석 리포트

## Executive Summary

본 분석은 총 16개의 키워드에 대한 검색 트렌드 데이터를 대상으로 진행되었으나, **현재 수집된 영상 데이터가 존재하지 않는 것으로 확인**되었습니다. 모든 키워드의 노출 지수(nb_score), 영상 수(video_count), 평균 조회수(avg_views)가 0으로 표기되어 있어, 실제 성과 지표 기반의 정량적 분석은 불가능한 상태입니다. 다만 키워드 구성을 통해 채널의 콘텐츠 방향성과 잠재적 기회 영역을 도출할 수 있습니다.

## 1. 키워드 카테고리 분석

수집된 키워드는 다음 4개의 주요 영역으로 분류됩니다:

| 카테고리 | 키워드 예시 | 비중 |
|---------|-----------|------|
| **경제/금융** | S&P 500 지수, 필라델피아 반도체, 코스피 저PBR, NDF 환율 | 37.5% |
| **지정학/안보** | 미국 이란 공습, 중동 긴장, K방산, 한캐나다 해군 훈련 | 31.3% |
| **기업/산업** | LG엔솔 관세 환급, 스페이스X 투자 | 12.5% |
| **사회/스포츠** | 건강보험 재정, 멕시코 월드컵 | 12.5% |

**주요 인사이트**: 채널은 **지정학 리스크와 금융 시장의 상관관계**를 다루는 경제 안보(Geo-Economics) 콘텐츠에 특화된 것으로 보입니다. 특히 반도체, 2차 전지, 방산 등 한국 핵심 산업과 관련된 키워드가 다수 포함되어 있습니다.

## 2. 데이터 품질 현황

- **수집 완료률**: 0% (16/16 키워드 데이터 누락)
- **원인 추정**: 
  - 최신 트렌드 키워드로 아직 영상화되지 않은 주제
  - 검색 필터 설정 오류 (날짜 범위, 지역 설정 등)
  - API 할당량 초과 또는 수집 오류

## 3. 전략적 제안

### 즉시 실행 필요 사항
1. **데이터 재수집**: YouTube Data API v3를 활용하여 최근 30일간의 영상 데이터를 재수집할 것을 권장합니다.
2. **키워드 정제**: "오늘의 주요 뉴스 🔒"와 같이 특수문자가 포함된 키워드는 검색 정확도를 위해 정제가 필요합니다.

### 콘텐츠 기회 영역
- **블루오션 키워드**: "LG엔솔 미국 관세 환급", "NDF 환율 변동성" 등은 경쟁이 낮으면서도 실무자들의 니즈가 높은 틈새 주제로 보입니다.
- **시즈널리티 활용**: "멕시코 월드컵 한국"은 2026년 월드컵을 앞두고 선제적 콘텐츠 제작이 가능합니다.

### 리스크 관리
- 민감한 지정학 이슈(이란 공습, 중동 긴장 등)는 사실 확인이 필수이며, 투자 권유 관련 키워드는 금융 규제 준수가 필요합니다.
