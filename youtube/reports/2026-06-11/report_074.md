# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 뉴스/시사 콘텐츠 중심의 YouTube 채널 키워드 트렌드를 분석한 결과입니다. 총 16개의 키워드가 수집되었으나, **모든 성과 지표(nb_score, 조회수, 영상 수 등)가 0으로 표기**되어 정량적 분석은 제한적입니다. 따라서 본 분석은 키워드의 주제적 특성과 트렌드 방향성에 중점을 두었습니다.

## 1. 데이터 품질 현황
- **수집 상태**: 16개 키워드 확인됨
- **지표 현황**: 평균 조회수, 영상 수, NB Score 등 모든 수치 데이터 미수집(0값)
- **분석 한계**: 경쟁 강도, 시청자 반응, 콘텐츠 성과 측정 불가

## 2. 키워드 카테고리 분석

### 경제/산업 (37.5%)
- 반도체 공장 증설, 반도체 협력 벨기에
- AI 초과이익 분배, 카카오 노조 파업
- 주식 기관청약 제한, 스페이스X IPO 주가
- *특징*: 첨단 산업과 노사 관계, 금융 규제 이슈가 복합적으로 나타남

### 사회/복지 (25%)
- 펫보험 만 10세 가입, 전세 감소 정상화
- 투표지 부족 규탄, 탄저백신 국산화
- *특징*: 민생 밀착형 정책과 공공의료 안보 이슈가 혼재

### 국제/외교 (18.75%)
- 우크라이나 평화 지원, 한국 캐나다 해군훈련
- 월드컵 열기 멕시코
- *특징*: 안보 협력과 문화 교류가 균형을 이룸

### 기술/문화 (18.75%)
- 휴머노이드 패션 가능성, 드파운드 대만 팝업
- *특징*: 첨단 기술과 패션/유통의 융합 트렌드

## 3. 콘텐츠 전략 제안

### 즉각적 조치 필요사항
1. **데이터 수집 시스템 점검**: 현재 모든 지표가 0으로 표기되어 있어 실제 콘텐츠 기획에 활용하기 어려움. API 연동 상태 및 크롤링 로직 확인 필요

2. **"오늘의 주요 뉴스 🔒" 키워드 분석**: 유일하게 잠금 아이콘이 포함된 키워드로, 구독자 전용 콘텐츠 또는 프리미엄 콘텐츠 전략을 시사할 수 있음

### 중장기 전략
- **반도체/AI 클러스터링**: 관련 키워드가 4개(25%)로 가장 많아 전문 시리즈 기획 권장
- **실시성 강조**: "투표지 부족", "카카오 노조 파업" 등 긴급 이슈성 키워드가 다수 포함되어 있어 뉴스 속보형 콘텐츠 적합

## 4. 결론
현재 데이터는 키워드 발굴 단계까지만 확인 가능하며, 실제 검색량 및 경쟁 강도 파악이 불가능한 상태입니다. 정확한 콘텐츠 기획을 위해서는 **조회수, 경쟁 채널 수, 검색 트렌드 지표**의 정상적인 수집이 선행되어야 합니다.

**권고사항**: 데이터 수집 시스템 정상화 후 재분석을 통해 키워드 우선순위 및 콘텐츠 투자 대비 효율을 측정할 것을 권장합니다.
