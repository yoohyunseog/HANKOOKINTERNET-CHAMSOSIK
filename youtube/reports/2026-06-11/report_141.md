# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (실행 요약)

본 분석은 총 16개의 키워드에 대한 현황을 점�한 결과, **모든 키워드에서 NB Score, 조회수, 영상 수 등 핵심 메트릭스가 0으로 수집**되고 있는 것으로 나타났습니다. 이는 데이터 수집 시스템의 미작동 또는 아직 콘텐츠가 배포되지 않은 신규 키워드 세트로 판단됩니다. 키워드 구성은 시사/뉴스(25%), 경제/증시(37.5%), 스포츠(18.75%), 기술/사회이슈(18.75%)로 다양한 카테고리를 포괄하고 있으며, **블루오션 키워드로서 선점 기회**가 존재하는 상황입니다.

## 2. 키워드 카테고리 분석

### 2.1 경제/금융 섹터 (6개 키워드)
- **주요 키워드**: 스페이스X 상장 일정, SK이노베이션 배터리, 반도체 수출 호조, 코스피 7500대, 삼성전자 반도체 파업, 원화 약세 수출
- **특징**: 반도체(3개)와 증시 동향(2개)이 중심을 이루며, 투자자 대상 콘텐츠 적합성이 높음

### 2.2 스포츠/엔터테인먼트 (3개 키워드)
- **주요 키워드**: 뉴욕 샌안토니오 NBA, 이유비 배구, 이정후 MLB
- **특징**: 해외 스포츠(NBA, MLB)와 국내 배구 리그를 아우르는 스포츠 중심 채널 성향 예상

### 2.3 시사/사회이슈 (4개 키워드)
- **주요 키워드**: 오늘의 주요 뉴스 🔒, 청년 취업자 감소, 통화 공포증 콜포비아, 중부내륙고속도로 교통
- **특징**: "오늘의 주요 뉴스 🔒"의 자물쇠 이모지는 멤버십 전용 콘텐츠 또는 구독자 전용 콘텐츠를 시사

### 2.4 기술/국제이슈 (3개 키워드)
- **주요 키워드**: 이란 호르무즈 해협, 비트코인 마약 거래, AI 초과이익 배분
- **특징**: 지정학적 리스크와 첨단 기술 윤리 이슈를 복합적으로 다루는 특성

## 3. 데이터 품질 진단 및 리스크 분석

**심각한 데이터 결함**: 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 기록되어 있어 경쟁 분석이 불가능한 상태입니다. 이는 다음과 같은 원인으로 추정됩니다:

1. **API 수집 오류**: YouTube Data API 할당량 초과 또는 연결 끊김
2. **키워드 정합성 문제**: 특수문자(🔒) 포함 또는 장문 키워드로 인한 검색 불일치
3. **신규 기획 단계**: 아직 영상화되지 않은 기획안 단계의 키워드 리스트
