# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 금융·경제 중심의 YouTube 콘텐츠 기획을 위한 키워드 데이터 분석 결과입니다. 총 16개 키워드에 대한 현황 분석 결과, **모든 메트릭(nb_score, 조회수, 영상 수 등)이 미수집 상태(0값)**로 확인되어 데이터 수집 초기 단계 또는 API 연동 이슈가 있는 것으로 판단됩니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 방향성과 잠재적 기회 요인을 도출할 수 있습니다.

## 2. 키워드 카테고리 분석

### 2.1 거시 경제 및 글로벌 시장 (37.5%)
- **S&P 500 실시간 차트**, **미국 이자율 인하 전망**, **미국 CPI 인플레이션**, **한미 환율 정상회담**
- 미국 중앙은행(Fed) 정책과 글로벌 지수 동향에 대한 실시간 정보 수요가 높은 카테고리
- 특히 'CPI 인플레이션'과 '이자율 인하'는 현재 글로벌 투자자들의 최대 관심사

### 2.2 국내 증시 및 기업 분석 (25%)
- **코스피 저PBR 기업**, **반도체 수출 단가 상승**, **LG엔솔 미국 관세 환급**, **삼성바이오 노조 설립**
- 가치투자(저PBR)와 성장주(반도체, 바이오) 양쪽을 아우르는 포트폴리오 구성
- 기업별 특수 이벤트(관세 환급, 노조 설립)에 대한 뉴스형 콘텐츠 기회 존재

### 2.3 정책·사회·국제 관계 (25%)
- **초과이익 국민배분 방안**, **한캐나다 해군 연합훈련**, **MASGA 군함 건조 협정**, **기자회견**
- 정부 정책 및 국방·외교 이슈에 대한 심층 분석 콘텐츠 가능성

### 2.4 기타 (12.5%)
- **FAANG 대체 MANGOS 주식**: 기술주 섹터 로테이션 전략
- **한국 멕시코 월드컵**: 스포츠 이벤트(단, 현재 월드컵 예선 일정과 시점 불일치 확인 필요)

## 3. 데이터 품질 및 한계 분석

| 지표 | 현황 | 분석 |
|------|------|------|
| **nb_score** | 0 | 경쟁 강도 및 검색량 데이터 미확보 |
| **video_count** | 0 | 해당 키워드로 태그된 영상 수 미확인 |
| **avg_views** | 0 | 평균 조회수 산출 불가 |
| **views/videos** | Empty Array | 원본 데이터 미수집 |

**결론**: 현재 데이터는 키워드 기획 단계의 '아이디어 리스트' 수준이며, 실제 검색량 기반 우선순위 설정이 불가능합니다.

## 4. 전략적 제언

### 즉시 실행 과제
1. **데이터 수집 인프라 점검**: YouTube Data API v3 또는 외부 분석 툴(예: VidIQ, TubeBuddy) 연동 상태 확인
2. **키워드 정제**: 
   - "오늘의 주요 뉴스 🔒"의 잠금 이모지(🔒)는 검색 알고리즘에서 필터링될 수 있으므로 제거 권장
   - "한국 멕시코 월드컵"은 시의성이 불분명하므로 "2026 월드컵 예선" 등 구체화 필요

### 콘텐츠 기획 방향
- **단기**: '미국 CPI' 및 '이자율 인하' 키워드로 Fed 정책 관련 시리즈 기획 (검색 수요 급증 중)
- **중기**: '저PBR 기업'과 '반도체 수출'을 연계한 국내 가치주 분석 콘텐츠 구성
- **차별화**: 'FAANG→MANGOS' 전환과 같은 글로벌 섹터 로
