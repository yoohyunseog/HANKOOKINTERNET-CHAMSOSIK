# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 분석은 총 16개 키워드에 대한 YouTube 검색 트렌드 데이터를 대상으로 진행되었으나, **실제 메트릭스(video_count, avg_views, nb_score 등)가 수집되지 않은 상태**입니다. 제공된 키워드 목록만으로도 정치, 경제, 연예, 사회 등 다양한 섹터의 실시간 이슈를 포착하고 있어 채널 콘텐츠 전략 수립의 기초 자료로 활용 가능합니다.

---

## 2. 데이터 현황 및 품질 분석

### 2.1 데이터 수집 상태
- **수집 완료 항목**: 키워드 텍스트 데이터 (16개)
- **미수집 항목**: 조회수, 경쟁도(NB Score), 영상 수, 최대/최소 조회수
- **상태**: API 연동 오류 또는 크롤링 미완료로 추정됨

### 2.2 키워드 분포 분석
제공된 키워드는 다음 5개 카테고리로 분류됩니다:

| 카테고리 | 키워드 수 | 주요 키워드 예시 |
|---------|---------|----------------|
| **정치/선거** | 4개 | 송파구 선거 관리 위원회, 이재명 정청래 갈등, 선거 투표지 부족 사태 |
| **반도체/경제** | 4개 | 반도체주 하락 원인, 광주 반도체 투자, 중국 반도체 기술 유출 |
| **사회/시사** | 3개 | 대학생 시국 선언, 오늘의 주요 뉴스, 모스 탄 무기 |
| **국제/외교** | 3개 | 한국 우크라이나 지원, 한국 체코 축구, 미국 금리 인상 영향 |
| **연예/문화** | 2개 | 임영웅 콘서트, 드파운드 대만 팝업스토어 |

## 3. 전략적 시사점

### 3.1 콘텐츠 기회 분석
**고우선순위 키워드**:
- **"반도체" 관련 키워드 군집**: 4개 키워드가 반도체 산업에 집중되어 있어, 현재 반도체 이슈가 급부상하고 있음을 시사. 특히 "호남 반도체 공장 논란"은 지역 갈등 + 산업 정책의 복합적 이슈로 조회수 잠재력 높음.
- **선거 관련 키워드**: "송파구 선거 관리 위원회", "선거 투표지 부족 사태" 등 선거 사무 관련 키워드가 상위권에 위치해 선거일 임박 또는 재보궐 상황을 반영.

### 3.2 리스크 요인
- **정치적 민감도**: "이재명 정청래 갈등", "대학생 시국 선언" 등 정치적 성향이 명확한 키워드는 노출 알고리즘 리스크 및 시청자 갈등 유발 가능성 존재.
- **데이터 부재**: 실제 경쟁도(NB Score)와 조회수 데이터 없이는 키워드 선정의 객관적 근거가 부족함.

2. **반도체 특집 기획**: "반도체주 하락 원인"을 중심으로 한 경제 분석 콘텐츠 제작 (시의성 활용)
