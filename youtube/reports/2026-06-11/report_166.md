# YouTube 채널 키워드 분석 리포트

## 1. 데이터 개요 (Executive Summary)

분석 대상 16개 키워드 중 **15개(93.75%)는 실제 영상 데이터가 수집되지 않은 상태**로, 현재 데이터셋의 품질이 매우 낮은 것으로 판단됩니다. 유일하게 성과 데이터가 확인된 키워드는 **"오타니 쇼헤이 MLB"**로, 1개 영상이 894회 조회수를 기록했습니다.

## 2. 키워드 현황 분석

### 2.1 데이터 수집 현황
| 구분 | 키워드 수 | 비율 |
|------|----------|------|
| 영상 데이터 있음 | 1개 | 6.25% |
| 영상 데이터 없음 | 15개 | 93.75% |

### 2.2 카테고리별 분포
수집된 키워드는 다음과 같이 분류됩니다:

- **시사/뉴스**: 오늘의 주요 뉴스 🔒, 쿠팡 개인정보 유출, 중동 전쟁 코스피, 이란 호르무즈 봉쇄, 투표지 부족 사태, 수원 투표 착오 (6개)
- **스포츠**: 오타니 쇼헤이 MLB (1개)
- **여행/문화**: 울릉도 관광, 서울 국제도서전 (2개)
- **사회/환경**: 서울 지하철 확장, 기후위기 토종씨앗, 도깨비 오존 주의보 (3개)
- **건강**: 건강 불평등 무역, 나트륨 폭탄 식품, 잔여 콜레스테롤 대장암 (3개)
- **경제**: 금시장 개방 논란 (1개)

## 3. 유효 데이터 분석: 오타니 쇼헤이 MLB

**성과 지표:**
- **영상 수**: 1개
- **평균 조회수**: 894회
- **콘텐츠 특성**: 타일러 캘리한의 MLB 데뷔전 하이라이트 (오타니 상대 홈런 포함)

**인사이트:**
해당 영상은 MLB(메이저리그 베이스볼)의 신인 선수 데뷔전 하이라이트로, 오타니 쇼헤이와의 매치업을 활용한 스포츠 콘텐츠입니다. 894회 조회수는 스포츠 하이라이트 콘텐츠로서 초기 진입 단계에서 **양호한 수준의 참여율**을 보입니다.

## 4. 결론 및 제언

### 주요 문제점
1. **데이터 수집 실패**: 대부분의 키워드에서 영상 데이터가 수집되지 않아 경쟁 분석이 불가능합니다.
2. **정확성 검증 필요**: "오늘의 주요 뉴스 🔒"와 같이 특수 문자가 포함된 키워드는 검색 알고리즘에서 제외되었을 가능성이 있습니다.

### 전략적 제언
1. **스포츠 콘텐츠 강화**: 오타니 키워드의 유일한 성공 사례를 바탕으로 MLB 및 해외 스포츠 스타 관련 콘텐츠를 확대할 것을 권장합니다.
2. **데이터 수집 시스템 점검**: 키워드 추출 및 영상 검색 API의 정확성을 재검증하여 실제 검색 결과와의 괴리를 줄여야 합니다.
3. **시사 키워드 모니터링**: 현재 랭킹에 다수 포진한 시사/사회 키워드는 실제 영상 데이터가 수집되면 즉각적인 콘텐츠 제작을 고려해야 합니다.
