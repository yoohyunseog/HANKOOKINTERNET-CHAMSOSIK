# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 분석은 총 16개 키워드에 대한 YouTube 채널 성과 데이터를 바탕으로 진행되었으나, **데이터 완성도의 심각한 불균형**이 확인되었습니다. 전체 키워드 중 87.5%(14개)는 실제 콘텐츠 데이터가 수집되지 않았거나(video_count: 0), 조회수 및 노출 지표가 기록되지 않은 상태입니다. 유의미한 성과 데이터가 확인된 키워드는 '선관위 투표지 폐기 논란'과 '여야 국정조사 협상' 등 2개 정치/사회 이슈 키워드에 한정되며, 이들 간에도 약 3배의 조회수 격차(1,742회 vs 595회)가 관찰됩니다.

## 2. 데이터 품질 및 수집 현황

### 2.1 데이터 공백 현상
- **미수집 키워드 비율**: 14/16개(87.5%) 키워드에서 video_count, avg_views, nb_score 등 모든 성과 지표가 0으로 기록
- **원인 추정**: 
  1) 키워드 선정 후 실제 콘텐츠 제작이 이루어지지 않음
  2) 데이터 수집 시점과 콘텐츠 게시 시점의 불일치
  3) 키워드 추출 알고리즘의 오류 또는 API 수집 한계

## 3. 실질적 성과 키워드 심층 분석

### 3.1 '선관위 투표지 폐기 논란' (Rank 6)
- **성과 지표**: 1,742회 조회수 기록 (상대적 우위)
- **콘텐츠 특성**: 선거관리위원회의 투표지 보관함 폐기 논란을 다룬 뉴스 콘텐츠
- **시사점**: 선거/정치적爭議(쟁의)성 키워드가 단기간 내 높은 조회수를 확보하는 경향 확인
