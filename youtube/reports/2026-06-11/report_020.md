# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 15개 핵심 키워드에 대한 YouTube 채널 성과 데이터를 분석한 결과입니다. 현재 수집된 데이터는 초기 단계로, 모든 메트릭(video_count, avg_views 등)이 0값을 기록하고 있어 정량적 분석이 제한적입니다. 다만 키워드 구성을 통해 채널의 콘텐츠 전략 방향성을 파악할 수 있습니다.

## 1. 데이터 현황 분석

### 1.1 수집 상태
- **분석 대상 키워드**: 15개
- **데이터 축적 상태**: 미수집 (All metrics: 0)
- **콘텐츠 실적**: Video count, View count 데이터 부재

*본 데이터는 키워드 선정 초기 단계 또는 크롤링 미완료 상태로 판단됩니다.*

## 2. 키워드 카테고리 분석

### 2.1 섹터별 분포
| 카테고리 | 키워드 수 | 비중 | 대표 키워드 |
|---------|---------|-----|------------|
| **정치/사회** | 6개 | 40% | 투표 용지 부족 사태, 선관위 증거보전, 정청래 발언 등 |
| **기술/산업** | 6개 | 40% | AI 신약 개발, 연료전지, 휴머노이드, 스페이스X 등 |
| **경제/기업** | 2개 | 13% | 코스피 롤러코스터, 카카오 파업 |

### 2.2 키워드 특성 분석
- **시의성 중심**: "오늘의 주요 뉴스", "투표 용지 부족" 등 현재 이슈 중심
- **정치적 중립성**: 여야 관련 키워드가 균형 있게 분포 (국민의힘, 정청래, 이재명 등)
- **테크 트렌드 반영**: AI, 연료전지, 휴머노이드 등 4차 산업혁명 키워드 다수 포함

## 3. 전략적 제언

### 3.1 콘텐츠 전략
1. **정치/사회 섹터**: 높은 검색량을 기대할 수 있으나 민감한 주제이므로 사실 확인 및 중립적 보도 필요
2. **기술/산업 섹터**: 장기적 조회수 유지 가능한 에버그린 콘텐츠로 활용 권장
3. **경제 섹터**: "코스피 롤러코스터" 등 실시간성 강조하여 단기 조회수 확보 가능

### 3.2 데이터 수집 개선 방안
- YouTube Data API v3 연동 상태 점검
- 키워드별 검색 필터(업로드 날짜, 조회수 필터) 설정 확인
- 수집 주기 설정 (일간/주간 단위 권장)

## 4. 결론
현재 데이터는 콘텐츠 기획 단계의 키워드 후보군으로 보이며, 실제 성과 분석을 위해서는 video_count 및 views 데이터 축적이 필수적입니다. 정치(40%)와 기술(40%)이 주를 이루는 채널 성격을 고려할 때, **시사+테크 융합 콘텐츠**가 차별화 포인트가 될 수 있습니다.
