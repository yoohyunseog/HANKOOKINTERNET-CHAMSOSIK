# YouTube 키워드 분석 보고서

**생성 시각**: 2024년 5월 21일

## 1. 분석 요약

제공된 데이터는 유튜브 채널의 키워드 순위 정보를 담고 있으나, 모든 항목에 대해 조회수(`avg_views`, `max`, `min`), 영상 수(`video_count`), 그리고 N/B 스코어(`nb_score`)가 '0'으로 집계되었습니다. 이는 해당 키워드들이 현재 채널 내에서 실제 조회 성과를 내지 못했거나, 분석 시점 기준으로 업로드된 영상이 없거나 혹은 데이터가 아직 집계되지 않은 상태임을 시사합니다.
