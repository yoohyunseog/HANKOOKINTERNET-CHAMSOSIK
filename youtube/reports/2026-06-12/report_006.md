# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 2024년 주요 이슈 키워드 15개에 대한 YouTube 콘텐츠 분석 자료입니다. **데이터 수집 현황 상 모든 키워드의 영상 데이터(video_count, avg_views 등)가 0으로 집계**되어 실제 성과 지표 분석은 불가능한 상태이나, 키워드 구성을 통해 채널의 콘텐츠 전략 방향성을 도출할 수 있습니다.

## 1. 데이터 품질 현황
- **수집 상태**: 전체 키워드(15/15)에서 영상 데이터 미수집
- **원인 추정**: API 할당량 초과, 필터링 조건 불일치, 또는 실시간 트렌드 데이터 미반영
- **분석 한계**: 조회수, 경쟁 강도(NB Score), 콘텐츠 수량 기반의 정량적 분석 불가

## 2. 키워드 카테고리 분석

### 2.1 정치/사회 이슈 (20%)
- **선관위 해체 논란**, **투표용지 부족 사태**
- 선거 관리 기관에 대한 신뢰도 문제와 선거 사정 논란을 다루는 고위험/고관심 키워드
- 정치적 중립성 유지가 필수적인 뉴스성 콘텐츠

### 2.2 경제/금융 트렌드 (33%)
- **미국 도매물가 상승**, **EU 철강 관세 협상**, **FOMC 금리 시장 영향**, **금값 폭락 투자 전략**, **반도체 로또 투자**
- 거시 경제 지표와 투자 전략을 아우르는 금융 정보 채널 특화 키워드
- 특히 "반도체 로또 투자", "금값 폭락" 등은 변동성 큰 시장에서의 수익률 관심을 반영

### 2.3 기업/산업 심층 분석 (20%)
- **포스코인터내셔널 해상 물류**, **와콤코리아 디지털 손글씨 체험**, **스페이스X 투자 포인트**
- 특정 기업의 사업 영역(물류, 디지털 기기)과 우주 산업(스페이스X)까지 아우르는 산업별 심층 취재 성향

### 2.4 부동산 및 생활 경제 (7%)
- **아파트 전세 사라짐**
- 전세 사기 후폭풍과 주택 시장 구조 변화에 대한 민감한 사회적 이슈

### 2.5 국제/외교/지정학 (13%)
- **한-이탈리아 전략적 동반자**, **중동 전쟁 취업자 감소**
- 교역 관계와 지정학적 리스크가 노동 시장에 미치는 영향을 연결하는 고차원 분석 시도

### 2.6 기술/미래 산업 (7%)
- **AI 산업 발전 트렌드**
- 디지털 전환 시대의 핵심 키워드로 장기적 콘텐츠 가치 보유

## 3. 전략적 제언

### 즉시 실행 필요사항
1. **데이터 재수집**: 현재 0값으로 표시된 메트릭스(NB Score, 평균 조회수 등)의 정상화
2. **키워드 우선순위 재조정**: "반도체 로또", "금값 폭락" 등 자극적 표현의 클릭베이트 성향 키워드는 신뢰도 하락 우려가 있으므로 사실 기반 분석으로 전환 필요
