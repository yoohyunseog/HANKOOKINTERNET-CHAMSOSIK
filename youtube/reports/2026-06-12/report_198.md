# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 16개 대상 키워드에 대한 YouTube 검색 트렌드 분석을 수행하였으나, **모든 메트릭(nb_score, video_count, avg_views 등)이 Null 값(0)으로 수집**되어 정량적 분석이 불가능한 상태입니다. 이는 데이터 수집 API 오류, 검색 필터 미적용, 또는 크롤링 차단으로 인한 것으로 추정됩니다. 본 분석은 키워드 구성 및 주제별 분류를 중심으로 한 정성적 분석에 한정됩니다.

---

## 1. 데이터 품질 현황 (Critical Issue)

| 메트릭 | 상태 | 비고 |
|--------|------|------|
| nb_score | 0 | 노출 경쟁력 점수 미수집 |
| video_count | 0 | 검색 결과 영상 수 미확인 |
| avg_views | 0 | 평균 조회수 데이터 없음 |
| views/videos 배열 | Empty | 개별 영상 메타데이터 누락 |

**분석 제한사항**: 현재 데이터로는 경쟁 강도, 조회수 잠재력, 콘텐츠 공백 여부를 판단할 수 없어 전략 수립이 불가합니다.

---

## 2. 키워드 카테고리 분석

수집된 16개 키워드는 다음 5개 영역으로 분류됩니다:

### 2.1 정치/행정/사회 (37.5%, 6개)
- **선거/투표**: 투표용지 보관 문제, 송파구 선관위 사건  
- **정책/제도**: 청년 정책 대화, 유아교사 처우 개선  
- **정보/안보**: 국가정보원 최신 활동  

*특징*: 선거 관리 이슈와 사회적 약자 처우 개선 키워드가 혼재되어 있어 시의성이 높은 정치 콘텐츠로 분석됩니다.

### 2.2 경제/금융/기업 (25%, 4개)
- **증시**: 코스피 4.6% 상승, 반도체 ETF 수익률  
- **가상화폐**: 이더리움 가격 변동  
- **기업**: 쿠팡 개인정보 과징금  

*특징*: 단기 급등락 수치(4.6%)와 규제 이슈(과징금)가 포함되어 있어 뉴스성이 강합니다.

### 2.3 과학/의료/바이오 (18.75%, 3개)
- 유전자 교정 기술  
- 암살자 단백질 아고넛  
- 장기 재생 의학 발전  

*특징*: 최신 바이오 기술 용어로 전문성이 높으나 대중성은 상대적으로 낮을 수 있습니다.

### 2.4 외교/안보/사고 (12.5%, 2개)
- 미 이란 종전 MOU  
- 고속도로 낙석사고 대응  
- 소링 이글 공중훈련  

### 2.5 뉴스 아그레게이션 (6.25%, 1개)
- 오늘의 주요 뉴스 🔒 (락 아이콘 포함으로 구독자 전용 콘텐츠 추정)

## 3. 전략적 권고사항

### 즉시 조치 필요 (Priority: High)
1. **데이터 재수집**: YouTube Data API v3 할당량 확인 및 검색 파라미터(기간, 지역, 카테고리) 재설정  
2. **키워드 정제**: "🔒" 특수문자 포함 키워드는 검색 불가능할 수 있어 URL 인코딩 확인 필요  
3. **Long-tail 전환**: "코스피 4.6% 상승"과 같이 시의성이 지나면 검색량이 급감하는 키워드는 지속적 트래픽 확보가 어려움

### 콘텐츠 전략 (Priority: Medium)
- **정치/사회 키워드**: 높은 검색량과 경쟁률 예상, 신속성이 생명
