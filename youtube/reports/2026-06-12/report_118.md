# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 총 16개 키워드에 대한 YouTube 검색 트렌드 분석을 수행한 결과입니다. **현재 수집된 데이터의 모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0으로 표시**되어 있어, 통계적 분석보다는 키워드의 **주제별 분포와 시사적 특성**을 중심으로 한 정성적 분석을 제공합니다.

## 2. Keyword Category Analysis

수집된 키워드는 4개의 주요 카테고리로 분류됩니다:

### A. 정치/외교/안보 (37.5%)
- **트럼프 이란 합의 서명식**, **이란 공습 취소 유가**, **한미 경제협력 안보**
- **선관위 표절 보고서**, **선거 투표 연장 결정**
- 미국 중심의 국제 정세와 국내 선거 관리 이슈가 동시에 포착되었습니다.

### B. 경제/금융/산업 (31.3%)
- **금시세 실시간 차트**, **반도체 ETF 폭등**, **반도체 고용 없는 성장**
- **홈플러스 투자 자금 동결**, **면세점 쇼핑 혜택**, **LPG 가격 인상 택시**
- 자산 가격(금, 반도체)과 유통/물가 관련 키워드가 혼재되어 있습니다.

### C. 라이프스타일/문화 (18.8%)
- **베트남 한식 미슐랭**, **MZ세대 물냉면 비냉면**, **여름 면치기 건강법**
- K-푸드의 해외 진출과 계절별 건강 트렌드가 부각됩니다.

### D. 기술/테스트 (6.3%)
- **AI 감별능력 테스트**
- 생성형 AI에 대한 대중의 인식 검증 수요를 반영합니다.

## 3. Critical Data Gap Analysis

**주요 제약사항**: 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 기록되어 있습니다. 이는 다음 가능성을 시사합니다:
- 데이터 수집 API의 응답 지연 또는 차단
- 특정 기간 필터(24시간 내 등)에서 검색 결과 부재
- 채널 특화 필터링 조건과의 불일치

## 4. Strategic Recommendations

1. **데이터 재수집**: YouTube Data API v3의 할당량 및 응답 상태 확인이 필요합니다.
2. **우선순위 설정**: '반도체 ETF', '금시세' 등 투자 심리 관련 키워드는 조회수 변동성이 클 것으로 예상되어 모니터링 우선순위로 선정합니다.
3. **시사성 키워드**: '트럼p', '이란' 등은 실시간 검색량 급증 가능성이 높아 빠른 콘텐츠 기획이 요구됩니다.
