# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드의 트렌드 패턴을 분석한 결과입니다. **현재 수집된 데이터의 모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0으로 표기**되어 있어, 실제 성과 분석은 불가능한 상태입니다. 본 분석은 키워드 텍스트 자체의 시맨틱 특성과 뉴스 클러스터링 패턴에 기반한 정성적 분석입니다.

---

## 1. 데이터 현황 개요

| 구분 | 상태 | 비고 |
|------|------|------|
| **수집 키워드 수** | 16개 | Rank 1~16 |
| **정량 데이터** | 미수집 | nb_score, views, video_count 전부 0 |
| **데이터 품질** | 주의 필요 | API 연동 또는 크롤링 미완료 상태로 추정 |

> ⚠️ **분석 한계**: 실제 검색량, 경쟁 강도, 조회수 분포 등의 정량적 분석이 불가능하므로, 키워드 기반 콘텐츠 기획 시 추가 데이터 수집이 필수적입니다.

## 2. 키워드 카테고리 분석

제공된 키워드는 다음 4개 카테고리로 클러스터링됩니다:

### A. 거시경제/금융 (37.5%)
- 미국 PPI 급등 호르무즈 충격
- 금값 하락 미국 금리 인상  
- 세계은행 경제성장률 전망 하향
- 환율 고공행진 정부 대응
- 반도체 레버리지 투자 위험

**특징**: 미국 중심의 금리 정책, 원화 가치, 원자재 가격 변동성에 대한 관심 집중

### B. 기업/산업 동향 (31.3%)
- 기아 전기차 PV5 출시
- 삼성전자 브랜드 가치 1위
- 한화 차기 구축함 사업 수주
- AI 모험자본 플랫폼 가동
- EU 철강 관세 협상

**특징**: 자동차(EV), 방산, 반도체, AI 등 첨단 제조업 및 기술 산업 중심

### C. 정치/사회 이슈 (25.0%)
- 이탈리아 국빈 방문 훈장 수여
- 투표용지 부족 사태 검찰 수사
- 도급근로자 최저임금 적용 무산
- 서울 아파트 월세 비중 증가

**특징**: 외교, 선거 관리, 노동 정책, 주거 불안정성 등 민감한 사회 현안

### D. 건강/라이프 (6.3%)
- 스트레스성 복통 완화 음식

## 3. 전략적 시사점

### 🔴 즉각 조치 필요사항
1. **데이터 수집 시스템 점검**: 모든 메트릭이 0인 것은 API 키 만료, 할당량 초과, 또는 파싱 에러를 의심할 수 있음
2. **"오늘의 주요 뉴스 🔒" 메타 키워드**: 잠금 이모지(🔒)가 포함된 해당 키워드는 구독자 전용 콘텐츠 또는 프리미엄 콘텐츠를 의미할 가능성이 높아 별도 분석 필요

### 🟡 콘텐츠 기획 방향
- **경제 뉴스 채널**: PPI, 금리, 환율 키워드가 3위권 내에 분포되어 있어 금융/경제 뉴스 콘텐츠가 주력임을 시사
- **기업 분석 콘텐츠**: 기아, 삼성전자, 한화 등 대기업 동향이 지속적으로 모니터링 대상
- **정치적 중립성 고려**: 선거, 외교, 노동 정책 키워
