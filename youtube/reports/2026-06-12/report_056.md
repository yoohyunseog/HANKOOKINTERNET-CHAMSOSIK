# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드 데이터를 기반으로 한 트렌드 분석입니다. **현재 수집된 데이터의 모든 정량적 지표(nb_score, 조회수 등)가 0으로 표시**되어 있어, 키워드 텍스트 기반의 정성적 분석 위주로 진행되었습니다.

## 1. 데이터 현황 및 한계점

| 구분 | 현황 |
|------|------|
| **수집 키워드 수** | 16개 |
| **정량 데이터** | 미수집 (전 항목 0값) |
| **카테고리 분포** | 시사/정치 31%, 경제/산업 38%, 기술/IT 19%, 엔터테인먼트 6%, 기타 6% |

> **주의**: 실제 검색량, 경쟁률, 평균 조회수 데이터가 없어 정확한 트래픽 예측은 불가능합니다. 향후 유튜브 데이터 API 연동 및 실제 영상 메타데이터 수집이 필요합니다.

## 2. 키워드 카테고리 분석

### A. 정치/사회 (Ranks 1, 4, 5, 6, 12)
- **"오늘의 주요 뉴스 🔒"**: 구독자 전용 콘텐츠(🔒)로, 채널의 핵심 유료 콘텐츠로 추정
- **선거 관련**: "투표용지 부족 사태", "선관위 개표 오류" - 선거 시즌 또는 선거 관련 이슈 커버리지
- **외교**: "이탈리아 국빈방문", "이란 공습 취소" - 국제 정치 이슈

### B. 경제/산업 (Ranks 3, 7, 8, 9, 11, 15)
- **자동차**: "기아 PV5 출시" - 신차 발표 관련
- **부동산**: "월세 비중 증가" - 주거 비용 트렌드
- **무역/금융**: "철강 관세 협상", "금값 폭락 전망", "세계경제성장률 전망"
- **노동**: "최저임금 도급근로자"

### C. 기술/IT (Ranks 10, 14, 16)
- **반도체/AI**: "반도체 AI 협력", "삼성 구글 AI 반도체" - 빅테크 협력 이슈
- **우주산업**: "스페이스X 주식 전망"

### D. 엔터테인먼트 (Rank 2)
- **"샤키라 신곡"**: 유일한 문화/엔터 콘텐츠

## 3. 시사점 및 콘텐츠 전략

### 주요 특징
1. **뉴스 중심 채널**: 75%가 시사/경제/기술 뉴스 키워드로 구성
2. **실시간성**: "오늘의", "출시", "사태" 등 시의성 강한 키워드 다수
3. **전문성**: 정치 외교, 금융, 반도체 등 고급 정보 콘텐츠 성향

### 제안 사항
- **데이터 보완**: 키워드 플래너(VidIQ, TubeBuddy) 연동으로 검색량 및 경쟁률 확인 필요
- **콘텐츠 믹스**: 엔터테인먼트 비중이 6%로 낮음. 대중성 확보를 위해 문화 콘텐츠 비중 검토
- **시리즈화**: "오늘의 주요 뉴스"를 중심으로 한 일일 뉴스 브리핑 포맷 강화

## 4. 결론
현재 데이터는 **정성적 트렌드 파악**에 한계가 있으나, 시사/경제 전문 뉴스 채널로서의 방향성이 명확히 드러납니다. 정량적 데이터 수집 인프라 구축 후 재분석이 필요합니다.
