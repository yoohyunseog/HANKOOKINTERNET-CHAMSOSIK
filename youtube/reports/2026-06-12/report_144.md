# YouTube 채널 키워드 분석 리포트

**분석 기간:** 2024년 실시간 트렌딩 데이터  
**분석 대상:** 16개 핵심 키워드  
**보고일:** 2024년  

---

## 1. Executive Summary

본 분석은 YouTube 플랫폼 내 주요 검색 키워드 16개를 대상으로 수행되었으나, **데이터 수집 과정에서 통계적 지표(nb_score, 조회수, 영상 수 등)의 누락**이 확인되었습니다. 따라서 본 리포트는 정량적 수치 분석 대신 키워드의 **주제별 분포 및 트렌드 특성**을 중심으로 한 정성적 분석을 제공합니다.

---

## 2. 키워드 카테고리 분석

수집된 16개 키워드는 다음 4개 카테고리로 분류됩니다:

| 카테고리 | 키워드 수 | 비중 | 주요 키워드 |
|---------|----------|------|------------|
| **경제/금융** | 6개 | 37.5% | 삼성전자 주가, 도지코인, 레버리지 ETF, 스페이스X 상장 |
| **스포츠** | 4개 | 25.0% | AVC컵 여자배구, 브레이브스 화이트삭스, 한국 피파랭킹 |
| **뉴스/시사** | 4개 | 25.0% | 오늘의 주요 뉴스, 쿠팡 개인정보 유출, 홈플러스 회생 |
| **과학/건강** | 2개 | 12.5% | 스트레스 기억력 연구, 유전자 교정 기술 |

### 2.1 경제/금융 키워드 특성
- **시장 불확실성 반영:** 도지코인, 레버리지 ETF 등 고위험 자산에 대한 관심 집중
- **기업 특정 이슈:** 삼성전자(반도체), 스페이스X(우주산업), 홈플러스(유통) 등 산업별 대표 기업 중심

### 2.2 스포츠 키워드 특성
- **국제 대회 중심:** AVC컵(아시아 배구), FIFA 랭킹 등 글로벌 스포츠 이벤트 위주
- **하이라이트 콘텐츠 선호:** "하이라이트" 키워드가 2개 포함되어 있어 **짧은 형식의 경기 요약 콘텐츠** 수요 확인

## 3. 데이터 품질 진단 및 한계

### ⚠️ 심각한 데이터 결함 발견
모든 16개 키워드에서 다음 지표가 **0 또는 null 상태**로 수집됨:
- `nb_score` (경쟁도 점수)
- `video_count` (영상 수)
- `avg_views` (평균 조회수)
- `views`, `videos` 배열 데이터

**원인 추정:**
1. YouTube Data API 할당량 초과
2. 키워드 검색 결과 페이지 접근 제한
3. 데이터 수집 시간대의 비활성성 (새벽 시간대 등)

---

## 4. 전략적 권고사항

### 즉시 조치 필요
1. **데이터 재수집:** API 연결 상태 확인 및 수집 로그 점검
2. **백업 데이터 소스:** 공식 YouTube Trending 페이지 크롤링 병행

### 콘텐츠 기획 방향
- **경제 키워드:** 삼성전자 주가 전망, 반도체 상용화 등 **장기 투자 관점**의 분석 콘텐츠 기획
- **스포츠 키워드:** AVC컵, MLB(브레이브스) 등 **실시간 하이라이트** 콘텐츠의 Shorts 형식 최적화
- **시사 키워드:** 쿠팡 개인정보 유출, 홈플러스 회생 등 **소비자 권익** 관련 심층 보도
