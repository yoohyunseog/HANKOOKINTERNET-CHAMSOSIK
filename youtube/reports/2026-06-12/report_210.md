# YouTube 채널 키워드 분석 리포트

## 1. 데이터 개요 및 품질 분석
분석 대상 16개 키워드 중 **75%(12개)**가 영상 데이터 미수집 상태(`video_count: 0`)로, 실질적인 분석 가능 키워드는 4개에 불과함. 데이터 무결성 확보가 시급하며, 현재 수집된 4개 키워드만으로 한정적인 인사이트 도출 가능.

## 2. 콘텐츠 성과 분석

### 2.1 조회수 상위 키워드
- **외국인 SK하이닉스 매수** (22,212회): 금융 전문 콘텐츠 중 유일하게 2만 회 이상 조회. 삼성전자와의 비교 분석 형식이 투자자 관심을 끌음
- **송파구 투표용지 부족** (7,090회): 정치/사회 이슈로 뉴스 채널의 신속한 보도가 높은 도달률 기록
- **BTS 부산 공연 경제효과** (3,529회): 동일 영상 중복 업로드(6,161회 vs 897회)로 인한 데이터 노이즈 발생. K팝 글로벌 영향력 관련 콘텐츠의 지속적 수요 확인

### 2.2 저성과 키워드
- **스페이스X 주가 평가액** (평균 381회): 우주항공 테마주(스피어, 미래에셋증권) 분석 콘텐츠지만 조회수 저조. 틈새 금융 정보로서 타겟팅은 명확하나 대중성 부족
- **엘앤에프 주가 전망** (4회): 2차전지 소재주 분석 콘텐츠로 극소수 조회. 제목의 SEO 최적화 미흡 및 경쟁 채널 과잉 공급 추정

## 3. 시사점 및 전략 제안

**콘텐츠 전략:**
- **금융/투자**: SK하이닉스 사례처럼 '비교 분석' 프레임(삼성전자 vs SK하이닉스)이 단순 정보 전달보다 효과적. 단, 스페이스X/엘앤에프 사례에서 보듯 과도한 전문 용어와 낮은 검색 가시성이 진입 장벽
- **이슈/뉴스**: 선관위, 지자체 등 공공기관 관련 콘텐츠는 신속성이 핵심. 7,000회 이상 조회를 기록한 '송파구 투표용지' 사례는 채널A 등 언론사의 빠른 대응이 주효
- **엔터테인먼트**: BTS 콘텐츠의 중복 업로드(동일 제목, 상이한 조회수)는 데이터 관리 체계의 허술함을 시사. 중복 콘텐츠 필터링 및 메타데이터 정제 필요

**데이터 운영:**
전체 키워드의 75%가 수집 실패한 점은 크롤링 로직 또는 API 제한 문제로 추정. 데이터 수집 인프라 점검 및 백업 체계 구축이 우선 과제임.
