# YouTube 채널 키워드 분석 리포트

**분석 기간:** 2024년 데이터 기준  
**분석 대상:** 16개 핵심 키워드  
**보고일:** 2024년 12월

---

## 1. Executive Summary

본 분석은 경제·정치 복합 뉴스 채널의 콘텐츠 전략 수립을 위한 키워드 포트폴리오 분석입니다. 수집된 16개 키워드는 **거시경제**(금값, 금리, 세계경제), **산업정책**(반도체, 철강, 방산), **사회이슈**(선관위, 주거) 3대 영역으로 구분되며, 현재 데이터 수집 초기 단계로 실제 성과 지표는 미측정 상태입니다.

---

## 2. 키워드 카테고리 분석

### 2.1 경제·금융 중심 키워드 (50%, 8개)
- **금리·물가 관련:** "미국 금리 인상 가능성", "원유 가격 동향", "금값 하락 전망"
- **부동산·금융:** "아파트 월세 비중 증가", "가계대출 급증 현황", "금융권 대출 증가"
- **투자·성장:** "AI 투자 전망", "세계경제 성장률 전망"

**인사이트:** 금리 인플레이션과 부채 문제에 대한 시청자 우려가 높은 영역으로, 해설형 콘텐츠 기획 시 높은 관심도 예상됩니다.

### 2.2 정치·외교 키워드 (25%, 4개)
- "선관위 개혁 논란", "투표용지 부족 사태", "EU 외교 협력", "이탈리아 국빈 방문"

**인사이트:** 선관위 관련 키워드가 2개(25%) 포함되어 선거 관리 기관에 대한 공론화 수요가 높음을 시사합니다.

### 2.3 산업·통상 키워드 (19%, 3개)
- "철강 관세 협상", "반도체 협력 논의", "구축함 사업 수주"

**인사이트:** 방위산업(구축함)과 첨단 제조업(반도체)이 동시에 포착되어 안보·경제 연계 분석 콘텐츠의 니즈가 존재함을 보여줍니다.

## 3. 데이터 품질 및 수집 현황

현재 모든 키워드의 **NB Score**, **조회수(avg_views)**, **영상 수(video_count)**가 0으로 표기되어 데이터 정합성 검증이 필요합니다. 

**권장 조치:**
- YouTube Data API v3 연동 상태 확인
- 키워드 검색 필터(업로드 날짜, 동영상 길이) 재설정
- 대조군 채널 ID 기반 competitor 분석 병행

## 4. 콘텐츠 전략 제언

### 단기 전략 (1-2주)
1. **"금값 하락 전망" vs "금리 인상"** 연계 분석 콘텐츠 제작
   - 금융권 대출 급증과의 인과관계 설명으로 시청자 이해도 극대화

### 중기 전략 (1개월)
2. **선관위 개혁 + 투표용지 부족** 통합 기획
   - 선거 행정의 구조적 문제점을 진단하는 시리즈물 구성

3. **반도체·철강 관세** 글로벌 공급망 분석
   - 산업 전문성을 활용한 차별화된 해설 콘텐츠
