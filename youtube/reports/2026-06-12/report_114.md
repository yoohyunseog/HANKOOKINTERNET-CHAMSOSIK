# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석 대상 채널은 뉴스 및 경제 정보 콘텐츠 중심의 키워드 포트폴리오를 보유하고 있으나, **현재 수집된 모든 성과 지표(nb_score, 조회수, 영상 수)가 0으로 표시**되어 정량적 분석이 불가능한 상태입니다. 이는 데이터 수집 시스템의 오류 또는 API 연동 문제를 시사하며, 즉각적인 데이터 품질 점검이 필요합니다.

## 1. 키워드 카테고리 분석
현재 랭킹된 15개 키워드를 주제별로 분류한 결과, 다음과 같은 4대 영역으로 집중되어 있습니다:

### 1.1 경제/금융 (40%)
- 금시세 실시간, 반도체 ETF 폭등, 가계대출 증가율, 유가 하락 전망
- **특징**: 실시간 시장 데이터와 투자 정보에 중점을 둔 고관여 키워드

### 1.2 기업/산업 동향 (33%)
- 홈플러스 투자 자금, 쿠팡 역대급 과징금, 반도체 고용 없는 성장, 로봇 훈련소 LG
- **특징**: 대기업 동향 및 규제 이슈 중심의 기업 뉴스 성격

### 1.3 정치/사회 이슈 (20%)
- 트럼프 이란 합의, 선관위 투표지 부족, LPG 가격 인상
- **특징**: 국제 정세와 국내 선거 관리 이슈 병행

### 1.4 문화/글로벌 (7%)
- 한식 미슐랭 스타, 월드컵 열기 멕시코, AI CEO 방한
- **특징**: 소프트 파워 및 글로벌 이벤트 관심사

## 2. 데이터 품질 진단 및 권고사항

### Critical Issue: Zero-Value Data
모든 키워드의 `nb_score`, `video_count`, `avg_views`가 0으로 기록된 것은 다음 가능성을 내포합니다:
- YouTube Data API 할당량 초과 또는 인증 오류
- 키워드 검색 시 필터링 로직의 과도한 제한
- 데이터 파이프라인의 ETL 프로세스 중단

**즉각 조치사항**: 
1. API 연결 상태 및 할당량 확인
2. 키워드 검색 파라미터(검색 기간, 지역 설정) 검증
3. 원본 데이터 소스 재수집

## 3. 전략적 제언

### 콘텐츠 기획 방향
데이터 복구 후 다음 우선순위로 모니터링할 것을 권합니다:

1. **실시간성 키워드 집중**: "금시세 실시간", "유가 하락 전망" 등 시간 민감도가 높은 키워드는 업로드 타이밍이 조회수 결정 요인
2. **이슈 복합 키워드**: "반도체 ETF 폭등"과 "반도체 고용 없는 성장"을 연계한 심층 분석 콘텐츠 기획
3. **지역 특화**: "월드컵 열기 멕시코"와 같은 글로벌 이벤트는 현지 연결성을 강조한 차별화 필요

### 모니터링 지표
데이터 정상화 후 반드시 추적해야 할 KPI:
- **검색 가시성(Search Visibility)**: nb_score 변화 추이
- **경쟁 강도**: video_count 대비 avg_views 비율(시장 포화도)
- **시즌성 패턴**: 금시세, 유가 등 주기적 변동성 키워드의 주간/월간 트렌드
