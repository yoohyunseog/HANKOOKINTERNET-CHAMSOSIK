# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 보고서는 제공된 16개 키워드 데이터를 기반으로 콘텐츠 트렌드 및 시장 관심사를 분석한 결과입니다. **데이터 수집 메트릭(video_count, avg_views 등)이 현재 0값으로 표시**되어 있어 정량적 성과 분석은 제한적이나, 키워드 구성을 통해 채널의 콘텐츠 방향성과 시장 포지셔닝을 도출할 수 있습니다.

---

## 1. 데이터 품질 현황

| 항목 | 상태 | 분석 |
|------|------|------|
| **nb_score** | 0 (전체) | 노출 빈도 점수 미수집 |
| **video_count** | 0 (전체) | 관련 영상 수 미확인 |
| **avg_views** | 0 (전체) | 평균 조회수 데이터 부재 |
| **views/videos** | Empty | 원본 데이터 미연동 |

**진단**: API 연동 오류 또는 필터링 조건 미충족으로 추정됩니다. 키워드 자체만으로 트렌드 매핑이 가능합니다.

## 2. 키워드 카테고리 분석

### 2.1 산업별 분포
- **경제/금융 (31%)**: 에코프로 주가, 레버리지 ETF, 금값 하락, 세계경제 성장률, 쿠팡 과징금  
  → **투자 심리 및 기업 이슈에 대한 높은 관심** 반영
  
- **IT/기술 (25%)**: 삼성 갤럭시 Z 폴드, 데이터센터 수요, 반도체 고용 없는 성장, 와콤 디지털 손글씨  
  → **하드웨어 혁신 + 인프라 + 고용 구조** 복합적 기술 이슈
  
- **사회/정책 (25%)**: 고속철도 프로젝트, LPG 가격 인상, 주택가격 동탄, 폭염 건강수칙  
  → **생활 밀착형 정책 및 계절형 이슈** 포착

- **문화/안보/일반 (19%)**: 오늘의 주요 뉴스, 미슐랭 스타 한식, 한캐나다 해군 훈련

### 2.2 키워드 특성 분석
- **기업 특화**: 삼성(폴더블), 에코프로(2차전지), 쿠팡(플랫폼 규제) — **대형주 및 테마주 중심**
- **지역 특화**: "동탄" 키워드 포함 — **수도권 부동산 민감도** 반영
