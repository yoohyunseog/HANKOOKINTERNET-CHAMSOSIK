# YouTube 채널 키워드 분석 리포트

## 1. 개요 및 데이터 품질 진단

본 분석은 총 16개 키워드에 대한 YouTube 검색 트렌드 데이터를 대상으로 합니다. **현재 수집된 모든 키워드의 노출 지수(nb_score), 조회수(views), 영상 수(video_count)가 0으로 표기**되어 있어 정량적 분석은 불가능한 상태입니다. 이는 데이터 수집 API의 응답 지연, 검색 기간 설정 오류, 또는 특정 필터링 조건 미충족으로 인한 것으로 판단됩니다.

## 2. 키워드 카테고리 분류 및 특성 분석

제공된 키워드들은 다음 6개 카테고리로 분류됩니다:

| 카테고리 | 키워드 예시 | 특성 |
|---------|-----------|------|
| **시사/뉴스** | 오늘의 주요 뉴스 🔒, 트럼프 종전 선언 | 실시간성, 검색량 급등 패턴 |
| **스포츠** | 월드컵 축구 한국 경기 중계, 축구 팀 경기 일정 | 이벤트 기반, 시즌성 의존도 높음 |
| **경제/금융** | 코스피 급등 이유, 스페이스X 주가 상승 | 변동성 시장에서 관심 급증 |
| **라이프스타일/F&B** | 맥도날드 맘스터치 비교, 피자플래닛 팝업스토어 | 비교/방문 유도 콘텐츠 적합 |
| **건강/의학** | 족저근막염 부상, 마그네슘 많은 음식 | 정보 탐색형, 장기적 조회수 유지 |
| **사회 이슈** | 음주강요 감찰 사건, 유전자 교정 기술 논란 | 감정적 반응 유발, 논쟁성 콘텐츠 |

## 3. 전략적 제안

### 즉시 실행 필요 사항
1. **데이터 재수집**: 검색 기간(최소 30일 권장) 및 지역 설정(한국) 확인 후 API 재호출
2. **경쟁 강도 분석**: `nb_score`가 정상 수집되면 70점 이상 고경쟁 키워드(뉴스/스포츠)와 30점 이하 저경쟁 키워드(세부 건강 정보) 구분 필요

### 콘텐츠 기획 방향
- **단기 트래픽**: "코스피 급등", "트럼프 종전" 등 시의성 키워드는 24시간 이내 발행 필수
- **장기 SEO**: "마그네슘 많은 음식", "족저근막염" 등 상시 검색 키워드는 심층 가이드 콘텐츠 제작 권장
- **틈새 기회**: "피자플래닛 팝업스토어"와 같은 특정 브랜드 키워드는 리뷰 영상으로 초기 독점 트래픽 확보 가능

## 4. 결론

현재 데이터의 정량적 부재로 인해 구체적인 경쟁 분석은 불가하나, 키워드 구성만으로 **시사(40%) > 라이프스타일(25%) > 경제/건강(35%)**의 분포를 확인했습니다. 데이터 정상화 후 재분석을 권장하며, 특히 뉴스성 키워드의 경우 발행 타이밍이 조회수의 80%를 좌우하므로 실시간 모니터링 체계 구축이 긴급합니다.
