## 3. 핵심 인사이트

### 3.1 시의성 분석
- **실시성 높은 키워드**: "오늘의 주요 뉴스 🔒", "트럼프 종전" 등은 당일 또는 단기 트렌드에 민감한 키워드로, **빠른 콘텐츠 제작**이 필요한 영역입니다.
- **계절성 키워드**: "여름 물냉면 비냉면"은 시즌성 수요를 반영하며, 6-8월 사이 조회수 급증이 예상됩니다.

### 3.2 산업별 특성
- **금융/투자 키워드**가 25%를 차지하여, 현재 시장의 경제 불확실성에 대한 사용자 관심도가 높음을 시사합니다.
- **AI/로보틱스** 관련 키워드(보스턴 다이내믹스, 오픈AI, 삼성 AI)가 동시 등장하여, 4차 산업혁명 관련 콘텐츠 수요가 꾸준함을 확인할 수 있습니다.

### 3.3 데이터 품질 이슈
⚠️ **경고**: 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 기록되어 있습니다.
- 실제 영상 데이터 수집 미완료 또는 API 연동 오류로 추정됩니다.
- **정확한 경쟁 분석을 위해서는 해당 키워드로 검색된 실제 영상 데이터의 재수집이 필요합니다.**
