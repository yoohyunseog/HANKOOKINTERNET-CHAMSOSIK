# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
본 리포트는 뉴스/시사 콘텐츠 채널의 키워드 포트폴리오 분석 결과입니다. 현재 수집된 데이터가 초기화 상태(모든 메트릭 0)인 관계로, 키워드 구성을 통한 콘텐츠 전략적 분석을 중심으로 진행하였습니다. 총 16개 키워드는 정치·경제·사회·문화·국제 분야를 고르게 아우르는 복합 뉴스 채널의 특성을 보여줍니다.

## 2. 키워드 포트폴리오 분석

### 2.1 카테고리별 분포
| 구분 | 키워드 예시 | 비중 |
|------|------------|------|
| **국제/외교** | EU 철강 관세, 트럼프 이란 공습, 호르무즈 해협 | 31% |
| **경제/산업** | 반도체 호황, WB 경기 전망, 쿠팡 과징금 | 31% |
| **사회/사건** | 선관위 개표 오류, 여성 소방관 사망, 서울 전세 | 19% |
| **문화/라이프** | MZ세대 냉면, 한식 미슐랭, 월드컵 | 19% |

### 2.2 트렌드 특성 분석
- **시의성 중심**: "오늘의 주요 뉴스"와 같이 실시간성을 강조하는 키워드 존재
- **글로벌 이슈**: 미국(트럼프), 중동(호르무즈), 유럽(EU), 베트남 등 지리적 다양성
- **경제 심층 분석**: 고용 없는 성장, 과징금 영향 등 단순 뉴스를 넘어선 분석 콘텐츠 지향

## 3. 콘텐츠 전략 제안

### 3.1 데이터 보완 우선순위
현재 모든 키워드의 `video_count`와 `avg_views`가 0으로 표시되어 있어 성과 측정이 불가능합니다. 다음과 같은 데이터 수집이 필요합니다:
- 검색량(Search Volume) 및 경쟁도(Competition) 메트릭 추가
- 시청자 유지율(Retention Rate) 데이터 연동
- 키워드별 CTR(클릭률) 분석

### 3.2 키워드 최적화 방향
1. **장기 트래픽 키워드**: "WB 세계경제 성장률 전망" → 분기별 업데이트 콘텐츠 기획
2. **이슈 대응형**: "AI 국방산업 경쟁" → 기술 전문성을 산 업계 인터뷰 콘텐츠
3. **라이프스타일 접목**: "MZ세대 물냉면 비냉면" → 세대별 소비 트렌드 분석으로 확장

## 4. 결론
해당 채널은 종합 뉴스 미디어로서 정치·경제·사회 분야의 균형 잡힌 포트폴리오를 구성하고 있습니다. 다만 실제 성과 데이터의 부재로 인해 현재는 정성적 분석에 한정되며, 조회수 및 참여도(Engagement) 데이터 확보 후 정량적 ROI 분석이 필요합니다.

**권고사항**: 우선 "반도체 호황", "서울 아파트 전세" 등 국내 경제 이슈 중심으로 시범 콘텐츠를 제작하여 메트릭을 수집한 후, 글로벌 이슈로 확장하는 단계적 접근을 권장합니다.
