# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 15개 키워드의 검색 트렌드 데이터를 분석한 결과입니다. **현재 수집된 모든 정량적 지표(nb_score, video_count, avg_views 등)가 0으로 표기**되어 있어 통계적 분석은 불가능하나, 키워드 구성을 통해 채널의 콘텐츠 방향성과 시사점을 도출할 수 있습니다.

## 1. 데이터 현황 및 한계점
- **수집 상태**: 전체 15개 키워드에서 조회수, 영상 수, 경쟁 점수 등의 핵심 메트릭스가 미수집 상태
- **원인 추정**: API 연동 오류, 데이터 수집 지연, 또는 프리미엄 키워드(🔒 표기)의 접근 권한 제한 가능성
- **분석 범위**: 정량 분석 대신 **키워드 시맨틱 분석(의미론적 분류)** 및 콘텐츠 전략 제언으로 대체
