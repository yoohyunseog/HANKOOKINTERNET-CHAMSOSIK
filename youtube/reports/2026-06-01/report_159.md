# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 총 16개 키워드에 대한 YouTube 검색 트렌드 분석을 수행한 결과입니다. **현재 수집된 데이터 상 모든 키워드의 검색 지수(nb_score) 및 영상 통계량(video_count, avg_views)이 0으로 표시**되어 있어, 정량적 경쟁 분석은 불가능한 상태입니다. 다만, 키워드 구성을 통해 최근 시장의 관심사와 콘텐츠 기획 방향성을 도출할 수 있습니다.

---

## 2. 데이터 품질 현황 및 한계

| 항목 | 현황 | 분석 |
|------|------|------|
| **검색 지수(nb_score)** | 0 (전 키워드) | 데이터 미수집 또는 신규 트렌드로 반영 지연 가능성 |
| **영상 수(video_count)** | 0 (전 키워드) | 해당 키워드로 태깅된 콘텐츠 부재 또는 API 수집 오류 |
| **조회수(views)** | Empty Array | 실제 콘텐츠 성과 분석 불가 |

**※ 참고사항**: 본 데이터는 실시간 트렌드 키워드 목록이나 검색어 제안 데이터로 보이며, 아직 YouTube 콘텐츠화되지 않은 **블루오션 키워드**일 가능성이 있습니다.

- **CJ 올리브영 미국 진출**: K-뷰티 해외 확장 가속화

### 3.3 사회/노동/정치 (3개 키워드, 18.8%)
