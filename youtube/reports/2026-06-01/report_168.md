# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 총 16개 키워드에 대한 성과 데이터를 기반으로 채널의 콘텐츠 방향성과 시장 기회를 진단합니다. 현재 대부분의 키워드가 실제 영상 콘텐츠와 연결되지 않은 상태이며, 유효한 성과 데이터는 **"청년미래적금 우대금리"** 키워드 단일 항목에 한정됩니다. 이는 채널이 초기 콘텐츠 구축 단계이거나, 키워드 기반 콘텐츠 전략 수립이 필요한 상태임을 시사합니다.

## 1. 데이터 현황 분석

### 1.1 콘텐츠 공백 현상
분석 대상 16개 키워드 중 **15개(93.75%)**가 영상 수(`video_count`), 조회수(`avg_views`), 노출 점수(`nb_score`)가 모두 0인 상태입니다. 이는 다음 두 가지 가능성을 내포합니다:
- **수집 시점 문제**: 최신 트렌드 키워드를 선정했으나 아직 콘텐츠화되지 않은 상태
- **메타데이터 불일치**: 실제 콘텐츠는 존재하나 키워드 태깅이나 메타데이터 최적화가 미흡함

### 1.2 유일한 성과 데이터
**"청년미래적금 우대금리"** 키워드만 1개 영상이 등록되어 있으며, 조회수는 **31회**로 나타났습니다. 해당 영상은 금융 뉴스 형식의 정보성 콘텐츠로, 2026년 5월 30일자 출시 예정인 청년미래적금 상품을 다루고 있습니다.

## 3. 콘텐츠 성과 진단

### 3.1 청년미래적금 콘텐츠 분석
- **제목**: "[금융뉴스] 최고 연 8% 금리 '청년미래적금'···다음 달 22일 출시(2026.5.30.)"
- **조회수**: 31회
- **분석**: 조회수가 상대적으로 낮으나, **정보 전달형 콘텐츠**로서 향후 검색 수요가 있을 수 있는 에버그린 콘텐츠임. 특히 8%라는 높은 금리와 정부 정책 관련 내용은 타겟 청년층의 관심을 끌 수 있는 요소입니다.

### 3.2 개선 필요 영역
- **썸네일 및 타이틀 최적화**: 현재 제목이 뉴스 형식이나, 유튜브 알고리즘에 최적화된 감성 키워드 부재
- **키워드 태깅**: "우대금리", "청년적금", "8% 금리" 등의 세부 키워드 메타데이터 보강 필요
