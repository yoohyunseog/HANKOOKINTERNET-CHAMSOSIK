# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 보고서는 수집된 14개 키워드의 YouTube 콘텐츠 데이터를 분석한 결과이다. 전반적으로 **뉴스/정보성 키워드 중심의 실시간 트렌드 데이터**로 확인되며, 실제 영상이 등록된 키워드는 3개(21.4%)에 불과하여 초기 단계의 콘텐츠 시장 형성이 진행 중인 것으로 분석된다.

## 1. 데이터 품질 및 수집 현황

### 1.1 데이터 완성도 분석
- **전체 키워드**: 14개
- **영상 보유 키워드**: 3개 (한화에어로스페이스 폭발 사고, 레이저대공무기 천광 국산화 성공, 미얀마 광산 폭발 사)
- **미등록 콘텐츠**: 11개 (78.6%) - video_count 및 조회수 데이터 0

**분석**: NB Score(경쟁 강도 지수)가 전 키워드에서 0으로 표기된 것으로 보아, **실시간 급상승 검색어 기반의 예비 데이터**로 추정된다. 이는 해당 키워드들이 아직 YouTube 콘텐츠화되지 않은 블루오션 키워드임을 시사한다.
