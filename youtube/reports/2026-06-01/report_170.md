# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 채널의 키워드 성과 데이터를 분석하여 콘텐츠 전략 방향을 제시합니다. 분석 결과, 전체 15개 대상 키워드 중 **2개(13.3%)**만 실제 비디오 데이터가 수집되었으며, 나머지 키워드는 미등록 또는 비공개 상태로 확인되었습니다. 실측된 키워드는 모두 **금융·경제 섹터**에 집중되어 있어, 해당 분야의 콘텐츠 전문성 강화가 시급함을 시사합니다.

- 실제 성과가 확인된 키워드는 3위(LG전자 주가 전망)와 4위(코스피 8600 돌파)에 불과
