# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
본 분석은 총 16개 키워드에 대한 YouTube 검색 데이터를 기반으로 채널의 콘텐츠 전략 방향성을 제시합니다. 전반적으로 **데이터 수집의 불완전성**이 확인되었으며, 실제 영상 데이터가 존재하는 키워드는 5개(31.25%)에 불과합니다. 유효 데이터는 정치 뉴스 콘텐츠 1건에 집중되어 있어 채널의 콘텐츠 다양성 측면에서 개선이 필요합니다.

## 2. 데이터 품질 및 커버리지 분석

### 2.1 데이터 공백 현황

- **유효 데이터**: Rank 11~15 키워드만 실제 영상 정보 보유
- **데이터 오염**: 일부 `subtitle_summary` 필드에 분석 메타데이터(예: "이전 응답이 영어로 된 분석 과정...")가 섞여 있는 품질 이슈 확인

## 3. 키워드 클러스터링 분석

### 3.1 정치/시사 키워드 그룹 (Rank 11-15)
- **핵심 주제**: 6·3 지방선거 관련 여야 전직 대통령(이명박, 박근혜, DJ)의 유세 동향
- **세부 키워드**: "서울숲", "MB", "박근혜", "DJ 소환"
- **특징**: Long-tail 키워드 변형(키워드 순서 변경, 조합 확장)이 유효하게 노출되고 있음

### 3.2 경제/금윸 키워드 그룹 (Rank 1-10, 16)
- **주요 키워드**: "코스피 간다는데", "은행별 우대금리", "반도체 초과세수", "용인 반도체"
- **현황**: 모든 메트릭이 0으로, 실제 콘텐츠 부재 또는 데이터 미수집 상태
- **시사점**: 경제 정보 콘텐츠 영역에서 채널의 검색 가시성이 전무함

## 4. 콘텐츠 전략 제안

### 4.1 즉시 실행 과제
1. **데이터 파이프라인 점검**: 68% 키워드에서 0값이 나타나는 것은 수집 로직 오류 또는 콘텐츠 미게재를 의미. 기술적 검토 필요
2. **자막 데이터 정제**: `subtitle_summary` 필드의 메타데이터 오염 문제 해결로 분석 정확도 향상

### 4.2 중장기 전략
- **키워드 다각화**: 현재 정치 뉴스(100%)에 편중된 콘텐츠 믹스를 경제/금융(코스피, 금리, 반도체) 정보로 확장
- **Long-tail 최적화**: "MB 오늘은 서울숲으로"처럼 구체적인 4-5어구 키워드가 상위 노출되는 패턴을 활용한 타이틀 전략 수립
- **지역 키워드 활용**: "전북", "용인", "서울숲" 등 지역명
