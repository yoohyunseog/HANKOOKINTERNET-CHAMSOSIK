**YouTube 채널 키워드 분석 리포트**

## 1. Executive Summary

본 리포트는 제공된 15개 키워드에 대한 경쟁 분석 및 콘텐츠 전략 방향성을 제시합니다. 단, **모든 키워드의 정량적 지표(nb_score, 조회수, 영상 수 등)가 0으로 수집**되어 데이터 품질 검증이 필요한 상태입니다. 현재 데이터는 키워드 발굴 단계로 보이며, 실제 경쟁 강도 분석을 위해서는 추가 데이터 수집이 필수적입니다.

## 2. 키워드 카테고리 분석

제공된 키워드는 6개 주요 영역으로 분류됩니다:

| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **시사/뉴스** | 오늘의 주요 뉴스 🔒, 이스라엘 레바논 휴전 협상 | 실시간성 중시, 🔒 표시는 유료 콘텐츠 가능성 |
| **경제/주식** | 에코프로비엠 주가, 한화시스템 최신뉴스, 동탄 신도시 분양 | 2차 전지, 방산, 부동산 트렌드 반영 |
| **기술/과학** | AI 개표 예측 시스템, 현무암 수소 저장 기술, 교황 AI 발언 | 첨단 기술 및 윤리 논쟁 주제 |
| **엔터테인먼트** | 성시경 새 앨범, 네이마르 이적설 | 팬덤 기반 검색 수요 |
| **국제관계** | 멕시코 한국 관계, 미중 무역 전쟁 한국 | 지정학적 이슈 |
| **건강/라이프** | 혈관 건강 슈퍼푸드 비트 | 웰니스 트렌드 |

## 3. 전략적 제안

### 3.1 데이터 품질 개선 필요
- 모든 키워드의 `video_count`와 `avg_views`가 0인 것은 API 연동 오류 또는 수집 시점 미스매칭을 시사합니다.
- **즉시 조치사항**: YouTube Data API v3 재호출 및 검색 기간 설정 확인 (최근 30일/90일 등).

### 3.2 우선순위 키워드 선정
현재 트렌드와 검색 의도를 고려할 때:
1. **즉시 제작 권장**: "이스라엘 레바논 휴전 협상", "AI 개표 예측 시스템" (시의성 중시)
2. **중장기 전략**: "현무암 수소 저장 기술", "교황 AI 발언" (교육/정보형 콘텐츠)
3. **니치 전략**: "진양곤 기업" (기업 특화 콘텐츠, 경쟁 적음 예상)

### 3.3 콘텐츠 시너지 방안
- **AI × 사회**: "AI 개표 예측" + "교황 AI 발언" + "인공지능 인간성 논란"을 묶은 AI 윤리 시리즈 기획
- **경제 클러스터**: 2차 전지(에코프로비엠) + 방산(한화시스템) + 부동산(동탄)을 연결한 "대체투자 포트폴리오" 콘텐츠
