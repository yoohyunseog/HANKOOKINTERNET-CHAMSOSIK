# YouTube 채널 키워드 분석 리포트

## Executive Summary

본 리포트는 제공된 16개 키워드에 대한 채널 분석 데이터를 바탕으로 작성되었습니다. **현재 모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0으로 표시**되어 있어 경쟁 강도나 성과 분석은 불가능한 상태입니다. 다만 키워드 구성을 통해 채널의 콘텐츠 방향성과 시장 기회를 정성적으로 분석할 수 있습니다.

## 데이터 품질 현황

| 지표 | 상태 | 분석 가능 여부 |
|------|------|---------------|
| NB Score | 0 (미수집) | 불가 |
| 평균 조회수 | 0 (미수집) | 불가 |
| 영상 수 | 0 (미수집) | 불가 |
| 키워드 리스트 | 정상 수집 | 가능 |

**⚠️ 데이터 수집 오류**: API 연동 문제 또는 필터링 조건 불일치로 인해 실제 메트릭이 누락된 것으로 보입니다. 본 분석은 키워드 텍스트 기반의 정성적 분석에 한정됩니다.

## 키워드 카테고리 분석

제공된 키워드는 5개 주요 영역으로 분류됩니다:

### 1. 경제/금융 (37.5%, 6개)
- **기업 뉴스**: 카카오엔터테인먼트 주가, 삼성전자 성과급, 한화에어로 사고
- **거시 경제**: 현금 없는 사회, 금융당국 규제, 반도체 호황, 캐나다산 원유
- **특징**: 시의성이 강한 기업 이슈와 정책 관심사가 혼재됨

### 2. 정치/사회 (25%, 4개)
- 오늘의 주요 뉴스, 지방선거 사전투표율, 르완다 학생 추모비, 트럼프 계좌
- 국내외 정치 현안과 역사적 이슈를 아우름

### 3. 국방/안보 (12.5%, 2개)
- F-35 라이트닝 II 성능, 이란 우라늄 농축
- 군사 전문 콘텐츠 가능성 시사

### 4. 기업/브랜드 (12.5%, 2개)
- 스타벅스 카드 충성고객 이탈
- 고객 경험(CX) 및 마케팅 전략 분석 주제

### 5. 건강/라이프 (12.5%, 2개)
- 비타민C 많은 채소 과일, 혈액 속 피로 물질
- 라이프스타일 및 웰니스 콘텐츠 포지셔닝 가능

## 시사점 및 전략 제안

### 즉시 실행 필요 사항
1. **데이터 재수집**: YouTube Data API 또는 분석 도구 연결 상태 확인
2. **메트릭 확보**: 검색량, 경쟁률, 평균 조회수 등 정량 데이터 확보 시 재분석 필요

### 콘텐츠 전략적 제안
- **니치 포지셔닝**: 경제/금융 키워드가 과밀화된 반면, "르완다 학생 추모비"와 같은 역사/인권 이슈는 차별화 가능
- **시의성 활용**: "오늘의 주요 뉴스"는 뉴스 채널의
