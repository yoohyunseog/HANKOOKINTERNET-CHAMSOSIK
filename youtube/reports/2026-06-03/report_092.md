# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 총 15개 키워드에 대한 YouTube 검색 트렌드 분석을 수행하였으나, **모든 정량적 메트릭(nb_score, video_count, avg_views 등)이 0값으로 수집**되어 실제 성과 분석은 불가능한 상태입니다. 이는 데이터 수집 과정의 오류 또는 API 연동 실패를 시사하며, 현재로서는 키워드 카테고리별 특성 분석에 한정된 인사이트를 제공합니다.

## 2. Keyword Category Analysis

수집된 키워드는 5개 주요 영역로 분류됩니다:

### A. 정치/선거 및 행정 (20%)
- *지방선거 투표시간*, *출구조사 예측 시간*, *교육소통령 예산 규모*
- **특징**: 시의성이 높은 이벤트 중심 키워드로, 선거일 기준 급격한 검색량 변동 예상

### B. 경제/투자 (27%)
- *삼성SDI 주가 전망*, *상장지수펀드 투자 방법*, *비트코인 가격 추락 이유*
- **특징**: 정보탐색형(Intent: Informational) 키워드로, 재무상식 교육 콘텐츠와 시장 분석 콘텐츠로 양분 가능

### C. 기술/반도체 산업 (13%)
- *HBM 반도체 호황 전망*, *젠슨 황 방한 일정*
- **특징**: 전문성이 요구되는 B2B 성향의 니치 키워드로, 높은 CPM(천당 비용) 기대 가능

### D. 건강/라이프스타일 (13%)
- *위암 식도암 위험 음식*, *비타민C 많은 채소 과일*
- **특징**: evergreen 콘텐츠로서 장기적 유입 가능, 의료 정보의 정확성 검증 필요

### E. 국제/외교 및 기타 (27%)
- *이란 제재완화 핵포기 연계*, *한미 안보합의 협상 진행*, *K컬처 브랜드 프로젝트* 등
- **특징**: 뉴스 가치가 높은 키워드군으로, *오늘의 주요 뉴스 🔒*와 결합 시 시너지 예상

## 3. Strategic Implications

현재 데이터 품질 문제로 인해 다음과 같은 한계가 확인됩니다:
- **경쟁 강도 분석 불가**: nb_score가 0으로 표시되어 해당 키워드의 진입 장벽 측정 불가
- **수익성 예측 불가**: avg_views 데이터 부재로 예상 조회수 및 광고 수익 산정 불가
- **콘텐츠 갭 분석 불가**: 기존 영상 대비 차별화 포인트 도출 어려움

## 4. Recommendations

1. **데이터 재수집**: YouTube Data API 또는 서드파티 툴(vidIQ, TubeBuddy)을 활용한 메트릭 재조사 필요
2. **우선순위 설정**: 현재 키워드 중 *HBM 반도체*, *비트코인* 등 검색량 변동성이 큰 키워드에 대한 모니터링 강화
3. **콘텐츠 클러스터링**: '투자/경제' 키워드군을 중심으로 주제 권위성(Topical Authority) 구축 전략 수립 권고
