# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 수집된 16개 핵심 키워드에 대한 데이터 기반 분석을 수행하였으나, **모든 메트릭(nb_score, 조회수, 영상 수 등)이 0값으로 표시**되어 정량적 성과 분석이 불가능한 상태임을 확인하였습니다. 따라서 본 분석은 키워드의 주제별 분류 및 콘텐츠 전략적 방향성 제시에 중점을 두었습니다.

## 1. 데이터 품질 현황

| 항목 | 상태 | 비고 |
|------|------|------|
| NB Score | 0 (전체) | 경쟁도 분석 불가 |
| 평균 조회수 | 0 (전체) | 성과 측정 불가 |
| 영상 수 | 0 (전체) | 콘텐츠 공급량 파악 불가 |
| 데이터 수집일 | 미상 | 타임스탬프 부재 |

**Critical Issue**: 데이터 수집 API 연동 오류 또는 크롤링 실패로 추정됩니다. 즉각적인 시스템 점검 및 재수집이 필요합니다.

## 2. 키워드 카테고리 분석

수집된 키워드는 5개 주요 영역으로 분류됩니다:

### A. 정치/사회 (25%)
- 지방선거 사전투표율 역대최고
- 현금 없는 사회 한국은행
- 르완다 학생 추모비 파리

### B. 경제/기업 (31%)
- 삼성전자 직원 스톡옵션 수익
- 한국 자본시장 규제 개선
- 트럼프 은퇴계좌 정책
- 반도체 호황 리스크 분석
- 스타벅스 카드 충성고객 이탈

### C. 국제/안보 (19%)
- F-35 라이트닝 II 성능
- 이란 우라늄 농축 논란
- 한화에어로스페이스 사고 책임

### D. 스포츠 (13%)
- 크로아티아 벨기에 축구 경기
- MLB 9회말 역전승 변수

### E. 건강/라이프 (13%)
- 비타민C 많은 채소 과일
- 피로감 유발 혈중 물질

## 3. 전략적 시사점

**뉴스성 vs. 정보성 혼재**: "오늘의 주요 뉴스"와 같은 실시간성 키워드와 "비타민C 많은 채소"와 같은 evergreen 콘텐츠가 공존하여 채널 정체성이 불분명합니다.

**B2B/금융 중심**: 경제/기업 키워드(5개)가 가장 많아 금융/투자 정보 채널로의 포지셔닝 가능성을 시사합니다.

**국제 안보 niche**: F-35, 이란 우라늄 등 군사/외교 키워드가 다수 포함되어 있어 차별화된 전문성 확보 기회가 존재합니다.

## 4. 결론 및 제언

1. **즉각 조치**: 데이터 수집 시스템 점검 및 유효한 메트릭 확보 (48시간 내)
2. **키워드 정제**: 뉴스성/정보성 키워드 분리 및 채널 아이덴티티 재정립
3. **우선순위 설정**: 현재 데이터로는 "반도체 호황 리스크 분석", "트럼프 은퇴계좌 정책" 등 검색 수요가 높을 것으로 예상되는 경제 키워드 중심의 테스트 콘텐츠 제작 권장

**분석일**: 2024년 (데이터 기준일 미상)
