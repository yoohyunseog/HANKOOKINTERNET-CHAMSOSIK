# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 총 16개의 키워드에 대한 YouTube 콘텐츠 성과 데이터를 바탕으로 진행되었습니다. 전반적으로 **데이터 수집 완료율이 12.5%(2/16)**에 불과해 분석의 한계가 명확하며, 실측 데이터를 보유한 키워드는 '지방선거 투표율'과 'SK하이닉스 주가 전망'으로 한정됩니다. 키워드 구성은 경제·금융(31%), 기술·산업(31%), 정치·사회(19%), 건강(13%) 등 무거운 주제 중심으로 집중되어 있습니다.

- **수집 오류**: API 연동 실패 또는 데이터 크롤링 과정에서의 기술적 문제
- **콘텐츠 부재**: 해당 키워드로 실제 업로드된 영상이 없거나, 검색 가시성이 극도로 낮음
