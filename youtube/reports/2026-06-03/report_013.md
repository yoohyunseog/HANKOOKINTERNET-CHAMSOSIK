# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 16개의 키워드에 대한 YouTube 검색 데이터를 분석한 결과입니다. **현재 수집된 데이터의 모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0으로 표시**되어 있어, 실제 성과 분석은 불가능한 상태입니다. 본 보고서는 키워드 구성의 정성적 특성과 카테고리별 전략적 방향성을 중심으로 분석합니다.

---

## 1. 키워드 카테고리 분석

수집된 키워드는 4개의 주요 영역으로 분류됩니다:

### 📰 시사/정치 (25%)
- **"오늘의 주요 뉴스"**, **"지방선거 투표"**, **"미국 국무차관 방한"**, **"한미 핵협력 협의"**, **"트럼프 계좌 정책"**
- 시의성이 높은 뉴스 키워드로, **검색량 급등(Spike)** 특성을 보유

### 💹 경제/투자 (37.5%)
- **"비트코인 시세 전망"**, **"업비트 거래소"**, **"코스피 8000 돌파"**, **"환율 1500원"**, **"연금저축펀드 수익률"**
- 금융 투자자층을 타겟으로 한 **고관여(High-involvement)** 키워드 군집

### 🔧 기술/반도체 (25%)
- **"AI 반도체 동맹"**, **"삼성 HBM5 기술"**, **"반도체 장비규제 완화"**
- 산업 전문가 및 테크 투자자를 겨냥한 **B2B 성향**의 키워드

### 🏢 기업/브랜드/스포츠 (12.5%)
- **"스타벅스 카드 혜택"**, **"스페이스X 기업평가"**, **"U.S. 여자 오픈 골프"**
- 기업 가치 평가 및 라이프스타일 콘텐츠로 **브랜드 키워드** 특성

---

## 2. 콘텐츠 전략 제안

### ⚠️ 데이터 수집 개선 필요
현재 모든 키워드의 `video_count`와 `avg_views`가 0으로 표시되어 있어 **경쟁 강도(Competition Density)** 및 **수요-공급 비율** 분석이 불가능합니다. 다음 조치가 필요합니다:
- YouTube Data API v3의 할당량(Quota) 확인
- 키워드 검색 필터(게시일, 지역, 영상 길이) 재설정
- `nb_score`(경쟁력 지수) 산출 알고리즘 검증

### 🎯 우선순위 전략 (데이터 기반 가정)
**Tier 1: 시세/전망 키워드** ("비트코인 시세 전망", "환율 1500원")
- 검색 의도(Search Intent)가 명확하고 시청 지속률이 높음
- **Shorts + Long-form** 병행 전략 권장

**Tier 2: 기술 뉴스** ("삼성 HBM5 기술", "AI 반도체 동맹")
- 전문가 권위(Authority) 확보에 유리
- **심층 분석 콘텐츠**로 채널 전문성 강화

**Tier 3: 이벤트성 키워드** ("지방선거 투표", "U.S. 여자 오픈")
- 시의성에 따른 급등 현상 활용
- **뉴스 속보형** 콘텐츠로 조회수 확보 가능

## 3. 결론 및 권고사항

현재 데이터는 **정량적 분석이 불가능한 상태**입니다. 키워드 선정 자체는 시사, 경제, 기술 분야의 균형 잡힌 포트폴리오를 보여주나, 실제 영상 기획을 위해서는:

1. **즉시 데이터 재수집** 실행 (API 연결 상태 점검)
2. **경쟁 채널 분석** 추가 (동일 키워드 상위 노출 채널의 콘텐츠 구조 분석)
3. **시즌성 캘린더** 작성 (선거, 금리 발표 등 시의성 키워드의 타임라인 관리)
