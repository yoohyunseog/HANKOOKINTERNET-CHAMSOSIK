# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 제공된 16개 키워드에 대한 YouTube 검색 트렌드 분석 결과입니다. **데이터 품질상의 한계**로 인해 정량적 지표(nb_score, 조회수, 영상 수 등)가 모두 0으로 표시되어 있어, 키워드별 경쟁 강도 및 성과 예측은 불가능한 상태입니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 방향성 및 시장 트렌드를 정성적으로 분석할 수 있습니다.

## 2. 키워드 카테고리 분석

제공된 키워드는 다음 6개 카테고리로 분류됩니다:

| 카테고리 | 키워드 | 특징 |
|---------|--------|------|
| **경제/금융** | 필라델피아 반도체 지수, 나스닥 100, LG 주가, 반도체 산업 전망 | 투자 정보 수요가 높은 고관여 키워드 |
| **정치/선거** | 지방선거 출구조사, 교육감 선거 양자 대결 | 시의성이 강한 정치 콘텐츠 |
| **사회/사건** | 검찰 사과 취소 논란, 대전공장 화재 조사 | 뉴스 가치가 높은 이슈 중심 |
| **국제/지정학** | 이란 호르무즈 해협 | 글로벌 이슈 및 원자재 시장 영향 |
| **문화/라이프** | 마포 K컬처 브랜드, 독립영화 3학년 2학기, 혈당 관리 쌀 대체식품 | 틈새 문화 및 건강 정보 |
| **부동산/건설** | 도시정비 재개발 현대 GS 삼성 | 기업 연계 재개발 정보 |

## 3. 데이터 품질 검토 및 한계

**심각한 데이터 결함**이 확인되었습니다:
- 모든 키워드의 `nb_score`, `video_count`, `avg_views`가 0으로 기록
- `views` 및 `videos` 배열이 비어있음

**원인 추정:**
1. 데이터 수집 API 연동 실패
2. 특정 기간(일자) 필터링으로 인한 결과 누락
3. 키워드 정규화 과정에서의 오류

## 4. 전략적 제안

### 즉시 실행 필요 사항
- **데이터 재수집**: YouTube Data API 또는 분석 툴(예: VidIQ, TubeBuddy)을 통해 실제 검색량 및 경쟁률 데이터 확보 필요
- **키워드 정제**: "독립영화 3학년 2학기"와 같이 지나치게 특정한 키워드는 검색량이 극히 낮을 수 있으므로, "독립영화 추천" 등으로 확장 검토

### 콘텐츠 기획 방향
1. **시의성 콘텐츠**: 선거, 화재, 사과 논란 등은 조회수 급증 가능성이 높으나 수명이 짧음 (Shorts 형식 권장)
2. **Evergreen 콘텐츠**: 혈당 관리, 반도체 산업 전망 등은 장기적 유입 가능 (장평 영상 권장)
3. **틈새 전략**: "마포 K컬처"와 같은 지역 특화 키워드는 경쟁이 낮아 초기 채널 성장에 유리
