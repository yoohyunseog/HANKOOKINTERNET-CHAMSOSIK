# YouTube 채널 키워드 분석 리포트

**분석 기준일:** 2024년  
**분석 대상:** 상위 16개 키워드  
**데이터 상태:** 메트릭 미수집 (수집 오류 또는 처리 대기 중)

---

## 1. Executive Summary

본 리포트는 YouTube 채널의 키워드 성과 분석을 위한 데이터셋을 검토한 결과입니다. **현재 제공된 데이터는 모든 성과 지표(nb_score, 조회수, 영상 수 등)가 0값으로 표기**되어 있어 정량적 성과 분석은 불가능한 상태입니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 전략 방향성과 잠재적 개선 포인트를 도출할 수 있습니다.

---

## 2. 데이터 품질 현황 및 한계점

| 지표 | 상태 | 비고 |
|------|------|------|
| **NB Score** | 0 (전체) | 노출 경쟁력 점수 미계산 |
| **Video Count** | 0 (전체) | 색인된 영상 수 미확인 |
| **Avg Views** | 0 (전체) | 평균 조회수 데이터 누락 |
| **Views/Videos** | Empty Array | 원본 데이터 미수집 |

**⚠️ Critical Issue:** 데이터 수집 파이프라인의 오류로 판단됩니다. YouTube Data API 할당량 초과, 크롤링 차단, 또는 DB 동기화 실패 가능성을 검토해야 합니다.

## 3. 키워드 카테고리 분석

현재 상위 16개 키워드는 다음과 같이 5개 카테고리로 분류됩니다:

### 3.1 정치/시사 (6개, 37.5%)
- **주요 키워드:** "오늘의 주요 뉴스 🔒", "취임 1년 성적표 정치", "지방선거 사전투표율 역대 최고"
- **국제 이슈:** "이스라엘 헤즈볼라 교전 중단", "우크라이나 EU 가입 헝가리", "르완다 학살 추모비 파리"
- **분석:** 시사 교육 채널 또는 뉴스 큐레이션 채널로 추정. 실시간성이 중요한 키워드군으로, **조회수 데이터 누락 시 알고리즘 노출 최적화가 불가능**합니다.

### 3.2 경제/기업 (5개, 31.25%)
- **금융:** "현금 없는 시대 한국은행", "금융당국 자본시장 규제", "트럼프 계좌 은퇴 자금"
- **기업:** "삼성전자 연봉 수억 직원", "스타벅스 카드 충성고객 이슈"
- **분석:** 기업 분석 및 재테크 콘텐츠 비중이 높음. "삼성전자 연봉" 키워드는 구독자 참여율(댓글/공유)이 높을 것으로 예상되나, 현재 데이터로는 검증 불가.

### 3.3 스포츠 (2개, 12.5%)
- **국제:** "크로아티아 벨기에 축구 경기"
- **국내:** "KBO 올스타전 경기 결과"
- **분석:** 스포츠 하이라이트 채널 특성. 실시간 검색 트렌드에 민감하므로 데이터 수집 지연 시 기회비용 발생.

### 3.4 사회/사건 (2개, 12.5%)
- "한화에어로 사망자 사고", "F-35 라이트닝 II 성능"
- **분석:** 사고 보도 및 군사 정보 콘텐츠. 민감한 키워드군으로 노출 제한 가능성을 고려해야 하나, 현재 nb_score 미제공으로 확인 불가.

### 3.5 라이프/건강 (1개, 6.25%)
- "비타민C 많은 채소 과일"
- **분석:** 검색(SEO) 중심의 에버그린 콘텐츠로 보임. 장기적 트래픽 유입 기대 키워드.
