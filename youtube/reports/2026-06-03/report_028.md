# YouTube 채널 키워드 분석 리포트

## Executive Summary

본 분석은 총 15개 키워드에 대한 YouTube 검색 트렌드 데이터를 기반으로 한 채널 콘텐츠 전략 수립을 목적으로 합니다. **현재 수집된 데이터는 메트릭 값이 모두 0으로 표시되어 있어, 정량적 분석보다는 키워드 의도와 카테고리별 전략적 접근이 필요한 상태**임을 확인하였습니다.

---

## 1. 데이터 품질 현황

| 항목 | 상태 | 분석 |
|------|------|------|
| **NB Score** | 0 (전체) | 경쟁 강도 측정 불가 |
| **Video Count** | 0 (전체) | 검색 결과 수집 미완료 |
| **Avg Views** | 0 (전체) | 성과 메트릭 부재 |

> **결론**: API 수집 제한 또는 데이터 로딩 지연으로 판단됩니다. 키워드 선정 자체는 유효하므로, **키워드 의도 분석**을 우선 진행합니다.

---

## 2. 키워드 카테고리 분류 및 전략

### A. 뉴스/시사 (실시간성 중시)
- **오늘의 주요 뉴스 🔒** (Rank 1): 락 아이콘 표시로 프리미엄 콘텐츠 가능성
- **사전투표율 역대 최고 의미** (Rank 7): 선거/정치 콘텐츠, 시의성 매우 높음

**전략**: Shorts 형식의 속보성 콘텐츠 권장. 조회수 급등 가능성 높으나 수명 주기 짧음.

### B. 군사/안보 (니치 타겟팅)
- **F-35 라이트닝 II 최신 소식**, **이스라엘 헤즈볼라 교전 상황**, **이란 우라늄 농축 제재 완화**, **한미 핵추진잠수함 협의**

**전략**: 2030 남성 타겟의 강력한 관심사. **장기 조회수 유지** 특성 보유. 썸네일에 전투기/지도 활용 시 CTR 상승 기대.

### C. 경제/금융 (수익화 우수)
- **카카오엔터테인먼트 주가 전망**, **코스피 8800 돌파 전망**, **환율 1500원 돌파 영향**, **계좌 공개**

**전략**: CPM(천당 수익)이 높은 카테고리. **"계좌 공개"**는 브이로그 형식의 신뢰도 구축에 효과적.

### D. 기업/IT (정보성 콘텐츠)
- **스타벅스 카드 혜택 변경**, **삼성전자 직원 성과급 소식**, **스페이스X 기업평가 논란**, **AI 반도체 협력 동향**

**전략**: 구독자 전환율이 높은 실용 정보. 특히 **AI 반도체**는 미래 지향적 테마로 시리즈화 권장.

## 4. 실행 권고사항

1. **즉시 조치**: 현재 0값으로 표시된 메트릭은 YouTube Data API v3의 일일 할당량 초과 또는 키워드 플래닝 툴 미연동으로 추정됩니다. 수동 검색을 통해 경쟁 영상 수와 평균 조회수를 보완 조사하시기 바랍니다.

2. **콘텐츠 믹스**: 뉴스(빠른 트래픽) + 경제(수익) + 군사(충성도) 조합으로 채널 정체성 구축을 권장합니다.

3. **썸네일 A/B 테스트**: 특히 "F-35", "이스라엘" 등 시각적 자극이 가능한 키워드는 썸네일 최적화가 조회수에 결정적 영향을 미칠 것으로 예상됩니다.
