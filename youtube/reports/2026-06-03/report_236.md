# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 해당 채널의 키워드별 콘텐츠 성과를 점검한 결과, **데이터 수집 품질 이슈**가 심각하게 감지되었습니다. 전체 16개 키워드 중 15개(93.75%)가 영상 수(view_count), 조회수(views), NB 스코어 등 모든 지표에서 0값을 기록하고 있어 실제 콘텐츠 성과 분석이 불가능한 상태입니다. 유일하게 유효한 데이터를 보유한 "트럼프 철강 관세 인하" 키워드(1개 영상, 2,575뷰)를 중심으로 한정적인 인사이트를 도출하였으며, 채널의 콘텐츠 메타데이터 수집 시스템의 긴급 점검이 필요합니다.

## 1. 데이터 품질 및 수집 현황 분석

### 1.1 데이터 공백 현상
- **심각한 데이터 결손**: 순위 1~5, 7~16까지 총 15개 키워드에서 video_count, avg_views, nb_score 등 모든 성과 지표가 0으로 기록
- **원인 추정**: 
  - 실시간 뉴스 키워드 크롤링 후 영상 메타데이터 미연동
  - 검색 노출은 되었으나 실제 콘텐츠 미제작 상태
  - API 수집 오류 또는 데이터 동기화 지연

### 1.2 유효 데이터 현황
- **유일한 유효 키워드**: "트럼프 철강 관세 인하" (Rank 6)
  - 영상 수: 1개
  - 조회수: 2,575회
  - 출처: KBS 뉴스 (외부 콘텐츠 가능성)

## 2. 키워드 카테고리 및 트렌드 분석

### 2.1 주요 카테고리 분포
수집된 키워드들은 다음 4가지 카테고리로 분류됩니다:

| 카테고리 | 해당 키워드 | 비중 |
|---------|------------|------|
| **정치/외교** | 핵잠 원자력 협의, 지방선거(투표율/딥페이크/투표 독려), 한미 안보협의 | 37.5% |
| **경제/금융** | OECD 한국 성장률, 닛케이지수, 트럼프 철강 관세, 코스피 사이드카, 골드만삭스 전망, 반도체 수요, 서학개미 | 43.75% |
| **산업/기업** | 젠슨 황 한국 기업 | 6.25% |
| **사회/생활** | 에그플레이션(계란 수입), 재택의료 포럼 | 12.5% |
