# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드의 성과 데이터를 분석한 결과입니다. **전반적인 데이터 품질이 매우 낮으며**, 대부분의 키워드에서 검색량, 노출수, 영상 수 등 핵심 메트릭이 '0'으로 기록되어 실질적인 성과 분석이 제한적인 상황입니다. 유일하게 유효한 데이터를 보인 키워드는 "갓오브워 라우페이 반응"으로, 1개 영상이 36회 조회를 기록했습니다.

## 1. 데이터 품질 및 수집 현황

### 1.1 데이터 공백 문제
분석 대상 16개 키워드 중 **15개(93.75%)**가 완전한 데이터 공백 상태입니다:

| 구분 | 키워드 수 | 비율 | 특징 |
|------|----------|------|------|
| 무효 데이터 | 15개 | 93.8% | 모든 메트릭 0값 |
| 유효 데이터 | 1개 | 6.2% | "갓오브워 라우페이 반응" |

> **주의**: "오늘의 주요 뉴스 🔒"가 1위 키워드로 선정되었으나, 실제 데이터가 없어 검색 트렌드 반영 여부를 확인할 수 없습니다.

### 1.2 카테고리별 키워드 분포
데이터가 존재하는 키워드들의 주제별 분류:

- **정치/선거**: 지방선거 투표율 현황, 모바일 신분증 투표 방법, 한미 안보협의회 결과
- **경제/투자**: 고려아연 주가, 반도체 산업 전망, 삼성전자 레버리지, 코스피 9000선, 대한항공 아시아나 통합
- **기술/AI**: AI 개표 예측 시스템, 피지컬 AI 한국 발전, 국민연금 AI 영상
- **게임/엔터**: 갓오브워 라우페이 반응, 프랑스 오픈
- **국방**: KF-21 시제기 호위비행
- **의료**: 재택의료 법안 시행

## 2. 유일한 성과 데이터 분석

### "갓오브워 라우페이 반응" (Rank 6)
- **영상 수**: 1개
- **평균 조회수**: 36회
- **콘텐츠 유형**: State of Play 라이브 리액션 (게임 공개 행사 반응 영상)

**분석 인사이트**:
- *니치 마켓 성공 사례*: 36회 조회수는 대중적이지 않으나, 특정 게임 타이틀(갓오브워)에 대한 리액션 콘텐츠로서 타겟 오디언스에게 정확히 도달했음을 시사합니다.
- *시의성*: 2026년 6월 State of Play 행사와 관련된 실시간 콘텐츠로, 트렌드 선점형 콘텐츠 전략의 가능성을 보여줍니다.

## 3. 전략적 제언

### 즉각 조치 필요사항
1. **데이터 수집 시스템 점검**: 현재 키워드 추적 시스템의 오류로 보입니다. API 연결 상태 및 검색 볼륨 측정 도구의 정상 작동 여부를 확인해야 합니다.

2. **채널 정체성 수립**: 
   - 금융(코스피, 레버리지), 정치(선거, 안보), 게임(갓오브워) 등 주제가 산만하게 분포되어 있습니다.
   - 현재 유일한 성과를 낸 **게임/리액션 콘텐츠**에 집중하거나, 명확한 카테고리 분리를 통한 멀티 채널 전략을 고려하세요.

3. **"뉴스" 키워드의 실효성**: "오늘의 주요 뉴스"가 상위권에 있으나 데이터가 없는 것은, 실제로는 경쟁이 치열하거나 채널과의 연관성이 낮음을 의미할 수 있습니다. 락(🔒) 표시는 프리미엄/제한 콘텐츠를 의미하나, 실제 노출 데이터가 없어 전략적 가치를 평가하기 어렵습니다.

현재 데이터 품질상 의사결정에 활용하기 어려운 수준입니다. 데이터 수집 인프라를 먼저 정비한 후, 유일하게 성과를 보인 **게임 리액션 콘텐츠**를 중심으로 한 콘텐츠 전략 재수립을 권장합니다.
