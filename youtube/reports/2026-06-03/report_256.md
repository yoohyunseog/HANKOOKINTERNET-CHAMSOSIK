# YouTube 채널 키워드 분석 리포트

## 1. 개요 및 데이터 품질 진단

본 분석 대상 채널은 **뉴스/시사 콘텐츠 중심**의 성격을 보이며, 정치, 경제, 사회, 국제 현안을 아우르는 키워드 포트폴리오를 구성하고 있습니다. 그러나 **데이터 수집 품질에 심각한 문제**가 확인되었습니다.

분석 대상 16개 키워드 중 **15개(93.75%)가 실제 비디오 데이터 없이** 노출되고 있으며, `nb_score`, `video_count`, `avg_views` 등 핵심 지표가 전부 0으로 기록되었습니다. 이는 키워드 추출 로직의 오류, API 수집 실패, 또는 데이터 동기화 지연 등 기술적 문제를 시사합니다.

## 2. 키워드 카테고리 분석

유효한 메타데이터만을 기준으로 한 주제별 분류 결과는 다음과 같습니다:

| **경제/금융** | 닛케이지수, 코스피 사이드카, 골드만삭스 전망, 에그플레이션 | 31% |
