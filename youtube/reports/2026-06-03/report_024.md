# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 15개 후보 키워드에 대한 경쟁 분석 데이터를 검토한 결과입니다. **현재 수집된 메트릭 데이터(video_count, avg_views 등)가 전무**하여 정량적 경쟁 강도 분석은 불가능한 상태이나, 키워드별 시장 카테고리 및 콘텐츠 전략적 방향성은 도출 가능합니다.

## 1. 데이터 현황 및 한계점
- **수집 상태**: 모든 키워드의 nb_score, 조회수, 영상 수가 0으로 표기
- **원인 추정**: API 수집 오류, 필터링 미적용, 또는 초기 샘플링 단계
- **분석 범위**: 키워드 의미론적 분석 및 카테고리 분류에 한정

## 2. 키워드 카테고리 분석

### A. 뉴스/시사 ( ranks 1, 2, 7)
- **"오늘의 주요 뉴스 🔒"**: 락 아이콘 포함으로 구독자 전용 콘텐츠 가능성
- **"F-35 전투기 뉴스"**, **"한국 아프리카 외교"**: 국방/외교 특화 채널 적합
- *전략*: 단발성 조회수보다 구독자 충성도가 중요한 영역

### B. 금융/경제 (ranks 3, 5, 8, 12, 14)
- **"비트코인 가격 변동"**, **"코스피 지수 전망"**, **"환율 동향 분석"**
- **"주식 단타 거래 전략"**: 고위험 고수익 키워드로 알고리즘 노출 규제 가능성
- **"삼성전자 성과급 발표"**: 기업 특화 이슈, 시즌성 강함
- *전략*: 실시간성이 생명, 뉴스 발행 타이밍과 24시간 내 업로드 필수

### C. 산업/기술 (ranks 6, 11)
- **"AI 기술 협력"**, **"반도체 산업 전망"**
- B2B 성향 강하며, 전문가 포지셔닝 필요
- 장기적 조회수 누적 가능 (에버그린 콘텐츠)

### D. 기타 (ranks 4, 9, 13, 15)
- **"스타벅스 카드 이슈"**: 소비자 민원/정보형
- **"대학생 창업 성공 사례"**: 동기부여/교육 카테고리
- **"영화 3학년 2학기"**: 특정 작품 키워드 (시즌성)
- **"도시 재개발 프로젝트"**: 부동산/지역 정보

## 3. 전략적 제안

### 즉시 실행 필요사항
1. **데이터 재수집**: YouTube Data API v3를 통한 실제 검색량, 경쟁 채널 수, 평균 조회수 수집
2. **우선순위 설정**: 
   - **Tier 1**: 비트코인, 코스피 (검색량 높음, 경쟁 치열)
   - **Tier 2**: 반도체, AI (경쟁 적당, 전문가 영역)
   - **Tier 3**: 삼성전자 성과급 (시즌성 이슈, 단기 집중)

### 콘텐츠 방향성
- **뉴스성 키워드**(1, 2, 5, 7위): 오전 7-9시 업로드, 썸네일에 날짜 명시
- **정보성 키워드**(11, 12위): 10분 이상 장평 영상, SEO 최적화 필수
- **이슈성 키워드**(4, 13위): 발행 48시간 내 알고리즘 노출 집중

## 4. 결론
현재 데이터는 키워드 선정의 **질적 방향성**만 확인 가능한 상태입니다. 정량적 경쟁 강도 분석을 위해서는 실제 YouTube 검색 결과 기반 메트릭 재수집이 선행되어야 하며, 특히 "주식 단타 거래"와 같은 규제 대상 키워드는 커뮤니티 가이드라인 준수 여부를 사전 검토할 것을 권장합니다.
