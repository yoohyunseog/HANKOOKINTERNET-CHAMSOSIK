## 3. 데이터 품질 진단

### ⚠️ 심각한 데이터 결함 발견
- **video_count**: 전 키워드 0건 (콘텐츠 미게재 또는 수집 실패)
- **avg_views**: 전 키워드 0회 (성과 측정 불가)
- **nb_score**: 0점 (경쟁력 분석 불가)

**조치 필요**: YouTube Data API 연동 상태 확인 및 검색 필터 재설정 필요.

2. **"환율 1500원" 우선 제작**: 현재 고환율 시대 배경으로 시급성 최고
3. **F-35/헤즈볼라 콘텐츠**: 국제 뉴스의 시간 가치 활용
