# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 총 16개 키워드에 대한 YouTube 검색 및 성과 데이터를 대상으로 진행되었으나, **모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0으로 수집되어 실제 성과 측정이 불가능한 상태**입니다. 이는 데이터 수집 API 연동 오류, 검색 기간 설정 미스, 또는 채널 미등록 상태 등을 시사합니다.

## 키워드 카테고리 분석

### 1. 콘텐츠 주제 분포
수집된 키워드는 다음 6개 카테고리로 분류됩니다:

| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **경제/금융** | 비트코인 시세, 반도체 거품, 삼성전자 시총, 생활물가 | 투자자 관심사 중심 |
| **암호화폐** | 코인판 뉴스, 업비트 소식 | 국내 거래소 중심 |
| **기술/IT** | AI 데이터 품질, HBM5 메모리 | 첨단 기술 트렌드 |
| **뉴스/정치** | 오늘의 주요 뉴스, 지방선거 투표율 | 시의성 중심 |
| **스포츠** | KBO 올스타전, 대한항공 경기 | 실시간 중계 성격 |
| **기업/산업** | GS건설 수주, SpaceX, 스타벅스 | 기업 동향 중심 |

### 2. 키워드 특성 분석
- **시의성 의존도 높음**: "지방선거 사전투표율", "KBO 올스타전" 등 특정 시점에만 유효한 키워드가 37.5%를 차지
- **금융/투자 비중 과다**: 암호화폐 및 주식 관련 키워드가 50%에 달해 채널 주제가 투자 정보에 치우친 경향
- **기술 심화 키워드**: "HBM5", "AI 데이터 품질" 등 전문성이 요구되는 키워드 존재

## 주요 인사이트 및 한계점

### ⚠️ 데이터 품질 경고
현재 수집된 데이터는 **모든 정량적 지표가 0값**을 보이고 있어 다음과 같은 한계가 있습니다:
- 경쟁 강도(NB Score) 파악 불가
- 평균 조회수 및 영상 수 추정 불가
- 키워드별 시장 포화도 분석 불가

### 전략적 시사점
1. **주제 통일성 부족**: 뉴스, 스포츠, 금융, 기술 등 분야가 산재되어 있어 채널의 정체성이 모호함
2. **단기 트래픽 의존**: 선거, 올스타전 등 일회성 키워드 비중이 높아 지속적 조회수 유발이 어려움
3. **틈새 키워드 발굴 가능성**: "HBM5 메모리", "AI 데이터 품질" 등 경쟁이 덜한 전문 키워드는 블루오션 가능성

## 권고사항

### 즉시 조치 필요사항
1. **데이터 수집 시스템 점검**: YouTube Data API 연동 상태 및 검색 파라미터(기간, 지역, 카테고리) 재확인
2. **키워드 검증**: 실제 YouTube 검색 결과에서 해당 키워드의 영상 존재 여부 확인

### 콘텐츠 전략 제안
- **클러스터링**: 금융/투자 키워드(비트코인, 반도체, 삼성전자) 중심으로 주제를 좁혀 권위성 확보
- **시리즈화**: "오늘의 주요 뉴스"를 메인으로 하되, 하위 카테고리(경제/기술/스포츠)로 세분화
- **장기 키워드 비중 확대**: "AI 데이터 품질"과 같이 시의성이 덜한 키워드로 evergreen 콘텐츠 비중 강화
