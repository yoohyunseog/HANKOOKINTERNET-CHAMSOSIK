# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 15개 후보 키워드에 대한 초기 데이터 수집 결과를 분석하였습니다. 현재 모든 키워드의 노출 지수(nb_score) 및 영상 메트릭이 0으로 표시되어 있어, **실제 콘텐츠 제작 전 정밀한 시장 조사 및 경쟁 분석이 필수적**임을 확인하였습니다.

## 1. 데이터 현황 및 한계점

| 구분 | 현황 | 분석 |
|------|------|------|
| **수집 데이터** | 모든 키워드 0값 | 실제 검색량 및 경쟁 영상 데이터 미수집 상태 |
| **키워드 수** | 15개 | 시사, 스포츠, 경제, 정치, 건강 등 다양한 카테고리 혼재 |
| **시급성** | High | 선거 관련 키워드(교육감, 투표용지, 지방선거) 시의성 존재 |

**주의사항**: 현재 데이터는 키워드 후보군 선정 단계로 보이며, 실제 YouTube SEO 분석을 위해서는 `video_count`, `avg_views` 등의 실제 수치 수집이 선행되어야 합니다.

## 2. 키워드 카테고리 분석

### A. 시사/정치 (40%)
- **오늘의 주요 뉴스 🔒**, **이스라엘 레바논 회담 재개**
- **선거 클러스터**: 교육감 분석, 투표용지 사용 방법, 지방선거 경합지 여론조사  
  *→ 선거일 proximity에 따른 급격한 검색량 변동 예상*

### B. 경제/산업 (26.7%)
- 상장지수펀드 수익률 비교, 현대모비스 전기차 부품, 반도체 산업 구조개혁, 에너지 공급망 협력  
  *→ 정보 취약계층 대상 '설명형' 콘텐츠 기회 존재*

### C. 스포츠/라이프 (20%)
- 이정후 MLB 기록, 테니스 그랜드슬램 결과, 자전거 전기 모델 출시  
  *→ 실시간 경기 결과 중심의 Shorts 콘텐츠 적합*

### D. 건강/문화 (13.3%)
- 비타민C 많은 채소 과일, 햄 소시지 암 위험, K컬처 브랜드 프로젝트  
  *→ 꾸준한 검색량 유지 기대, 시즌성 낮음*

## 3. 전략적 제안

### 즉시 실행 과제
1. **데이터 수집 자동화**: YouTube Data API v3를 활용한 실제 검색량 및 경쟁 채널 분석
2. **선거 키워드 선제 대응**: "교육감 분석", "투표용지 사용 방법"은 선거일 전 2주 내 조회수 급증 예상. **Shorts 형식의 가이드 콘텐츠** 우선 제작 권장

### 중장기 전략
- **틈새 키워드 발굴**: "현대모비스 전기차 부품", "에너지 공급망 협력" 등 기업 특화 키워드는 경쟁이 적을 가능성이 높아 **B2B 정보 제공 채널**로 차별화 가능
- **시리즈 기획**: "오늘의 주요 뉴스 🔒"는 락(🔒) 이모지 사용으로 유료 콘텐츠 또는 멤버십 전용 콘텐츠를 암시. **멤버십 가입 유도 전략** 검토

## 4. 결론

현재 데이터는 **의사결정 불가능 상태**이나, 키워드 구성을 통해 해당 채널이 **시사/정치 중심의 종합 정보 채널**로 기획되고 있음을 파악할 수 있습니다. 

**우선순위**: 선거 관련 키워드(시의성) → 스포츠 실시간 결과(트래픽) → 경제/건강(지속성) 순으로 콘텐츠 제작을 권장하며, 본격적인 제작 전 반드시 경쟁사 영상 분석 및 검색량 확인을 완료할 것을 제언합니다.
