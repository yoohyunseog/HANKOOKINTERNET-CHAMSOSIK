**YouTube 채널 키워드 분석 리포트**

## 1. Executive Summary

본 리포트는 총 16개의 키워드에 대한 현황 분석을 제공합니다. **현재 수집된 데이터의 모든 수치 지표(nb_score, 조회수, 영상 수 등)가 0으로 표기**되어 있어 정량적 분석은 불가능한 상태입니다. 이는 데이터 수집이 완료되지 않았거나, API 연동 오류, 혹은 키워드 기획 단계의 초안 데이터일 가능성이 높습니다. 따라서 본 리포트는 키워드의 **주제적 특성과 트렌드 방향성**에 중점을 두고 분석합니다.

## 2. 키워드 카테고리 분석

수집된 키워드들은 다음 4개의 주요 영역으로 분류됩니다:

### A. 정치/선거 논란 (3개 키워드)
- **모스탄 선거 논란**, **잠실 개표소 시위**, **올림픽공원 재선거 요구**
- 선거 후 유권자들의 불만과 재검표 요구가 주요 쟁점으로, 정치 채널의 긴급 뉴스 콘텐츠로 적합합니다.

### B. 경제/금융 동향 (6개 키워드)
- **반도체주 폭락**, **중국 전기차 수출**, **삼성전자 성과급**, **ELS 과징금**, **사내대출**, **AI 반도체 수급**
- 반도체 산업과 금융 정책 변화가 지배적인 테마입니다. 특히 **젠슨 황 삼성 회동**은 기업가 인터뷰 콘텐츠로 활용 가능합니다.

### C. 사회/사건사고 (4개 키워드)
- **케냐 에볼라 센터**, **CU 개인정보 유출**, **국립발레단장 임명**, **서울 지하철 노선**
- 해외 이슈와 국내 기업 사고가 혼재되어 있어 시사/정보 채널의 복합적 소재로 활용 가능합니다.

### D. 일반/브이로그 (2개 키워드)
- **오늘의 주요 뉴스**, **깜짝 방문**
- 제목이 모호하여 경쟁 분석이 어려우며, 브랜디드 콘텐츠 또는 일상 브이로그일 가능성이 있습니다.

## 3. 데이터 품질 진단 및 한계

| 지표 | 현황 | 분석 |
|------|------|------|
| **nb_score** | 0 | 경쟁 강도 측정 불가 |
| **video_count** | 0 | 시장 규모 파악 불가 |
| **avg_views** | 0 | 수익성 예측 불가 |
| **views/videos 배열** | Empty | 개별 영상 분석 불가 |

**위험 요인**: 현재 상태로는 실제 검색량과 경쟁률을 알 수 없어 키워드 선정의 객관적 근거가 부족합니다. 특히 "오늘의 주요 뉴스"와 같이 제목이 불분명한 키워드는 검색意圖 파악이 어렵습니다.

## 4. 전략적 제안

### 즉시 실행 필요 사항
1. **데이터 재수집**: YouTube Data API v3를 통해 실제 검색량, 경쟁 영상 수, 평균 조회수를 수집해야 합니다.
2. **키워드 정제**: "깜짝 방문"과 같이 모호한 키워드는 "연예인 깜짝 방문" 등으로 롱테일 키워드로 구체화해야 합니다.

### 콘텐츠 기획 방향
- **단기 전략**: **젠슨 황 삼성 회동**, **반도체주 폭락** 등 IT/경제 키워드는 검색 수요가 높고 시의성이 강하므로 우선 제작 권장
- **중장기 전략**: **선거 논란** 관련 키워드는 법적 이슈가 있을 수 있으므로 사실 확인 후 신중한 접근 필요
