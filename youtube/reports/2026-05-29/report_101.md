# YouTube 채널 키워드 분석 리포트

## 1. 데이터 개요 및 특이사항

제공된 분석 데이터를 살펴보면, 총 16개의 키워드가 선정되어 있으나 모든 항목의 **정량적 지표(조회수, 영상 수, 점수 등)가 '0'으로 기록**되어 있습니다. 이는 해당 키워드들이 특정 기간 동안 실제 조회 성과를 내지 못했거나, 데이터 수집 시점에 해당 태그가 부여된 영상이 없었음을 의미합니다. 따라서 본 리포트는 성과 지표 대신 **키워드의 구성과 주제적 특성**을 중심으로 채널의 콘텐츠 방향성을 분석합니다.

## 2. 키워드 주제별 분석

키워드 목록은 크게 정치·사회, 경제·금융, 산업·기술의 세 가지 카테고리로 분류됩니다.
