# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 YouTube 채널 키워드 데이터(총 16개)를 바탕으로 채널의 성격과 콘텐츠 전략을 분석하고자 작성되었습니다. 분석 대상 데이터의 모든 항목(Rank 1~16)에 대해 조회수, 영상 수, 점수 등의 수치 데이터가 `0`으로 기록되어 있어 성과 지표에 대한 정량적 분석은 불가능합니다. 따라서 본 보고서는 **키워드의 의미적 연관성과 주제별 카테고리화**를 통해 채널의 잠재적 타겟층과 콘텐츠 방향성을 정성적으로 분석하는 데 중점을 두었습니다.

## 2. 키워드 카테고리 분석
수집된 키워드를 주제별로 분류한 결과, 해당 채널은 **시사·정치**와 **경제·증권** 정보를 중심으로 구성된 **뉴스 및 정보성 채널**로 파악됩니다.
