# 유튜브 채널 키워드 분석 리포트

## 1. 데이터 개요
본 분석 리포트는 제공된 유튜브 채널 키워드 데이터 총 16개를 바탕으로 작성되었습니다. 분석 대상 키워드는 `rank` 1위부터 16위까지 순서대로 정렬되어 있으나, 모든 항목의 `video_count`(영상 수), `avg_views`(평균 조회수) 등 주요 성과 지표가 **0**으로 기록되어 있습니다. 이는 해당 키워드들이 현재 채널 내에서 실제 조회수를 발생시킨 유효 키워드가 아니며, **분석 대상 후보군 혹은 추천 키워드 리스트**일 가능성이 높음을 시사합니다.
