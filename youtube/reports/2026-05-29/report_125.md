# 유튜브 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 유튜브 채널의 키워드 분석 데이터를 바탕으로 채널의 콘텐츠 성향과 현황을 진단하고자 작성되었습니다. 분석 대상 키워드는 총 16개이며, 수치적 데이터(조회수, 영상 수 등)의 특성을 바탕으로 심층적인 분석을 진행합니다.

## 2. 키워드 주제별 분류 및 특성
수집된 키워드는 크게 정치·사회, 경제·금융, 산업·기술의 세 가지 카테고리로 분류됩니다.
