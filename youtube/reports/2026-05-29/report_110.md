# 유튜브 채널 키워드 분석 리포트

## 1. 데이터 개요
본 리포트는 제공된 유튜브 채널 키워드 분석 데이터(총 16개)를 바탕으로 작성되었습니다. 분석 대상 데이터의 가장 두드러지는 특징은 모든 키워드(1위~16위)의 `nb_score`, `video_count`, `avg_views` 등 핵심 성과 지수가 ‘0’으로 기록되었다는 점입니다. 이는 해당 키워드들이 실제 검색 트래픽이나 조회수를 발생시킨 실적 데이터가 아닌, **분석 대상으로 선정된 키워드 후보군** 또는 **특정 기간 내 미반영 데이터**일 가능성을 시사합니다. 따라서 본 분석은 수치적 성과보다는 키워드의 **속성과 주제적 성격**을 중심으로 진행합니다.
