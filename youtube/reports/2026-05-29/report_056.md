# 유튜브 채널 키워드 전략 및 콘텐츠 성향 분석 리포트

## 1. 개요
본 리포트는 제공된 유튜브 채널 키워드 분석 데이터(총 16개)를 바탕으로 작성되었습니다. 분석 대상 데이터의 모든 항목이 조회수, 영상 수, 점수 등에서 '0' 값을 기록하고 있어 성과 지표를 통한 정량적 분석은 불가능합니다. 따라서 본 리포트는 **키워드 리스트의 구성과 주제적 성격**을 중심으로 채널의 콘텐츠 기획 의도와 타겟 오디언스를 유추하는 정성적 분석에 초점을 맞춥니다.
