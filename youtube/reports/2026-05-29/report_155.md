# 유튜브 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 유튜브 채널 키워드 데이터 16개를 분석하여, 채널의 콘텐츠 성향과 전략적 방향성을 도출하기 위해 작성되었습니다. 분석 대상 데이터의 모든 항목이 조회수, 영상 수, 점수 등에서 '0'의 수치를 기록하고 있어 정량적 성과 측정은 불가능하나, 키워드의 **질적 속성과 주제 분포**를 통해 채널의 잠재적 운영 방향성을 진단하였습니다.

## 2. 키워드 주제 분석
수집된 키워드는 크게 정치/사회, 경제/금융, 산업/기술, 생활/이슈 등 4개의 카테고리로 분류됩니다.
