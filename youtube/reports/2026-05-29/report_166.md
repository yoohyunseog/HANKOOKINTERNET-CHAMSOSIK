# 유튜브 채널 키워드 분석 리포트

## 1. 분석 개요

본 리포트는 제공된 유튜브 채널의 키워드 분석 데이터를 바탕으로 작성되었습니다. 분석 대상 데이터는 총 16개의 키워드로 구성되어 있으나, 모든 항목의 조회수(`avg_views`), 영상 수(`video_count`), 점수(`nb_score`) 등의 정량적 지표가 **0**으로 기록되어 있습니다. 이는 해당 채널이 분석 시점 기준으로 리스트업된 키워드에 대한 콘텐츠를 보유하고 있지 않거나, 데이터 수집 범위 내에서 성과를 창출하지 못했음을 의미합니다.
