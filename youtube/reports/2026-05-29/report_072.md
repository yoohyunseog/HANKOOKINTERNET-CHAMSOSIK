# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 YouTube 채널 키워드 데이터(총 15개)를 기반으로 작성되었습니다. 분석 대상 데이터의 모든 항목(`nb_score`, `video_count`, `avg_views` 등)이 '0'으로 기록되어 있어, 실제 조회수 성과나 영상 누적량을 기반으로 한 정량적 성과 분석은 불가능합니다. 따라서 본 보고서는 **키워드의 주제적 특성과 채널의 예상 콘텐츠 전략**을 중심으로 정성적 분석을 수행하였습니다.
