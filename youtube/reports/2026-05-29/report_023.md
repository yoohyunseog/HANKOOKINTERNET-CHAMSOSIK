# 유튜브 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 유튜브 채널의 키워드 분석 데이터(총 16개)를 바탕으로 작성되었습니다. 분석 대상 키워드의 성과 지표(조회수, 영상 수, 점수 등)가 모두 '0'으로 기록되어 있어, 현재 채널의 콘텐츠 성과보다는 **선정된 키워드의 주제적 특성과 잠재적 콘텐츠 전략 방향성**을 중심으로 분석을 진행합니다.
