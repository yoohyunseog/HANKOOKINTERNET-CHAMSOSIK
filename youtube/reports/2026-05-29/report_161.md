# 유튜브 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 유튜브 채널 키워드 데이터(총 16개)를 바탕으로 작성되었습니다. 분석 대상 데이터의 가장 두드러지는 특징은 모든 키워드에 대해 `nb_score`, `video_count`, `avg_views` 등의 핵심 성과 지표가 **'0'**으로 기록되어 있다는 점입니다. 이는 해당 키워드들이 현재 채널 내에서 실제 검색 트래픽이나 조회수를 발생시키지 못하고 있거나, 데이터 수집 시점에 해당 키워드 관련 영상이 존재하지 않음을 의미합니다. 따라서 본 리포트는 성과 수치가 아닌 **키워드의 주제적 성격과 콘텐츠 전략적 잠재력**을 분석하는 데 중점을 둡니다.
