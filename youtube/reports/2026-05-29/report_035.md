# 유튜브 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 유튜브 채널 키워드 분석 데이터(총 15개)를 바탕으로 작성되었습니다. 분석 대상 데이터의 핵심 특징은 모든 키워드에 대해 `nb_score`, `video_count`, `avg_views` 등의 주요 성과 지표가 **0**으로 기록되어 있다는 점입니다. 이는 해당 키워드들이 현재 채널 내에서 검색 유입이 발생하지 않았거나, 관련 콘텐츠가 전무한 상태임을 시사합니다.
