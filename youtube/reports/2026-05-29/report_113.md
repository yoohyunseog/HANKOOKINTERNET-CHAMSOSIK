# 유튜브 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 유튜브 채널 키워드 분석 데이터(총 16개)를 바탕으로 작성되었습니다. 분석 대상 데이터의 가장 두드러지는 특징은 모든 키워드의 `nb_score`, `video_count`, `avg_views` 등 핵심 성과 지표가 **'0'으로 집계**되었다는 점입니다. 이는 해당 채널이 특정 기간 동안 수집된 데이터 내에서 조회수 발생이 없었거나, 키워드에 대응하는 영상이 존재하지 않는 상태임을 시사합니다. 따라서 본 리포트에서는 성과 수치 대신 **키워드의 구성과 주제적 특성**을 중심으로 채널의 콘텐츠 방향성을 분석합니다.

## 2. 키워드 주제 분석
제공된 키워드 목록은 명확한 주제적 군집을 형성하고 있습니다. 이를 통해 해당 채널이 다루고자 하는 콘텐츠의 성격을 파악할 수 있습니다.
