# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 YouTube 채널 키워드 데이터(총 15개)를 기반으로 작성되었습니다. 분석 대상 데이터의 특이사항으로는 모든 키워드의 `nb_score`, `video_count`, `avg_views` 등 핵심 성과 지표가 **0**으로 기록되어 있다는 점입니다. 이는 해당 키워드들이 현재까지 조회수를 발생시키지 못했거나, 데이터 수집 시점에서의 집계가 이루어지지 않은 상태임을 시사합니다. 따라서 본 리포트는 성과 지표 분석 대신, **키워드의 주제별 분류와 콘텐츠 전략적 가치**에 초점을 맞추어 작성되었습니다.
