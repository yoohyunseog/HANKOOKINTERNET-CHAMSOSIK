# 유튜브 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 유튜브 채널 키워드 데이터(총 16개)를 바탕으로 채널의 콘텐츠 전략 및 현황을 분석합니다. 분석 대상 키워드는 정치, 경제, 사회, 게임, 라이프스타일 등 다양한 카테고리를 포괄하고 있으나, 모든 지표가 '0'으로 기록되어 있어 데이터 수집 초기 단계 혹은 채널 신규 시작 단계로 해석됩니다.

## 2. 데이터 현황 및 주요 특징

### 2.1. 데이터 지표 분석
분석된 16개 키워드의 공통적인 특징은 다음과 같습니다.
- **영상 생산 부재 (`video_count`: 0):** 해당 키워드로 제작된 영상이 전무합니다. 이는 채널 운영자가 아직 콘텐츠를 제작하지 않았거나, 데이터 분석 도구가 신규 키워드를 수집 단계에 둔 것으로 보입니다.
- **성과 지표 미확보:** 조회수(`avg_views`, `max`, `min`)와 점수(`nb_score`)가 모두 0으로, 현재 시점에서는 채널의 성과를 측정할 수 없습니다.

### 2.2. 키워드 주제 분석
제공된 키워드 리스트는 크게 4가지 카테고리로 분류됩니다.

| 분류 | 주요 키워드 예시 | 특징 |
| :--- | :--- | :--- |
| **시사/정치** | 오늘의 주요 뉴스, 사전투표 방법, EU 대러시아 제재, 자 유세 일정 | 시의성
