# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 대상 채널의 검색 키워드 노출 현황을 분석한 결과이다. 총 15개 키워드 중 대부분이 메트릭스 미수집 상태(Video Count: 0)로, 데이터 수집 환경의 점검이 필요하다. 유일하게 '명목 성장률 호조' 키워드만 유효한 영상 데이터(조회수 107회)를 보유하고 있으며, 이를 통해 경제 뉴스 콘텐츠의 초기 성과를 확인할 수 있다.

## 1. 데이터 품질 현황
- **수집률**: 15개 키워드 중 1개(6.7%)만 유효한 영상 데이터 보유
- **데이터 공백**: Rank 1~8, 10~15까지 총 14개 키워드에서 Video Count, Avg Views, NB Score 등 전 지표가 0으로 표기
- **원인 분석**: API 호출 오류, 비공개 영상 처리, 또는 키워드-콘텐츠 매칭 실패로 추정됨
