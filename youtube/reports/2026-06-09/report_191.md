# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
분석 대상 16개 키워드 중 **실제 영상 데이터가 존재하는 키워드는 2개(12.5%)**에 불과하여 데이터 신뢰성 및 샘플 대표성에 한계가 확인되었습니다. 유효 데이터를 보유한 "투표지 부족 재선거"(38,228뷰)와 "삼성 kt"(1,148뷰)는 정치/사회 이슈와 스포츠 콘텐츠로, **시의성이 강한 토픽일수록 조회수 격차가 극대화**되는 경향을 보였습니다.

## 2. 데이터 품질 현황
- **데이터 공백률**: 87.5%(14/16)의 키워드가 영상 수 0건, 조회수 0회로 분석 불가 상태
- **측정 가능 키워드**: Rank 3(삼성 kt), Rank 8(투표지 부족 재선거)만 유효 데이터 보유
- **NB Score 전반**: 모든 키워드 0점으로 경쟁 강도 측정 불가

## 3. 핵심 키워드 인사이트

### 3.1 고성과 키워드: "투표지 부족 재선거" (Rank 8)
- **조회수**: 38,228회 (전체 유효 트래픽의 97.1% 점유)
- **콘텐츠 특성**: SBS 논스톱 라이브의 실시간 정치 보도로, 2030 세대의 선거 참여 문제와 사회적 논란을 다룸
- **전략적 의미**: **Breaking News 형태의 사회 이슈**가 안정적인 구독자 기반 없이도 단기간 고조회수를 기록할 수 있음을 시사

### 3.2 저성과 키워드: "삼성 kt" (Rank 3)
- **조회수**: 1,148회 (전체의 2.9%)
- **콘텐츠 특성**: KBO 리그 순위 분석 콘텐츠로, 팬심 기반의 니치 스포츠 커뮤니티 타겟팅
- **한계점**: 제목의 길이(60자 이상)와 복잡한 부제로 인해 알고리즘 노출 효율성이 저하된 것으로 추정

## 4. 카테고리별 분포 특성
- **정치/사회**: 즉각적 반응 유도, 바이럴 잠재력 높음
- **스포츠**: 팬덤 기반 안정적 조회수 but 성장 한계 명확
- **경제/부동산/기술**: 데이터 부재로 시장 관심도 측정 불가 (수출바우처, 동탄신도시, AI 특허 등)

## 5. 전략적 제안
1. **데이터 수집 보완**: 현재 87.5%의 공백률은 의사결정에 치명적 오류를 유발할 수 있으므로, 키워드 추출 로직 및 수집 기간 재검토 필요
2. **콘텐츠 믹스 전략**: "투표지 부족 재선거" 사례처럼 **실시간 사회 이슈 + 라이브 포맷**을 주기적으로 활용하여 비구독자 유입 확대
3. **스포츠 콘텐츠 최적화**: "삼성 kt" 키워드의 경우, 제목 길이를 40자 내외로 축소하고 썸네일에 순위 변동 그래픽을 추가하여 CTR 개선 필요
