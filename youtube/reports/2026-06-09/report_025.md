# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 2024년 주요 시사 키워드 16개에 대한 YouTube 채널 분석 데이터를 바탕으로 작성되었으나, **현재 수집된 모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0값으로 표시**되어 실제 성과 측정은 불가능한 상태입니다. 따라서 본 분석은 키워드의 주제적 특성과 트렌드 방향성을 중심으로 한 정성적 분석에 초점을 맞추었습니다.

## 1. 데이터 품질 진단

**이상 징후**: 모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 기록되어 있습니다.
- **가능성 1**: YouTube Data API 수집 권한 미설정 또는 할당량 초과
- **가능성 2**: 키워드 필터링 조건(검색 기간, 지역 제한 등) 과다 설정
- **가능성 3**: 데이터 정제 과정에서의 파이프라인 오류

**조치 권고**: 데이터 수집 인프라 점검 및 재수집이 선행되어야 정확한 경쟁 분석이 가능합니다.

## 2. 키워드 카테고리 분석

현재 키워드들은 4대 영역으로 분류됩니다:

| 카테고리 | 주요 키워드 | 특징 |
|---------|-----------|------|
| **지정학/안보** | 이스라엘 이란 갈등, 러우 전쟁, 아르메니아 총선 | 글로벌 안보 리스크 중심 |
| **산업/기술** | AI 반도체 투자, 젠슨 황 방문, K-AI 동맹 | 반도체 초국가적 동맹 관련 |
| **경제/금융** | 코스피 블랙먼데이, 부동산 양도세, 외환 공동검사 | 시장 변동성 및 정책 대응 |
| **사회/정치** | 교육교부금, 민주당 전당대회, 조선소 사망사고 | 국내 정책 및 노동 이슈 |

## 3. 콘텐츠 전략 시사점

### 즉시 실행 가능한 전략
1. **실시성 우선**: "오늘의 주요 뉴스"는 락(🔒) 표시로 프리미엄 콘텐츠 가능성을 시사하며, 구독 전환율이 높은 시리즈로 개발 가능
2. **시리즈화 기회**: "AI 반도체"와 "K-AI 동맹", "젠슨 황 방문"은 삼각 편성으로 심층 보도 시너지 예상
3. **이슈 몰빵**: "코스피 블랙먼데이"와 같은 금융 이벤트는 단기 조회수 급증이 예상되나, 발행 타이밍이 핵심

### 데이터 보완 후 분석 필요 사항
- **경쟁 강도**: `nb_score` 기반 블루오션 키워드 선별
- **조회수 분포**: `max`/`min` 비율로 헤드테일 콘텐츠 구분
- **업로드 패턴**: `videos` 데이터 기반 최적 발행 시간대 도출

## 결론
현재 데이터는 정량적 분석이 불가능하나, 키워드 구성만으로도 **AI·반도체 중심의 산업 정책 뉴스**와 **지정학적 리스크**를 아우르는 비즈니스 뉴스 채널의 포지셔닝을 확인할 수 있습니다. 데이터 수집 시스템 정상화 후 재분석을 권장하며, 당분간은 키워드의 검색 트렌드(네이버/구글 트렌드)와 연계한 기획을 우선시할 것을 제안합니다.
