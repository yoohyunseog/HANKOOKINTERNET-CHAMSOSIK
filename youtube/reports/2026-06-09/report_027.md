# YouTube 채널 키워드 분석 리포트

## Executive Summary

본 리포트는 제공된 16개 키워드에 대한 데이터 현황을 분석한 결과, **모든 키워드의 노출 지수(nb_score), 조회수(views), 영상 수(video_count) 등 정량적 지표가 0으로 수집**된 것으로 확인되었습니다. 이는 데이터 수집 시점의 API 오류, 채널 미등록 상태, 또는 검색 필터링 문제로 추정됩니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 방향성과 잠재적 기회 영역을 도출할 수 있습니다.

## 키워드 카테고리 분석

현재 키워드들은 **뉴스/시사 중심의 종합 채널** 성향을 보이며, 다음 4개 영역으로 분류됩니다:

### 1. 국제 정치/안보 (4개)
- 이란 이스라엘 군사 충돌, 러시아 우크라이나 드론 공격, 아르메니아 총선 결과
- **특징**: 지정학적 리스크와 군사 충돌 관련 키워드로, 긴급 뉴스 가치가 높으나 생명주기가 짧음

### 2. 국내 정치/사회 (5개)
- 광화문광장 집회 현황, 검찰 표적 수사 논란, 잠실 개표소 시위, 민주당 당권 경쟁, 교육교부금 내국세 연동 폐지
- **특징**: 정치적 중립성이 요구되는 민감한 주제들로, 시의성과 논쟁성이 공존

### 3. 경제/산업 (5개)
- 골드만삭스 투자 동향, 대규모 투자 프로젝트, 반도체 초과세수 활용, AI 반도체 협력, 부동산 보유세 인상
- **특징**: 금융 투자와 정책 경제가 혼재되어 있으며, 전문성과 대중성의 균형이 필요

### 4. 생활/사회 (2개)
- 유학생 구직 현황, 렉서스 신차 출시
- **특징**: 특정 계층(유학생, 자동차 소비자)을 타겟팅한 니즈 기반 콘텐츠

## 콘텐츠 전략 제안

### 즉시 실행 과제
1. **데이터 재수집**: 현재 모든 지표가 0인 점을 고려, YouTube Data API v3 또는 서드파티 툴(TubeBuddy, vidIQ)을 통해 실제 검색량, 경쟁률, 조회수 데이터를 재확인해야 함

2. **키워드 우선순위 재설정**: 
   - **단기 전략**: "오늘의 주요 뉴스 🔒"와 같이 검색 의도가 명확한 헤드라인 키워드 중심의 시의성 콘텐츠
   - **중장기 전략**: "AI 반도체 협력", "반도체 초과세수 활용" 등 검색 수요가 꾸준한 산업 심층 분석 콘텐츠

### 리스크 관리
- 정치적 키워드(집회, 시위, 수사 논란 등)는 유튜브 알고리즘의 정치적 중립성 필터에 걸릴 위험이 있으므로, 사실 기반 보도와 분석적 시각을 명확히 구분하여 제작 필요

## 결론 및 제언

현재 데이터는 정량적 분석이 불가능한 상태이나, 키워드 구성을 통해 **'글로벌 안보 리스크 + 국내 정치 현안 + 첨단 산업 경제'**라는 3축 콘텐츠 전략을 확인할 수 있습니다. 향후 데이터 수집 시에는 각 키워드별 **클릭률(CTR)**, **평균 시청 지속률**, **구독 전환율** 등 품질 지표를 함께 수집하여 단순 조회수가 아닌 **채널 성장 기여도** 중심의 분석 체계를 구축할 것을 권장합니다.
