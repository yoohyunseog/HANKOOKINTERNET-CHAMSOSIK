# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
본 분석은 총 14개 키워드에 대한 현황 점검 결과, **모든 성과 지표(nb_score, video_count, avg_views 등)가 미수집 상태(0값)**인 데이터 품질 이슈가 확인되었습니다. 따라서 정량적 경쟁 분석은 불가하나, 키워드 구성을 통한 주제별 클러스터링 및 콘텐츠 전략 방향성은 도출 가능합니다.

## 2. 키워드 클러스터링 분석

### 2.1 경제·금융 중심 키워드 (50%)
- **거시 경제**: 코스피 폭락 원인, 환율 교란 대응, 보유세 인상 논란
- **산업 정책**: 반도체 초과세수 활용, 대규모 투자 프로젝트
- **해외 투자**: 골드만삭스 한국 투자

### 2.2 사회·노동 이슈 (21%)
- 광화문광장 집회, 조선소 노동자 시위, 교육교부금 내국세 연동 폐지

### 2.3 기술·글로벌 트렌드 (21%)
- AI 창작 시대, 유학생 미국 진학 트렌드, 아르메니아 친서방 정책

### 2.4 산업 동향 (7%)
- 렉서스 신차 출시

## 3. 시의성 및 리스크 분석

**긴급 뉴스형 키워드 비중 과다**: '오늘의 주요 뉴스 🔒'를 포함한 70% 이상이 시의성에 민감한 단발성 이슈로, **검색 수요의 급격한 변동성**이 예상됩니다. 특히 '🔒' 표기는 유료 콘텐츠 또는 제한적 접근을 암시하므로, 채널의 독점적 정보원 역할을 강조하는 전략이 필요합니다.

## 4. 전략적 제언

### 즉시 실행 과제
1. **데이터 수집 인프라 점검**: YouTube Data API 연동 상태 및 검색 필터 설정 오류 확인 필요
2. **경쟁사 벤치마킹**: video_count=0은 해당 키워드로 아직 콘텐츠가 미생성되었거나, 수집 기준 불일치를 의미함

### 콘텐츠 기획 방향
- **경제 포트폴리오**: 반도체·보유세·환율 키워드 연계 시리즈 기획으로 시너지 창출
- **이슈 대응형**: 'AI 창작 시대'와 같은 기술 트렌드는 장기적 검색 수요 확보 가능
