# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 16개 키워드에 대한 검색 트렌드 분석을 수행하였으나, **모든 정량적 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 수집되어 정량 분석이 불가능한 상태**입니다. 따라서 본 보고서는 키워드 텍스트 자체의 시맨틱 분석과 카테고리 분류를 중심으로 전략적 방향성을 제시합니다.

---

## 1. 데이터 품질 현황

| 메트릭 | 상태 | 비고 |
|--------|------|------|
| NB Score | 0 (전체) | 경쟁 강도 측정 불가 |
| 평균 조회수 | 0 (전체) | 시장 수요 파악 불가 |
| 영상 수 | 0 (전체) | 공급량 분석 불가 |
| Views/Videos 배열 | Empty | 세부 데이터 부재 |

**⚠️ Critical Issue**: 데이터 수집 API 오류 또는 필터링 설정 문제로 인해 실제 검색량 및 경쟁도 데이터가 누락되었습니다. 본 분석은 키워드 명칭 기반의 정성적 분석에 한정됩니다.

## 2. 키워드 카테고리 분석

수집된 16개 키워드는 다음 6개 카테고리로 분류됩니다:

### 📰 뉴스/정치 (4개)
- `오늘의 주요 뉴스 🔒`, `이창수 뉴스`, `지방의회 선거`, `투표지 부족 사태`
- **특징**: 시의성이 강한 정치/사회 이슈 중심, 뉴스 채널 콘텐츠 적합

### 💰 경제/주식 (5개)
- `알 테오 젠 주식`, `리노공업 주가`, `아리바이오 한미약품 빅딜`, `나스닥 기술주 반등`, `이 하락`
- **특징**: 바이오/제약(아리바이오, 리노공업), 반도체(엔비디아), 미국 증시(나스닥) 등 고관심 투자 테마

### 🤖 AI/테크 (3개)
- `젠슨 황 엔비디아 AI 협력`, `AI 감별능력 테스트`, `AI 패러독스 설명`
- **특징**: 엔비디아(반도기체), AI 리터러시(감별능력, 패러독스) 등 첨단 기술 교육 콘텐츠

### 🏠 부동산 (1개)
- `부동산 보유세 인상`
- **특징**: 세금 정책 관련 민감 경제 이슈

### ⚾ 스포츠/여가 (2개)
- `한화 이글스 경기 하이라이트`, `초안산 수국동산 vlog`
- **특징**: 프로야구 하이라이트 및 계절별 여행(수국) 콘텐츠

### 🎭 엔터테인먼트 (1개)
- `이효리 유튜브`
- **특징**: 셀럽 채널 진출 관련 검색
