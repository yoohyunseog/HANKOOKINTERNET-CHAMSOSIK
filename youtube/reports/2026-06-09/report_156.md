## 3. 데이터 품질 진단 및 리스크 분석

### 🔴 Critical Issue: 데이터 미수집 상태
모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 표기된 점은 다음 가능성을 제기합니다:

1. **API 연동 오류**: YouTube Data API 키 만료 또는 할당량 초과
2. **크롤링 실패**: 최근 24시간 내 수집 로직의 기술적 오류
3. **신규 키워드 선정**: 해당 키워드들이 방금 모니터링 대상에 추가되어 축적 데이터가 없는 경우

### ⚠️ 키워드 특성상의 리스크
- **"오늘의 주요 뉴스 🔒"**: 자물쇠 이모지(🔒) 포함으로 인한 검색 정확도 저하 우려
- **장문 키워드**: "근력 측정 앉았다 일어서기"와 같이 자연어 형태의 긴 키워드는 검색 정확도 대비 트래픽이 낮을 수 있음
