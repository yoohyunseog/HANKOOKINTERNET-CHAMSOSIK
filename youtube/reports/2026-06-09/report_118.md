# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 분석은 총 15개 키워드에 대한 채널 성과 데이터를 점검한 결과입니다. **현재 수집된 모든 키워드의 성과 지표(조회수, 경쟁률, 영상 수)가 0으로 표시**되어 있어, 실제 콘텐츠 성과 분석보다는 키워드 포트폴리오의 주제별 분류 및 향후 데이터 수집 전략 수립에 중점을 두어야 합니다.

## 2. 키워드 카테고리 분석

### 2.1 기술·산업 클러스터 (46.7%)
- **핵심 키워드**: AI 반도체 협력, 젠슨 황 방한, 한미 AI 동맹, K-AI 산업 발전, 반도체 주가 전망, 드론 요격 시스템
- **특징**: 최근 글로벌 AI 경쟁과 국내 반도체 산업의 지정학적 이슈를 반영
- **시사점**: 삼성전자 임금 협상 키워드와 결합 시, 기업-노사 관계와 산업 정책의 교차점에서 콘텐츠 기획 가능

### 2.2 정치·외교 클러스터 (26.7%)
- **핵심 키워드**: 한국 TPP 가입, 한일 관계 여론, 재보선 결과 분석, 투표용지 부족 사태
- **특징**: 선거 제도(재보선, 투표용지)와 통상 외교(TPP)가 병존
- **리스크**: 선거 관련 키워드는 시의성이 민감하며, 정치적 중립성 유지 필요

### 2.3 경제·부동산 클러스터 (20.0%)
- **핵심 키워드**: 부동산 세제 개편, 초과이윤 논쟁, 주택 보유세 인상
- **특징**: 세제 개편과 자산 불평등 관련 사회적 담론을 반영

### 2.4 뉴스 아그리게이션 (6.6%)
- **키워드**: 오늘의 주요 뉴스 🔒
- **특징**: 잠금(🔒) 표시로 보아 구독자 전용 콘텐츠 또는 멤버십 전용 콘텐츠로 추정

## 3. 전략적 시사점

### 즉각 조치 필요사항
**데이터 수집 미비**: 모든 키워드의 `nb_score`, `video_count`, `avg_views`가 0인 것은 데이터 수집 API 연동 오류 또는 크롤링 미실시를 의미합니다. YouTube Data API v3 또는 서드파티 분석 툴(예: VidIQ, TubeBuddy) 연결을 우선적으로 확인해야 합니다.

### 콘텐츠 전략 제안
1. **시너지 키워드 조합**: "젠슨 황 방한" + "AI 반도체 협력" + "삼성전자 임금 협상"을 연계한 '글로벌 AI 패권과 국내 산업' 시리즈 기획
2. **시의성 우선순위**: 재보선, 투표용지 부족 등 선거 관련 키워드는 이벤트 기반 콘텐츠로 신속하게 커버리지해야 가치가 있음
3. **딥다이브 vs 브리핑**: 부동산 세제, 초과이윤 등 복잡한 경제 이슈는 장기 분석 콘텐츠로, 뉴스 아그리게이션은 단기 브리핑으로 포지셔닝
