# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 2024년 6월 기준 수집된 16개 핵심 키워드에 대한 분석 결과입니다. **현재 수집된 데이터의 모든 정량적 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표시**되어 있어, 통계적 분석보다는 키워드 트렌드 및 주제별 분류를 중심으로 한 정성적 분석이 수행되었습니다. 데이터 수집 시스템의 재점검 및 API 연동 상태 확인이 시급히 요구됩니다.

## 1. 키워드 카테고리 분석

수집된 키워드는 6개 주요 영역으로 분류됩니다:

### 1.1 금융·투자 (37.5%, 6개)
- **주식 개별 종목**: 알테오젠, 리노공업, 아리바이오-한미약품 M&A
- **시장 동향**: 나스닥 기술주 반등, 부동산 보유세 인상, 이 하락(환율/금리 관련 추정)
- **특징**: 바이오·제약 업종에 대한 관심이 두드러지며, 미국 기술주와 국내 부동산 정책에 대한 시장 민감도가 반영됨

### 1.2 기술·AI (18.8%, 3개)
- **하드웨어**: 젠슨 황 엔비디아 AI 협력
- **콘텐츠·윤리**: AI 감별능력 테스트, AI 패러독스 설명
- **특징**: 생성형 AI에 대한 대중의 인식 전환(기술적 호기심 → 비판적 사고)이 감지됨

### 1.3 뉴스·시사 (25%, 4개)
- **정치**: 지방의회 선거, 투표지 부족 사태
- **미디어**: 오늘의 주요 뉴스, 이창수 뉴스
- **특징**: 선거 관련 이슈와 함께 특정 언론인(이창수)에 대한 브랜드 검색이 공존

### 1.4 라이프스타일·여가 (12.5%, 2개)
- **연예**: 이효리 유튜브 (셀럽 채널 진출)
- **여행**: 초안산 수국동산 vlog (계절성 여행 콘텐츠)

### 1.5 스포츠 (6.3%, 1개)
- **야구**: 한화 이글스 경기 하이라이트 (KBO 리그 팬덤 콘텐츠)

## 2. 데이터 품질 진단 및 권고사항

### Critical Issue
모든 키워드의 `video_count`, `avg_views`, `nb_score`가 0으로 기록된 점은 다음 가능성을 시사합니다:
1. **API 할당량 초과** 또는 인증 키 만료
2. **데이터 수집 크롤러**의 선택자(Selector) 변경으로 인한 파싱 실패
3. **키워드 정규화** 과정에서의 인코딩 오류 (특히 "🔒" 이모지 포함 키워드)

### 즉시 조치 항목
- [ ] YouTube Data API v3 연결 상태 확인
- [ ] 한국어 키워드 URL 인코딩(UTF-8) 검증
- [ ] "🔒" 특수문자 처리 로직 점검

## 3. 콘텐츠 전략 제안

### Short-term (1-2주)
**선거 및 정책 키워드** ("지방의회 선거", "투표지 부족 사태")는 시의성이 중요하므로, 데이터 복구 즉시 긴급 콘텐츠 기획 필요

### Mid-term (1개월)
**AI 윤리 및 바이오 투자** 키워드는 장기적인 시리즈 기획에 적합:
- "AI 패러독스" → 철학·기술 융합 콘텐츠
- "아리바이오 빅딜" → 제약·바이오 산업 분석

### Long-term (분기)
**"이효리 유튜브"**와 같은 셀럽 채널 키워드는 구독자 확보 전략상 협업(콜라보) 후보군으로 활용 가능

## 4. 결론

현재 데이터는 정량적 분석이 불가능한 상태이나, 수집된 키워드들이 **금융 투자(37.5%)**, **시사 뉴스(25%)**, **기술 AI(18.8%)**에 집중되어 있음을 확인했습니다. 이는 해당 채널이 **경제·시사·테크 복합 장르**를 지향하고 있음을 시사합니다.
