**YouTube 채널 키워드 분석 리포트**

## 1. Executive Summary

본 리포트는 14개 핵심 키워드에 대한 YouTube 검색 트렌드 분석을 통해 채널의 콘텐츠 전략 방향을 제시합니다. 현재 수집된 데이터는 성과 지표(조회수, 영상 수, 경쟁 점수)가 미기록 상태이나, 키워드 구성을 통해 경제·사회 분야의 시의적절한 주제 포착이 가능함을 확인했습니다.

## 2. 데이터 품질 현황

**⚠️ 데이터 수집 이슈 감지**
- 전체 키워드의 NB Score, 조회수, 영상 수가 0으로 표기되어 실제 성과 데이터 누락 상태
- 원인: API 수집 오류, 신규 급상승 키워드(데이터 축적 전), 또는 검색 필터 미적용 가능성
- **조치 필요**: 데이터 재수집 및 검증 로직 점검 권고

## 3. 키워드 카테고리 분석

| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **경제/금융** | 골드만삭스 한국 투자, 코스피 폭락 원인, 환율 교란 대응, 반도체 초과세수 활용, 보유세 인상 논란, 대규모 투자 프로젝트 | 시장 불확실성 관심 고조 |
| **사회/노동** | 광화문광장 집회, 조선소 노동자 시위, 교육교부금 내국세 연동 폐지 | 정책 변화 및 사회 갈등 이슈 |
| **기술/미래** | AI 창작 시대 | 기술 트렌드 선점형 콘텐츠 |
| **교육** | 유학생 미국 진학 트렌드 | 학부모/청년층 타겟 |
| **자동차** | 렉서스 신차 출시 | 리뷰 콘텐츠 기회 |
| **국제** | 아르메니아 친서방 정책 | 지정학 심층 분석 소재 |

## 4. 콘텐츠 전략 제안

**즉시 실행 권고 (High Priority)**
- **"AI 창작 시대"**: 기술 초기 도입 단계로 선점 효과 기대, 교육/법제 콘텐츠 기획
- **"코스피 폭락 원인" + "환율 교란 대응"**: 현재 시장 불안 심리 반영, 실시간 분석 콘텐츠 유리

**심층 분석 권고 (Deep Dive)**
- **"교육교부금 내국세 연동 폐지"**: 지방교육재정 개편의 사회적 파급력 분석
- **"보유세 인상 논란"**: 부동산 정책 관심 지속, 세금 폭탄 우려 심리 파고들기

**주의 필요 (Risk Assessment)**
- **"광화문광장 집회"**, **"조선소 노동자 시위"**: 정치적 중립성 및 저작권 이슈 주의, 사실관계 확인 필수

## 5. 결론 및 권고사항

1. **데이터 인프라 보완**: 현재 0값 데이터는 분석 신뢰도를 저하시키므로, YouTube Data API v3 재연동 및 검색 기간 설정(최근 30일) 확인 필요

2. **콘텐츠 파이프라인 구축**: 경제 불확실성 키워드(6개, 43%)가 과반을 차지하므로, 금융·경제 전문 채널로서의 포지셔닝 강화 검토

3. **시즌성 대응**: "렉서스 신차 출시" 등 자동차 키워드는 발표 시점에 맞춘 타이밍 전략 중요
