# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 16개 키워드에 대한 채널 성과 데이터를 분석한 결과입니다. **현재 모든 키워드의 정량적 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 수집되지 않은 상태**이므로, 본 분석은 키워드의 주제적 특성과 카테고리 분포를 중심으로 한 정성적 분석에 초점을 맞추었습니다.

## 1. 데이터 품질 현황
- **수집 상태**: 전체 키워드(16/16)에서 video_count, avg_views, nb_score 등 모든 성과 지표가 미수집 상태
- **분석 한계**: 경쟁 강도, 조회수 잠재량, 콘텐츠 성과 비교가 불가능한 상태
- **필요 조치**: YouTube Data API 연동 및 실제 검색 결과 스크래핑을 통한 데이터 재수집 필요
