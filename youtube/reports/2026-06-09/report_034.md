# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 수집된 16개 핵심 키워드에 대한 데이터 기반 분석을 제공합니다. 그러나 현재 수집된 모든 메트릭(nb_score, 조회수, 영상 수 등)이 **0값으로 표기**되어 있어 정량적 분석이 불가능한 상태입니다. 이는 데이터 수집 과정의 미완료 또는 API 연동 오류를 시사하며, 본 분석은 키워드의 **의미론적 특성 및 카테고리 분류**를 중심으로 진행됩니다.

## 1. 데이터 품질 진단
| 항목 | 상태 | 분석 |
|------|------|------|
| **검색량 지표** | 비정상 | 모든 키워드의 nb_score, avg_views가 0으로 표기 |
| **콘텐츠 수** | 비정상 | video_count 미수집 |
| **데이터 완성도** | 12.5% | 키워드 텍스트만 존재, 메트릭 누락 |

**조치 필요**: 데이터 수집 모듈 재점검 및 유효성 검증(Validation) 로직 확인이 시급합니다.

## 2. 키워드 카테고리 분석
수집된 키워드는 다음 5개 섹터로 분류됩니다:

### A. 정치/사법 (37.5%)
- **검찰 고발 사건**, **표적수사 논란**, **당권 경쟁**, **투표용지 부족**, **MAGA 시위**
- *특징*: 사법 리스크 및 선거 관련 이슈가 주를 이룸

### B. 국제/지정학 (25%)
- **이란 이스라엘 충돌**, **러시아 열차 테러**, **아르메니아 총선**
- *특징*: 중동 및 유라시아 지역의 안보 이슈 집중

### C. 경제/금융 (18.75%)
- **골드만삭스 주가**, **대규모 투자 프로젝트**, **렉서스 신차 출시**
- *특징*: 월가 대형 IB 및 자동차 산업 동향

### D. 교육/사회 (12.5%)
- **유학생 지원 프로그램**, **교육교부금 폐지**
- *특징*: 교육 정책 변화 관심사

### E. 지역/기타 (6.25%)
- **포천시 개발 계획**, **팀 감독**, **오늘의 주요 뉴스 🔒**

## 3. 콘텐츠 전략 제안
현재 키워드 포트폴리오는 **뉴스/시사 전문 채널**의 특성을 강하게 보입니다.

**즉시 실행 과제**:
1. **데이터 재수집**: YouTube Data API v3를 통한 실제 검색량 및 경쟁 강도 파악
2. **시의성 점검**: "러시아 열차 테러", "이란 이스라엘 충돌" 등 긴급 뉴스 키워드의 업로드 시점 확인
3. **니치 선정**: 정치/국제 뉴스 외 **렉서스 신차**(자동차) 또는 **골드만삭스**(투자) 등 전문 분야 다각화 검토

## 4. 결론 및 권고사항
본 데이터는 **원시 데이터(Raw Data)** 수준에 머물러 있어 실제 SEO 성과 예측이 불가능합니다. 키워드 선정 자체는 시사/경제 분야의 전문성을 요구하는 고품질 콘텐츠 방향성을 보여주나, **정량적 기반 마련** 없이는 경쟁 채널 대비 전략 수립이 어렵습니다.

**우선순위**: 데이터 정합성 확보 → 검색량 기반 우선순위 재배치 → 콘텐츠 캘린더 수립
