# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 분석은 총 16개 키워드에 대한 YouTube 검색 및 성과 데이터를 대상으로 진행되었으나, **모든 지표(nb_score, 조회수, 영상 수 등)가 0값으로 수집**되어 정량적 분석이 불가능한 상태입니다. 이는 데이터 수집 API의 오류, 검색 제한, 또는 수집 시점의 비활성화로 인한 것으로 판단됩니다. 본 리포트는 키워드 포트폴리오의 질적 특성 분석과 데이터 인프라 개선 방안을 중심으로 작성되었습니다.

## 1. 키워드 포트폴리오 분석

현재 선정된 키워드들은 다음 5개 카테고리로 분류됩니다:

| 카테고리 | 키워드 | 특성 |
|---------|--------|------|
| **정부/공공** | 디지털배움터, 국립생태원, 국가유산청, 교직원공제회 | 정책 정보 및 공공 서비스 |
| **기업/노동** | 삼성바이오 노조, 맘스터치, 레미콘 파업, SK하이닉스, 쿠팡 | 산업 뉴스 및 노사 관계 |
| **금융/경제** | 레버리지 ETF 급락, 한국차 역수입 | 투자 정보 및 무역 동향 |
| **사회/시사** | 오늘의 주요 뉴스, 투표용지 부족, 초미세먼지 | 뉴스 및 사회 이슈 |
| **문화/기술** | 서울국제도서전, 카카오내비 신호 | 문화 행사 및 IT 서비스 |

**분석 의견**: 키워드 선정이 시사성 높은 이슈 중심으로 이루어졌으나, 검색 볼륨이 낮은 장기적 키워드(예: 서울국제도서전)와 단기 이슈성 키워드(예: 투표용지 부족)가 혼재되어 콘텐츠 전략의 일관성이 다소 약합니다.

## 2. 데이터 품질 진단 및 한계

### 심각한 데이터 결함
- **Zero-value Issue**: 모든 키워드의 `video_count`, `avg_views`가 0으로 표기
- **배열 누락**: `views` 및 `videos` 배열이 비어있어 세부 분석 불가
- **NB Score 무효**: 경쟁 강도 측정 지표(nb_score) 미동작

### 가능한 원인
1. YouTube Data API v3 할당량 초과 또는 인증 오류
2. 키워드 검색 결과 없음(비활성화 또는 삭제된 콘텐츠)
3. 데이터 수집 시점(특정 날짜)에 검색량이 없었던 키워드

## 3. 전략적 제안

### 즉시 실행 필요사항
1. **데이터 파이프라인 점검**: API 연결 상태 및 할당량 확인, 재수집 실시
2. **키워드 정제**: "오늘의 주요 뉴스 🔒"와 같이 특수문자가 포함된 키워드의 검색 가능성 확인
3. **백업 데이터 확보**: Google Trends 또는 타사 분석 툴(Noxinfluencer, VidIQ) 활용

### 중장기 콘텐츠 전략
- **시사 키워드**: 단기 트래픽 확보용으로 활용하되, SEO 장기 키워드와 분리 관리
- **기업/노동 이슈**: 뉴스 채널로서의 정체성 확립 시 효과적이나, 법적 리스크 검토 필요
- **공공 정보**: 경쟹률이 낮은 블루오션 키워드로, 선제적 콘텐츠화 권장
