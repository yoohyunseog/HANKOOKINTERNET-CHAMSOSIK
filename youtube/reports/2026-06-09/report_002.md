# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 2024년 기준 주요 뉴스 및 시사 키워드 15개에 대한 YouTube 검색 데이터 분석 결과입니다. **현재 수집된 모든 키워드의 정량적 지표(nb_score, 조회수, 영상 수)가 0으로 표시**되어 있어, 실제 콘텐츠 성과 분석보다는 키워드 기반 콘텐츠 기획 방향성 제시에 중점을 두었습니다.

## 1. 데이터 현황 및 한계점

| 구분 | 현황 |
|------|------|
| **분석 대상 키워드** | 15개 |
| **수집된 영상 수** | 0건 (전 키워드 동일) |
| **평균 조회수** | 0회 |

## 2. 키워드 카테고리 분석

### 2.1 글로벌 테크/경제 (Rank 2-3)
- **"젠슨 황 한국 방문"**, **"엔비디아 AI 반도체"**
- NVIDIA CEO 방한 및 AI 반도체 관련 키워드로, IT/테크 채널의 핵심 트래픽 유발 요소
- *전략*: 실시간 뉴스 클리핑 + 전문가 해설 콘텐츠 기획 권장

### 2.2 정치/사회 이슈 (Rank 5, 9, 15)
- **"광화문광장 집회 현황"**, **"선관위 투표소 문제"**, **"잠실 개표소 시위"**
- 선거 및 정치 집회 관련 실시성 높은 키워드군
- *주의*: 정치적 중립성 및 사실 확인 필수, Shorts 형식의 속보 전달 유효

### 2.3 지역/생활 뉴스 (Rank 4, 6, 7)
- **"한국타이어 기술 혁신"**, **"설운도 가요계 소식"**, **"포천시 지역 뉴스"**
- 산업/연예/지역사회 복합 카테고리
- *전략*: 틈새 마켓(Niche Market) 타겟팅 가능

### 2.4 국제 정세 (Rank 8, 10, 11)
- **"EU 이란 제재"**, **"러시아 우크라이나 드론"**, **"아르메니아 총선 결과"**
- 지정학적 이슈로 2030 남성층 및 외교 관심 시청자 타겟
- *전략*: 지도 기반 인포그래픽 + 전문가 인터뷰 형식 추천

### 2.5 정책/환경 (Rank 12-14)
- **"교육교부금 내국세 연동"**, **"초가공식품 건강 위험"**, **"한국 플라스틱 감축"**
- 교육/보건/환경 정책 관련 심층 보도 소재
- *전략*: 교육 콘텐츠 및 라이프스타일 채널과의 협업 가능

## 3. 전략적 제안

### 즉시 실행 과제
1. **데이터 수집 인프라 점검**: 현재 모든 메트릭이 0으로 표시되는 것은 API 연동 오류 또는 수집 기간 미설정을 의심할 수 있음. YouTube Data API v3 및 검색 트렌드 데이터 재수집 필요

2. **"오늘의 주요 뉴스" 키워드 분석**: Rank 1에 위치한 해당 키워드는 뉴스 채널의 핵심 트래픽 키워드로, 경쟁 채널 분석 및 업로드 타이밍 최적화가 긴급히 요구됨

### 중장기 전략
- **실시성 우선**: 집회, 선거, CEO 방한 등 실시간 이슈는 업로드 후 2시간 내 노출이 관건
- **숏폼(Shorts) 활용**: "젠슨 황 방문", "초가공식품" 등은 60초 내 요약 영상으로 진입 장벽 낮추기
- **지역 뉴스 강화**: "포천시"와 같은 로컬 키워드는 경쟁 저감 및 지역 광고 수익화 가능성 보유
