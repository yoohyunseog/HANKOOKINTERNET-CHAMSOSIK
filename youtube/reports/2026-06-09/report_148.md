# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)
본 보고서는 YouTube 채널의 키워드 성과 데이터를 분석한 결과입니다. 총 16개 키워드에 대한 검색 결과를 분석한 결과, **모든 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 수집**되어 실제 성과 측정은 불가능한 상태입니다. 다만, 키워드 포트폴리오 자체를 통해 채널의 콘텐츠 방향성과 주제별 분포는 파악할 수 있습니다.

## 2. 데이터 품질 현황
| 항목 | 상태 | 비고 |
|------|------|------|
| nb_score | 0 (미수집) | 노출 빈도 점수 미측정 |
| 평균 조회수 | 0 (미수집) | 영상 성과 데이터 부재 |
| 영상 수 | 0 (미수집) | 콘텐츠량 파악 불가 |
| 데이터 완성도 | **위험** | 분석 불가 수준 |

**⚠️ 데이터 품질 알림**: 현재 제공된 데이터는 API 연결 오류 또는 초기 수집 단계로 보이며, 실제 성과 분석을 위해서는 데이터 재수집이 필요합니다.

## 3. 키워드 포트폴리오 분석

### 3.1 주제별 분류
수집된 키워드는 다음 6개 카테고리로 분류됩니다:

**① 공공/정책 정보 (25%)**
- 교직원공제회, 국립생태원, 국가유산청, 디지털배움터
- *정부 및 공공기관 관련 정보성 콘텐츠*

**② 경제/금융 동향 (25%)**
- 환율 물가 상승, GDP 성장률 1분기, 반도체 경제 성장, 미국 주식 차익실현
- *거시 경제 및 투자 관련 시사 콘텐츠*

**③ 기업/노사 이슈 (18.75%)**
- 맘스터치, 삼성바이오 노조 교섭, 군납품 부정업체 적발
- *기업 동향 및 노사 관계 콘텐츠*

**④ 사회/문화 (12.5%)**
- 서울국제도서전, 시어머니
- *문화 행사 및 사회 관계 콘텐츠*

**⑤ 과학/기술 (6.25%)**
- 초음속 비행기 X-59
- *첨단 기술 및 과학 콘텐츠*

**⑥ 건강/의학 (6.25%)**
- 근력 측정 앉았다 일어서기
- *의학 정보 및 건강 콘텐츠*

**⑦ 뉴스 아카이브 (6.25%)**
- 오늘의 주요 뉴스 🔒 (잠금 표시로 프리미엄 콘텐츠 추정)

### 3.2 키워드 특성 분석
- **시사성**: GDP, 환율, 반도체 등 시의성이 강한 경제 키워드 다수
- **정보성**: 공공기관 및 정책 관련 키워드 비중이 높아 정보제공형 채널로 추정
- **독점성**: "오늘의 주요 뉴스 🔒" 표시로 구독자 전용 콘텐츠 운영 가능성
