# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 분석은 총 16개의 키워드에 대한 성과 데이터를 바탕으로 채널의 콘텐츠 전략 방향성을 제시합니다. 전반적으로 **데이터 수집의 불완전성**이 확인되며, 실제 성과 데이터가 존재하는 키워드는 "물가 환율 상승"(19,606뷰)과 "오늘의 주요 뉴스"(178뷰)에 한정됩니다. 뉴스/시사성 키워드 중심의 채널 특성상 **실시간성과 검색 최적화**가 핵심 성과 요인으로 분석됩니다.

## 2. 데이터 현황 및 품질 분석

### 2.1 데이터 수집 현황
- **전체 키워드**: 16개
- **실제 영상 데이터 보유**: 2개 (12.5%)
- **미수집/무성과 키워드**: 14개 (87.5%)

### 2.2 주요 이슈
대다수 키워드(`윤승아 스페인`, `콰우테모크 블랑코`, `맘스터치 이슈` 등)에서 `video_count: 0` 및 `nb_score: 0`이 기록되었습니다. 이는 다음 가능성을 시사합니다:
- 키워드 수집 시점과 콘텐츠 게시 시점의 불일치
- 비공개 또는 삭제된 영상 존재
- 키워드 추출 알고리즘의 정확도 문제

## 3. 성과 분석: 유효 키워드 중심

### 3.1 고성과 키워드: "물가 환율 상승"
- **조회수**: 19,606회 (전체 대비 99.1% 차지)
- **콘텐츠 특성**: 경제 뉴스 (`[손경제] NDF 거래 | 앤트로픽 | 장바구니 물가상승`)
- **성공 요인**: 
  - 실시간 경제 이슈(환율 1,550원 돌파)에 대한 시의적절한 커버리지
  - 복합 키워드(NDF, 앤트로픽, 물가상승)를 통한 검색 노출 다각화

### 3.2 저성과 키워드: "오늘의 주요 뉴스 🔒"
- **조회수**: 178회
- **콘텐츠 특성**: SBS 뉴스 클립
- **문제점**: 
  - 락(🔒) 표시로 인한 검색 노출 제한 가능성
  - 제네릭(Generic) 키워드로 인한 경쟁 심화

1. **데이터 수집 인프라 점검**: 87.5%의 키워드가 데이터가 없는 것은 분석 불가능 수준입니다. API 연동 및 크롤링 주기를 점검해야 합니다.
2. **뉴스성 콘텐츠의 타이밍**: "물가 환율 상승"의 사례처럼 **실시간 검색어 트렌드**와의 연계가 유일한 성과원임을 확인했습니다. 업로드 타이밍을 검색량 급증 시점에 맞춰야 합니다.

### 4.2 중장기 전략
- **니치 키워드 발굴**: "오늘의 주요 뉴스"와 같은 범용 키워드 대신, "NDF 거래"와 같은 구체적인 경제 키워드로 전환
