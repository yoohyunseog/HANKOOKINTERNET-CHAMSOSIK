# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 수집된 15개 키워드에 대한 데이터 현황을 분석한 결과입니다. **모든 키워드의 노출 지수(nb_score), 조회수, 영상 수가 0으로 표기**되어 있어, 데이터 수집 시점의 API 오류 또는 아직 콘텐츠가 생성되지 않은 **실시간 급상승 검색어**로 추정됩니다. 이는 선제적 콘텐츠 제작의 기회가 될 수 있음을 시사합니다.

---

## 1. 데이터 품질 현황

| 항목 | 상태 | 분석 |
|------|------|------|
| **nb_score** | 0 (전체) | 노출 경쟁력 데이터 미수집 |
| **video_count** | 0 (전체) | 관련 영상 미생성 또는 미인덱싱 |
| **avg_views** | 0 (전체) | 성과 지표 부재 |
| **views/videos** | Empty Array | 원시 데이터 누락 |

> **결론**: 현재 데이터는 정량적 분석이 불가능하며, **키워드 기반의 정성적 트렌드 분석**만 가능한 상태입니다.

## 2. 키워드 카테고리 분석

수집된 키워드는 다음 5개 카테고리로 분류됩니다:

### A. 시사/정치 (4개, 26.7%)
- 오늘의 주요 뉴스 🔒
- 이스라엘 레바논 공격
- 한일관계 TPP 가입  
- 투표용지 부족 사태

**특징**: 국제 분쟁, 외교, 선거 관리 등 **고관심도 사회 이슈**가 포진되어 있어 뉴스 채널의 즉각적인 커버리지가 요구됩니다.

### B. 경제/산업 (5개, 33.3%)
- 반도체 국민소득 증가
- 증시 급반등 공포지수
- 한국차 역수입 가능성
- 젠슨 황 현대차 협력
- 자 아파트 처분

**특징**: 반도체, 자동차, 부동산 등 **한국 경제의 핵심 산업** 키워드가 다수 포함되어 있어 재테크/경제 채널의 타겟 키워드로 적합합니다.

### C. 스포츠/연예 (3개, 20%)
- 두산 베어스 경기 결과
- 양민혁 오영훈 (축구 선수 관련)
- 브래드 피트 한국 관련

**특징**: 실시간 검색어 특성상 **경기 결과, 해외 스타 방한** 등의 이벤트성 키워드가 확인됩니다.

### D. 기술/교육 (2개, 13.3%)
- AI 검증법 모름
- 초등 미술 수능 비문학

**특징**: AI 규제와 교육 정책에 대한 **정보 불확실성**을 반영한 키워드로, 정보 제공형 콘텐츠의 수요가 예상됩니다.

### E. 기타 (1개, 6.7%)
- 사이드카 트렌드
