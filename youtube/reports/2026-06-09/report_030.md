# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 리포트는 총 16개 키워드에 대한 YouTube 검색 트렌드 분석을 수행하였으나, **수집된 데이터의 모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 0값으로 표기**되어 실제 성과 분석은 불가능한 상태입니다. 다만 키워드 텍스트 분석을 통해 채널의 콘텐츠 방향성과 시의성 있는 주제 포착 현황은 파악 가능합니다.

---

## 2. 데이터 품질 현황

| 구분 | 상태 | 비고 |
|------|------|------|
| **정량 데이터** | ⚠️ 미수집 | 모든 키워드의 nb_score, avg_views, video_count가 0 |
| **시계열 데이터** | ⚠️ 공백 | views, videos 배열 미포함 |
| **키워드 텍스트** | ✅ 정상 | 16개 키워드 텍스트 정상 수집 |

**분석 한계**: 경쟁 강도, 조회수 잠재량, 시장 포화도 등의 핵심 지표 산출이 불가능하여 전략적 우선순위 설정에 제약이 있습니다.

## 3. 키워드 카테고리 분석

수집된 키워드는 다음 4개 카테고리로 분류됩니다:

### 3.1 정치·사회 (40%, 6개)
- **시사 뉴스**: "오늘의 주요 뉴스 🔒", "표적 수사 논란"
- **선거·정당**: "선거 투표용지 부족 사태", "정당 전당대회 당권 경쟁", "서울 광화문 집회"
- **사회 사건**: "조선소 산업 재해 사망 사고"

### 3.2 국제·외교 (31%, 5개)
- **지정학**: "이란 이스라엘 군사 충돌", "러시아 우크라이나 드론 공격"
- **미국 정치**: "트럼프 지지자 시위"
- **유럽 동향**: "아르메니아 총선 친서방 승리"
- **해외 교육**: "미국 유학생 트렌드"

### 3.3 경제·산업 (19%, 3개)
- **산업 동향**: "일본 자동차 브랜드", "대규모 투자 프로젝트 전략"
- **거시 경제**: "경제 분석"

### 3.4 교육·정책 (12%, 2개)
- **제도 개편**: "교육교부금 내국세 연동 폐지"
- **스포츠**: "한국 축구 팀 감독"

## 4. 콘텐츠 전략 제언

### 4.1 즉각 조치 사항
- **데이터 재수집**: YouTube Data API v3 또는 외부 분석 툴(예: VidIQ, TubeBuddy)을 활용하여 실제 검색량, 경쟁률, 조회수 데이터 확보가 **필수적**입니다.
- **🔒 표시 키워드**: "오늘의 주요 뉴스 🔒"의 잠금 아이콘은 구독자 전용 콘텐츠 또는 제한적 공개를 의미할 수 있으므로 채널 멤버십 전략 검토가 필요합니다.

### 4.2 시의성 활용 전략
현재 키워드들은 **고시정성(高時政性)**을 보이므로:
- **뉴스 속보형 콘텐츠**: "이란-이스라엘", "트럼프 시위" 등 긴급 이슈는 24-48시간 내 업로드 필요
- **심층 분석형**: "경제 분석", "교육교부금" 등은 장기 조회수 유지가 가능한 에버그린 콘텐츠로 기획

### 4.3 검색 최적화 권장
- **장기 키워드**: "미국 유학생 트렌드 2024", "일본 자동차 브랜드 비교" 등 시즌성이 낮은 키워드로 확장
- **지역 특화**: "서울 광화문" 등 지역명이 포함된 키워드는 로컬 SEO 강화로 경쟁 우위 확보 가능
