# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 16개 키워드에 대한 YouTube 검색 트렌드 분석을 수행한 결과입니다. 수집된 데이터는 정치·선거, 경제·투자, 기술·산업, 건강·라이프스타일, 문화 등 5대 카테고리로 분류되며, **현재 수집된 모든 정량적 지표(nb_score, 조회수, 영상 수)가 0으로 표시되어 데이터 품질 검증 및 재수집이 시급한 상태**입니다.

---

## 1. 데이터 품질 현황

| 지표 | 상태 | 분석 가능성 |
|------|------|-------------|
| NB Score | 0 (전체) | 불가 |
| Video Count | 0 (전체) | 불가 |
| Avg/Max/Min Views | 0 (전체) | 불가 |
| Raw Data (views/videos) | Empty Array | 불가 |

**Critical Issue**: 모든 키워드의 경쟁도 및 성과 지표가 수집되지 않아 정량적 분석이 불가능합니다. API 연동 오류 또는 데이터 수집 시점의 필터링 문제로 추정됩니다.

---

## 2. 키워드 카테고리 분석

### A. 정치/사회 (7개, 43.8%)
- **핵심 키워드**: 지방선거 결과 분석, 서울시장 선거 개표, 민주당 압승 배경, 국민의힘 재보선 성적
- **특이사항**: "투표용지 부족 사태", "재선거 논란" 등 이슈성 키워드 포함
- **시사점**: 선거 직후 또는 특정 정치적 이슈 발생 시점의 트렌드로 보이며, 시의성이 매우 높은 키워드 군집

### B. 경제/투자 (3개, 18.8%)
- **핵심 키워드**: 미국 증시 하락 이유, 반도체 ETF 투자 열기, 코스피 전망 분석
- **특성**: 시장 변동성에 따른 정보 수요가 높은 금융 콘텐츠

### C. 기술/산업 (2개, 12.5%)
- **AI 패러독스 현상**: 생성형 AI에 대한 사회적 논의
- **현대차 주차로봇 기술**: 모빌리티 기술 혁신 관련 콘텐츠

### D. 건강/라이프 (3개, 18.8%)
- **K-푸드 건강 트렌드**, **약식동원 K-푸드**: 한국 음식의 글로벌 건강 트렌드화
- **갑상선암 증가 원인**: 대중 건강 관심사

### E. 문화 (1개, 6.3%)
- **한미 문화예술 교류**: 소프트 파워 및 문화 외교 관련 콘텐츠

---

## 3. 전략적 제언

### 즉시 조치 필요사항
1. **데이터 재수집**: YouTube Data API v3 연동 상태 확인 및 검색량, 조회수 데이터 재수집
2. **시의성 체크**: "지방선거" 관련 키워드는 선거 이후 검색량 급감이 예상되므로, 콘텐츠 기획 시 타임라인 검토 필요

### 콘텐츠 기획 방향
- **정치 카테고리**: 높은 검색량 대비 공급(영상 수)이 0으로 표시되는 점은 데이터 오류일 가능성이 높으나, 만약 실제로 경쟁이 적다면 **선거 분석 콘텐츠**가 블루오션일 수 있음
- **기술/건강 크로스**: "AI 패러독스"와 "갑상선암" 등 전문 지식 기반 키워드는 진입장벽이 높지만 전문성이 확보될 경우 높은 체류시간 확보 가능
