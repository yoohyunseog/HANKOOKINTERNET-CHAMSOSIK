# YouTube 채널 키워드 분석 리포트

## 1. 개요 (Executive Summary)

본 분석은 총 16개 키워드에 대한 YouTube 콘텐츠 성과 데이터를 기반으로 합니다. 분석 결과, **정치/선거 관련 콘텐츠가 압도적인 조회수를 기록**하는 반면, 금융·테크 키워드는 상대적으로 낮은 성과를 보였습니다. 또한 데이터 수집 과정에서 **전체 키워드의 75%(12개)가 영상 데이터 미수집 상태**인 품질 이슈가 확인되었습니다.

## 2. 데이터 현황 및 품질 분석

### 2.1 데이터 수집 현황
- **전체 키워드**: 16개
- **영상 데이터 보유**: 4개 (25%)
- **영상 데이터 미보유**: 12개 (75%)

데이터 미수집 키워드는 `video_count`, `views`, `avg_views` 등 모든 성과 지표가 0으로 표기되어 있어 실질적인 성과 분석이 불가능합니다.

### 2.2 데이터 품질 이슈
`subtitle_summary` 필드에 실제 영상 내용 요약이 아닌, AI 검색 결과 분석 과정에서 생성된 **메타 텍스트(영어)**가 포함된 것으로 확인됩니다. 이는 향후 콘텐츠 분석 정확도를 저하시킬 수 있는 구조적 한계입니다.
