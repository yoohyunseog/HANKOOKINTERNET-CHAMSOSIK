## 3. 데이터 품질 및 인프라 진단

### 주요 이슈
| 지표 | 현황 | 분석 |
|------|------|------|
| nb_score | 전 키워드 0 | 노출 경쟁력 데이터 미수집 |
| video_count | 전 키워드 0 | 크롤링 차단 또는 필터링 오류 가능성 |

### 원인 추정
1. **실시간성 이슈:** 선거 이슈 등 급변하는 키워드에 대한 데이터 갱신 지연
2. **API 제한:** YouTube Data API 할당량 초과로 인한 수집 실패
3. **필터링 조건:** '오늘의 주요 뉴스' 등 특수문자(🔒) 포함 키워드의 인코딩 문제

## 4. 전략적 제언

### 단기 조치 (1-2주)
- **데이터 파이프라인 점검:** API 키 유효성 및 크롤링 로그 확인
- **키워드 정제:** 특수문자(🔒) 및 공백 처리 로직 보완

### 중기 전략 (1개월)
- **카테고리별 콘텐츠 밸런스:** 정치(40%) > 경제(35%) > 사회(25%)의 현재 비중을 AI/테크 분야 비중 확대를 통해 리스크 분산
- **선거 이슈 디클라이닝 대응:** 6월 지방선거 이후 정치 키워드 검색량 감소에 따른 교육/건강 콘텐츠 비중 조정

### 데이터 분석 기준 설정
```
- 수집 주기: 일일 단위 → 시간 단위 변경 (뉴스 채널 특성 고려)
- 경쟁 지표: nb_score 대신 검색량 대비 공급 영상 수 비율 추가
- 성과 지표: avg_views → 조회수 대비 구독자 전환율(CTR) 추가
```
