# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 14개 키워드에 대한 데이터 현황을 분석한 결과입니다. **현재 수집된 모든 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 표시**되어 있어 정량적 분석은 불가능한 상태입니다. 다만 키워드 구성을 통해 컨텐츠 전략 방향성을 제시할 수 있습니다.

## 1. 데이터 품질 현황

| 구분 | 상태 | 비고 |
|------|------|------|
| **nb_score** | 미수집 | 모든 키워드 0점 |
| **조회수 데이터** | 미수집 | avg_views, max/min 전부 0 |
| **영상 수** | 미수집 | video_count 0 |
| **데이터 완성도** | 0% | API 연결 또는 수집 오류 의심 |

> ⚠️ **분석 한계**: 현재 데이터는 실제 YouTube 메트릭이 반영되지 않은 초기 상태입니다. 본 리포트는 키워드 구성 패턴만을 기반으로 한 정성적 분석입니다.

## 2. 키워드 카테고리 분석

### 2.1 주제별 분포
- **정치/선거** (28.6%): 선관위, 서울시장, 한동훈 등 선거 관련 이슈
- **경제/금융** (35.7%): 브로드컴, OECD, 코스피, 비트코인 등 투자 정보
- **사회/문화** (21.4%): 이주노동자 문학, AI 교육, 스타벅스 마케팅
- **기타** (14.3%): 엘살바도르 축구, 형지I&C

### 2.2 키워드 특성
**시사성 중심**: "오늘의 주요 뉴스", "실적 발표", "전망" 등 **실시성이 중요한 키워드**가 다수 포함되어 있습니다. 이는 뉴스 채널 또는 경제 정보 채널로 추정됩니다.

## 3. 전략적 제안

### 즉시 실행 필요 사항
1. **데이터 수집 시스템 점검**: YouTube Data API 연결 상태 및 할당량 확인
2. **키워드 정제**: "🔒" 특수문자 포함 키워드는 검색 정확도를 낮출 수 있어 모니터링 필요

### 컨텐츠 전략 (데이터 수집 후)
- **정치 키워드**: 선거 이슈는 단기적 트래픽 유발 가능하나 지속성이 낮음
- **경제 키워드**: "코스피 9000", "비트코인" 등 투자 심리 자극 키워드는 조회수 상승潜力 높음
- **틈새 키워드**: "이주 노동자 문학"은 경쟁이 낮을 것으로 예상되나 타겟팅 명확해야 함

## 4. 결론

현재 데이터는 **분석 불가능 수준**입니다. YouTube Analytics 연동 또는 외부 데이터 툴(예: VidIQ, TubeBuddy) 연결을 통해 실제 nb_score, 조회수, 경쟁 강도 데이터를 확보한 후 재분석이 필요합니다.

키워드 포트폴리오는 **정치(단기) + 경제(중기) + 문화(장기)**의 균형을 이루고 있어, 데이터 확보 시 시사/경제 채널로서의 포지셔닝이 가능할 것으로 보입니다.
