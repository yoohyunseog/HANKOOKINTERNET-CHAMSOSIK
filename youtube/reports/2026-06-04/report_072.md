# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 총 15개 키워드에 대한 분석 데이터를 바탕으로 작성되었습니다. **현재 모든 키워드의 노출 지수(nb_score) 및 조회수 관련 데이터가 0으로 수집**되고 있어, 정량적 성과 분석은 불가능한 상태입니다. 다만, 키워드 구성을 통해 채널의 콘텐츠 전략 방향성과 시의성 있는 주제 선정 패턴을 파악할 수 있습니다.

## 2. 키워드 카테고리 분석

수집된 키워드는 4개의 주요 영역으로 분류됩니다:

| 카테고리 | 키워드 | 비중 |
|---------|--------|------|
| **정치/선거** | 투표용지 부족 사태, 선관위 재선거 요구, 광주 민주당 압승, 청주시장 당선자, 한동훈 부산 북갑 승리 | 33% |
| **경제/금융** | 현금 없는 시대, 스타벅스 카드 아성, 골드만삭스 코스피 전망, ETF 수급 영향력, 조선업 데이터센터 | 33% |
| **외교/국제** | 한미 무역 합의, 이란 협상 트럼프 | 13% |
| **기술/사회** | AI 감별능력 테스트, 거짓 정보 퍼트리기 | 13% |

*기타: 오늘의 주요 뉴스 🔒 (뉴스 큐레이션)*

## 3. 핵심 인사이트

### 3.1 시의성 중심의 키워드 구성
대부분의 키워드가 **선거 결과, 무역 협상, 기업 실적 발표** 등 시의성이 높은 현안 중심으로 구성되어 있습니다. 특히 '투표용지 부족', '재선거 요구' 등은 선거 관련 이슈에 대한 실시간 대응을 목표로 한 것으로 보입니다.

### 3.2 정치·경제 균형 잡힌 포트폴리오
정치(33%)와 경제(33%)가 동일한 비중을 차지하고 있어, **시사 교양 채널**로서의 정체성을 보여줍니다. '현금 없는 시대', '스타벅스 카드' 등은 일상과 결합한 경제 소재로, 대중 친화적 접근을 시도한 것으로 분석됩니다.

### 3.3 데이터 부재의 한계
현재 모든 메트릭이 0으로 표시되는 것은 다음 가능성을 시사합니다:
- **신규 키워드 기획 단계**: 아직 영상 제작이 시작되지 않은 예비 키워드
- **데이터 수집 지연**: API 연동 문제 또는 수집 기간 미설정
- **비공개 콘텐츠**: 🔒 표시와 같이 비공개 또는 멤버십 전용 콘텐츠로 분류

## 4. 전략적 제안

### 즉시 실행 과제
1. **데이터 수집 인프라 점검**: nb_score 및 조회수 데이터가 정상적으로 수집되도록 API 연동 상태 확인
2. **우선순위 설정**: '오늘의 주요 뉴스'와 같이 시의성이 높은 키워드는 24시간 내 콘텐츠화 필요

### 중장기 전략
- **정치 키워드의 검색량 분석**: 선거 이후 관심도 감소가 예상되므로, 지속 가능한 정책 분석 콘텐츠로 전환 필요
- **경제 키워드의 심화**: 'ETF 수급', '코스피 전망' 등은 검색 수요가 안정적인 장기 키워드로 활용 가능
