# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 총 16개 키워드에 대한 채널 분석 데이터를 바탕으로 작성되었으나, **모든 핵심 지표(nb_score, video_count, avg_views 등)가 0값으로 수집**되어 데이터 품질에 심각한 문제가 확인되었습니다. 현재 데이터는 키워드 후보 목록 수준에 머물러 있으며, 실제 성과 분석이 불가능한 상태입니다.

## 2. 데이터 품질 진단

| 구분 | 현황 | 위험도 |
|------|------|--------|
| **수집 상태** | 모든 수치 0값 | 🔴 Critical |
| **샘플 사이즈** | 16개 키워드 | 🟡 부족 |
| **시계열 데이터** | 미수집 | 🔴 없음 |

**주요 이슈**: API 연동 오류, 크롤링 차단, 또는 데이터 파이프라인 미구동으로 추정됩니다. 즉각적인 데이터 재수집이 필요합니다.

## 3. 키워드 카테고리 분석

수집된 키워드는 5개 주요 영역으로 분류됩니다:

### A. 시사/정치 (25%)
- 오늘의 주요 뉴스, 지방선거 결과 분석, 정치인 비리 수사, 교육감 당선 진보
- **특성**: 시의성 의존도 높음, 트래픽 급등락 심함

### B. 경제/투자 (37.5%)
- AI 반도체, 주식 시장, 부동산, 스페이스X, LG전자, 삼성물산, 외환보유고
- **특성**: 검색량 안정적, CPC(클릭당 비용) 높음, 경쟁 심화

### C. 라이프스타일/건강 (18.75%)
- 서울 날씨, 전자담건 건강영향, 반려동물 항암치료
- **특성**: 서울 날씨는 계절성, 반려동물 의료는 니치 마켓

### D. 문화/엔터테인먼트 (12.5%)
- 무형문화재 석공예, BTS 부산 콘서트
- **특성**: 타겟층 명확하나 검색량 불규칙

## 4. 전략적 제안

### 즉시 실행 (Short-term)
1. **데이터 파이프라인 점검**: YouTube Data API v3 연동 상태 확인 및 재수집
2. **키워드 확장**: 현재 16개는 통계적 유의미성 부족 → 최소 100개 이상 확보
3. **시의성 키워드 선별**: "지방선거", "BTS 콘서트" 등 이벤트성 키워드는 기간 한정 컨텐츠로 전환 필요

### 중장기 전략 (Long-term)
- **경제/투자 카테고리 집중**: 전체 키워드의 37.5%를 차지하며 광고 단가(수익성) 높음
- **틈새 키워드 발굴**: "반려동물 항암치료", "석공예" 등 저경쟁 니치 영역 선점
- **지역성 고려**: "서울 날씨" 등 로컬 키워드는 지역 타겟팅 광고와 연계
