# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 16개 키워드에 대한 YouTube 검색 트렌드 분석을 수행하였으나, **데이터 수집 단계에서의 기술적 이슈로 인해 정량적 지표(nb_score, 조회수, 영상 수 등)가 전무한 상태**임을 우선적으로 보고합니다. 따라서 본 분석은 키워드의 **시맨틱(의미적) 카테고리 분류**와 **콘텐츠 전략적 방향성** 제시에 중점을 두었습니다.

---

## 1. 데이터 품질 현황

| 지표 | 상태 | 비고 |
|------|------|------|
| nb_score | 0 | 노출 가능성 점수 미수집 |
| video_count | 0 | 검색 결과 영상 수 미확인 |
| avg_views | 0 | 평균 조회수 데이터 없음 |
| views/videos 배열 | Empty | 개별 영상 메타데이터 부재 |

**분석 한계**: 현재 데이터셋은 키워드 리스트업만 완료된 상태로, 실제 YouTube 검색 API 연동 또는 크롤링 과정에서 오류가 발생한 것으로 추정됩니다. 정확한 경쟁 강도 분석을 위해서는 데이터 재수집이 필수적입니다.

---

## 2. 키워드 카테고리 분석

수집된 16개 키워드는 다음 5개 카테고리로 분류됩니다:

### A. 정치/사회 이슈 (3개)
- `오늘의 주요 뉴스 🔒`, `투표용지 부족 사태`, `선관위원장 사퇴`
- **특징**: 시의성이 강한 뉴스 키워드로, 검색량 급등 가능성 높음
- **주의**: 🔒 표시는 유료 콘텐츠 또는 제한적 접근을 의미할 수 있음

### B. 경제/금융/테크 (4개)
- `나스닥 지수 동향`, `코스피 급락 원인`, `젠슨 황 한국 방문`, `AI 반도체 동맹`
- **특징**: NVIDIA 관련 키워드(젠슨 황, AI 반도체)가 글로벌 테크 트렌드 반영
- **시장성**: 투자자층 타겟팅 가능한 고부가가치 키워드

### C. 문화/여가/라이프스타일 (4개)
- `경기장 대신 뷰잉펍`, `서울국제환경영화제`, `전주 한옥마을 여행`, `프랑스 요리와 궁중요리`
- **특징**: 경험 소비 및 로컬 여행 중심의 안정적 수요 키워드

### D. 푸드/로컬 맛집 (2개)
- `나주곰탕 맛집`, `프랑스 요리와 궁중요리`(중복 카테고리)
- **특징**: 지역 특화 음식 키워드로 롱테일 검색 유효

### E. 정책/행정/기타 (3개)
- `한미 유해 봉환`, `육군 진급 인사`, `농어촌 삶의질 정책`, `간편보험 비교`
- **특징**: 니즈 기반 실용적 검색 키워드

## 3. 전략적 제안

### 즉시 실행 필요사항
1. **데이터 재수집**: YouTube Data API v3를 활용하여 각 키워드별 검색 결과 수, 평균 조회수, 경쟁 채널 수 재확인
2. **시의성 우선순위**: `젠슨 황 한국 방문`, `투표용지 부족 사태` 등 시급성 높은 키워드는 즉시 콘텐츠 기획 검토

### 카테고리별 접근 전략
- **뉴스/정치**: 단발성 트래픽 확보 가능하나 지속적 구독자 유입 한계. Shorts 형식 권장
- **경제/테크**: 심층 분석 콘텐츠로 채널 전문성 구축. 10분 이상 롱폼 전략
- **여행/푸드**: 지역 SEO 최적화 및 브이로그 형태로 안정적 조회수 확보 가능

### 키워드 조합 제안
단일 키워드 경쟁이 심할 경우, 다음과 같은 롱테일 조합 고려:
- `젠슨 황 한국 방문` + `AI 반도체 동맹` → "젠슨 황이 밝힌 한국 AI 반도체 전략"
- `전주 한옥마을` + `나주곰탕` → "전라도 투어: 한옥마을과 나주곰탕 맛�
