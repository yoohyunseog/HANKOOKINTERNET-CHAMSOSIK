# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 제공된 15개 키워드에 대한 성과 데이터 분석을 수행한 결과입니다. 현재 모든 키워드의 노출 점수(nb_score), 조회수(views), 영상 수(video_count) 등 핵심 지표가 0값으로 표기되어 있어 **정량적 성과 분석이 불가능한 상태**입니다. 이는 데이터 수집 과정의 미완료 또는 특정 필터링 조건 미충족을 시사하며, 우선적인 데이터 정합성 확인이 필요합니다.

## 1. 데이터 현황 및 품질 진단

### 1.1 데이터 수집 상태
- **샘플 크기**: 15개 키워드
- **수집 완료율**: 0% (모든 메트릭스 미수집)
- **영상 데이터**: views[], videos[] 배열 Empty 상태

> ⚠️ **Critical Issue**: 현재 데이터로는 경쟁 강도, 조회수 잠재력, 시장 포화도 등 핵심 의사결정 지표를 산출할 수 없습니다.

## 2. 키워드 카테고리 분석

제공된 키워드들을 주제별로 분류하면 다음과 같은 패턴이 확인됩니다:

| 카테고리 | 키워드 수 | 비율 | 대표 키워드 |
|---------|---------|------|------------|
| **금융/투자** | 9개 | 60% | 나스닥 100, LG유플러스 주가, 연준 금리인상, 비트코인, 마이크론 주가 |
| **기업/산업** | 3개 | 20% | AI 메모리 산업, 엔비디아 CEO 방한, 스페이스X |
| **사회/뉴스** | 2개 | 13% | 한미 전사자 유해 봉환, 지방선거 |
| **라이프스타일** | 1개 | 7% | 오이 여름 요리 레시피 |

### 2.1 채널 포지셔닝 추정
키워드 구성을 통해 본 채널은 **'경제/금융 정보 제공형'** 콘텐츠로 추정됩니다. 특히:
- **단기 트래픽 키워드**: "엔비디아 CEO 방한", "연준 금리인상" (시의성 의존)
- ** evergreen 키워드**: "나스닥 100 실시간", "비트코인 가격" (지속적 수요)
- **니치 키워드**: "LNG 캐나다 가치", "AI 메모리 산업" (전문성 기반)

## 3. 전략적 제언

### 3.1 즉시 실행 필요 사항
1. **데이터 재수집**: YouTube Data API v3 또는 외부 분석 툴(예: VidIQ, TubeBuddy)을 통해 실제 검색량, 경쟁률, 평균 조회수 데이터 확보
2. **키워드 세분화**: "오늘의 주요 뉴스 🔒"와 같이 이모지가 포함된 키워드는 검색 알고리즘에서 필터링될 수 있으므로 순수 텍스트 버전 병행 분석 필요

### 3.2 콘텐츠 전략 방향
**Short-term (1-2주)**:
- "엔비디아 CEO 방한", "연준 금리인상" 등 시의성 키워드는 발행 시점에 따라 조회수 변동성이 극심하므로, 뉴스 발표 24시간 이내 업로드 필수

**Long-term (1-3개월)**:
- "AI 메모리 산업 전망", "LNG 캐나다 가치" 등 저경쟁-고전문성 키워드로 채널 권위성(Authority) 구축
- "오이 여름 요리 레시피"와 같은 생활 키워드는 금융 채널과의 일관성 부족으로 구독자 혼란 유발 가능성 있음 → **제외 권장**

## 4. 결론 및 다음 단계

현재 데이터는 **분석 불가 상태**입니다. 정확한 경쟁 분석을 위해서는:
1. 각 키워드별 월간 검색량(MSV) 확인
2. 상위 랭킹 영상의 평균 조회수 및 채널 구독자 수 확인
3. 키워드 난이도(Keyword Difficulty) 산정

위 3가지 데이터 확보 후 재분석을 권장하며, 특히 금융 정보 채널의 경우 **정보의 정확성과 시의성**이 핵심 KPI이므로, 데이터 기반 업로드 타이밍 전략 수립이 필수적입니다.
