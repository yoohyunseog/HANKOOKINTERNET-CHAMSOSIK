## 3. 데이터 품질 진단 및 한계

| 지표 | 상태 | 분석 |
|------|------|------|
| video_count | 0 | 실제 영상 색인 미완료 |
| avg_views | 0 | 조회수 데이터 누락 |
| nb_score | 0 | 경쟁 강도 측정 불가 |
| views/videos 배열 | Empty | 원시 데이터 미수집 |

**결론:** 현재 데이터는 키워드 트렌딩 순위만 확인 가능하며, 실제 YouTube SEO 및 경쟁 분석을 위해서는 API 재수집 또는 서드파티 툴(VidIQ, TubeBuddy) 활용이 필요합니다.
