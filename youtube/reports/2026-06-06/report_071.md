# YouTube 채널 키워드 트렌드 분석 리포트

**분석 기간:** 실시간 트렌딩 데이터  
**데이터 소스:** YouTube 검색 키워드 API  
**보고 일자:** 2024년  

---

## Executive Summary

본 보고서는 총 16개의 실시간 트렌딩 키워드를 대상으로 한 시맨틱 분석 결과입니다. **현재 수집된 메트릭(video_count, avg_views 등)이 모두 0으로 표시**되어 있어, 정량적 경쟁도 분석은 제한적이나 키워드의 주제별 분포 및 트렌드 방향성을 통해 콘텐츠 전략을 도출할 수 있습니다.

---

## 1. 데이터 품질 및 수집 현황

| 항목 | 상태 | 비고 |
|------|------|------|
| 키워드 수집 | ✅ 완료 | 16개 키워드 식별 |
| 조회수 데이터 | ⚠️ 미수집 | API 응답 지연 또는 필터 미적용 가능성 |
| 경쟁도 점수(NB Score) | ⚠️ 0값 | 초기 데이터 수집 단계로 추정 |

> **분석 제한사항:** 현재 제공된 데이터는 키워드 식별값만 존재하며, 실제 영상 수량, 평균 조회수, 경쟁 밀도 등의 정량적 지표가 누락되어 있습니다. 본 분석은 **키워드 시맨틱(의미적) 분석**에 중점을 두었습니다.

## 2. 키워드 카테고리 분석
