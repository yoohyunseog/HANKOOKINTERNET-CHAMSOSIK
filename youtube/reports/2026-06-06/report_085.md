# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 분석은 채널의 핵심 키워드 15개를 대상으로 한 트렌드 분석입니다. 수집된 키워드는 **경제/금융**, **정치/사회**, **기술/산업**, **문화/생활** 4대 카테고리로 분류되며, 시의성 높은 현안 중심의 뉴스/정보 채널 성향을 보여줍니다.

## 2. 키워드 카테고리 분석

### 2.1 경제/금융 섹터 (33%)
- **비트코인 시세 전망**, **미국 금리 인상 영향**, **주요 증시 변동성**, **AI 반도체 주가 동향**
- 디지털 자산과 전통 금융 시장의 교차점을 다루며, 특히 AI 반도체 관련 키워드는 최근 기술주 중심의 시장 관심도를 반영합니다.

### 2.2 정치/사회 이슈 (40%)
- **오늘의 주요 뉴스**, **지방선거 결과 분석**, **투표용지 부족 사태**, **한미 경제 협력**, **EU 확대 협상 전망**, **해군 작전사령관 인사**
- 선거 관련 키워드(지방선거, 투표용지)와 외교/안보 이슈(한미, EU, 해군)가 복합적으로 나타나 정치 뉴스 채널의 특성을 보입니다.

### 2.3 첨단 기술/산업 (20%)
- **젠슨 황 한국 방문**, **유기분자 신약 개발**, **스페이스X 청약 규제**
- 반도체(엔비디아 CEO 방문), 바이오, 우주산업까지 폭넓은 기술 산업을 커버합니다.

### 2.4 사회/문화 트렌드 (7%)
- **삼겹살 치킨 불금 문화**, **출산율 저하 문제**
- 소비 문화와 인구학적 이슈를 아우르는 사회적 관심사를 포함합니다.

## 3. 데이터 품질 진단 및 한계

**심각한 데이터 결함 확인**: 모든 키워드의 `nb_score`, `video_count`, `avg_views`가 0으로 표기되어 실제 성과 지표 분석이 불가능합니다. 이는 다음 중 하나의 상황을 의미합니다:
- API 데이터 수집 실패
- 신규 키워드 선정으로 아직 콘텐츠 미생성
- 데이터 정제 과정에서의 누락

## 4. 전략적 제언

### 즉시 실행 필요사항
1. **데이터 재수집**: YouTube Analytics 및 검색 API를 통한 실제 조회수, 경쟁 강도, 검색량 데이터 확보
2. **우선순위 재조정**: 현재 15개 키워드 중 검색량과 경쟁률 데이터를 바탕으로 Tier 1(즉시 제작), Tier 2(모니터링), Tier 3(보류) 구분 필요

### 콘텐츠 전략 방향
- **시의성 키워드**(젠슨 황 방문, 투표용지 사태): 빠른 발행이 생명, 24-48시간 내 업로드 권장
- ** evergreen 키워드**(출산율, 비트코인 전망): 장기적 검색 유입 가능, SEO 최적화 필수
- **카테고리 밸런스**: 현재 정치/경제 비중이 70% 이상으로, 삼겹살/치킨과 같은 라이프스타일 콘텐츠 비중 확대 시 시청자층 다변화 가능
