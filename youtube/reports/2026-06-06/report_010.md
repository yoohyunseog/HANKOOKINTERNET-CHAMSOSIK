# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 수집된 15개 핵심 키워드에 대한 채널 성과 분석을 수행하였으나, **현재 모든 정량적 지표(nb_score, 조회수, 영상 수 등)가 미수집 상태**임을 확인하였습니다. 따라서 본 분석은 키워드 구성의 정성적 특성과 주제별 분류를 중심으로 한 전략적 방향성 제시에 중점을 두었습니다.

## 2. 데이터 수집 현황 및 한계

| 지표 항목 | 수집 상태 | 분석 가능성 |
|---------|---------|----------|
| NB Score | 미수집 (0) | 불가 |
| 평균/최대/최소 조회수 | 미수집 (0) | 불가 |
| 영상 수 (video_count) | 미수집 (0) | 불가 |
| 개별 영상 데이터 | 미수집 (Empty Array) | 불가 |

**분석 제한사항**: 현재 제공된 데이터는 키워드 텍스트 정보만 존재하며, 실제 성과 지표가 부재하여 경쟁 강도 분석이나 조회수 예측 모델링이 불가능한 상태입니다.

## 3. 키워드 카테고리 분석

수집된 15개 키워드는 다음 4개 섹터로 분류됩니다:

### 3.1 정치/사회 이슈 (40%)
- **핵심 키워드**: "오늘의 주요 뉴스", "투표용지 부족 사태", "선관위 사과 브리핑", "장성 진급 인사"
- **특성**: 시의성이 강한 정치 사회적 이슈로, 단기 조회수 급등 가능성이 높으나 수명 주기가 짧음

### 3.2 경제/산업 동향 (33%)
- **핵심 키워드**: "젠슨 황 한국 방문", "AI 반도체 동맹", "미국 실업률 발표", "경제 지표 순증"
- **특성**: NVIDIA 관련 키워드(젠슨 황, AI 반도체)가 포함되어 있어 IT/경제 채널의 핵심 트래픽 키워드로 판단됨

### 3.3 국제/외교 (7%)
- **핵심 키워드**: "레바논 이란 발언"
- **특성**: 중동 지역 정세 관련 키워드로, 글로벌 이슈에 민감한 시청자층 타겟팅 가능

### 3.4 문화/라이프스타일 (20%)
- **핵심 키워드**: "환경영화제 개막식", "한옥마을 관광지", "경복궁 러너 카페", "BBQ 치킨 프랜차이즈", "삼겹살 회동 화제"
- **특성**: 지역 축제, 맛집, 프랜차이즈 정보 등 라이프스타일 콘텐츠로 장기적 안정적 트래픽 기대

## 4. 시사점 및 제언

### 즉시 조치 필요사항
1. **데이터 재수집**: YouTube Data API v3를 통한 실제 검색량, 경쟁 채널 수, 평균 조회수 데이터 확보가 우선되어야 함
2. **키워드 세분화**: "오늘의 주요 뉴스"와 같은 범용 키워드는 검색 정확도를 위해 "오늘의 주요 뉴스 2024" 등으로 롱테일 키워드 확장 필요

### 전략적 방향성
- **단기 전략**: "젠슨 황 한국 방문", "AI 반도체 동맹" 등의 IT/반도체 키워드는 현재 높은 검색 트렌드를 보이고 있으므로, 데이터 수집 완료 시 우선 순위 검토 권장
- **중장기 전략**: "한옥마을 관광지", "경복궁 러너 카페" 등 지역 기반 키워드는 SEO 최적화를 통해 지속적 유입 가능

**결론**: 현재 데이터는 키워드 기획 초기 단계의 샘플링 목록
