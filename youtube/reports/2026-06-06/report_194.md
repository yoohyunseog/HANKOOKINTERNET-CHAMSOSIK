**YouTube 채널 키워드 분석 리포트**

## 1. Executive Summary

본 리포트는 총 15개 키워드에 대한 채널 성과 데이터를 분석한 결과입니다. 현재 수집된 데이터 상 **모든 키워드의 노출 점수(nb_score), 조회수(views), 영상 수(video_count)가 0으로 표기**되어 있어 정량적 성과 분석은 불가능한 상태입니다. 다만 키워드 구성을 통해 채널의 콘텐츠 전략 방향성과 개선 포인트를 도출할 수 있습니다.

## 2. 키워드 카테고리 분석

현재 키워드 포트폴리오는 **5개 주요 영역**로 구분됩니다:

| 카테고리 | 키워드 | 비중 |
|---------|--------|------|
| **시사/뉴스** | 오늘의 주요 뉴스, 대통령 G7 순방, 핵잠수함 신채호함, 슈퍼 태풍 | 26.7% |
| **경제/금융** | 실업급여, 원달러 환율, K푸드 종목, 레버리지, 임대수익형 부동산, 기름값 | 40.0% |
| **스포츠** | MLS 올스타전, U.S. 여자 오픈 | 13.3% |
| **기술/산업** | AI 팩토리 삼성반도체, 공기열히트펌프 | 13.3% |
| **정치/행정** | 사전투표 방법 | 6.7% |

**주요 인사이트**: 경제/금융 관련 키워드가 40%로 가장 높은 비중을 차지하며, **정보형 콘텐츠("방법", "전망", "안내")**에 대한 수요가 두드러집니다.

## 3. 데이터 품질 및 리스크 분석

**크리티컬 이슈**: 모든 키워드의 성과 지표가 0으로 기록되어 있어 다음의 가능성을 검토해야 합니다:
- 데이터 수집 API 연동 오류
- 채널 미등록 또는 비공개 상태
- 키워드 설정 후 아직 콘텐츠 게시 전 단계

## 4. 전략적 제언

**즉시 실행 과제**:
1. **데이터 검증**: YouTube Analytics API 연결 상태 확인 및 메트릭 재수집
2. **우선순위 설정**: "실업급여 신청 방법", "사전투표 방법 안내" 등 **실용적 정보형 키워드**를 우선 제작 (검색 수요 안정적)
3. **시의성 대응**: "슈퍼 태풍", "G7 순방" 등 **실시간 뉴스 키워드**는 게시 타이밍이 중요하므로 신속한 콘텐츠화 필요

**중장기 전략**:
- 금융/경제 키워드(40%)에 대한 전문성을 살린 **시리즈 콘텐츠** 기획
- "오늘의 주요 뉴스 🔒"의 자물쇠 이모지는 멤버십 전용 콘텐츠를 암시하므로, **구독자 전환 전략** 수립

## 5. 결론

현재 데이터는 성과 측정이 불가능하나, 키워드 구성을 통해 **'실용 경제 정보 채널'**로의 포지셔닝이 명확히 보입니다. 데이터 수집 시스템 정상화 후, 경제/금융 키워드 중심의 SEO 최적화와 시의성 있는 뉴스 콘텐츠의 병행을 권장합니다.
