# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary
본 분석은 총 16개 키워드에 대한 메트릭을 검토한 결과, **데이터 완전성 불균형**이 가장 큰 특징으로 나타났습니다. 전체 키워드 중 69%(11개)는 영상 데이터가 수집되지 않았으며, 실제 콘텐츠가 확인된 5개 키워드만을 기반으로 한 분석을 수행했습니다.

## 2. 데이터 품질 및 완전성 분석
- **결측 현황**: Rank 1, 5, 7, 8, 10-16까지 총 11개 키워드에서 `video_count: 0` 및 `avg_views: 0` 상태
- **유효 데이터**: Rank 2(젠슨 황), 3(장성 인사), 4(반도체 주가), 6(미국 이란), 9(AI 기술센터)만 실제 콘텐츠 보유
- **수집 오류 가능성**: "오늘의 주요 뉴스 🔒" 등 상위 랭킹 키워드조차 데이터가 없어, 실시간 트렌딩 키워드 수집 과정에서의 누락 또는 접근 권한 제한으로 추정됨

## 3. 콘텐츠 카테고리별 성과 분석

### 3.1 기술/경제 뉴스 (High Performance)
- **젠슨 황 한국 기업 회동**: 평균 조회수 102,755회로 압도적 1위
  - KBS(47,994회) vs JTBC(157,516회)로 보도사별 편차 큼
  - AI/반도체 산업 이슈에 대한 시장 관심도 확인
- **반도체 주가 급락 원인**: 평균 3,949회, 총 3개 영상
  - 금융/투자 정보 콘텐츠로서 안정적 수요 존재

### 3.2 엔터테인먼트/드라마 (Low Engagement)
- **장성 인사 군 인사变动**: 평균 조회수 257.5회로 최저 성과
  - 중국 웹소설/드라마 콘텐츠로 추정되나, 한국어 키워드 최적화 미흡
  - 조회수 편차(514회 vs 1회)로 알고리즘 노출 불안정성 확인

### 3.3 정치/사회 이슈 (Moderate)
- **미국 이란 호르무즈 충돌**: 6,606회
- **AI 기술센터 서울 설립**: 3,506회 (단, 영상 제목이 선거 관련으로 실제 키워드 매칭 오류 가능성)

## 4. 전략적 제언

### 즉시 실행 과제
1. **데이터 파이프라인 점검**: 11개 키워드의 누락 원인 분석 및 API 수집 로직 보완 필요
2. **키워드 정제**: "장성 인사 군 인사变动"과 같은 비자연스러운 키워드는 검색 최적화 실패 가능성이 높아 자연어 처리(NLP) 개선 필요

### 콘텐츠 전략
- **반도체/AI 클러스터**: 젠슨 황 관련 콘텐츠의 10만+ 조회수를 고려할 때, 삼성전자-SK하이닉스-NVIDIA 삼각 관계 분석 콘텐츠 확보 권장
- **금융 뉴스**: 단순 주가 분석보다는 "버핏 투자 전략"과 같은 구체적 투자자 행동 분석으로 차별화 필요

### 리스크 관리
- **정치적 중립성**: 선거/계엄 관련 키워드(Rank 7, 9, 13, 14)가 다수 포함되어 있으나 데이터 누락 상태. 향후 수집 시 사실 확인 및 균형 잡힌 보도 주의 필요
