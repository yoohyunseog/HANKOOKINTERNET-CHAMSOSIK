# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 제공된 16개 핵심 키워드를 대상으로 한 YouTube 검색 트렌드 분석 결과입니다. 분석 기간 내 수집된 데이터를 바탕으로 콘텐츠 기획 및 채널 전략 수립을 위한 인사이트를 제시합니다.

**분석 대상 키워드 수:** 16개  
**데이터 수집 상태:** 메트릭 수집 진행 중 (현재 모든 수치 0값 상태)

---

## 2. 키워드 카테고리 분석

제공된 키워드는 다음 6개 주요 영역으로 분류됩니다:

| 카테고리 | 키워드 수 | 주요 키워드 |
|---------|---------|------------|
| **경제/금융** | 5개 (31%) | 비트코인 시세, 주요국 금리, 반도체 시총, 나스닥, 삼성전자 |
| **스포츠** | 3개 (19%) | 샌프란시스코 자이언츠, 마카오 축구, 레알 마드리드 |
| **뉴스/시사** | 3개 (19%) | 오늘의 주요 뉴스, 현충일 대체공휴일, 투표용지 부족 |
| **기술/산업** | 2개 (13%) | AI 기술 양산, 스페이스X 공모주 |
| **정치/행정** | 2개 (13%) | EU 확대, 해군 작전사령관 인사 |
| **부동산** | 1개 (6%) | 주상복합 동선 가치 |

### 2.1 핵심 특징
- **경제 금융 중심**: 전체 키워드의 31%를 차지하며, 특히 주식 시장(나스닥, 삼성전자, 반도체)과 가상화폐(비트코인)에 대한 관심이 두드러집니다.
- **글로벌 스포츠**: MLB(샌프란시스코 자이언츠)와 유럽 축구(레알 마드리드)를 아우르는 국제 스포츠 소식이 포함되어 있습니다.
- **시의성**: 현충일, 투표용지 등 특정 시점의 사회적 이슈가 반영되어 있습니다.

---

## 3. 데이터 현황 및 분석 한계

현재 제공된 데이터셋의 모든 수치(nb_score, video_count, avg_views 등)가 **0값**으로 표기되어 있어 정량적 분석이 불가능한 상태입니다. 이는 다음과 같은 상황을 시사합니다:

1. **초기 데이터 수집 단계**: 키워드 선정은 완료되었으나 실제 영상 메트릭 수집이 진행 중
2. **API 연동 미완료**: YouTube Data API 또는 분석 툴 연결 상태 확인 필요
3. **필터링 설정 오류**: 특정 기간/지역 설정으로 인해 데이터가 필터링된 가능성

---

## 4. 전략적 제언

### 4.1 콘텐츠 기획 방향
**단기 전략 (시의성 키워드)**
- "현충일 대체공휴일", "투표용지 부족 사태" 등 시의성 있는 키워드는 즉각적인 콘텐츠 제작이 필요합니다.

**중장기 전략 (시세/전망 키워드)**
- "비트코인 시세 전망", "삼성전자 주가 전망" 등 지속적인 검색이 예상되는 키워드는 시리즈 콘텐츠로 기획할 것을 권장합니다.

### 4.2 데이터 수집 개선안
정확한 경쟁 분석을 위해 다음 메트릭 수집이 필요합니다:
- **경쟁 강도 (Competition Score)**: 해당 키워드로 검색 시 노출되는 영상 수
- **조회수 분포**: 상위 영상의 평균/최대/최소 조회수
- **업로드 주기**: 신규 콘텐츠의 업로드 빈도
