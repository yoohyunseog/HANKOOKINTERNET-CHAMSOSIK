# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 보고서는 제공된 16개 키워드 데이터를 기반으로 한 YouTube 콘텐츠 트렌드 분석입니다. **정량적 메트릭(video_count, avg_views 등)이 수집되지 않은 데이터 한계**를 고려하여, 키워드의 시의성, 카테고리 분포, 주제 연관성 중심의 정성적 분석을 수행하였습니다.

---

## 1. 데이터 현황 및 한계점

| 구분 | 현황 |
|------|------|
| **분석 대상** | 16개 키워드 |
| **수집 기간** | 미상 (실시간 트렌드 추정) |
| **데이터 품질** | 모든 수치 메트릭(nb_score, views 등) 0값 상태 |
| **분석 방법** | 키워드 시맨틱 분석 및 카테고리 분류 |

> **주의**: 현재 데이터는 검색량, 경쟁도, 조회수 등 정량적 지표가 수집되지 않아 **경쟁 강도 분석이 불가능**합니다. 향후 VidIQ 또는 TubeBuddy 등의 도구로 메트릭 재수집이 필요합니다.

- **특징**: K-컬텐츠와 환경 이슈 병행
- **시사점**: 뉴스 채널보다는 브이로그/푸드 채널 적합
