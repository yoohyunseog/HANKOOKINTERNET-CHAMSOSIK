# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary (요약)

본 보고서는 총 16개의 키워드에 대한 YouTube 채널 성과 데이터를 분석한 결과입니다. **현재 수집된 모든 키워드의 노출(nb_score), 조회수(views), 영상 수(video_count) 등 정량적 지표가 0으로 표시**되어 있어, 실제 성과 분석보다는 키워드 포트폴리오의 주제별 분류 및 콘텐츠 전략적 방향성 제시에 중점을 두었습니다. 수집된 키워드는 시사/정치, 경제/금융, 과학/기술, 문화/예술, F&B(음식) 등 5개 핵심 카테고리로 분류되며, 고도로 세분화된 전문 주제와 대중성을 겸비한 트렌드 키워드가 혼재된 특징을 보입니다.

## 2. 키워드 포트폴리오 분석

### 2.1 카테고리별 분포 현황

| 카테고리 | 주요 키워드 | 특성 |
|---------|------------|------|
| **경제/금융** | 나스닥 시장 동향, 환율 급등 경제 영향, 코스피 급락 원인 | 실시간성 중시, 긴급 뉴스성 콘텐츠 |
| **기술/과학** | 젠슨황 AI 동맹, 로봇공학 미래 전망, 신약 개발 유기분자 연구 | 전문 지식 기반, 심층 분석 콘텐츠 |
| **시사/정치** | 오늘의 주요 뉴스 🔒, 투표용지 부족 사태, 임장 인천형 정책 | 사회 이슈, 정책 해설 중심 |
| **문화/예술** | 프랑스 요리 궁중요리 비교, 서울국제환경영화제, 에코프렌즈 바다 공연 | 교양/인문학적 가치, 시각적 콘텐츠 적합 |
| **라이프스타일/F&B** | 삼겹살 치킨 회동, 나주곰탕 유래, 뷰잉펍 여름 경쟁, 치매머니 사냥 게임 | 대중성 높은 트렌드/푸드 콘텐츠 |

### 2.2 키워드 특성 분석

**전문성 vs 대중성 스펙트럼**
- **고전문성 키워드**: "신약 개발 유기분자 연구", "젠슨황 AI 동맹" 등은 전문 지식을 요구하는 니치 콘텐츠로, 타겟층이 명확하나 진입 장벽이 높음
- **대중 트렌드 키워드**: "삼겹살 치킨 회동", "치매머니 사냥 게임" 등은 즉각적인 시청 유인이 가능한 라이트한 콘텐츠
- **뉴스성 키워드**: "투표용지 부족 사태", "환율 급등" 등은 시의성이 중요하며 빠른 발행이 필수

## 3. 데이터 품질 및 수집 현황

**주요 이슈**: 모든 키워드의 정량적 지표(nb_score, avg_views, video_count)가 0으로 기록되어 있어, 다음과 같은 가능성을 검토해야 합니다:

1. **데이터 수집 미완료**: API 수집 지연 또는 필터링 조건 미충족
2. **채널 특화 키워드**: 해당 채널에서 아직 다루지 않은 신규 키워드 후보군
3. **비공개/제한 콘텐츠**: 🔒 표시가 있는 "오늘의 주요 뉴스"처럼 접근 제한이 있는 콘텐츠

### 4.1 우선순위 설정
- **즉시 실행**: 경제/시사 키워드(환율, 코스피, 투표용지)는 시의성이 중요하므로 24-48시간 내 발행 권장
