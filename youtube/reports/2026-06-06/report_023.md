# YouTube 채널 키워드 분석 리포트

## 1. 개요
본 리포트는 대상 채널의 핵심 키워드 15개에 대한 현황 분석을 제공합니다. 분석 결과, 현재 수집된 성과 지표(조회수, 영상 수, 경쟁 점수 등)가 미측정 상태이나, 키워드 포트폴리오 구성을 통해 채널의 콘텐츠 방향성과 시장 포지셔닝을 파악할 수 있습니다.

## 2. 데이터 현황 분석
**측정 상태**: 모든 키워드의 NB Score, 조회수(avg_views), 영상 수(video_count)가 0으로 표기  
**해석**: 데이터 수집 초기 단계 또는 API 연동 미완료 상태로 추정됩니다. 본격적인 콘텐츠 성과 분석을 위해서는 실제 영상 메타데이터 및 성과 지표의 수집이 선행되어야 합니다.
