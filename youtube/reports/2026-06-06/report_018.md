# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 총 16개의 키워드에 대한 YouTube 채널 분석 데이터를 바탕으로, 현재 트렌드 키워드의 카테고리별 분포와 콘텐츠 전략적 시사점을 제시합니다. 현재 수치 데이터(video_count, avg_views 등)가 미수집 상태이므로, 키워드 자체의 시장성과 카테고리별 특성을 중심으로 한 정성적 분석을 제공합니다.

## 1. 데이터 현황 및 한계점

**데이터 수집 상태**: 현재 모든 키워드의 nb_score, video_count, avg_views가 0으로 표기되어 있어, 실제 검색량 및 경쟁도 분석이 불가능한 상태입니다. 이는 데이터 수집 API 연동 미완료, 특정 필터 조건(기간/지역) 미충족, 또는 신규 트렌드 키워드로 인한 데이터 누적 부족을 의미할 수 있습니다.

**분석 가능 범위**: 키워드 텍스트 자체의 의미와 카테고리 분류를 통한 정성적 분석만 가능합니다.

## 2. 키워드 카테고리 분석

수집된 16개 키워드는 다음 5개 카테고리로 분류됩니다:

| 카테고리 | 키워드 수 | 비중 | 주요 키워드 |
|---------|---------|------|------------|
| **시사/정치** | 4개 | 25% | 투표용지 부족 사태, 선관위원장 사퇴, 장성 인사 진급 |
| **경제/금융** | 4개 | 25% | 환율 17년 만에 고점, 코스피 급락 원인, 나스닥 실업률 발표 |
| **기술/산업** | 2개 | 12.5% | AI 동맹 기업 협력, 피지컬AI 신산업 |
| **라이프스타일** | 4개 | 25% | 삼겹살에 치킨 회동, 프라페 뷰잉펍 트렌드, 전주 한옥마을 여행 |
| **의료/복지** | 2개 | 12.5% | 유기분자 신약 개발, 간편보험 유병자 차등 |

### 2.1 시사/정치 카테고리 특징
선거 관련 키워드("투표용지 부족 사태", "선관위원장 사퇴")와 인사 관련 키워드가 혼재되어 있어, **선거 시즌** 또는 **정치적 이슈 발생 시기**의 데이터임을 추정할 수 있습니다. "오늘의 주요 뉴스 🔒"는 뉴스 채널의 주요 콘텐츠 형식을 나타냅니다.

### 2.2 경제/금융 카테고리 특징
환율 고점, 코스피 급락, 나스닥 실업률 등 **거시경제 지표** 중심의 키워드가 포진되어 있습니다. 특히 "17년 만에 고점"과 같은 구체적 수치가 포함되어 있어, 시장 변동성이 큰 시기의 검색 트렌드로 보입니다.

### 2.3 기술/산업 카테고리 특징
"AI 동맹"과 "피지컬AI(Physical AI)" 키워드는 최신 기술 트렌드를 반영하고 있으며, 특히 Physical AI는 2024-2025년 급부상한 메가트렌드로 **성장 가능성이 높은 키워드**입니다.

## 3. 전략적 시사점 및 제언

### 즉시 실행 필요사항
1. **데이터 수집 재확인**: 현재 모든 수치가 0인 상태이므로, YouTube Data API 연동 상태 및 검색 필터(기간 설정, 지역 설정)를 우선 점검해야 합니다.

2. **시사/경제 키워드의 시의성**: 선거, 환율, 주식 관련 키워드는 **시의성이 매우 중요**한 카테고리입니다. 해당 키워드들은 검색량이 특정 이벤트 중심으로 급등하므로, 실시간 데이터 수집이 필수적입니다.
