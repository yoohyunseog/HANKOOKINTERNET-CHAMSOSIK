# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 분석은 총 15개 키워드에 대한 YouTube 채널 성과 데이터를 대상으로 진행되었으나, **모든 메트릭(nb_score, 조회수, 영상 수 등)이 0으로 수집**되어 정량적 성과 분석이 불가능한 상태입니다. 데이터 수집 과정의 오류 또는 API 연동 문제로 판단됩니다.

다만, 키워드 구성을 통해 채널의 콘텐츠 전략 방향성은 파악 가능합니다.

## 2. 키워드 포트폴리오 분석

수집된 키워드는 다음 5개 카테고리로 분류됩니다:

| 카테고리 | 키워드 | 비중 |
|---------|--------|------|
| **금융/투자** | 주식시장 급락 전망, 비트코인 시세 분석, 미국 금리 인상 영향, 원달러 환율 전망, 금융 시장 변동성 | 33% |
| **거시경제** | 경상수지 흑자 기록, 무역협상 중국산 부품 | 13% |
| **기술/산업** | 반도체 시총 감소, AI 기업 양산 경쟁 | 13% |
| **정치/사회** | 오늘의 주요 뉴스 🔒, 지방선거 결과 분석, EU 확대 제안 | 20% |
| **부동산/기타** | 주상복합 동선 가치, 자 분석*, K팝 스타 일정 | 20% |

*참고: "자 분석"은 데이터 오류로 추정

**핵심 특성**: 금융 경제 뉴스 중심의 정보형 채널로, 실시간 시장 동향(주식, 코인, 환율)과 정책 이슈(금리, 무역)에 초점을 맞춘 포트폴리오입니다.

## 3. 데이터 품질 진단

### Critical Issue: 메트릭 Null 상태
- **nb_score**: 모든 키워드 0점 (경쟁력 점수 미산출)
- **영상 메트릭**: video_count, avg_views, max/min views 전부 0
- **콘텐츠 리스트**: views 및 videos 배열 Empty

### 원인 추정
1. YouTube Data API 할당량 초과
2. 키워드 필터링 로직 오류 (검색 결과 0건)
3. 데이터 수집 크롤러 장애
4. 채널 미인증 또는 비공개 상태

## 4. 전략적 권고사항

### 즉시 조치 필요 (Priority 1)
- 데이터 수집 인프라 점검 및 API 연동 상태 확인
- "오늘의 주요 뉴스 🔒" 등 잠금 표시 키워드의 접근 권한 확인
- "자 분석" 등 불완전한 키워드 정제

### 콘텐츠 전략 제안 (데이터 복구 후)
현재 키워드 구성상 **'실시간 금융 뉴스'**와 **'시장 전망 분석'**이 핵심 테마입니다. 데이터 복구 후 다음 지표 중점 모니터링이 필요합니다:
- 금융 키워드의 검색량 대비 공급 영상 수 (경쟁 밀도)
- 뉴스성 키워드의 조회수 분포 (최신성 민감도)
- 시세/전망 키워드의 시청 유지율 (전문성 척도)

### 데이터 재수집 체크리스트
- [ ] YouTube API 키 유효성 확인
- [ ] 키워드 인코딩 문제 확인 (한글 깨짐 여부)
- [ ] 날짜 범위 필터 설정 확인 (과도한 필터링 여부)
- [ ] 채널 ID 기반 필터링 정상 작동 여부
