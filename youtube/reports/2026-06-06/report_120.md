## 1. 키워드 포트폴리오 분석

### 1.1 카테고리별 분포
수집된 키워드는 6개 주요 영역로 분류됩니다:

| 카테고리 | 키워드 | 전략적 중요도 |
|---------|--------|-------------|
| **금융/투자** | AI 반도체 투자, 나스닥 100, ETF 수익률, 미국 증시 기술주, 스페이스X 기업공개 | ⭐⭐⭐⭐⭐ |
| **기술/산업** | 삼성전자 HBM, 로봇산업 전망, 반도체 공급망 | ⭐⭐⭐⭐ |
| **정치/선거** | 지방선거 투표율, 주택가격-투표 상관관계, 선거 결과 | ⭐⭐⭐ |
| **뉴스/시사** | 오늘의 주요 뉴스 🔒, 한미 전사자 봉환식 | ⭐⭐⭐⭐ |
| **건강/라이프** | 혈당 관리 아침식사, 모기 퇴치제 | ⭐⭐ |
| **문화** | 환경영화제 개막식 | ⭐ |

### 1.2 키워드 특성 분석
- **시의성 키워드**: "지방선거", "선거 결과", "환경영화제 개막식" 등은 특정 시점에만 검색량이 집중되는 **이벤트성 키워드**입니다.
- ** evergreen 콘텐츠**: "혈당 관리", "ETF 수익률 비교" 등은 **상시 검색 수요**가 있는 안정적인 키워드입니다.
- **락 아이콘(🔒) 포함**: "오늘의 주요 뉴스" 키워드의 잠금 표시는 유료 구독 콘텐츠 또는 제한적 접근 권한을暗示할 수 있습니다.

## 2. 데이터 품질 진단 및 한계

### Critical Issue: 데이터 미수집 상태
현재 모든 키워드의 성과 지표가 0으로 표시되어 있어 다음과 같은 **액션이 필요**합니다:

1. **API 연결 상태 점검**: YouTube Data API v3의 할당량(Quota) 초과 또는 인증 키 만료 가능성
2. **수집 기간 설정**: 실제 검색 및 조회수 데이터가 수집되지 않은 기간의 확인
3. **키워드 정확도 검증**: "오늘의 주요 뉴스 🔒"와 같이 특수문자가 포함된 키워드의 검색 가능성 확인
