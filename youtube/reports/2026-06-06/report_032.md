# YouTube 채널 키워드 분석 리포트

## Executive Summary
본 리포트는 채널의 검색 최적화(SEO) 현황을 진단하기 위한 키워드 포트폴리오 분석입니다. 현재 수집된 16개 핵심 키워드는 정치·경제·문화·라이프스타일 등 광범위한 영역을 포괄하고 있으나, **성과 지표(조회수, 경쟁률, 노출 점수) 데이터의 수집이 미흡**하여 정량적 경쟁력 분석에는 한계가 있습니다. 따라서 본 분석은 키워드 구성 전략의 질적 평가와 개선 방향 제시에 중점을 둡니다.

## 1. 키워드 포트폴리오 분석

### 1.1 카테고리별 분포
현재 키워드는 4개의 주요 섹터로 구분됩니다:

| 카테고리 | 키워드 | 비중 |
|---------|--------|------|
| **정치/사회** | 오늘의 주요 뉴스, 투표용지 부족 사태, 선관위원장 사퇴, 한미 유해 봉환 | 25% |
| **경제/테크** | 나스닥 지수 동향, 젠슨 황 한국 방문, AI 반도체 동맹, 코스피 급락 원인 | 25% |
| **라이프스타일** | 경기장 대신 뷰잉펍, 서울국제환경영화제 | 12.5% |
| **여행/음식** | 전주 한옥마을 여행, 프랑스 요리와 궁중요리, 나주곰탕 맛집 | 18.75% |
| **기타** | 육군 진급 인사, 농어촌 삶의질 정책, 간편보험 비교 | 18.75% |

### 1.2 키워드 특성 진단
- **시의성 키워드**: "투표용지 부족 사태", "젠슨 황 한국 방문" 등 시점 특정 이슈가 다수 포함되어 있어 단기 트래픽 효과는 기대되나, 장기적 검색 유입에는 한계가 있습니다.
- **정보형 키워드**: "간편보험 비교", "코스피 급락 원인" 등 사용자 의도가 명확한 정보 탐색 키워드가 존재하나, 경쟁 강도 분석 데이터가 없어 입지 전략 수립이 어렵습니다.

## 2. 데이터 품질 및 수집 현황

### 2.1 지표 공백 현상
모든 키워드에서 `nb_score`, `video_count`, `avg_views`가 0으로 표기되어 있습니다. 이는 다음 중 하나의 상황으로 추정됩니다:
- **API 수집 오류**: YouTube Data API 또는 분석 툴의 연결 문제
- **초기 설정 단계**: 키워드 등록만 완료되고 성과 추적이 시작되지 않은 상태
- **비공개 데이터**: 🔒 마크가 있는 "오늘의 주요 뉴스"를 제외한 나머지 키워드도 실제로는 데이터 수집이 안 된 상태

### 2.2 분석 한계점
정량적 지표 부재로 인해 다음 분석이 불가능합니다:
- 키워드별 검색량 대비 공급량(경쟁률) 분석
- 조회수 기반 콘텐츠 성과 벤치마킹
- 채널 권한(Authority)에 따른 랭킹 가능성 예측

## 3. 전략적 제언

### 3.1 키워드 최적화 방향
1. **장기 vs 단기 키워드 균형**: 현재 시의성 키워드 비중이 높습니다. "간편보험 비교", "전주 한옥마을 여행" 등 ** evergreen(계절성 없는) 키워드** 비중을 높여 안정적인 유입 기반을 마련해야 합니다.

2. **롱테일 키워드 확보**: "AI 반도체 동맹"과 같은 광범위 키워드는 경쟁이 치열합니다. "젠슨 황 한국 방문 일정"처럼 구체화된 롱테일 키워드로 전략을 세분화할 것을 권장합니다.

### 3.2 데이터 인프라 구축
