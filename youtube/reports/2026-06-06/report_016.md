# YouTube 채널 키워드 분석 리포트

## 1. Executive Summary

본 리포트는 수집된 15개 핵심 키워드에 대한 초기 분석 결과를 제시합니다. **현재 데이터 수집이 진행 중이거나 API 연동 지연이 확인되어 정량적 지표(nb_score, 조회수, 영상 수)는 측정되지 않은 상태**입니다. 그러나 키워드 구성을 통해 채널의 콘텐츠 방향성과 잠재적 성장 영역을 도출할 수 있습니다.

## 2. 키워드 카테고리 분석

수집된 키워드는 4개의 주요 섹터로 분류됩니다:

### A. 정치·사회 이슈 (40%)
- **핵심 키워드**: 투표용지 부족 사태, 선관위원장 사퇴, 정치권 책임론, 한미 안보 협의
- **특성**: 시의성이 높은 브레이킹 뉴스 중심. 단기 조회수 급등 가능성이 높으나 수명 주기가 짧음
- **리스크**: 정치적 편향성에 따른 구독자 이탈 가능성 유의

### B. 경제·테크 동향 (33%)
- **핵심 키워드**: 젠슨 황 한국 방문, AI 반도체 동맹, 나스닥 지수, 원달러 환율, 경상수지 흑자
- **특성**: 고소득·전문가 구독자층 유입 가능. 장기적 검색 유지율 우수
- **기회**: 젠슨 황 방문과 AI 반도체 키워드는 현재 글로벌 트렌드와 일치하여 고성과 영상 생성 가능

### C. 문화·라이프스타일 (27%)
- **핵심 키워드**: 환경영화제 개막, 반딧불이 축제, 한옥마을 여행, 프라페 여름 트렌드
- **특성**: 계절성(여름)과 지역성이 강함. 시청자 참여율(댓글, 공유)이 높은 편
- **제안**: 여름철(6-8월) 집중 편성 시 효과 극대화 예상

## 3. 데이터 품질 진단 및 조치 방안

**현재 상태**: 모든 키워드의 NB Score, 조회수, 경쟁 영상 수가 0으로 표기됨

**원인 추정**:
1. 데이터 수집기(API)의 지연 또는 할당량 초과
2. 키워드 검색 필터링 조건이 과도하게 제한적
3. 실시간 트렌드 키워드로 아카이브 데이터 미형성

**즉시 조치 사항**:
- 데이터 수집 재시도 및 로그 확인
- '오늘의 주요 뉴스 🔒'와 같이 특수문자 포함 키워드의 인코딩 문제 점검
- 수집 기간 설정(최근 7일/30일) 재검토

## 4. 전략적 제안

### 단기 전략 (1-2주)
데이터 복구 전까지 **키워드 선행 제작**을 권장합니다. 특히 '젠슨 황 한국 방문'과 'AI 반도체 동맹'은 시의성이 중요하며, 선제적 콘텐츠 발행 시 알고리즘 선점 효과 기대됩니다.

### 중장기 전략 (1개월+)
정치(단기)와 경제·문화(중장기) 키워드를 **6:4 비율**로 편성하여 채널의 전문성과 대중성을 균형 있게 유지하세요. '오늘의 주요 뉴스'는 플레이리스트 타이틀로 활용하여 시리즈화를 권장합니다.
